1、补码与原码的相互转换
①符号位不变，各位取反，末位加1。
②符号为不变，从低位到高位找到第1个1，1右边的保持不变（全为0），1左边的取反。


2、[x补] 与 [-x补]的相互转化。
①符号位取反，各位取反，末位加1。
②符号为取反，从低位到高位找到第1个1，1右边的保持不变（全为0），1左边的取反。


02、16进制的相加“7E5+4D3”。
解析：“5+3=8”（未满16），“E+D=13+14=27，27-16=11，即27=16+11，这里的16向前进1位，保留11=B”，“7+4=11，在加上进来的1位得到12，为C”，最后为“CB8”。

解析：
方法一：采用定义公式来做。
[x]移 = 2^n + x，[-x]移 = 2^n + (-x)，既然“2^n + x”不会溢出，而“2^n + (-x)”会溢出，那就说明了x为负数。
根据移码的符号位为0表示负数，为1表示整数，先排除符号位为1的“A选项”和“C选项”。
对于B选项，[x]移 = 0，000 0000 =  2^7 + x = 1，000 0000 + x。得到“x = -1，000 0000”，即“x=-128”。则“[-x]移 = [128]移 = 2^7 + 128 = 1，000 0000 + 1,000 0000”会发生溢出。
对于D选项，[x]移 = 0，111 1111 = 2^7 + x = 1，000 0000 + x。得到“x = -0,000 0001”，即“x=-1”。则“[-x]移 = [1]移 = 2^7 + 1 = 1，000 0001 + 1,000 0001”不会发生溢出。

方法二：利用移码符号位的性质、补码与移码数值位相等的性质、移码所表示的范围进行解题。
8位移码数值位为7位，表示的范围为“-2^7~~~2^7-1”,即“-128~~~127”。

******补充知识点：由于移码的符号位与补码的符号位相反，而数值位与补码的数值位相等，故是可以将“移码真值的计算”转化为“补码真值的计算”的。
移码转化为补码计算真值：符号位取反，数值位不动，得到的“补码的真值”就与“移码的真值”一样。


A选项表示的移码真值：移码 1,111 1111 中符号位为1，故为正的；符号位取反，数值位不动，得到补码“0,111 1111”；补码“0,111 1111”对应真值为 +127，+127就是为移码“1,111 1111”的真值，对应的-x就是为“-127”，位于“-128~~~127”内，故没有溢出。

B选项表示的移码真值：移码 0,000 0000 中符号位为0，故为负的；符号位取反，数值位不动，得到补码“1,000 0000”；补码“1,000 0000”对应真值为 -128，-128就是为移码“0,000 0000”的真值，对应的-x就是为“128”，不位于“-128~~~127”内，故有溢出。

C选项表示的移码真值：移码 1,000 0000 中符号位为1，故为正的；符号位取反，数值位不动，得到补码“0,000 0000”；补码“0,000 0000”对应真值为 0，0就是为移码“0,000 0000”的真值，对应的-x就是为“0”，位于“-128~~~127”内，故没有溢出。

D选项表示的移码真值：移码 0,111 1111 中符号位为0，故为负的；符号位取反，数值位不动，得到补码“1,111 1111”；补码“1,111 1111”对应真值为 -127，-127就是为移码“0,111 1111”的真值，对应的-x就是为“127”，位于“-128~~~127”内，故没有溢出。

******补充知识点：对于补码表示的负整数来说，从低位到高位找到第1位1，1左边的0越多，1右边的1越多，则数值位所表示的数的绝对值就越大。
******补充知识点：越往高位权值越大，因此只要高位保持0，1连续排列在最低位 对于补码来说 就可以使得数值位的绝对值最大。
方法一：1个“1”表示符号位，越高位权重越大，因此地位连续排列1，即“1,000 0011”，此时这个“1,000 0011”数所表示的绝对值最大。

方法二：将A、B、C、D 全部转化为补码表示，满足题意，找最小的就行了。

***补充知识点：二进制数的绝对值比较大小（由于二进制数可能为正，可能为负，故这里比较其绝对值），由于高位的权重较高，从高为依次到低位进行比较，若出现1和0，则为1的那个绝对值较大。
***无符号数或者补码正数比较大小：从高位到低位依次进行比较，遇到1和0时，为1的那个无符号数或者补码表示的正数比较大。
***补码负数比较大小：先按照“从右向左的原则找到第1个1,1左边取反，右边不动”的原则转化为原码，然后从高位到低位依次进行比较，遇到1和0时，为1的那个 绝对值比较大，由于为负的，故就比较小。
