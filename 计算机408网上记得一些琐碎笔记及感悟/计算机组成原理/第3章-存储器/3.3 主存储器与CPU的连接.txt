

3.3.1 连接原理

见P90页连接图：
CPU 是通过 数据总线、地址总线 来与内存相连的。
CPU 内部的 MAR 与地址总线相连，地址总线 连接到地址寄存器， 地址寄存器经过主存中的译码器 连接到主存中的地址单元。
CPU 内部的 MDR 与数据总线相连，数据总线连接到主存中的每一个存储单元的每一位。

CPU通过读写控制线与主存相连，来控制对主存的读写。
CPU与主存相连的地址总线中可以挑选出一些用作主存的片选线。

3.3.2 主存容量的扩展



想象存储芯片长这个样子：
	D0	D1	D2	……	D7
            A0	
            A1
           ……
            A7

1、位扩展法（扩展字长）
将两个存储器芯片横着排列：

CPU的MDR引出的数据总线按照次序分别连接到 芯片1，芯片2 并排排列的每一位（即是 数据总线先连接芯片1的 D0~D7 端口，剩下数据总线然后连接芯片2的D0~D7端口）。
CPU的MAR引出的地址总线按照经过译码器后，选中0号单元的这条地址线 分别引出两条， 连接芯片1的0号地址单元，连接芯片2的0号地址单元（即是连接芯片1的A0端口，连接芯片2的A0端口）。
CPU的读写控制线 分别引出两条，连接到 芯片1的读写引脚，连接到芯片2的读写控制引脚。


2、字扩展法（扩展字的数量，即存储单元的数量）
既然是字扩展，说明CPU的MDR经过译码器后的地址线的总数多余 存储芯片1 的存储单元个数。

将两个存储器芯片竖着排列：

CPU的MDR引出的数据总线，第0条分别引出两条，连接 芯片1的D0端口，连接 芯片2的D0端口。
CPU的MAR引出的地址总线按照经过译码器后，选中0号单元的这条地址线 连接 芯片1的A0，选中1号单元的这条地址线 连接 芯片1的A1，……，选中8号单元的这条地址线 连接 芯片2的A0，依次类推。最后剩下的高1位地址线，经过译码器后得出两条，分别连接 芯片1的片选引脚，连接芯片2的片选引脚。（高两位假设为11，则译码过后为 3，译码后的第3条线有效，第3个芯片会被选中）
CPU的读写控制线 分别引出两条，连接到 芯片1的读写引脚，连接到芯片2的读写控制引脚。


3、字位同时扩展法

CPU的MDR引出的数据总线按照次序分别连接横向排列的芯片中的每一位。
CPU的MAR引出的地址总线按照经过译码器后，选中0号单元的这条地址线 连接 芯片1的A0，选中0号单元的这条地址线 连接 芯片2的A0（这里 芯片1 和 芯片2 是 横向排列的），选中1号单元的这条地址线 连接 芯片3的A0，选中0号单元的这条地址线 连接 芯片4的A0（这里 芯片3 和 芯片4 是 与 芯片1、芯片2 是 纵向排列的）。最高位地址线经过译码器后，所得到的第0条线连接到 芯片1的片选端口，所得到的第0条线连接到 芯片2的片选端口，所得到的第1条线连接到 芯片3的片选端口，所得到的第1条线连接到 芯片3的片选端口。
