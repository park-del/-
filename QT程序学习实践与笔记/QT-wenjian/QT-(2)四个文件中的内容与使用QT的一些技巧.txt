(2)自定义窗口类widget.h头文件

#ifndef WIDGET_H
#define WIDGET_H

#include <QWidget>    //自定义的类名有一个基类（那三个基类中的某一个），这是
                                       //所继承的那个基类的头文件。
QT_BEGIN_NAMESPACE
namespace Ui { class Widget; }
QT_END_NAMESPACE

class Widget : public QWidget   /*public继承QWidget基类（说明了用Widget所定义的对象继承了父类中的东西，父类QWidget所定义的一个对象就是定义一个窗口的，而用Widget所定义的一个对象也是定义的一个窗口，但由于是可以在Widget类中自己添加一些成员函数的，故用Widget类所定义的对象对应的窗口是可以多增加一些功能或者图案的，故Widget所定义的对象当成是是用户自定义的窗口。
*/ 
{
 Q_OBJECT  //一个宏，有了这个宏就可以在这个类中使用信号和槽的机制

public:
    Widget(QWidget *parent = nullptr);  //用户自定义窗口类的构造函数，定义对象时
//括号( )中的内容为一个地址，派生类的对象的地址是可以赋值给基类定义的指针的。
    ~Widget();         //用户自定义窗口类的构造函数。

private:
    Ui::Widget *ui;
};
#endif // WIDGET_H

(3)用户自定义窗口类widget.cpp源文件。
在这个源文件的默认构造函数里面写的函数在用户利用自定义窗口类widget定义对象时会自动调用，完成的是对用户自定义窗口类所定义的窗口的默认设置。
注意:用户自定义窗口类的.h头文件与用户窗口类的.cpp源文件共同组成了一个类，用户自定义窗口类的.h文件中的内容是这个类的声明，即是这个类有哪些成员函数，有哪些数据成员；用户自定义窗口类的.c头文件中的内容是.h这个头文件中所声明的函数的定义，即就是在类外来具体定义该函数。

命名规范：
<1>类名：首字母大写，单词和单词之间首字母大写（用户自定义窗口的类名除外，不过一般为了与类名的命名规则保持一致性，一般将用户自定义的窗口类名的首字母也大写，单词和单词之间的首字母也大写）
<2>函数名 变量名：首字母小写，单词和单词之间首字母大写
<3>在.cpp中包含的与类名同名的头文件名全部小写且带有.h（前提是该头文件必须是用户自定义类的头文件），若是系统中自带的头文件则首字母也是要大写且不带.h的。
注意:在.h中这个头文件中所包含的头文件一般是系统自带的，用户根据系统自带的头文件来定义自己想要的那一个类，在.cpp的源文件(包含了所有的.cpp的源文件)中所包含的头文件一般是用户自定义类的头文件，故一般都是小写且带.h的，但也会包含一些系统的头文件，故也会有首字母大写且不带.h的。
