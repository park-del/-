### 视频核心内容讲解

视频的核心是**从零开始设计一个链表类 `MyLinkedList`**，并实现其内部的核心功能。讲解者强调了两个关键的设计决策来简化实现和避免错误：

1. **维护一个 `size` 变量**：在类中始终记录链表的当前长度。这样做的好处是可以在 O(1) 时间内获取链表大小，并且在进行索引相关的操作（如 `get`, `addAtIndex`, `deleteAtIndex`）时，可以快速判断索引是否有效。
2. **使用虚拟头节点 (Dummy Head/Sentinel Node)**：这是视频中反复强调的最重要的技巧。通过在实际的头节点前创建一个固定的、不存储实际数据的虚拟节点 `_dummyHead`，可以将所有插入和删除操作（包括在头部进行的操作）统一为同一种逻辑，极大地简化了代码，避免了对头节点的复杂分类讨论。

接下来，视频逐一讲解了需要实现的五个核心方法：

1. **`get(index)`: 获取第 `index` 个节点的值**
   - **思路**：先判断 `index` 是否合法（`index` 必须在 `[0, size-1]` 范围内）。然后，从虚拟头节点的下一个节点（即真正的头节点）开始，向后遍历 `index` 次，即可到达目标节点。
2. **`addAtHead(val)`: 在头部插入节点**
   - **思路**：这被视为在索引 `0` 处插入节点的特例，即调用 `addAtIndex(0, val)`。通过虚拟头节点，插入操作的逻辑非常统一。
3. **`addAtTail(val)`: 在尾部追加节点**
   - **思路**：这被视为在索引 `size` 处插入节点的特例，即调用 `addAtIndex(size, val)`。
4. **`addAtIndex(index, val)`: 在第 `index` 个节点前插入节点**
   - **思路**：这是最核心的插入操作。
     - 首先判断 `index` 的有效性（`index` 可以在 `[0, size]` 范围内）。
     - 关键在于找到要插入位置的**前一个节点**。从 `_dummyHead` 开始，遍历 `index` 次，就可以找到第 `index` 个节点的前驱节点。
     - 执行插入操作，注意指针的更新顺序：先将新节点的 `next` 指向后一个节点，再将前驱节点的 `next` 指向新节点，以防链表断裂。
5. **`deleteAtIndex(index)`: 删除第 `index` 个节点**
   - **思路**：与 `addAtIndex` 类似。
     - 首先判断 `index` 的有效性（`index` 必须在 `[0, size-1]` 范围内）。
     - 同样需要找到要删除节点的**前一个节点**。从 `_dummyHead` 开始，遍历 `index` 次，找到前驱节点。
     - 执行删除操作：让前驱节点的 `next` 指针“跳过”要删除的节点，直接指向被删除节点的下一个节点。

#### 1. 完整的 C++ 实现

视频中讲解的是思路，这里给出一个完整的、可以直接使用的 C++ 类实现，包含了视频中讲解的所有逻辑，以及 C++ 特有的构造函数和析构函数（用于内存管理）。

C++

```C++
#include <iostream>

// 单链表节点定义
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

class MyLinkedList {
private:
    int _size;
    ListNode* _dummyHead;

public:
    // 构造函数：初始化链表
    MyLinkedList() {
        _dummyHead = new ListNode(0); // 创建虚拟头节点
        _size = 0;
    }

    // 析构函数：释放所有节点的内存，防止内存泄漏
    ~MyLinkedList() {
        ListNode* curr = _dummyHead;
        while (curr != nullptr) {
            ListNode* temp = curr;
            curr = curr->next;
            delete temp;
        }
    }

    // 获取第 index 个节点的值
    int get(int index) {
        if (index < 0 || index >= _size) {
            return -1; // 索引无效
        }
        ListNode* curr = _dummyHead->next;
        while (index--) { // 移动 index 次
            curr = curr->next;
        }
        return curr->val;
    }

    // 在头部插入节点
    void addAtHead(int val) {
        addAtIndex(0, val);
    }

    // 在尾部追加节点
    void addAtTail(int val) {
        addAtIndex(_size, val);
    }

    // 在第 index 个节点前插入一个值为 val 的新节点
    void addAtIndex(int index, int val) {
        if (index > _size) {
            return; // 索引大于链表长度，无效
        }
        // index 可以等于 _size，表示在末尾追加
        index = std::max(0, index); // 如果 index 是负数，则在头部插入

        ListNode* newNode = new ListNode(val);
        ListNode* pred = _dummyHead;
        
        // 找到要插入位置的前驱节点
        while(index--) {
            pred = pred->next;
        }

        // 插入操作
        newNode->next = pred->next;
        pred->next = newNode;
        _size++;
    }

    // 删除第 index 个节点
    void deleteAtIndex(int index) {
        if (index < 0 || index >= _size) {
            return; // 索引无效
        }

        ListNode* pred = _dummyHead;
        
        // 找到要删除节点的前驱节点
        for (int i = 0; i < index; ++i) {
            pred = pred->next;
        }

        // 删除操作
        ListNode* toDelete = pred->next;
        pred->next = toDelete->next;
        delete toDelete; // 释放内存
        _size--;
    }
};
```



#### 2. 复杂度分析总结

| 方法                     | 时间复杂度 | 空间复杂度 | 备注                            |
| ------------------------ | ---------- | ---------- | ------------------------------- |
| `get(index)`             | O(k)       | O(1)       | k 是目标索引，最坏情况是 O(N)。 |
| `addAtHead(val)`         | O(1)       | O(1)       | 直接操作虚拟头节点，无需遍历。  |
| `addAtTail(val)`         | O(N)       | O(1)       | 需要遍历整个链表找到尾部。      |
| `addAtIndex(index, val)` | O(k)       | O(1)       | k 是目标索引，最坏情况是 O(N)。 |
| `deleteAtIndex(index)`   | O(k)       | O(1)       | k 是目标索引，最坏情况是 O(N)。 |



#### 3. 优化思考：双向链表 (Doubly Linked List)

视频中实现的是**单向链表**。一个重要的扩展是思考如果使用**双向链表**，性能会有什么变化。

- **什么是双向链表？**
  - 每个节点除了有 `next` 指针指向后继节点，还有一个 `prev` 指针指向上一个节点。
- **如何优化 `MyLinkedList`？**
  - 在 `MyLinkedList` 类中额外维护一个 `_tail` 指针，始终指向最后一个节点。
  - **`addAtTail` 的优化**：因为有了 `_tail` 指针，我们可以直接在尾部进行插入，时间复杂度从 O(N) **优化到 O(1)**。
  - **`deleteAtIndex` 的优化**：删除操作本身会稍微复杂一点，因为需要同时更新前后节点的 `next` 和 `prev` 指针。但如果配合 `_tail` 指针，删除尾节点的操作也可以达到 O(1)。
  - **`get` 和 `addAtIndex` 的优化**：在查找第 `index` 个节点时，可以做一个判断：如果 `index` 小于 `_size / 2`，就从头部开始遍历；否则，就从尾部开始遍历。这可以将最坏情况下的遍历次数减半，但时间复杂度级别仍然是 O(N)。
