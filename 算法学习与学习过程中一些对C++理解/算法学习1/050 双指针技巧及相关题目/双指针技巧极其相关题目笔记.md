## 题目1 奇偶排序数组（同向双指针）



<span style="font-size:1.2em; font-weight:bold;">https://leetcode.cn/problems/sort-array-by-parity-ii/</span>



### Java代码

```java
package class050;

// 按奇偶排序数组II
// 给定一个非负整数数组 nums。nums 中一半整数是奇数 ，一半整数是偶数
// 对数组进行排序，以便当 nums[i] 为奇数时，i也是奇数
// 当 nums[i] 为偶数时， i 也是 偶数
// 你可以返回 任何满足上述条件的数组作为答案
// 测试链接 : https://leetcode.cn/problems/sort-array-by-parity-ii/
public class Code01_SortArrayByParityII {

	// 时间复杂度O(n)，额外空间复杂度O(1)
	public static int[] sortArrayByParityII(int[] nums) {
		int n = nums.length;
		for (int odd = 1, even = 0; odd < n && even < n;) {
			if ((nums[n - 1] & 1) == 1) {
				swap(nums, odd, n - 1);
				odd += 2;
			} else {
				swap(nums, even, n - 1);
				even += 2;
			}
		}
		return nums;
	}

	public static void swap(int[] nums, int i, int j) {
		int tmp = nums[i];
		nums[i] = nums[j];
		nums[j] = tmp;
	}

}
```

```C++
// 按奇偶排序数组II
// 给定一个非负整数数组 nums。nums 中一半整数是奇数 ，一半整数是偶数

class Solution {
    
    private:
    // C++ 版本的 swap 辅助函数
    // 与 Java 版本一样，接收一个数组（这里是 vector 的引用）和两个索引
    void swap(std::vector<int>& nums, int i, int j) {
        int tmp = nums[i];
        nums[i] = nums[j];
        nums[j] = tmp;
    }
    
public:
    // 时间复杂度O(n)，额外空间复杂度O(1)
    std::vector<int> sortArrayByParityII(std::vector<int>& nums) {
        int n = nums.size();
        // odd 指针指向下一个需要放置奇数的位置 (1, 3, 5, ...)
        // even 指针指向下一个需要放置偶数的位置 (0, 2, 4, ...)
        // 算法的核心是：不断地将数组最后一个元素，根据其奇偶性，
        // 放到 even 或 odd 指针指向的位置。
        for (int odd = 1, even = 0; odd < n && even < n;) {
            if ((nums[n - 1] & 1) == 1) {  //注意：== 的优先级高于&，这里必须加上括号
                // 如果最后一个元素是奇数，则它应该被放到 odd 指向的位置
                swap(nums, odd, n - 1);
                odd += 2;
            } else {
                // 如果最后一个元素是偶数，则它应该被放到 even 指向的位置
                swap(nums, even, n - 1);
                even += 2;
            }
        }
        return nums;
    }
};
```

该算法采用了<span style="color:#CC0000;">经典的 Floyd 判圈算法（也称为快慢指针法），它巧妙地将数组索引和值的关系看作一个链表，从而在 O(1) 的额外空间内找到环的入口，即重复的数字</span>。



### java代码

```java
package class050;

// 寻找重复数
// 给定一个包含 n + 1 个整数的数组 nums ，其数字都在 [1, n] 范围内（包括 1 和 n）
// 可知至少存在一个重复的整数。
// 假设 nums 只有 一个重复的整数 ，返回 这个重复的数 。
// 你设计的解决方案必须 不修改 数组 nums 且只用常量级 O(1) 的额外空间。
// 测试链接 : https://leetcode.cn/problems/find-the-duplicate-number/
public class Code02_FindTheDuplicateNumber {

	// 时间复杂度O(n)，额外空间复杂度O(1)
	public static int findDuplicate(int[] nums) {
		if (nums == null || nums.length < 2) {
			return -1;
		}
		int slow = nums[0];
		int fast = nums[nums[0]];
		while (slow != fast) {
			slow = nums[slow];
			fast = nums[nums[fast]];
		}
		// 相遇了，快指针回开头
		fast = 0;
		while (slow != fast) {
			fast = nums[fast];
			slow = nums[slow];
		}
		return slow;  //补充：不是这个位置上的数试试重复数字，是这个位置就是重复数字
	}

}
```



### C++ 代码

```c++
#include <vector>

// 命名与原始 Java 文件保持一致，并适配 LeetCode 的 Solution 类结构
class Solution {
public:
    // 寻找重复数
    // 给定一个包含 n + 1 个整数的数组 nums ，其数字都在 [1, n] 范围内（包括 1 和 n）
    // 可知至少存在一个重复的整数。
    // 假设 nums 只有 一个重复的整数 ，返回 这个重复的数 。
    // 你设计的解决方案必须 不修改 数组 nums 且只用常量级 O(1) 的额外空间。
    // 测试链接 : https://leetcode.cn/problems/find-the-duplicate-number/

    // 时间复杂度O(n)，额外空间复杂度O(1)
    int findDuplicate(const std::vector<int>& nums) {
        // C++ 中，引用不能为空，所以不需要像 Java 那样检查 null
        if (nums.size() < 2) {
            return -1;
        }

        // 阶段一：快慢指针寻找环中的相遇点
        // 将数组值看作是下一个节点的指针，例如 slow = nums[slow]
        int slow = nums[0];
        int fast = nums[nums[0]];
        while (slow != fast) {
            slow = nums[slow];
            fast = nums[nums[fast]];
        }

        // 阶段二：寻找环的入口
        // 当快慢指针相遇后，将其中一个指针（例如 fast）重置到起点（索引0）
        // 然后两个指针都以每次一步的速度前进，再次相遇的点就是环的入口，也就是重复的数字。
        fast = 0;
        while (slow != fast) {
            fast = nums[fast];
            slow = nums[slow];
        }

        return slow;
    }
};
```

#### 1. 核心比喻：带跑道的操场

让我们把这个问题想象成一个特殊的操场：

- **一条直的跑道**：这是进入操场的唯一路径。
- **一个环形跑道**：直跑道的尽头连接着一个环形的跑道。
- **环的入口**：就是直跑道和环形跑道相连接的那个点。

在这个问题中，数组 `nums` 就是这张“地图”。数组的**索引**是你的位置，而该索引上存储的**值**告诉你下一步要去哪个位置。

- 例如，`nums[1] = 3` 意味着从位置 `1` 下一步要去位置 `3`。

因为数组中有一个重复的数字（例如 `nums[i] = nums[j] = k`），所以必定有至少两个不同的位置都指向同一个下一步的位置，这就形成了我们比喻中的“环”。**而这个重复的数字，恰好就是环入口位置的索引所指向的值**。(这一点稍微有些绕，但随着后面的解释会清晰起来，关键是找到环入口的**位置**)。





#### 2. 第一阶段：快慢指针的首次相遇（发现“有环”）

现在，我们派出两个运动员，一个“慢跑者”和一个“快跑者”。

- **慢跑者 (slow)**：每次移动一步 (`slow = nums[slow]`)。
- **快跑者 (fast)**：每次移动两步 (`fast = nums[nums[fast]]`)。

它们都从起点（索引 `0`）出发。只要存在一个环，速度更快的快跑者最终必然会在环形的赛道上从后面“追上”并“套圈”慢跑者。它们的第一次相遇，一定发生在环内的某个位置。

**现在，我们引入一些简单的数学符号来量化这个过程：**

- **H (Head)**：从起点（索引`0`）到**环入口**的距离（需要走多少步）。
- **L (Loop)**：环形跑道的周长（环内有多少个节点）。
- **D (Distance)**：从**环入口**顺时针走到**首次相遇点**的距离。

当它们首次相遇时：

- 慢跑者走过的总距离 = `H + D`
- 快跑者走过的总距离 = `2 * (H + D)` （因为它的速度是慢跑者的两倍）

同时，快跑者比慢跑者多走的路程，必然是环形跑道周长 `L` 的整数倍（因为它在环上套了 `n` 圈）。

- 快跑者距离 - 慢跑者距离 = `n * L`
- `2 * (H + D) - (H + D) = n * L`

我们得到了这个算法最核心、最神奇的数学关系式：

H + D = n * L

这个公式用大白话讲就是：**从起点出发，走到首次相遇点的总路程，不多不少，正好等于绕环 `n` 圈的距离**。





#### 3. 第二阶段：解开谜题（为什么相遇点在入口）

现在，第一阶段结束了，我们有了一个神奇的公式 `H + D = n * L`。接下来就是揭秘的时刻。

我们进行一个精心设计的操作：

1. 把其中一个指针（我们称之为**指针A**）放回**起点（索引 `0`）**。
2. 另一个指针（我们称之为**指针B**）留在**首次相遇点**。
3. 现在，让两个指针都用**相同的慢速**（一次走一步）前进。

**我们的目标是证明：它们下一次相遇的地点，必然是环的入口。**

- 指针A的行程：

  它在起点，要想到达环的入口，需要走多少步？非常简单，根据我们的定义，就是 H 步。

- 指针B的行程：

  现在我们来分析指针B。当指针A走了 H 步的时候，指针B也同样走了 H 步。那么，它现在会在哪里呢？

  为了精确计算它的位置，我们统一从**环的入口**这个参照点来衡量。

  - 指针B的出发点（首次相遇点）本身，就在环入口**顺时针前进 `D` 步**的位置。
  - 现在，它从这个位置**再走 `H` 步**。
  - 所以，指针B的最终位置，就是从环入口算起，一共走了 `D + H` 步。

  **最关键的时刻到了！** 我们把第一阶段的结论 `H + D = n * L` 代入进来。

  这意味着，指针B从环入口出发，总共走了 `n * L` 步。在一个周长为 `L` 的环上，走 `n * L` 步（也就是不多不少 `n` 个整圈），最终会停在哪里？

  **答案是：正好回到环的起点，也就是我们定义的“环入口”！（<span style="color:#CC0000;">关键点：指针B从环入口处走了D步走到相遇点，此时假设B从环入口处走 n * L 步，由于 n*L = D +  H，故此时B在之前相遇点的前面H步，而 n * L 又相当于是从起点绕了L圈最终还是会在起点，故从相遇点处再走H步，就到达了环入口处</span>）**

最终结论：

<span style="color:#CC0000;">当指针A花了 H 步，从起点到达环入口时；指针B也花了完全相同的 H 步，从首次相遇点出发，最终也恰好到达了同一个环入口。</span>

<span style="color:#CC0000;">因此，它们必然会在环的入口处相遇。此时，它们相遇的那个位置的值，就是我们要找的重复数。</span>

C++中的引用之所以不能够为空，根植于其核心的**设计哲学**和与指针的明确分工，这使其成为一种更安全、意图更明确的工具。

<span style="font-weight:bold; font-size:1.2em;">	1.核心定义：引用是“别名”，而非指针</span>

C++的引用被设计为已存在对象的“别名”。就像一个外号必须依附于一个真实存在的人，引用也必须绑定到一个已存在的对象上。它不是一个存储地址的独立变量，而是原始对象的另一个名字。



<span style="font-weight:bold; font-size:1.2em;">2.强制规则：创建时必须初始化</span>

C++语言通过一条强制规则来保证其“别名”的性质：引用在声明时必须立即初始化，并绑定到一个有效的对象。这就从语法层面根本杜绝了“空引用”产生的可能性。



```C++
int a = 10;
int& ref_a = a;      // 正确，必须在创建时绑定
// int& bad_ref;     // 编译错误！
```



<span style="font-weight:bold; font-size:1.2em;">3.功能划分：引用与指针的分工</span>

C++通过引用和指针提供了两种不同的工具来应对不同场景：

- **指针 (`\*`)**: 用于处理**“可能不存在”**或**“需要重新指向”**的情况。它可以被设为 `nullptr`，在使用前需要进行检查。

- **引用 (`&`)**: 用于处理**“保证一定存在”**的情况。它简化了语法，并提供了安全性保障。

  

<span style="font-weight:bold; font-size:1.2em;">4.与Java的区别：概念上的“近与远”</span>

对于Java开发者来说，最关键的一点是：<span style="color:#CC0000;">Java中的“引用”在行为上更接近C++的指针，因为它们都可以为 null。而C++的引用是一个完全不同的、更严格、更安全的概念。</span>

总结：设计的最终目的——安全与清晰

这种设计的核心优势在于安全性和代码意图的清晰化。当一个函数接收的参数是引用时（例如 void func(MyClass& obj)），程序员可以百分之百地确信他正在操作一个有效的对象，无需进行繁琐的空检查，从而能编写出更健壮、更易读的代码。





### <span style="font-size:1.2em;">提问：帮我区分下C++中的指针和对象，以及它们和java中的对象有什么区别呢，简洁回复下，不要长篇大论？</span>

- 是访问对象的“遥控器”或“地址牌”，<span style="color:#990000;">可以为空 (`nullptr`)</span>。

## 题目3 接雨水（从两头往中间的双指针）

注意：二维接雨水的问题，会在宽度优先遍历的章节讲述，后续的【必备】课程。



### java代码

```java
package class050;

// 接雨水
// 给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水
// 测试链接 : https://leetcode.cn/problems/trapping-rain-water/
public class Code03_TrappingRainWater {

	// 辅助数组的解法（不是最优解）
	// 时间复杂度O(n)，额外空间复杂度O(n)
	// 提交时改名为trap
	public static int trap1(int[] nums) {
		int n = nums.length;
		int[] lmax = new int[n];
		int[] rmax = new int[n];
		lmax[0] = nums[0];
		// 0~i范围上的最大值，记录在lmax[i]
		for (int i = 1; i < n; i++) {
			lmax[i] = Math.max(lmax[i - 1], nums[i]);
		}
		rmax[n - 1] = nums[n - 1];
		// i~n-1范围上的最大值，记录在rmax[i]
		for (int i = n - 2; i >= 0; i--) {
			rmax[i] = Math.max(rmax[i + 1], nums[i]);
		}
		int ans = 0;
		//   x              x
		//   0 1 2 3...n-2 n-1
		for (int i = 1; i < n - 1; i++) {
			ans += Math.max(0, Math.min(lmax[i - 1], rmax[i + 1]) - nums[i]);
		}
		return ans;
	}

	// 双指针的解法（最优解）
	// 时间复杂度O(n)，额外空间复杂度O(1)
	// 提交时改名为trap
	public static int trap2(int[] nums) {
		int l = 1, r = nums.length - 2, lmax = nums[0], rmax = nums[nums.length - 1];
		int ans = 0;
		while (l <= r) {
			if (lmax <= rmax) {
				ans += Math.max(0, lmax - nums[l]);
				lmax = Math.max(lmax, nums[l++]);
			} else {
				ans += Math.max(0, rmax - nums[r]);
				rmax = Math.max(rmax, nums[r--]);
			}
		}
		return ans;
	}

}
```

### C++ 代码

```C++
#include <vector>
#include <algorithm> // 用于 std::max 和 std::min

class Solution {
public:
    // 辅助数组的解法（不是最优解）
    // 时间复杂度O(n)，额外空间复杂度O(n)
    // LeetCode提交时函数名应为 trap
    int trap1(const std::vector<int>& height) {
        if (height.empty()) {
            return 0;
        }
        int n = height.size();
        std::vector<int> lmax(n);
        std::vector<int> rmax(n);

        lmax[0] = height[0];
        // 从左到右遍历，计算 0~i 范围上的最大值，记录在 lmax[i]
        for (int i = 1; i < n; i++) {
            lmax[i] = std::max(lmax[i - 1], height[i]);
        }

        rmax[n - 1] = height[n - 1];
        // 从右到左遍历，计算 i~n-1 范围上的最大值，记录在 rmax[i]
        for (int i = n - 2; i >= 0; i--) {
            rmax[i] = std::max(rmax[i + 1], height[i]);
        }

        int ans = 0;
        // 遍历 1 到 n-2 的位置（因为两端无法接水），计算每个位置能接的雨水
        for (int i = 1; i < n - 1; i++) {
            // 当前位置的水位取决于其左边最高墙和右边最高墙中较矮的那个
            int water_level = std::min(lmax[i - 1], rmax[i + 1]);
            if (water_level > height[i]) {
                ans += water_level - height[i];
            }
        }
        return ans;
    }

    // 双指针的解法（最优解）
    // 时间复杂度O(n)，额外空间复杂度O(1)
    // LeetCode提交时函数名应为 trap
    int trap2(const std::vector<int>& height) {
        if (height.size() < 3) {
            return 0;
        }

        int n = height.size();
        int l = 1, r = n - 2;
        int lmax = height[0];
        int rmax = height[n - 1];
        int ans = 0;

        while (l <= r) {
            if (lmax <= rmax) {
                // 左边的墙 lmax 是瓶颈，可以安全地计算 l 位置的雨水
                if (lmax > height[l]) {
                    ans += lmax - height[l];
                }
                // 更新左边遇到的最高墙，并移动左指针
                lmax = std::max(lmax, height[l]);
                l++;
            } else { // lmax > rmax
                // 右边的墙 rmax 是瓶颈，可以安全地计算 r 位置的雨水
                if (rmax > height[r]) {
                    ans += rmax - height[r];
                }
                // 更新右边遇到的最高墙，并移动右指针
                rmax = std::max(rmax, height[r]);
                r--;
            }
        }
        return ans;
    }
};
```

### 提问2：这里命名空间using namespace std； 这里的std是固定的吗，我可不可以这里改为其他的名字呢，比如using namespace tgh; ，这样可以吗？

很好的问题！这说明你开始思考 C++ 代码组织的核心概念了。

答案是：**`std` 是固定不变的**，你不能随意将它改成别的名字来使用标准库。但是，你可以**创建自己的命名空间**，并把它命名为 `tgh`。

让我们来详细分解一下：



#### 1. 什么是命名空间 (Namespace)？

你可以把“命名空间”想象成一个**“姓氏”**或“文件夹”。

在大型项目中，可能会有很多人编写代码。假如你写了一个名为 `print` 的函数，标准库里也有一个 `print` 函数，这时编译器就糊涂了，不知道该用哪个。

为了解决这种**命名冲突**，<span style="color:#CC0000;">C++ </span>引入了<span style="color:#CC0000;">命名空间</span>。它就像<span style="color:#CC0000;">给函数、类、变量</span>等<span style="color:#CC0000;">安上一个“姓氏”</span>，以示区分。



#### 2. `std` 是什么？

`std` 是 C++ **标准库 (Standard Library)** 的官方、固定的命名空间名称，是 **std**andard 的缩写。

C++ 语言提供的大量好用的工具，比如 `vector`, `string`, `cout`, `max`, `min` 等等，都住在 `std` 这个“姓氏”的大家族里。

所以，当你想要使用标准库里的 `vector` 时，它的全名其实是 `std::vector` (姓 `std`，名 `vector`)。你必须明确地告诉编译器你要用的是 `std` 这个家族里的东西。

**因此，`std` 是一个预先定义好的、你必须遵守的名字，不能更改。**



#### 3. `using namespace tgh;` 什么时候可以这样用？

你的想法 `using namespace tgh;` 在一种情况下是完全可行的，那就是：**当你自己创建了一个名为 `tgh` 的命名空间时**。

程序员完全可以创建自己的“姓氏”来组织自己的代码。例如：

C++

```c++
#include <iostream>

// 我创建了一个属于我自己的命名空间，并取名为 tgh
namespace tgh {
    void printMessage() {
        std::cout << "Hello from tgh namespace!" << std::endl;
    }
    
    int myValue = 100;
}

// 我再创建另一个命名空间
namespace other {
    void printMessage() {
        std::cout << "Hello from other namespace!" << std::endl;
    }
}


int main() {
    // 使用 tgh 命名空间里的函数，需要加上姓氏
    tgh::printMessage(); // 输出: Hello from tgh namespace!

    // 使用 other 命名空间里的函数
    other::printMessage(); // 输出: Hello from other namespace!

    // 现在，我告诉编译器：“接下来请默认使用 tgh 家族的东西”
    using namespace tgh;

    // 现在我可以省略 tgh:: 这个姓氏了
    printMessage();      // 输出: Hello from tgh namespace!
    std::cout << myValue << std::endl; // 输出: 100

    return 0;
}
```



#### 总结

- **`std`**：是 C++ **官方提供给你的**命名空间，里面装着标准库。你只能使用它，不能改它。
- **`tgh`** (或其他任何你喜欢的名字)：是**你自己创建的**命名空间，里面装着你自己的代码。
- **`using namespace ...;`**：这个指令是告诉编译器：<span style="color:#CC0000;">“请打开某个指定的姓氏（比如 `std` 或 `tgh`）的文件夹，接下来如果我只说名字，你就默认到这个文件夹里去找。”</span>









## 题目4 救生艇（从两头往中间的双指针）



### java代码

```java
package class050;

import java.util.Arrays;

// 救生艇
// 给定数组 people
// people[i]表示第 i 个人的体重 ，船的数量不限，每艘船可以承载的最大重量为 limit
// 每艘船最多可同时载两人，但条件是这些人的重量之和最多为 limit
// 返回 承载所有人所需的最小船数
// 测试链接 : https://leetcode.cn/problems/boats-to-save-people/
public class Code04_BoatsToSavePeople {

	// 时间复杂度O(n * logn)，因为有排序，额外空间复杂度O(1)
	public static int numRescueBoats(int[] people, int limit) {
		Arrays.sort(people);
		int ans = 0;
		int l = 0;
		int r = people.length - 1;
		int sum = 0;
		while (l <= r) {
			sum = l == r ? people[l] : people[l] + people[r];
			if (sum > limit) {
				r--;
			} else {
				l++;
				r--;
			}
			ans++;
		}
		return ans;
	}

}
```





### C++代码

这个 C++ 实现遵循了与 Java 版本完全相同的贪心算法和双指针逻辑。

```C++
#include <vector>
#include <algorithm> // for std::sort

// LeetCode 上的类名通常是 Solution
class Solution {
public:
    /**
     * @brief 计算承载所有人所需的最小船数
     * @param people 每个人的体重数组
     * @param limit 每艘船的最大承载重量
     * @return int 所需的最小船数
     *
     * 时间复杂度 O(n * logn)，因为对数组进行了排序。
     * 额外空间复杂度 O(1) 或 O(logn) 取决于排序算法的实现。
     */
    int numRescueBoats(std::vector<int>& people, int limit) {
        // 对所有人的体重进行排序，方便从最轻和最重的人开始考虑
        std::sort(people.begin(), people.end());

        int ans = 0; // 所需船的数量
        int l = 0;   // 指向最轻的人
        int r = people.size() - 1; // 指向最重的人

        // 当左指针不越过右指针时，说明还有人未上船
        while (l <= r) {
            // 每次循环都至少运走一个人（最重的那个），所以船数加一
            ans++;

            // 如果最轻的人和最重的人可以同乘一艘船
            if (l < r && people[l] + people[r] <= limit) {
                // 那么把最轻的人也送上船
                l++;
            }
            // 无论如何，最重的人都要上船
            r--;
        }
        return ans;
    }
};
```



### 代码逻辑对照

- **排序**:<span style="color:#CC0000;"> Java 的 `Arrays.sort(people)` 对应 C++ 的 `std::sort(people.begin(), people.end())`。</span>
- **变量**:
  - `people.length` 对应 `people.size()`。
  - 变量 `l`, `r`, `ans` 的定义和初始化逻辑相同。
- **核心算法**:
  - Java 版本中的 `if-else` 逻辑判断 `people[l] + people[r]` 是否超重，并移动指针。
  - 这个 C++ 版本采用了等价且更简洁的写法：每一轮循环都确保最重的人（`people[r]`）上船，所以 `ans` 先自增，`r` 最后自减。然后，我们再尝试让最轻的人（`people[l]`）“搭便车”，如果重量允许，就移动 `l` 指针。
  - 两种写法的最终结果和效率是完全一样的。





### 提问1：C++中的sort和java中的sort函数的用法和写法有什么不同吗，你能够给我详细解释下吗？



当然可以。C++ 的 `std::sort` 和 Java 中的 `sort` 函数在设计理念、用法和写法上有显著的不同，这些不同也反映了两种语言的核心特性。

总的来说，**C++ 的 `sort` 更通用、更底层，基于迭代器（iterator）对内存范围进行操作；而 Java 的 `sort` 更面向对象，区分了基本类型数组和对象集合，通过接口（Interface）来实现自定义排序。**

下面是详细的对比解释：



#### 1. C++ `std::sort`

`std::sort` 是 C++ 标准模板库（STL）中的一个函数，位于 `<algorithm>` 头文件中。

#### **核心理念：基于迭代器 (Iterator)**

C++ 的 `sort` 不直接操作容器（如 `vector`），而是<span style="color:#CC0000;">操作指向容器内元素的**迭代器**</span>。这使得它非常通用，不仅能排序 `std::vector`，还能排序 `std::deque`、C 风格的普通数组等<span style="color:#CC0000;">任何提供随机访问迭代器的数据结构。</span>



#### **基本用法**

`std::sort` <span style="color:#CC0000;">至少需要两个参数</span>，它们定义了一个<span style="color:#CC0000;">左闭右开的区间</span> `[first, last)`：

- `first`: 指向要排序的序列的第一个元素的迭代器。
- `last`: 指向要排序的序列的最后一个元素的**<span style="color:#CC0000;">下一个位置</span>**的迭代器。

C++

```C++
#include <iostream>
#include <vector>
#include <algorithm> // 必须包含 <algorithm> 头文件

int main() {
    // 示例1: 排序 std::vector
    std::vector<int> vec = {5, 2, 8, 1, 9};
    std::sort(vec.begin(), vec.end()); // 传入开始和结束迭代器

    // 示例2: 排序 C 风格数组
    int arr[] = {5, 2, 8, 1, 9};
    int n = sizeof(arr) / sizeof(arr[0]);
    std::sort(arr, arr + n); // 数组名本身就是指向首元素的指针

    return 0;
}
```



#### **自定义排序**

`std::sort` 可以<span style="color:#CC0000;">接受第三个可选参数</span>：一个**<span style="color:#CC0000;">比较函数</span>（Comparator）**。这个函数决定了<span style="color:#CC0000;">元素间的排序逻辑</span>。

- **比较函数的返回值**: 必须是 `bool` 类型。如果 `a` 应该排在 `b` 的前面，函数返回 `true`，否则返回 `false`。
- **实现方式**: 通常使用独立的函数、函数对象（Functor）或（在 C++11 及以后版本中）**Lambda 表达式**。Lambda 是最现代、最简洁的方式。

C++

```c++
// 自定义排序：降序排列
std::vector<int> vec = {5, 2, 8, 1, 9};

// 方式1: 使用 Lambda 表达式 (推荐)
std::sort(vec.begin(), vec.end(), [](int a, int b) {
    return a > b; // 如果 a 大于 b，则 a 排在前面
});

// 方式2: 使用普通函数
bool compareDescending(int a, int b) {
    return a > b;
}
std::sort(vec.begin(), vec.end(), compareDescending);
```

#### 2. Java `sort`

Java 中没有统一的 `sort` 函数，而是<span style="color:#CC0000;">根据数据类型提供了不同的静态方法</span>，主要分为两大类：

1. `java.util.Arrays.sort()`: 用于排序**数组**（包括基本类型数组和对象数组）。
2. `java.util.Collections.sort()`: 用于排序实现了 `List` 接口的**集合**（如 `ArrayList`）。



#### **核心理念：面向对象与接口**

Java 的 `sort` 直接操作数组或集合对象本身。对于自定义排序，它依赖于 `Comparable` 和 `Comparator` 两个接口。



#### **基本用法**

用法非常直接，将数组或 List 对象作为参数传给对应的方法即可。

Java

```java
import java.util.Arrays;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

public class SortExample {
    public static void main(String[] args) {
        // 示例1: 排序基本类型数组
        int[] arr = {5, 2, 8, 1, 9};
        Arrays.sort(arr); // 直接传入数组对象

        // 示例2: 排序 List 集合
        List<Integer> list = new ArrayList<>(Arrays.asList(5, 2, 8, 1, 9));
        Collections.sort(list); // 直接传入 List 对象
    }
}
```



#### **自定义排序**

Java 主要通过两种接口来实现自定义排序：

1. **`Comparable` 接口**: 让一个类**自身拥有可比较性**（自然排序）。需要实现 `compareTo` 方法。
   - `a.compareTo(b)`: 如果 `a` 小于 `b`，返回负整数；如果相等，返回 `0`；如果 `a` 大于 `b`，返回正整数。
2. **`Comparator` 接口**: 定义一个**外部的、独立的比较器**，用于临时的、特定的排序需求。
   - 需要实现 `compare(a, b)` 方法，返回值规则与 `compareTo` 相同。
   - 在 Java 8 及以后，同样推荐使用 **Lambda 表达式**来简洁地实现 `Comparator`。

Java

```java
// 自定义排序：降序排列
Integer[] arr = {5, 2, 8, 1, 9}; // 注意：要用包装类型 Integer
List<Integer> list = new ArrayList<>(Arrays.asList(arr));

// 方式1: 使用 Lambda 表达式 (推荐)
// 对于 Arrays.sort
Arrays.sort(arr, (a, b) -> b - a); // 如果 b-a > 0, 则 b 排在 a 前面，实现降序

// 对于 Collections.sort
Collections.sort(list, (a, b) -> b.compareTo(a)); // 或者 b - a

// 方式2: 创建一个实现了 Comparator 接口的匿名内部类 (Java 8 之前常见)
Arrays.sort(arr, new java.util.Comparator<Integer>() {
    @Override
    public int compare(Integer a, Integer b) {
        return b - a; // 返回正数、0或负数
    }
});
```

#### 总结与对比表格

| 特性           | C++ `std::sort`                                              | Java `sort` (`Arrays`/`Collections`)                         |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **所属库**     | `<algorithm>`                                                | `java.util.Arrays` 或 `java.util.Collections`                |
| **作用对象**   | **迭代器指定的内存范围** (非常通用)                          | **数组或 List 对象本身** (类型特定)                          |
| **基本语法**   | `std::sort(vec.begin(), vec.end());`                         | `Arrays.sort(arr);` 或 `Collections.sort(list);`             |
| **自定义排序** | **比较函数/Lambda**，返回 `bool` (true/false)                | **`Comparator` 接口/Lambda**，返回 `int` (负数/0/正数)       |
| **“自然排序”** | 无此概念，默认使用 `<` 运算符比较                            | **`Comparable` 接口**，在类内部定义 `compareTo` 方法         |
| **底层算法**   | **IntroSort** (快速排序、堆排序和插入排序的混合)             | **Dual-Pivot QuickSort** (基本类型) / **Timsort** (对象类型) |
| **稳定性**     | **不稳定** (相等元素的相对顺序可能改变)。如需稳定，请用 `std::stable_sort`。 | **稳定** (对于对象排序使用的 Timsort 是稳定排序)             |

**核心差异小结：**

- **调用方式**：C++ 传递的是<span style="color:#CC0000;">“范围”</span>（通过迭代器），而 Java 传递的是<span style="color:#CC0000;">“对象本身”</span>。
- **自定义逻辑**：C++ 的比较函数返回一个布尔值，回答“`a` 是否应该在 `b` 前面”；Java 的比较器返回一个整数，回答“`a` 和 `b` 谁大、谁小还是相等”。
- **设计哲学**：C++ 体现了泛型编程思想，一个算法适用于多种数据结构。Java 则体现了严格的面向对象思想，通过接口和类来组织功能。

#### <span style="color:#CC0000;">结论</span>

<span style="color:#CC0000;">**仅仅是调换函数定义中参数的声明顺序，而保持函数体 `return a > b;` 不变，会让你的排序结果从“降序”变为“升序”，完全相反。**</span>

这是因为 `std::sort` 是根据**参数位置**（第一个还是第二个）来传递元素的，而不是根据参数名。

<span style="color:#FF0000;">**最佳实践/记忆法则：**</span>

在编写比较函数时，养成一个习惯，始终将参数看作 `(a, b)` 或 `(lhs, rhs)` (<span style="color:#FF0000;">Left</span>-Hand Side, <span style="color:#FF0000;">Right</span>-Hand Side)，然后问自己：

> **“在什么条件下，我希望 `a` 排在 `b` 的前面？”**

这个条件就是你 `return` 语句应该返回 `true` 的条件。

- 想**升序**？`a` 排在 `b` 前面，当 `a < b` 时。所以 `return a < b;`。
- 想**降序**？`a` 排在 `b` 前面，当 `a > b` 时。所以 `return a > b;`。

### 提问：我的代码哪里出错了呢，你能够给我分析下吗？

你好！很高兴能帮你分析你的代码。

你的解题思路大方向是正确的：为了让两个人的体重之和为偶数，他们必须是**同奇同偶**。因此，将人群分为“奇数体重”和“偶数体重”两组，然后分别计算每组需要的船数，最后相加，这个想法非常棒。

但是，你的代码实现在细节上出了一些问题。我们来逐一分析：



#### 代码中的主要错误分析

##### 1. 计数变量未初始化 (Undefined Behavior)

在C++中，非静态的局部变量如果你不给它一个初始值，它的值是随机不确定的。

C++

```c++
int oddCount,evenCount;
oddCount++; evenCount++; // 对一个不确定的值进行自增，结果是未定义的
```

这会导致后面创建 `vector` 的时候，大小是完全错误的，可能会引发程序崩溃或内存访问错误。

**正确做法：** 应该将它们初始化为0。

C++

```c++
int oddCount = 0, evenCount = 0;
```



##### 2. 填充数组的循环逻辑错误

这个 `for` 循环存在两个严重的问题：

C++

```c++
// 错误的代码
for(int i=0,odd=0,even=0; i<people.size(); i++){
    if((people[i] & 1) == 1){
        // ...
        oddArray[odd++] = people[i++]; // 问题在这里
    } else {
        // ...
        evenArray[even++] = people[i++]; // 问题也在这里
    }
}
```

- **双重递增 `i`**：你在 `for` 循环的声明中已经写了 `i++` (它会在每次循环结束后执行)，但在 `if` 和 `else` 语句块内部，你又写了 `people[i++]`。这导致 `i` 在一次循环中被增加了两次，会使你跳过 `people` 数组中的一半元素，导致数据丢失和错误。
- **不推荐的填充方式**：先计数再创建固定大小的 `vector`，然后再用索引去填充，比较繁琐且容易出错。更简洁安全的方式是创建两个空的 `vector`，然后使用 `push_back()` 方法动态地添加元素。



##### 3. 算法核心错误：未对分组后的数组进行排序

你的原始解法（被注释掉的部分）核心思想是 **“贪心算法”**，即对所有人按体重排序后，让最重的人和最轻的人尝试配对。这个贪心策略能成立的前提是 **数组必须是有序的**。

在你的扩展解法中，你虽然把人分成了奇数和偶数两组，但在将他们放入 `oddArray` 和 `evenArray` 后，**完全没有对这两个新的数组进行排序**。在未经排序的数组上使用双指针算法，得到的结果几乎肯定是错误的。



##### 4. 双指针贪心逻辑错误

在你的 `while` 循环中，`else` 部分的逻辑是错误的。

C++

```C++
// 错误的代码
} else {
    l++;       // 错误
    ans1++;
}
```

这里的逻辑是：如果最轻的（`oddArray[l]`）和最重的（`oddArray[r]`）不能同船，怎么办？

- **你的逻辑 (`l++`)**：让最轻的人单独坐一艘船。
- **正确的贪心逻辑 (`r--`)**：最重的人 (`oddArray[r]`) 既然连最轻的人都无法搭档，那么他肯定也无法和任何其他比最轻的人更重的人搭档（因为数组已排序）。所以，最优解是让这个最重的人单独坐一艘船，然后我们再去处理剩下的人。



##### 修正后的正确代码

下面是根据以上分析修改后的完整代码。我添加了详细的注释来解释每一步。

C++

```C++
#include <vector>
#include <algorithm>
#include <numeric>

class Solution {
public:
    int numRescueBoats(std::vector<int>& people, int limit) {
        // 扩展问题：如果两人一船体重之和必须为偶数，该怎么做

        // 1. 将人群根据体重的奇偶性分组
        std::vector<int> odd_people;
        std::vector<int> even_people;

        for (int p : people) {
            if (p % 2 == 1) { // 或者 (p & 1) == 1
                odd_people.push_back(p);
            } else {
                even_people.push_back(p);
            }
        }

        // 2. 分别计算每组需要的船数
        // 为了使用贪心算法，必须先对每组进行排序
        std::sort(odd_people.begin(), odd_people.end());
        std::sort(even_people.begin(), even_people.end());

        // 3. 将计算逻辑封装成一个辅助函数，避免代码重复
        int odd_boats = calculate_boats(odd_people, limit);
        int even_boats = calculate_boats(even_people, limit);

        // 4. 总船数是两组之和
        return odd_boats + even_boats;
    }

private:
    // 辅助函数，用于计算一个给定人群列表所需的船数
    // 这段逻辑就是经典的“救生艇”问题的解法
    int calculate_boats(const std::vector<int>& group, int limit) {
        if (group.empty()) {
            return 0;
        }

        int boats = 0;
        int left = 0;
        int right = group.size() - 1;

        while (left <= right) {
            boats++; // 每次循环都至少需要一艘新船
            if (left == right) {
                // 只剩下一个人，单独一艘船
                break;
            }
            // 最轻的人和最重的人尝试配对
            if (group[left] + group[right] <= limit) {
                left++;  // 如果可以配对，最轻的人也上船
            }
            // 无论是否能配对，最重的人都要上船
            right--; 
        }
        return boats;
    }
};
```
