在 C++ 中，这些概念比 Java 更为底层和灵活（涉及指针、引用、内存管理）。下面我将把这份代码翻译为 C++，并重点解析 C++ 特有的机制。

# 第一部分：C++ 代码实现

为了完美对应 Java 的逻辑，我使用了 C++ 的指针（Pointer）来模拟 Java 的对象引用行为。

C++

```C++
#include <iostream>
#include <vector>

using namespace std;

// 1. 基础类型测试函数
void f(int a) {
    a = 0; // 修改局部副本，不影响外部
}

// 2. 自定义类
class Number {
public:
    int val;
    Number(int v) : val(v) {}
};

// 模拟 Java: g1(Number b) -> b = null
// 在 Java 中这是把局部引用变量指向 null，不影响外部。
// 在 C++ 中对应的是传入指针的值 (Number* b)。
void g1(Number* b) {
    b = nullptr; // 修改的是指针变量 b 本身（局部变量），不影响外部指针
}

// 模拟 Java: g2(Number b) -> b.val = 6
// 修改指针指向的内存区域的数据，影响外部。
void g2(Number* b) {
    if (b != nullptr) {
        b->val = 6;
    }
}

// 模拟 Java: g3(int[] c) -> c = null
// 数组名在 C++ 中退化为指针，或者我们传入指针。
void g3(int* c) {
    c = nullptr; // 同样只是修改局部指针，不影响外部
}

// 模拟 Java: g4(int[] c) -> c[0] = 100
void g4(int* c) {
    c[0] = 100; // 修改地址指向的内容，影响外部
}

// --- 单链表节点 ---
struct ListNode {
    int val;
    ListNode* next;

    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode* nextNode) : val(x), next(nextNode) {}
};

// --- 双链表节点 ---
struct DoubleListNode {
    int value;
    DoubleListNode* last; // 前驱，对应 Java 的 last
    DoubleListNode* next; // 后继

    DoubleListNode(int v) : value(v), last(nullptr), next(nullptr) {}
};

// --- 解决方案类 ---
class Solution {
public:
    // 反转单链表
    // LeetCode: https://leetcode.cn/problems/reverse-linked-list/
    static ListNode* reverseList(ListNode* head) {
        ListNode* pre = nullptr;
        ListNode* next = nullptr;
        while (head != nullptr) {
            next = head->next; // 暂存下个节点
            head->next = pre;  // 反转指向
            pre = head;        // 更新 pre
            head = next;       // 步进
        }
        return pre;
    }

    // 反转双链表
    static DoubleListNode* reverseDoubleList(DoubleListNode* head) {
        DoubleListNode* pre = nullptr;
        DoubleListNode* next = nullptr;
        while (head != nullptr) {
            next = head->next;
            
            // 双向链表的关键：next 和 last 指针都要反转
            head->next = pre;
            head->last = next;
            
            pre = head;
            head = next;
        }
        return pre;
    }
};

int main() {
    // 1. 基础类型：按值传递
    int a = 10;
    f(a);
    cout << "int a: " << a << endl; // 输出 10

    // 2. 对象类型：C++ 中使用指针模拟 Java 的引用
    // 注意：Java 有 GC，C++ new 出来的对象通常需要手动 delete，这里为了演示逻辑暂忽略 delete
    Number* b = new Number(5);
    
    g1(b); // 尝试把指针置空
    cout << "Number b val (after g1): " << b->val << endl; // 依然是 5

    g2(b); // 修改内容
    cout << "Number b val (after g2): " << b->val << endl; // 变成 6

    // 3. 数组
    // C++ 原生数组 int c[] = {1, 2, 3, 4};
    // 数组名 c 在作为参数传递时会自动退化为 int*
    int c[] = { 1, 2, 3, 4 };
    
    g3(c); // 尝试置空
    cout << "Array c[0] (after g3): " << c[0] << endl; // 依然是 1

    g4(c); // 修改内容
    cout << "Array c[0] (after g4): " << c[0] << endl; // 变成 100

    // 4. 链表测试 (简单演示)
    ListNode* n1 = new ListNode(1);
    n1->next = new ListNode(2);
    n1->next->next = new ListNode(3);
    
    ListNode* reversedHead = Solution::reverseList(n1);
    cout << "Reversed List Head: " << reversedHead->val << endl; // 应该是 3

    // 清理内存 (C++好习惯)
    delete b;
    // 链表内存清理略...

    return 0;
}
```

# 第二部分：C++ 知识扩展与补充

Java 程序员看这份代码时，最大的认知差异在于 **“引用”** 这个词。

#### 1. Java 的“引用”其实是 C++ 的“指针值传递”

在 Java 中：

Java

```C++
void g1(Number b) { b = null; }
```

这在 C++ 中等同于传入一个指针变量：

C++

```c++
void g1(Number* b) { b = nullptr; }
```

**解释**：你传递的是**地址的拷贝**。你在 `g1` 里把这个拷贝出来的地址改成了 `null`，原来的指针变量 `b` 依然指向对象。

#### 2. <span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">C++ 独有的“真·引用传递”</span>

C++ 引入了 `&` 符号，<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">允许你直接操作外部变量本身，这是 Java 做不到的（除非用包装类）</span>。

如果我们将 C++ 的 `g1` 改写为：

C++

```C++
// 注意类型后面的 &
void g1_cpp_reference(Number*& b) { 
    b = nullptr; 
}
```

此时调用 `g1_cpp_reference(b)`，外部的 `b` **真的会变成 null**！这在通过函数内部重新分配内存（如初始化链表头节点）时非常有用。

#### 3. 内存管理 (堆 vs 栈)

- **Java**: `new Number(5)` 分配在堆上，GC 自动回收。`int a = 10` 分配在栈上。
- **C++**:
  - `Number b(5);`<span style="color:#FF0000;"> (不带 new) -> 对象直接分配在**栈**上。函数结束自动销毁</span>。
  - `Number* b = new Number(5);` -> <span style="color:#FF0000;">对象分配在**堆**上。必须手动 `delete b`，否则内存泄漏。</span>

#### 4. Struct vs Class

在 Java 中，struct 不存在（JDK 14+ 有 Record，但不同）。

在 C++ 中，struct 和 class 几乎一样：

- **struct**: 成员默认是 `public`（常用于纯数据结构，如 `ListNode`）。
- **class**: 成员默认是 `private`（常用于封装逻辑）。

# 第三部分：经典面试问题与深度见解

这些问题用于考察你对链表、内存和语言特性的深度理解。

#### Q1: 为什么反转链表时，必须先 `next = head->next`？

> 简洁回复：
>
> 为了防止断链。一旦执行 head->next = pre，原本指向下一个节点的指针就丢失了。如果不先用变量 next 保存下来，链表后面所有的节点都将无法访问（内存泄漏/逻辑错误）。

#### Q2: 在 C++ 中，`Solution::reverseList` 的参数是 `ListNode* head`。如果我想在函数内部让外部的 `head` 变量直接指向新的头节点，参数应该怎么改？

> 简洁回复：
>
> <span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">应该改为指针的引用：ListNode*& head 或者 二级指针：ListNode** head。</span>
>
> 目前的代码返回新的头节点 pre，由调用者接收；<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">如果用 void 返回值并想修改外部变量，必须使用引用传递。</span>

#### Q3: 双向链表反转的核心操作只有两步吗？

> 简洁回复：
>
> <span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">核心是交换每个节点的 next 和 last 指针。</span>
>
> 遍历时，对每个节点执行 swap(curr->next, curr->last)，然后移动到原链表的下一个节点（即交换后的 last 指针指向的方向）。代码中虽然写的是赋值，但本质就是交换指向。

#### Q4: 从“堆栈视角”看，递归反转链表和迭代反转链表有什么本质区别？

> **简洁回复：**
>
> - **迭代法（当前代码）**：空间复杂度 $O(1)$。只使用了几个局部变量（寄存器/栈帧内），在堆上操作指针指向，效率高。
> - **递归法**：空间复杂度 $O(N)$。递归会利用系统栈（Stack）来隐式存储每个节点的状态。一直压栈直到尾节点，然后弹栈时进行反转。链表过长会导致 **StackOverflow**。

#### Q5: 在 C++ 中，如果 `ListNode` 对象不是 `new` 出来的，而是栈上局部变量，能用这个反转代码吗？

> 简洁回复：
>
> 极度危险。
>
> <span style="color:#FF0000; border:1px solid #FF00FF; background:#00FF80;">链表通常依赖堆内存（Heap）保证节点生命周期跨越函数调用。如果是栈上对象，一旦创建节点的函数返回，节点内存即被销毁。虽然反转逻辑本身只动指针，但如果涉及跨函数使用，必须确保节点内存有效。</span>



# 补充提问

## 提问1（指针引用 与 二级指针）

<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF; font-size:1.2em;">指针的引用：ListNode*& head 或者 二级指针：ListNode** head。这里指针引用和二级指针我有点看不太懂，它们是可以分开成每部分，然后按照从右向左的原则来分开再合并起来看吗。</span>



非常棒的直觉！**“从右向左读”（Right-to-Left Rule）** 正是解析 C/C++ 复杂指针定义的“黄金法则”。

你完全可以把它们拆开来看。我们用这个原则来彻底剥离这两个概念，并配合图解让你一眼看透。

------

### 1. 基础对照：普通指针 `ListNode* head`

先看最基础的，作为对照组。

- **拆解原则（从变量名开始，向左读）：**
  1. `head`：这是一个变量名。
  2. `*`：它是一个**指针**。
  3. `ListNode`：它指向一个 **ListNode 类型的对象**。

含义：head 盒子里装的是一个地址（比如 0x100），那个地址里住着一个节点。

局限：如果在函数里修改 head = nullptr，你只是把函数里的这个“临时盒子”清空了，外面的盒子不受影响。（这就是 Java 的默认行为）。

------

### 2. 二级指针 `ListNode** head`

这是<span style="color:#FF0000;"> C 语言时代的经典写法。</span>

- **拆解原则（从右向左）：**
  1. `head`：变量名。
  2. `*` （最右边的）：它是一个**指针**。
  3. `*` （中间的）：它指向的目标**还是一个指针**。
  4. `ListNode` （最左边的）<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">：最终的那个指针指向 **ListNode 对象**。</span>

**通俗解释**：

- **一级指针**是“藏宝图”（指向宝藏位置）。
- **二级指针**是“藏宝图的柜子钥匙”（指向藏宝图的位置）。

如果你想换掉一张藏宝图（改变外部指针的指向），你需要拿着钥匙打开柜子（拿到二级指针），把旧图拿走，放张新图进去。

**代码对比操作：**

C++

```C++
// 函数定义：接收一个指向指针的指针
void changeHead(ListNode** head) {
    // *head 表示“解引用”一次，拿到了外面的那个指针
    *head = nullptr; 
}

// 调用时：
ListNode* p = new ListNode(1);
changeHead(&p); // 必须传 p 的地址（&p）
```

------

### 3. 指针的引用 `ListNode*& head`

这是<span style="color:#FF0000;"> C++ 特有的语法糖</span>，<span style="border:1px solid #FF00FF; background:#00FF80;">为了让代码写起来更像普通变量，不用写那么多星星（*）</span>。

- **拆解原则（从右向左）：**
  1. `head`：变量名。
  2. `&`：它是一个**引用**（你可以<span style="color:#FF0000;">理解为“绰号”或“别名”</span>）。
  3. `*`：它引用的是一个**指针**。
  4. `ListNode`：<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">这个指针指向 **ListNode 对象**。</span>

**通俗解释**：

- **引用**就是“分身”。

- `ListNode*& head` 意味着：函数里的 `head` 就是外部那个指针变量的**真身**，只是换了个名字叫 `head`。

- 你动了 `head`，就等于动了外部原本的那个变量。

  <span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">（补充理解：ListNode *  &head，这样子看 head 是 ListNode * 类型的，然后&表示head是个引用，head是什么类型的引用由其类型决定，这里head是ListNode *类型的引用。）</span>

**代码对比操作：**

C++

```C++
// 函数定义：接收指针的引用
void changeHead(ListNode*& head) {
    // 像操作普通指针一样直接操作，不需要加 *
    head = nullptr; 
}

// 调用时：
ListNode* p = new ListNode(1);
changeHead(p); // 直接传 p，不需要取地址符 &
```

------

### 4. 终极图解：三者区别

假设你（main函数）手里有一张纸（指针 `p`），纸上写着 **"房间号 101"**（节点地址）。你想让清洁工（函数）把这张纸上的字改成 **"空"**。

| **方式**     | **代码写法**      | **现实类比**                                                 | **结果**                     |
| ------------ | ----------------- | ------------------------------------------------------------ | ---------------------------- |
| **按值传递** | `ListNode* head`  | 你复印了一张纸给清洁工。清洁工把复印件擦掉了。               | 你手里的原件没变。**失败**。 |
| **二级指针** | `ListNode** head` | 你把**放纸的抽屉钥匙**给了清洁工。清洁工打开抽屉，拿出了你的原件并修改。 | 你手里的原件变了。**成功**。 |
| **指针引用** | `ListNode*& head` | 你把你的纸**直接递给**清洁工（或者说清洁工的手伸过来抓住了你的纸）。 | 你手里的原件变了。**成功**。 |

### 总结与建议

- **怎么读**：你的方法完全正确，从变量名开始，**从右向左**一层层剥洋葱。
  - `*` = 指向...的指针
  - `&` = ...的引用
- **怎么用**：
  - 在 **C 语言**中，想修改外部指针，只能用二级指针 `ListNode**`。
  - 在 **C++** 中，<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">推荐用指针的引用 `ListNode*&`，因为代码更干净，不需要在函数里写一堆 `*head`，也不需要在调用时写 `&p`。</span>
