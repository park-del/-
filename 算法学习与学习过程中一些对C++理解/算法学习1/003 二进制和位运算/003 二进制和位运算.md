## 计算机底层加法的一套逻辑

<span style="color:#CC0000; font-weight:bold; font-size:1.2em;">提问：计算机底层中的负数是用补码表示的，而补码的作用就是能够实现非负数+非负数，负数+负数，非负数+负数用一整套逻辑来实现，这个我不是特别理解，你能够给我详细解释下吗？</span>



您提的这个问题非常棒，这正是计算机组成原理中最巧妙、最核心的设计之一！您已经理解了“是什么”（用补码表示负数）和“做什么”（统一加法逻辑），现在我们来深入探讨“**为什么能行**”。

简单来说，<span style="color:#CC0000;">补码的魔力</span>在于它把**<span style="color:#FF0000;">减法运算巧妙地转化为了加法运算</span>**。CPU不再需要一个独立的“减法器”，只需要一个“加法器”就能处理所有加减法，极大地简化了硬件设计。

下面我们通过一个简单的8位整数系统来详细解释这个过程。



### **如果没有补码，世界会怎样？(原码的问题)**

最符合直觉的表示法是“原码”：最高位是符号位，剩下的位表示绝对值。

- `7` -> `0000 0111`
- `-7` -> `1000 0111`

看起来很简单，但用它做运算就会出问题。比如计算 `7 + (-7)`，我们期望结果是 `0`。

```
  0000 0111  (7)
+ 1000 0111  (-7)
-----------------
  1001 1110  (-14)  // 错误的结果！
```

<span style="color:#CC0000;">为了得到正确结果，CPU需要判断符号位，然后根据情况决定是做加法还是减法，这会让硬件电路变得非常复杂。</span>



### **补码的魔法：<span style="color:#CC0000;">将减法变成加法</span>**

补码的<span style="color:#CC0000;">核心思想</span>是：<span style="color:#CC0000;">一个数减去另一个数，等于第一个数加上第二个负数的补码。</span>

即 A - B <span style="color:#FF0000;">等价于</span> A + (-B的补码)。

我们用一个8位系统来演示，能表示的范围是 -128 到 127。



<span style="color:#FF0000;">补充：</span>

（1）在计算机内部中 n位 补码表示，第n位为符号位，低n-1位 为数值位，<span style="color:#CC0000;">根据符号位0和1，可以划分成两部分（负数 和 非负数）</span>，每一部分都有<span style="color:#FF0000;"> $2^{(n-1)}$ 个数</span>。

（2）以8位补码为例，8位补码可以表示的数的范围为  $-2^7$ ~ $2^{7}-1$，划分成的<span style="color:#FF0000;">两部分</span>分别为 <span style="color:#FF0000;">-128 ~ -1 </span>与 <span style="color:#FF0000;">0 ~127</span>。发现从<span style="color:#CC0000;">最小值-128的补码依次递增1就可以得到-128~127之间的每个数的补码</span>，<span style="color:#CC00CC;">即 1000 0000（-128）、1000 0001（-127），……，0000 0000（0），0111 1111（127）。</span>

（3）由原码转为补码（只针对负数，因为正数原码补码都是一样的），看数值位，数值位每位取反，末位加1。



#### **示例1：正数 + 负数 (7 - 6 = 1)**

这等价于计算 `7 + (-6)`。

1. 7 的二进制 (原码、补码相同):

   0000 0111

2. **`-6` 的补码**:

   - `6` 的二进制: `0000 0110`
   - 按位取反: `1111 1001`
   - 加一: `1111 1010` (这就是-6)

3. **现在，我们把它们直接相加**:

   ```
     0000 0111   (7)
   + 1111 1010   (-6)
   -----------------
   1 0000 0001   (结果是9位)
   ```

4. **<span style="color:#FF0000;">魔法</span>发生的地方**：<span style="color:#CC0000;">因为我们是在一个8位系统中，第9位的进位 `1` 会被自然地**丢弃**（因为没有地方存放它）</span>。

5. **最终结果**：`0000 0001`，这<span style="color:#FF0000;">正是</span> `1` 的二进制！`7 + (-6)` 的结果正确。



#### **示例2：负数 + 负数 (-3 - 5 = -8)**

这等价于计算 `(-3) + (-5)`。

1. **`-3` 的补码**: `1111 1101`

2. **`-5` 的补码**: `1111 1011`

3. **直接相加**:

   ```
     1111 1101   (-3)
   + 1111 1011   (-5)
   -----------------
   1 1111 1000   (结果是9位)
   ```

4. **<span style="color:#FF0000;">再次丢弃进位</span>**：舍弃最高的第9位 `1`。

5. **最终结果**：`1111 1000`。我们来验证一下这是不是 `-8` 的补码：

   - `8` 的二进制: `0000 1000`
   - 取反: `1111 0111`
   - 加一: `1111 1000`。完全正确！



### **<span style="color:#CC0000;">为什么会这么神奇？</span>—— <span style="color:#CC6600;">模运算（时钟算术）</span>**

<span style="color:#CC0000;">补码的数学原理</span>是**模运算 (Modular Arithmetic)**，你可以<span style="color:#FF00FF;">用一个时钟来理解它</span>。

- <span style="color:#CC0000;">假设现在是**4点**，你想知道**5个小时前**是几点。你可以 `4 - 5`，但时钟上没法减。</span>
- 你可以<span style="color:#CC6600;">换个思路</span>：<span style="color:#FF00FF;">在12小时制的时钟上，**后退5小时**和**前进7小时** (`12-5=7`) 到达的位置是一样的。`4 + 7 = 11`，所以5小时前是11点。</span>
- 在这个<span style="color:#FF0000;">“模12”</span>的系统里，`7` 就是 `-5` 的“<span style="color:#FF0000;">补数</span>”。我们把<span style="color:#FF0000;">减法</span> `4 - 5` 变成了<span style="color:#FF0000;">加法</span> `4 + 7`。

计算机的<span style="color:#CC6600;">定长整数系统（比如8位、32位）就是一个模运算系统</span>。对于一个<span style="color:#CC0000;">n位的系统</span>，它的<span style="color:#CC0000;">“模”是 `2^n`</span>。

- `A - B` 就等价于 `A + (2^n - B)`（<span style="color:#FF0000;">这里将 $2^n$ 拆分成 $2^{(n-1)} + 1$ 会更加好理解，原式变为 $2^{n-1} - B + 1$ ，前面的负责对B的数值位的每一位取反操作，后面再进行加1)</span>。
- <span style="color:#FF0000;">而 `(2^n - B)` 这个值，恰好就是 `B` 的二进制**取反再加一**的结果！</span>

所以，当CPU执行 `A + (-B的补码)` 时，实际上就是在进行 `A + (2^n - B)` 的运算。因为系统最多只能表示n位，任何超过 `2^n` 的部分（也就是那个进位）都会被自动舍弃，这天然地完成了“取模”的操作。

**总结一下：**

**<span style="color:#CC0000;">补码通过将“负数”重新编码</span>，使得<span style="color:#CC0000;">“加一个负数”在二进制层面等同于“加上这个负数的补码”</span>，并且其运算规则与“正数+正数”完全统一。这使得<span style="color:#CC0000;">CPU可以用一套完全相同的加法电路来处理所有整数的加减法</span>，这是计算机设计史上一个里程碑式的创举。**
