# Code01_HeapSort

## java 版本

```java
package class025;

// 堆结构和堆排序，acm练习风格
// 测试链接 : https://www.luogu.com.cn/problem/P1177
// 请同学们务必参考如下代码中关于输入、输出的处理
// 这是输入输出处理效率很高的写法
// 提交以下的code，提交时请把类名改成"Main"，可以直接通过

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.io.StreamTokenizer;

public class Code01_HeapSort {
	
	public static int MAXN = 100001;

	public static int[] arr = new int[MAXN];

	public static int n;

	public static void main(String[] args) throws IOException {
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		StreamTokenizer in = new StreamTokenizer(br);
		PrintWriter out = new PrintWriter(new OutputStreamWriter(System.out));
		in.nextToken();
		n = (int) in.nval;
		for (int i = 0; i < n; i++) {
			in.nextToken();
			arr[i] = (int) in.nval;
		}
		// heapSort1();
		heapSort2();
		for (int i = 0; i < n - 1; i++) {
			out.print(arr[i] + " ");
		}
		out.println(arr[n - 1]);
		out.flush();
		out.close();
		br.close();
	}

	// i位置的数，向上调整大根堆
	public static void heapInsert(int i) {
		while (arr[i] > arr[(i - 1) / 2]) {
			swap(i, (i - 1) / 2);
			i = (i - 1) / 2;
		}
	}

	// i位置的数，向下调整大根堆
	// 当前堆的大小为size
	public static void heapify(int i, int size) {
		int l = i * 2 + 1;
		while (l < size) {
			int best = l + 1 < size && arr[l + 1] > arr[l] ? l + 1 : l;
			best = arr[best] > arr[i] ? best : i;
			if (best == i) {
				break;
			}
			swap(best, i);
			i = best;
			l = i * 2 + 1;
		}
	}

	public static void swap(int i, int j) {
		int tmp = arr[i];
		arr[i] = arr[j];
		arr[j] = tmp;
	}

	// 从顶到底建立大根堆，O(n * logn)
	// 依次弹出堆内最大值并排好序，O(n * logn)
	// 整体时间复杂度O(n * logn)
	public static void heapSort1() {
		for (int i = 0; i < n; i++) {
			heapInsert(i);
		}
		int size = n;
		while (size > 1) {
			swap(0, --size);
			heapify(0, size);
		}
	}

	// 从底到顶建立大根堆，O(n)
	// 依次弹出堆内最大值并排好序，O(n * logn)
	// 整体时间复杂度O(n * logn)
	public static void heapSort2() {
		for (int i = n - 1; i >= 0; i--) {
			heapify(i, n);
		}
		int size = n;
		while (size > 1) {
			swap(0, --size);
			heapify(0, size);
		}
	}

}
```

```C++
#include <iostream>

// C++中，我们通常使用 #include 来引入库
// <iostream> 对应 Java 的 I/O 类

// 使用 std 命名空间，这样就不必在 cin, cout 前写 std::
using namespace std;

// 相当于 public static int MAXN = 100001;
const int MAXN = 100001;

// 相当于 public static int[] arr = new int[MAXN];
// 这是一个全局数组
int arr[MAXN];

// 相当于 public static int n;
int n;

// 交换函数
// 相当于 public static void swap(int i, int j)
// 在C++中，函数默认是全局的，不需要 static 关键字
void swap(int i, int j) {
    int tmp = arr[i];
    arr[i] = arr[j];
    arr[j] = tmp;
}

// i位置的数，向上调整大根堆
// 相当于 public static void heapInsert(int i)
void heapInsert(int i) {
    // 逻辑与Java完全相同
    // C++的整数除法 (i - 1) / 2 与 Java 行为一致
    // 当 i = 0 时, (0 - 1) / 2 = 0，arr[0] > arr[0] 为 false，循环不执行
    while (arr[i] > arr[(i - 1) / 2]) {
        swap(i, (i - 1) / 2);
        i = (i - 1) / 2;
    }
}

// i位置的数，向下调整大根堆
// 当前堆的大小为size
// 相当于 public static void heapify(int i, int size)
（
i：一个从0开始的索引。
size：一个从1开始的计数（数量），它代表了堆中元素的总个数。这个大小为 size 的堆，其元素存储在数组的 [0] 到 [size - 1] 位置上。
）
void heapify(int i, int size) {
    int l = i * 2 + 1;
    while (l < size) {
        // C++ 的三元运算符与 Java 语法完全相同
        int best = l + 1 < size && arr[l + 1] > arr[l] ? l + 1 : l;
        best = arr[best] > arr[i] ? best : i;
        if (best == i) {
            break;
        }
        swap(best, i);
        i = best;
        l = i * 2 + 1;
    }
}

// 从顶到底建立大根堆，O(n * logn)
// 依次弹出堆内最大值并排好序，O(n * logn)
// 整体时间复杂度O(n * logn)
// 相当于 public static void heapSort1()
void heapSort1() {
    for (int i = 0; i < n; i++) {
        heapInsert(i);
    }
    int size = n;
    // C++ 的 --size (前缀递减) 与 Java 行为一致
    while (size > 1) {
        swap(0, --size);
        heapify(0, size);
    }
}

// 从底到顶建立大根堆，O(n)
// 依次弹出堆内最大值并排好序，O(n * logn)
// 整体时间复杂度O(n * logn)
// 相当于 public static void heapSort2()
void heapSort2() {
    for (int i = n - 1; i >= 0; i--) {
        heapify(i, n);
    }
    int size = n;
    while (size > 1) {
        swap(0, --size);
        heapify(0, size);
    }
}

// C++ 的主函数
// 相当于 public static void main(String[] args)

    // heapSort1();

    // 相当于 out.println(arr[n - 1]);

    cout << arr[n - 1] << "\n";

    // C++ 的 main 函数最后返回 0 表示程序正常退出
    // Java 中的 out.flush(), out.close(), br.close() 在 C++ 中
    // 当 main 函数结束时会自动处理（缓冲区刷新、流关闭）
    return 0;
}
```

### 关键转换逻辑说明

1. **类与结构 (Class vs. Global)**：

   - Java 是一种纯面向对象的语言，所有代码（包括 `main` 函数和辅助函数）都必须在类（`class`)中。在算法竞赛中，通常将所有方法和变量声明为 `static`，使其类似于全局函数和全局变量。
   - C++ 是一种多范式语言，它允许你直接在全局作用域中定义函数和变量。因此，Java 代码中所有的 `public static` 方法（如 `heapify`, `swap`）都转换为了 C++ 中的全局函数（只需去掉 `public static`）。

2. **I/O (输入/输出)**：

   - **Java**: 你使用了 `BufferedReader`, `StreamTokenizer`, 和 `PrintWriter` 来实现高效的 I/O。

   - **C++**: 我们使用 `<iostream>` 库中的 `cin` (标准输入) 和 `cout` (标准输出)。

   - **效率对等**: Java 中使用 `BufferedReader` 是为了缓冲。C++ 的 `cin`/`cout` 默认也是带缓冲的。为了达到 Java 中 `StreamTokenizer` 的速度，我们在 C++ `main` 函数的开头添加了

     C++

     ```C++
     ios_base::sync_with_stdio(false);
     cin.tie(nullptr);
     ```

     这两行代码解除了 C++ 标准流与 C 标准流（`printf`/`scanf`）的同步，并解除了 `cin` 和 `cout` 的绑定，这是 C++ 算法竞赛中实现快速 I/O 的标准做法。

   - **读写**:

     - `in.nextToken(); n = (int) in.nval;` 变为 `cin >> n;`
     - `out.print(arr[i] + " ");` 变为 `cout << arr[i] << " ";`
     - `out.println(arr[n - 1]);` 变为 `cout << arr[n - 1] << "\n";` (使用 `\n` 而不是 `std::endl` 来避免不必要的缓冲区刷新)。

3. **数组和常量**：

   - **Java**: `public static int MAXN = 100001;`
   - **C++**: `const int MAXN = 100001;` (使用 `const` 关键字定义常量)。
   - **Java**: `public static int[] arr = new int[MAXN];`
   - **C++**: `int arr[MAXN];` (在全局作用域声明一个C风格的数组)。

4. **函数声明顺序**：

   - 在 Java 中，你可以在类中的任何位置定义方法，它们可以互相调用。
   - 在 C++ 中，一个函数必须在使用它之前被*声明*或*定义*。在上面的代码中，我按照依赖顺序定义了函数（`swap` -> `heapInsert` / `heapify` -> `heapSort` -> `main`），这样 `main` 调用 `heapSort2` 时，`heapSort2` 已经是已知的，`heapSort2` 调用 `heapify` 时 `heapify` 也是已知的，以此类推。

5. **主函数 (Main)**：

   - **Java**: `public static void main(String[] args) throws IOException`
   - **C++**: `int main()`。C++ 的 `main` 函数标准返回类型是 `int`，`return 0;` 表示程序成功执行。C++ 中不需要（也不鼓励）在 `main` 函数签名上声明异常。

6. **核心算法逻辑**：

   - `heapInsert`, `heapify`, `heapSort1`, `heapSort2` 的**算法逻辑完全没有改变**。C++ 和 Java 在整数除法、三元运算符 (`? :`)、循环 (`for`, `while`) 和基本算术运算上的语法和行为是相同的，因此这部分代码可以近乎逐字地转换。







# 补充提问

## 提问1

<span style="font-weight:bold; font-size:1.2em;">静态static变量和全局变量二者效果是一样的吗，在C++中？</span>



这是一个非常好的问题！

**简短的回答是：不，它们的效果不一样。**

在 C++ 中，“全局变量”和“`static` 变量”在**作用域（Scope）**、**链接性（Linkage）**和**生命周期（Storage Duration）**这三个关键方面表现不同。

`static` 关键字的含义取决于它出现的位置。让我们来对比一下“全局变量”和两种最常见的“`static` 变量”。

我们通常所说的“全局变量”是指在所有函数和类之外定义的*非* `static` 变量。

------



### 1. 全局变量 (Global Variable)

在所有函数和类之外声明，并且**没有** `static` 关键字。

C++

```C++
// 在 A.cpp 文件中
int globalVar = 10; // 这是一个全局变量
```

- **生命周期 (Storage Duration):** 静态 (Static)。它在程序开始时被创建，在程序结束时被销毁。
- **作用域 (Scope):** 全局 (Global)。从它被声明的那一刻起，直到文件末尾，它都是可见的。
- **链接性 (Linkage):** **外部链接 (External Linkage)**。
  - **这是最关键的区别！** "外部链接"意味着这个变量可以被项目的**其他 `.cpp` 文件**访问。
  - 例如，在 `B.cpp` 文件中，你可以通过 `extern int globalVar;` 来声明并使用 `A.cpp` 中定义的 `globalVar`。



### 2. `static` 全局变量 (Static Global Variable)

在所有函数和类之外声明，并且**有** `static` 关键字。

C++

```C++
// 在 A.cpp 文件中
static int staticGlobalVar = 20; // 这是一个 static 全局变量
```

- **生命周期 (Storage Duration):** 静态 (Static)。(与全局变量相同)
- **作用域 (Scope):** 全局 (Global)。(与全局变量相同)
- **链接性 (Linkage):** **内部链接 (Internal Linkage)**。
  - **这是与全局变量的核心区别！** "内部链接"意味着这个变量**只能**在它被定义的当前 `.cpp` 文件（即当前翻译单元）中被访问。
  - 其他 `.cpp` 文件（如 `B.cpp`）**无法**通过 `extern` 来访问它。
  - 在现代 C++ 中，更推荐使用**匿名命名空间 (Anonymous Namespace)** 来实现这种“文件内可见”的效果，而不是 `static`。



### 3. `static` 局部变量 (Static Local Variable)

在**函数内部**声明，并且有 `static` 关键字。

C++

```C++
void myFunction() {
    static int counter = 0; // 这是一个 static 局部变量
    counter++;
    std::cout << counter << std::endl;
}

int main() {
    myFunction(); // 输出 1
    myFunction(); // 输出 2
    myFunction(); // 输出 3
}
```

- **生命周期 (Storage Duration):** **静态 (Static)**。
  - 这是它与普通局部变量（在函数退出时销毁）的**巨大**区别。
  - `counter` 变量在程序开始时创建（或在第一次调用时初始化），并且在**整个程序运行期间都存在**。它的值在函数调用之间会**保持不变**。
- **作用域 (Scope):** **局部 (Local)**。
  - 这是它与全局变量的**巨大**区别。
  - `counter` 变量**只能**在 `myFunction` 函数的内部被访问。在函数外部（如 `main` 函数中）尝试访问 `counter` 会导致编译错误。
- **链接性 (Linkage):** 无链接 (No Linkage)。它不能被其他任何地方访问。

------



### 总结对比

为了更清晰地看到效果差异，我们用一个表格来总结：

| **变量类型**          | **定义位置** | **static 关键字** | **生命周期 (Storage)** | **作用域 (Scope)**            | **链接性 (Linkage)**               |
| --------------------- | ------------ | ----------------- | ---------------------- | ----------------------------- | ---------------------------------- |
| **全局变量**          | 函数外       | 无                | 静态（整个程序）       | 全局（文件）                  | **外部 (External)** (可跨文件访问) |
| **`static` 全局变量** | 函数外       | 有                | 静态（整个程序）       | 全局（文件）                  | **内部 (Internal)** (仅限本文件)   |
| **`static` 局部变量** | 函数内       | 有                | 静态（整个程序）       | **局部 (Local)** (仅限函数内) | **无 (None)**                      |

**结论：**

1. **`static` 全局变量** vs **全局变量**：
   - 两者唯一的区别是**链接性**。全局变量可以被其他文件访问（`external`），而 `static` 全局变量不行（`internal`）。在只有一个 `.cpp` 文件的小程序中，你可能感觉不到它们的区别，但在多文件项目中，这个区别至关重要。
2. **`static` 局部变量** vs **全局变量**：
   - 两者完全不同。它们唯一的共同点是“生命周期”（都活得和程序一样久）。
   - 它们最大的区别是**作用域**。全局变量哪都能用（有“污染”全局命名空间的风险），而 `static` 局部变量只能在它自己的函数内部使用，非常安全和“私有”。

```C++
class Solution {

    void swap(int *arr, int i, int j){
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }

        while ( arr[i] > arr[(i-1)/2] ) {
            swap(arr, i, (i-1)/2);
            i = (i-1)/2;

            if( best == i){

            }

        for(int i=0; i<n; i++){
            heapInsert(arr,i);

            heapify(arr, i, n);
        }   
    }
```

## 代码bug审查

## 提问1

<span style="font-size:1.4em; font-weight:bold;">我的代码是哪里出现了问题吗，你能够给我解释下吗？</span>



你的代码中存在几个非常关键的问题，包括编译错误和严重的逻辑错误。我们来逐一分解：

### 1. 最关键的逻辑错误：传值 (Pass-by-Value)

这是导致你算法完全失效的核心原因。

- **问题**：你的 `heapInsert` 和 `heapify` 函数签名是 `void heapInsert(vector<int> arr, ...)` 和 `void heapify(vector<int> arr, ...)`。
- **解释**：在 C++ 中，当你不使用 `&` 时，`vector` (以及其他大部分对象) 是**按值传递**的。这意味着每当你调用 `heapInsert(nums, i)` 时，C++ 都会创建一份 `nums` 向量的**完整副本**，你的 `heapInsert` 函数对这份**副本**进行了修改。当函数返回时，这份副本被销毁，而**原始的 `nums` 向量根本没有被改变**。
- **修正**：你必须按**引用 (`&`)** 传递 `vector`，这样函数才能修改原始数据。

C++

```C++
// 错误
void heapInsert(vector<int> arr, int i) { ... }
void heapify(vector<int> arr, int i, int size) { ... }
void swap(int *arr, int i, int j) { ... } // 这个函数也有问题，见下一点

// 正确
void heapInsert(vector<int>& arr, int i) { ... }
void heapify(vector<int>& arr, int i, int size) { ... }
void swap(vector<int>& arr, int i, int j) { ... }
```

------



### 2. `swap` 函数的类型不匹配 (编译错误)

- **问题**：你定义的 `swap` 函数 `void swap(int *arr, ...)` 期望接收一个 C 风格的**指针** (`int *`)。
- **解释**：但在 `heapInsert` 和 `heapify` 中，你尝试传递一个 `vector<int>` 类型的对象给它。这两者类型不兼容，会导致编译错误。
- **修正**：如上所示，将 `swap` 函数也修改为接收 `vector<int>&`。

------



### 3. `sortArray` 函数中的变量名和作用域错误 (编译错误)

- **问题**：
  1. 在 `sortArray` 中，你接收的变量名是 `nums`，但在循环中你调用的是 `heapInsert(arr, i)` 和 `heapify(arr, i, n)`。`arr` 在这里是未定义的。
  2. 在 `heapify` 调用中，你使用了变量 `i`，但 `i` 只是第一个 `for` 循环的局部变量，在 `while` 循环中它已经不存在了（超出作用域）。
- **解释**：你应该始终操作 `nums` 向量。并且在 `heapify`（下沉）时，你应该总是从根节点（索引 `0`）开始。
- **修正**：
  1. `heapInsert(arr, i)`应改为 `heapInsert(nums, i)`。
  2. `heapify(arr, i, n)`应改为 `heapify(nums, 0, n)`。

------



### 4. `heapify` 函数中的逻辑错误

- **问题**：在 `heapify` 的最后，你有 `swap( arr, i, l);`。
- **解释**：`l` 始终是 `i` 的**左孩子**的索引。但你的 `best` 变量才存储着**左右孩子中值最大**的那一个的索引。你应该将父节点 `i` 与 `best` 索引处的节点交换，而不是固定与左孩子 `l` 交换。
- **修正**：`swap( arr, i, l);` 应改为 `swap(arr, i, best);`。

------



### 5. `sortArray` 中 `while` 循环的逻辑错误

- **问题**：你的循环 `while( (n--) > 1 )` 配合 `swap(nums, 0, n-1)` 是不正确的。

- **解释**：我们用 `n = 5` 模拟：

  1. `n--`：`n` 的值 `5` 被用于比较 (`5 > 1` 为真)，然后 `n` 变为 `4`。

  2. swap(nums, 0, n-1)：执行 swap(nums, 0, 3)。

     这是错的。你应该用堆顶（索引 0）与堆的最后一个元素（索引 4）交换。

- **修正**：一个更清晰、正确的写法是：

C++

```C++
int size = nums.size();
while (size > 1) {
    swap(nums, 0, --size); // 先将 size 减 1 (size 变为 4)，然后交换 0 和 4
    heapify(nums, 0, size);  // 对大小为 4 的新堆进行 heapify
}
```

**注意**：你之前代码中的 `heapify(arr, i, n)`，`n` 是在 `(n--)` 之后的值。如果你想保持你的循环结构，你需要写成 `swap(nums, 0, n)`，因为 `n` 已经被 `n--` 递减过了。但上面 `size` 的版本更标准，不易出错。

### 6. C++ 语法错误 (编译错误)



- **问题**：`if( best == i){ break }`
- **解释**：C++ 中每条语句都必须以分号 `;` 结尾。
- **修正**：`if( best == i){ break; }`

### 修正后的完整代码



这是整合了所有修改的正确代码：

C++

```C++
#include <vector>
#include <iostream>

using namespace std; // 方便使用 vector, swap 等

class Solution {
public:
    
    // 1. 修正 swap 函数以接收 vector 引用
    void swap(vector<int>& arr, int i, int j){
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
    
    // 2. 修正 heapInsert 以接收 vector 引用
    void heapInsert(vector<int>& arr, int i){
        // (i-1)/2 在 i=0 时是 0 (整数除法)，arr[0] > arr[0] 为 false，循环自动停止
        while ( arr[i] > arr[(i-1)/2] ) {
            swap(arr, i, (i-1)/2);
            i = (i-1)/2;
        } 
    }

    // 3. 修正 heapify 以接收 vector 引用
    void heapify(vector<int>& arr, int i, int size){
        int l = 2 * i + 1;
        while ( l < size ) {
            int best = l+1 < size && arr[l+1] > arr[l] ? l+1 : l;
            
            // 比较父节点和最大的子节点
            best = arr[i] > arr[best] ? i : best;

            // 6. 添加分号
            if( best == i){
                break;
            }
            
            // 4. 修正 swap 逻辑，与 best 交换
            swap( arr, i, best);
            
            i = best;
            l = 2*i+1;
        }
    }

    vector<int> sortArray(vector<int>& nums) {
        if (nums.size() < 2) {
            return nums;
        }
        
        int n = nums.size();
        
        // 建立大根堆
        // 5. 修正变量名，使用 nums
        for(int i=0; i<n; i++){
            heapInsert(nums,i);
        }
        
        // 也可以使用更高效的 O(n) 建堆方式（从下到上 heapify）
        // for(int i = n - 1; i >= 0; i--){
        //     heapify(nums, i, n);
        // }

        int size = n;
        // 5. 修正排序循环的逻辑
        while( size > 1 ){
            // 将堆顶（最大值）与堆的最后一个元素交换
            swap(nums, 0, --size); // size 先减 1，然后作为索引
            
            // 5. 修正 heapify 的调用，从 0 开始，堆大小为
            heapify(nums, 0, size);
        } 
        
        return nums;
    }
};
```

## 提问2

<span style="font-weight:bold; font-size:1.2em;">我记得vector不是在堆上开辟空间的吗，那么为什么函数参数传递vector<int> arr不就是直接堆上的地址吗，不就可以吗，为什么要传递 vector<int> arr呢，我不是太懂，你能够给我详细解释下吗？</span>

这是一个非常棒的问题，也是 C++ 初学者最容易混淆的点之一。

你说的非常对，`vector` 内部管理的数据**确实**在堆（Heap）上。

但你混淆了一个关键概念：**`vector` 对象本身** 和 **`vector` 对象所管理的数据**。

让我们来详细解释一下。



### 1. `vector` 到底是什么？

你可以把 `vector<int> nums` 这个变量想象成一个“管理器”对象。这个“管理器”对象本身（在你之前的 `sortArray` 函数中）是创建在**栈（Stack）**上的一个局部变量。

这个“管理器”对象（`nums`）内部至少保存了三个信息：

1. **一个指针**：指向在**堆（Heap）**上实际分配的连续内存块（这里面存着你的 `1, 5, 2` 等数据）。
2. **一个 `size` 变量**：记录当前存储了多少个元素。
3. **一个 `capacity` 变量**：记录在“堆”上总共分配了多少空间（在需要更多空间之前）。

**可视化：**

```
   在栈 (Stack) 上的 nums 对象
   +---------------------+
   |  ptr_to_heap   ------|----->  在堆 (Heap) 上的数据
   |  size = 4           |        +---+---+---+---+....
   |  capacity = 8       |        | 1 | 5 | 2 | 4 |   |
   +---------------------+        +---+---+---+---+....
```

------



### 2. 当你传递 `vector<int> arr` (传值)

当你调用一个函数 `void heapInsert(vector<int> arr, int i)` 时，C++ 默认执行**按值传递 (Pass-by-Value)**。

对于 `vector` 这种类对象，"按值传递"意味着 C++ 会调用 `vector` 的**拷贝构造函数 (Copy Constructor)** 来创建一个**全新的、独立的 `vector` 对象**，这个新对象就是参数 `arr`。

这个拷贝过程会：

1. 在**堆（Heap）上分配一块新的内存**。
2. 把 `nums` 所管理的所有数据（`1, 5, 2, 4`）**逐个复制**到这块新内存中。
3. 创建一个**新的**“管理器”对象 `arr`（在 `heapInsert` 函数的栈上），让它指向这块新内存。

**可视化：**

```
   在 main 的栈上
   +---------------------+
   | nums                |
   |  ptr_to_heap   ------|----->  堆上的数据 A
   |  size = 4           |        +---+---+---+---+
   +---------------------+        | 1 | 5 | 2 | 4 |
                                +---+---+---+---+

   调用 heapInsert(nums, i) ...

   在 heapInsert 的栈上
   +---------------------+
   | arr (一个全新的对象) |
   |  ptr_to_heap   ------|----->  堆上的数据 B (A的副本)
   |  size = 4           |        +---+---+---+---+
   +---------------------+        | 1 | 5 | 2 | 4 |
                                +---+---+---+---+
```

结果：

你在 heapInsert 函数中对 arr 进行的所有 swap 操作，都只发生在**“堆上的数据 B”**上。当函数结束时，arr 对象被销毁，“堆上的数据 B”也被释放。

而原始的 `nums` 和它所管理的“堆上的数据 A” **根本没有被碰过**。

------



### 3. 当你传递 `vector<int>& arr` (传引用)

当你调用 `void heapInsert(vector<int>& arr, int i)` 时，你告诉 C++：“不要复制，我要**按引用传递 (Pass-by-Reference)**。”

`&` 符号意味着 `arr` 不再是一个新对象，它现在是**原始 `nums` 对象的一个“别名” (Nickname)**。

**可视化：**

```
   在 main 的栈上
   +---------------------+
   | nums                |
   |  ptr_to_heap   ------|----->  堆上的数据 A
   |  size = 4           |        +---+---+---+---+
   +---------------------+        | 1 | 5 | 2 | 4 |
                                +---+---+---+---+

   调用 heapInsert(nums, i) ...

   在 heapInsert 的栈上
   +---------------------+
   | arr (是 nums 的别名) |  <-- 它就是 nums，不是副本
   +---------------------+
```

结果：

你在 heapInsert 函数中对 arr 进行的任何操作，就是对 nums 的操作。你通过 arr 访问的堆内存，就是 nums 所管理的“堆上的数据 A”。

这就是为什么你的 `swap` 操作能够成功修改原始的 `nums` 向量。

------



### 总结：与 C 风格指针的区别

你可能是把 `vector` 和 C 风格的数组指针搞混了：

1. **C 风格指针 `int\* p`**：
   - `int* p = new int[4];`
   - `p` 变量本身**只存储一个地址**。
   - 当你按值传递 `void func(int* p_copy)` 时，你只是复制了这个**地址**。`p` 和 `p_copy` 都指向**同一块**堆内存。所以修改 `p_copy[i]` 也会影响 `p[i]`。
2. **C++ `vector`**：
   - `vector<int> v(4);`
   - `v` 是一个**完整的“管理器”对象**，它内部*包含*一个指针，但它远不止是一个指针。
   - 当你按值传递 `void func(vector<int> v_copy)` 时，C++ 会执行**深拷贝 (Deep Copy)**，复制 `v` 的管理器，并**复制它所管理的所有堆数据**。

结论：

在 C++ 中，vector 被设计为具有“值语义”（value semantics）。这意味着当你复制它时，你会得到一个全新的、独立的副本。这在很多情况下是安全的，但在你需要修改原件或希望避免昂贵复制开销（比如排序一个大数组）时，你必须使用引用（&）。
