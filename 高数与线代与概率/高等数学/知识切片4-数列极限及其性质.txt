讲了数列极限的定义，数列极限的判定方法，数列极限的性质。


1、数列极限的定义
数列极限的形式：lim ( an )=a；
                            n->
提示：
（1）数列极限中的自变量为>0,且是取整数。
（2）借助数轴来帮助理解数列极限式子。当n>N时（n和N都是为正整数的），后面的无数个点都落在a附近的一个区域内，a区域外面是有有限个点的。
（3）数列极限存在与数列的前有限项无关，意思就是这个常数（数列极限就是为一个常数的）只与数列极限的某一个变化过程有关，而与这个变化过程前的有限项是没有关系的，这个变化过程指的就是为n>N时，这个变化过程的前有限为n<N,即是这个常数（数列极限）是什么与n<N前面的是没有任何关系的。

2、数列极限的判定
lim an=A 《=》lim a2n=lim a2n+1=A
提示：
（1）数列an收敛于A的话，则其任意一个子数列也收敛于A（子数列的意思就是将原来的数列按照某种规则所抽出来的项所构成的一个新的数列，这个规则可以是2n，2n+1，3n，3n+1,3n+2,……）。
（2）反过来由数列an的子数列存在也是可以推出原数列an极限存在，但是所选取的这些子数列必须要覆盖原来所有的值。

数列极限是否存在的判定方法：
（1）直接对原数列在 n->正无穷 求极限，如果求的结果为一个数的话，则说明数列极限存在。
（2）求这个数列的若干个子数列的极限（这若干个子数列必须全部覆盖原数列中的每一项），若个若干个子数列的极限都存在并且相等的话，则说明原数列极限存在，且原数列的极限就是这若干个子数列的极限。
选取的能够将原数列全部覆盖掉的子数列：
《1》lim a2n，lim a2n+1
《2》lim a3n，lim a3n+1，lim a3n+2
技巧：联系到C语言中的数组下标，3n就是数列的第1*k项，3n+1就是数列的第2k项，3n+3就是数列的第3k项。

3、数列极限的性质
（1）唯一性：设lim an=A，lim an=B，则A=B。
理解：从数列极限的数轴理解来帮助分析数列极限唯一性这个性质，lim an=A则说明了当某一个变化过程（n>N时）内的所有点都落在A附近的一个区域内，同理lim an=B说明了当某一个变化过程内的所有点也是都落在B附近的一个区域内。说明了A区域外是有有限个点的，同理B区域外有无限多个点，B区域内有有限多个点，则只能够是A与B相等。
（2）保号性
《1》若lim an=A>0，则存在正整数N，当n>N时，an>0。
理解：借助数轴来进行理解，在数轴>0的地方有一点A，在A的区域范围内有无限多个点，这无限多个点对应的数列值都是>0的。同理lim an=A<0,则存在正整数N，当n>N时，an<0也是一样的。

《2》若an>0且数列an的极限存在（即lim an=A），则A>=0。
理解：记住一个特殊数列1/n就可以了。

数列极限的保号性注意事项：
《1》极限都是与某一个变化过程有关的，可以简记为数列极限大于0，则数列大于0与变化过程有关。
《2》数列极限的保号性就是根据数列极限的正负来判断原数列在某一个变化过程中的正负的。注意lim an=A>0，即lim an>0这是为一个包含了极限式子的不等式的，可以通过数列极限的保号性来得到一个不包含极限式子的不等式，即an>0。
《3》应用场景，题目给的是极限的信息，要去解决不等式的问题时（不等式不包含极限式子），则用到的是保号性。
《4》数列极限的保号性就是根据数列极限的正负来得到数列的一些东西，根据数列的正负来得到数列极限的正负的一些东西的。

（3）有界性
定理：若lim an=A，则数列 { an }一定有界。


蕴含真值表：
A   B    结果
0   0      1
0   1      1 
1   0      0
1   1      1
技巧：借助离散数学中的知识来帮助理解一些定理及其一些变形。
离散数学中的命题逻辑中的“若……，则……”对应的是蕴含（->）,这里将A当成是lim an=A，将B当成是数列 { an }一定有界。则定理的命题符号化对应“A->B”,当A为1时，B必须为1整个式子才是真；当B为0时，A必须为0整个数字才是真；当B为1时，A可能为1，可能为0。这刚好对应了下面的2条推论。
《1》若数列 { an }无界，则 { an }极限不存在，即 { an }发散。
《2》若数列 { an }有界，不能推出 { an } 极限存在（极限可能存在，可能不存在）。


题型：
1、在选择题中考察数列极限的性质。
解题思路：
（1）最长考察的就是“收敛数列与其子数列的关系”。
即“数列xn收敛 《====》lim (n--->∞) x2n = lim (n--->∞) x（2n-1）”。
选取的能够将原数列全部覆盖掉的子数列：
《1》lim a2n，lim a2n+1
《2》lim a3n，lim a3n+1，lim a3n+2
技巧：联系到C语言中的数组下标，3n就是数列的第1*k项，3n+1就是数列的第2k项，3n+3就是数列的第3k项。
注意：由于数列极限与其前有限项无关，故只要当n>N时，选取的子数列能够将原数列全部覆盖，则就可以了。

（2）数列极限与前有限项无关。
即“lim (n--->∞) xn = lim (n--->∞) x ( n+1000 ) ”。（n是从1开始取的，故 x ( n+1000 ) 相比较于 xn 就是，从第1001项开始的，少了前1000项）

（3）数列有界与数列极限存在的关系。
数列 xn 的极限  lim (n--->∞) xn   存在  ====》数列 xn 有界。

注意：只要记住这一个最基本的公式就可以了，其他所有的推论都是在这个式子的基础上得来的。如“数列xn无界 ====》数列 xn 的极限  lim (n--->∞) xn   =  ∞”；“数列xn有界 ==（不能）==》数列 xn 的极限  lim (n--->∞) xn   存在”（这就是数列的 单调有界原理====》数列极限存在）

2、判断一个数列 xn 是否有界，是否无界。
解题思路：
（1）判断一个数列xn是否有界。
计算 lim (n--->∞) xn ，若这个数列的极限存在，则就说明了这个数列xn有界。

（1）判断一个数列xn是否无界。
计算 lim (n--->∞) xn ，若这个数列的极限不存在（且是不存在中的 ∞），则就说明了这个数列xn无界。


3、题目给的是数列极限的信息，要去解决不等式的问题时（不等式不包含极限式子）。
解题思路：想到使用数列极限的保号性。由数列 xn 的极限 lim (n--->∞) xn = a，这个a的正负（注意，当a为+∞，也是>0 ；当a为-∞，也是为<0），判断出xn是>0，还是<0。然后在进一步解决问题。
