

1、什么是函数展开成幂级数：
在幂级数的收敛域（-R，R]内，有 ∑(n=0，n=∞) an x^n = f(x)，由左边幂级数“∑(n=0，n=∞) an x^n”到右边函数“f(x)”的过程就叫做求这个幂级数的和函数，由右边函数“f(x)”到左边幂级数“∑(n=0，n=∞) an x^n”的过程就叫做“函数展开成幂级数”。


2、两个问题：

（1）函数f(x) 能够展开成幂级数需要满足什么条件。

假设f(x)可以展开成幂级数，即
f(x) = a0 + a1(x-x0) + a2(x-x0)^2 + ……+ an(x-x0)^n + a(n+1)(x-x0)^(n+1) + ……  = ∑(n=0，n=∞) an x^n 。

对f(x)求n阶导得到：
f^n (x) = n! an + (n+1)! a(n+1) (x-x0) + (n+2)!/2! a(n+2) (x-x0)^2 + ……
令 x=x0 ，得到：
f^n (x0) = n! an  ====》an = f^n (x0) / n! （n=0,1,2，……）。

∑(n=0，n=∞) an x^n = f(x)
要想满足上面这个式子，我们先求出无穷级数 ∑(n=0，n=∞) an x^n 的和，即先求出其前（n+1）项和Pn(x) ；
Pn(x) = a0 + a1(x-x0) + a2(x-x0)^2 + ……+ an(x-x0)^n + a(n+1)(x-x0)^(n+1)；
然后对Pn取的极限 lim (n-->∞) Pn(x) ；
此时就会有 lim (n-->∞) Pn(x) = ∑(n=0，n=∞) an x^n。
即要满足 lim (n-->∞) Pn(x) = f(x)。

条件为 lim (n-->∞) Pn(x) = f(x)；
结合着 f(x)的 泰勒展开的式子：f(x) = Pn(x) + Rn(x)；
可以推出 lim Rn(x) =0。

故函数f(x)能够展开成幂级数的条件为：
①f(x)具有任意阶导数（从0阶--->∞阶）；
②lim (n-->∞) Pn(x) = f(x)  或者 lim Rn(x) =0 。

因此，以后如果一个函数f(x)在区间T上满足任意阶可导（0--∞阶都可导），且其在区间T上的泰勒展开式 f(x)=Pn(x)+Rn(x) 满足lim Rn(x) =0 的话，则这个函数f(x)在这个区间T上就可以展开成幂级数Pn(x)。

当函数f(x)在区间T上能够展开成幂级数时，此时其每一项 (x-x0)^n 前的系数an就为：
an = f^n (x0) / n! （n=0,1,2，……）。
注意：0阶导相当于就是不求导的意思，即 f(0) (x0) = f(x0)

（2）在函数f(x)满足了这个条件的基础上，要将其如何在区间T上展开成幂级数。（即是“如果一个函数f(x)可以在区间T上满足任意阶可导（0--∞阶都可导），且其在区间T上的泰勒展开式 f(x)=Pn(x)+Rn(x) 满足lim Rn(x) =0 的话，则这个函数f(x)在这个区间T上就可以展开成幂级数Pn(x)。”）

《1》直接展开法
① 先看一下f(x)在区间T上是否有任意阶导数（0--∞阶）。
如果f(x)在区间T上没有任意阶导数的话，则 f(x) 就没有办法展开成泰勒级数，也就没有办法展开成幂级数。
如果f(x)在区间T上具有任意阶导数的话，就转去执行②。

②求出 f(x) 的 0阶---n阶导数，即 “f(x0)，f'(x0)，f''(x0)，……，f^n(x0)”。

③求出了“f^n(x0)”之后，就可以写出这个幂级数“∑(n=0，n=∞) an (x-x0)^n ”，同时求出这个幂级数的收敛半径R。

④验证 f(x)的泰勒展开式“f(x)=∑(n=0，n=∞) an (x-x0)^n +Rn(x)”中的余项Rn(x)是否满足 lim(n-->∞)  Rn(x) =0，如果是的话，则f(x)在区间T上展开的幂级数“∑(n=0，n=∞) an (x-x0)^n” 。
我们常常使用的余项 Rn(x) 为 拉格朗日余项，我们其实验证的就是 lim(n-->∞)  f^n+1 (x1) / (x-x0)^(n+1)，我们是看这个极限式子是否为0的。


《2》间接展开法
通过一定运算将函数转化为已知展开式的函数，进而利用已有函数的展开式将原来函数展开称为幂级数的方法。

常见函数的展开式：（利用等价无穷小的式子进行移项来进行记忆）
e^x =  ∑(n=0，n=∞) 1 / n！x^n（-∞<x<+∞）
sin x = ∑(n=0，n=∞) (-1)^n / (2n+1)! x^(2n+1) （-∞<x<+∞）
cos x = ∑(n=0，n=∞)  (-1)^n / (2n)!  x^2n （-∞<x<+∞）
1 / ( 1 -x ) = ∑(n=0，n=∞)  x^n （-1<x<1）
1 / ( 1+x ) = ∑(n=0，n=∞) (-1)^n x^n （-1<x<1）
ln (1+x) = ∑(n=1，n=∞) (-1)^(n-1) x^n / n（-1<x≤1）

记忆：
e^x 与 sin x 的形式很像，记住了 e^x 的泰勒展开之后，也就记住了 sin x 的泰勒展开。
cos x 的泰勒展开不用记忆，直接对 sin x 求导就可以得到。
1 / ( 1+x ) 的泰勒展开很容易记忆，将x变成-x之后就变成了 1 / ( 1+x ) 的泰勒展开，因此 1 / ( 1+x ) 的泰勒展开也不需要记忆。
ln (1+x) 的泰勒展开也不需要记忆，直接对 1 / ( 1+x ) 的泰勒展开进行积分就可以得到，直接进行积分得到的是“∑(n=0，n=∞) (-1)^n x^(n+1) / (n+1)”，将求和符号“∑(n=0，n=∞)”变换成“∑(n=1，n=∞)”后为“∑(n=1，n=∞) (-1)^(n-1) x^n / n”。
由于积分和求导不会改变正负号，故由 sin x 求导得到 cos x，由 1 / (1+ x) 进行积分得到 ln(1+x)，都是不会改变正负号的，即 (-1)^n 没有影响。

注意：这里的常见幂级数的展开式其实就前面的泰勒展开式，只不过泰勒展开式比其多了一个余项而已，两者可以结合在一起记忆。

解释：为什么 ln (1+x) 展开成幂级数后自变量x的取值范围变成了 -1<x≤1，即包含了“=1”。ln (1+x) 在x=1这一点处是有定义的，其展开成幂级数之后的收敛半径为1，即“-1<x<1”，这不是幂级数的收敛域的，由于端点 1 在函数 ln（1+x）中是有定义的，故还需要考虑端点处的1是否收敛，这里幂级数 ∑(n=0，n=∞) (-1)^(n-1) x^n / n 显然在x=1处是收敛的，故将这个函数f(x)展开成幂级数之后需要包含端点处的1。
 


1、函数展开成幂级数的概念
给定函数f(x)，如果能够找到一个幂级数，它在某区间内收敛，其和恰好就是给定的函数f(x)，我们就说函数f(x)在该区间内能展开成幂级数。
 

2、函数展开成幂级数的充要条件
定理：设函数f(x)在x0的某一邻域U(x0)内具有各阶导数，则f(x)能展开成泰勒级数的充分必要条件是在该邻域内f(x)的泰勒公式中的余项 Rn(x) 当n---->∞时的极限为零，即 lim n-->∞  Rn(x)=0，x∈U(x0)。



理解：
①泰勒公式的定义：如果函数f(x)在某一点x0处有 n 阶导数的话，且对于包含了x0的区间（a，b）内的每一点，f(x)都有n阶导数的话，则对于（a，b）内的任意一点，都有f(x)=f(x0)+ f'(x0)/1! (x-x0)+ f''(x0)/2! (x-x0)^2+ f'''(x0)/3! (x-x0)^3+ f^4(x)(x-x0)/4! (x-x0)+…………+f^n(x0)/n! (x-x0)^(n)+Rn(x) (x->x0)。
②f(x)在区间I上展开成幂级数时每一项前的系数an依次为“f^n (x0) / n! （n=0,1,2，……）”，刚好和这里的泰勒展开相对应。当f(x)具有∞阶导数的时候，此时将函数f(x)按照泰勒展开后为
f(x) ≈ f''(x0)/2! (x-x0)^2+ f'''(x0)/3! (x-x0)^3+ f^4(x)(x-x0)/4! (x-x0)+…………+f^n(x0)/n! (x-x0)^(n) + …… + Rn(x) ，此时如果余项 Rn(x) =0，我们就将这个函数f(x)展开成了一个无穷多项的级数相加。即函数f(x)展开成了一个幂级数。我们常常采用的余项为拉格朗日余项，当n--->∞时，n+1--->∞，对应的拉格朗日余项为“Rn(x)=f^n+1 (x1) / (x-x0)^(n+1)”，如果
lim (n--->∞) Rn(x) = lim (n--->∞) f^n+1 (x1) / (x-x0)^(n+1) =0，此时 f(x) =  ∑(n=0，n=∞) an x^n，即此时f(x)就展开成了一个幂级数。


题型：
1、将函数 f(x) = (1-x) ln (1+x) 展开成x的幂级数。
解题思路：借助 ln (1+x)的幂级数的展开式“ ∑(n=1，n=∞) (-1)^(n-1) x^n / n（-1<x≤1）”来解决。
因为 ln(1+x) = ∑(n=1，n=∞) (-1)^(n-1) x^n / n（-1<x≤1）
所以 f(x) = ( 1-x ) ln ( 1-x ) = ( 1-x )  ∑(n=1，n=∞) (-1)^(n-1) x^n / n = ∑(n=1，n=∞) (-1)^(n-1) x^n / n - ∑(n=1，n=∞) (-1)^(n-1) x^(n+1) / n （-1<x≤1）


***处理技巧1：
遇见了 ∑(n=1，n=∞)  an x^(n+1) ，要转化为 ∑(n=1，n=∞) an x^n，即是将“x^(n+1)”转化为“x^n”。
可以通过变量换元的方式。
“令 n+1=m”====》“n=m-1”；
“∑(n=1，n=∞)  ”====》“∑(m=2，m=∞)  ”。
将“∑(n=1，n=∞)  an x^(n+1) ”中所有的都用m来替换掉（n=m-1）：∑(m=2，m=∞)  am x^m。
最后统一将字母m给替换成n： ∑(n=2，n=∞)  an x^n。（注意，这里的an和一开始的时候的不一样）

 
因此，f(x) = ∑(n=1，n=∞) (-1)^(n-1) x^n / n -  ∑(n=2，n=∞) (-1)^(n-2) x^n / (n-1)。


***处理技巧2：
遇见了 ∑(n=1，n=∞)  (-1)^(n-1) x^n - ∑(n=1，n=∞)  (-1)^(n-2) x^n，要想合并必须将两个级数的  (-1)^ 的指数变成一样的。
可以采用对  某项(-1)^(n-1)分离出-1，此时该项前面会乘以一个 ( -1 ) ，该项 (-1)^(n-1) 的指数会减去一个数 ；可以采用对 某项(-1)^(n-2)多乘以 (-1)(-1)，该项指数会增加一个数。
这里将 (-1)^(n-1) 与 (-1)^(n-2) 保持一致，对 (-1)^(n-2) 乘以 (-1) (-1)，一个 (-1) 保证相减变成相加，一个(-1)保证将“ (-1)^(n-2) ”变成“ (-1)^(n-1) ”。
最后变成了“∑(n=1，n=∞)  (-1)^(n-1) x^n + ∑(n=1，n=∞)  (-1)^(n-1) x^n”，就可以对这两个级数进行合并了。


因此，f(x) = ∑(n=1，n=∞) (-1)^(n-1) x^n / n +  ∑(n=2，n=∞) (-1)^(n-1) x^n / (n-1)。


***处理技巧3：
当幂级数 ∑(n=0，n=∞) an x^n 中求和符号“∑(n=0，n=∞)” 与 幂级数 ∑(n=1，n=∞) an x^n 中求和符号“∑(n=1，n=∞)”不一致时，此时必须将这两个求和符号变成一致才可以合并。
将“∑(n=0，n=∞)”分成“n=1时 + ∑(n=1，n=∞)”，此时“ ∑(n=0，n=∞) an x^n +  ∑(n=1，n=∞) an x^n = n为1时 + ∑(n=1，n=∞) an x^n ∑(n=1，n=∞) an x^n”，就可以合并了。

因此，f(x) =  ∑(n=1，n=∞) (-1)^(n-1) x^n / n +  ∑(n=2，n=∞) (-1)^(n-1) x^n / (n-1) = x +  ∑(n=2，n=∞) (-1)^(n-1) x^n / n +  ∑(n=2，n=∞) (-1)^(n-1) x^n / (n-1)
                 =  ∑(n=1，n=∞) (-1)^(n-1) [ 1/n + 1/(n-1) ]x^n 。
                 =  ∑(n=1，n=∞) (-1)^(n-1) [  ( 2n-1 ) / n(n-1) ]x^n 。


***处理技巧4：
由于f(x)是通过 ln(1+x) 来展开的，故f(x)借助 ln(1+x)展开的幂级数在“-1<x≤1”上也是收敛的。
接下来，还需要判断 在端点“x=-1”处 f(x)是否有定义，f(x)展开的幂级数在 x=-1 处是否是收敛的（f(x)展开的幂级数在x=-1处，变成了一个数项级数，常常是为正项级数或者交错级数，故此时可以利用前面总结过的 正项级数判断敛散性，交错级数判断敛散性的方法 来去判断这个数项级数的敛散性）。
如果 f(x) 在端点“x=-1”处有定义，f(x)展开的幂级数在 x=-1 处是收敛的话，那么“-1”这一点也要包括，此时 f(x)展开的幂级数中自变量x的取值范围“-1≤x≤1”。
如果 f(x) 在端点“x=-1”处没有定义 或者 f(x)展开的幂级数在 x=-1 处是发散的话，那么“-1”这一点就不需要包括，此时 f(x)展开的幂级数中自变量x的取值范围“-1＜x≤1”


处理技巧5：
如果f(x) 既通过了 1/1+x 来展开，又通过了 1/(x+3) 来展开，则此时的 f(x)所展开的幂级数在 区间T 上是收敛的，这个区间T就是  1/1+x 和 1/3+x 这两个函数所展开的幂级数的收敛域的交集。

因，f(x)在-1处没有定义。故f(x)展开的幂级数的收敛域为 -1＜x≤1。
即 f(x)   =  ∑(n=1，n=∞) (-1)^(n-1) [  ( 2n-1 ) / n(n-1) ]x^n  （-1＜x≤1）。


2、 将函数 f(x) = 1/(x^2 + 4x +3)展开成（x-1）的幂级数。
解题思路：

处理技巧5：
当题目中的f(x)不是 常见的可以进行展开的函数的形式“e^x，sin x，cos x，1/(1+x)，1/(1-x)”时，我们此时可以对f(x)做适当的变形，使其变成可以进行展开的函数形式。
如对分式的函数 f(x) = 1/(x^2 + 4x +3)，可以进行拆分最终往“1/(1+x)，1/(1-x)”的方向转化，为 f(x) =  1/(x^2 + 4x +3) = 1/2  [ 1/(x+1 - 1/(x+3) ]，接下来就可以分别将 1/(x+1 和 1/(x+3)进行展开了。

对f(x)拆项，为 f(x) = 1/(x^2 + 4x +3) = 1/2  [ 1/(x+1） - 1/(x+3) ]。


处理技巧6：
如果函数 f(x) 是要展开成x的幂级数，则可以借助的函数的形式为“e^x，sin x，cos x，1/(1+x)，1/(1-x)”。
如果函数 f(x) 是要展开成（x-x0）的幂级数，则可以借助的函数的形式为“e^(x-x0)，sin (x-x0)，cos (x-x0)，1/ [ 1+(x-x0) ]，1 / [ 1-(x-x0) ]”。

因此，如果给出我们的函数f(x)为“ 1/(1+x）”，要将f(x)展开成“x-1”的幂级数，则需要凑出“1 / [ 1+(x-1) ]”的形式，为：
“1/(1+x）= 1 / [ 2+(x-1) ] = 1/2 × [ 1 / [ 1+(x-1)/2 ] ] = 1/2 ∑(n=0，n=∞) (-1)^n [ (x-1)/2 ]^n”。
同时要注意其收敛域为 | (x-1)/2  | < 1。

因此，如果给出我们的函数f(x)为“1/(x+3) ”，要将f(x)展开成“x-1”的幂级数，则需要凑出“1 / [ 1+(x-1) ]”的形式，为：
“1/(3+x）= 1 / [ 4+(x-1) ] = 1/4 × [ 1 / [ 1+(x-1)/4 ] ] = 1/4 ∑(n=0，n=∞) (-1)^n [ (x-1)/4 ]^n”。
同时要注意其收敛域为 | (x-1)/4  | < 1。

因此，f(x) =  1/2  [ 1/(x+1） - 1/(x+3) ] = 1/2 [ 1/2 ∑(n=0，n=∞) (-1)^n [ (x-1)/2 ]^n + 1/4 ∑(n=0，n=∞) (-1)^n [ (x-1)/4 ]^n ]
	=   ∑(n=0，n=∞) (-1)^n [ ( 1/2^(n+2) - 1/2^(2n+3) ] （x-1)^n  （-1＜x<＜3）
注意：收敛区间取 | (x-1)/2  | < 1 与 | (x-1)/4  | < 1 的交集。x^n 形式幂级数的收敛区间是对称的，但是 ( x-x0 )^n 形式幂级数的收敛区间一般是不对称的）

最后，验证端点 -1 和 3，发现 f(x) 在-1和3处都没有定义，故不取，其收敛域为“-1<x<3”。


3、将函数 f(x) = arctan x 展开成x的幂级数。
解题思路：

处理技巧7：
如果函数f(x)不能够通过变换 ，使其可以变成能够进行展开的函数形式“e^x，sin x，cos x，1/(1+x)，1/(1-x)”的话。此时，我们可以考虑对函数f(x) 求个导或者积个分，求他的 导函数（求导）或者原函数（积分）展开成的幂级数。利用“对幂级数求导或者积分，等于对它的每一项逐项求导，逐项积分”的原则，求了导的就给它积会去，积了分的就给它导回去，这样就可以得到函数f(x)展开成的幂级数了。

对f(x)求导， f ' (x) = 1/(1+x^2)。
将 f ' (x) 展开成对应区间上的幂级数，为 f '(x) = 1/(1+x^2) = ∑(n=0，n=∞)  (-1)^n (x^2)^n =  ∑(n=0，n=∞)  (-1)^n x^2n。
对 f'(x) 在 0---x 上积个分，求出f(x)，为：f(x) - f(0) = ∫ (0----x) f ' (t) dt。
f(x) - f(0) =  ∫(0----x) ∑(n=0，n=∞)  (-1)^n t^2n dt，  
f(x) - f(0) = ∑(n=0，n=∞) ∫(0----x) (-1)^n t^2n dt，
f(x) - f(0) = ∑(n=0，n=∞) ∫(0----x) (-1)^n t^2n dt，
f(x) - f(0) = ∑(n=0，n=∞) (-1)^n x^(2n+1) / (2n+1) ，
由于 f(0) = 0，
故 f(x) = ∑(n=0，n=∞) (-1)^n x^(2n+1) / (2n+1)。

由于 f(x) 是通过 “ 1/(1+x^2)”来进行展开的，故 f(x) 在区间（-1,1）上收敛。
讨论 -1和1，因为 ∑(n=0，n=∞) (-1)^n x^(2n+1) / (2n+1) 在-1和1处均收敛，且f(x)在-1和1处均有定义，f(x)展开成的幂级数的收敛域是包含 -1和1 这两个点的。
即 f(x) = ∑(n=0，n=∞) (-1)^n x^(2n+1) / (2n+1)     （-1≤x≤1）
