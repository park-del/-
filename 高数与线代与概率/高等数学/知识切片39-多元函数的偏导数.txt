1、偏导数的基本概念
由于二元函数f(x,y)是有两个自变量x和y的，故二元函数的导数是有两个的，一个是关于x的导数，一个是关于y的导数。函数f(x,y)关于x的导数就叫做函数f(x,y)对x的偏导数，函数f(x,y)关于y的偏导数就叫做函数f(x,y)对y的偏导数。

类比于一元函数，一元函数求在某一点x0的导数的形式有两种，分别为： f'(x0)= lim △x->0 [ f(x0+△x) - f(x0) ] /△x、f'(x0)= lim x->x0 [ f(x) - f(x0) ] / (x - x0)。二元函数也是有在某一点处的导数形式的，一元函数的自变量是为x轴上的一点x=x0的，而二元函数的自变量是为xoy面上的一点（x0，y0）的，故二元函数f(x,y)在某一点（x0，y0）处的关于x的偏数的形式为： f'(x0，y0)= lim △x->0 [ f(x0+△x，y0) - f(x0，y0) ] /△x、f'(x0，y0)= lim x->x0 [ f(x，y0) - f(x0，y0) ] / (x - x0)。

注意：求二元函数f(x,y)在某一点（x0，y0）处的关于x的偏导数的时候，和一元函数一样，也是通过定义来求的。求在（x0，y0）这一点关于x的偏导数就把y看做是常数，对x求导,f(x,y)在（x0，y0）这一点处的关于x的偏导数本质上就是求一元函数在某一点x=x0处的导数问题。（由于将y看成是了常数，故在计算二元函数f(x,y)在某一点（x0，y0）处的偏导数的时候是可以将y=y0先代入的，之后就转换成了 一元函数f(x)在某一点x=x0处的导数问题；也是可以先不带入y=y0的，再计算的过程中将y看成是常数，最后计算出结果时再将y=y0代入）

偏导函数：如果函数z=f(x,y)在区域D内每一点（x，y）处对x或者y的偏导函数都存在，则称fx(x,y),fy(x,y)为偏导函数。（就是对x求偏导的时候，把y看成是常数，对y求偏导的时候，把x看成是常数，其实就是一个一元函数的导数问题）

3、偏导数存在和连续的关系
多远函数在某一点处的偏导数存在（这里包含了多元函数在这一点关于x的偏导数存在和关于y的偏导数存在）推不出该函数在这一点处连续，函数在某一点处连续也推不出函数在这一点处的偏导数存在。
理解： 以二元函数为例，二元函数在某一点处的连续的充分条件是 lim (x->x0,y->y0) f(x,y)=f(x0,y0)，这里要求了（x，y）要以四面八方任意一条路径趋向于（x0，y0）时，都有这个关系。而二元函数在（x0，y0）处的关于x的偏导数为   lim (x->x0,y=y0) [ f(x，y0) - f(x0，y0) ] / (x - x0)，这里相当于已经确定了y=y0，并没有包含任意一条路径趋向于y0，故没有办法推出二元函数f(x,y)在该点（x0，y0）处连续。如果二元函数在该点（x0，y0）处关于x的偏导数和关于y的偏导数都存在也是没有办法推出二元函数f(x,y)在该点（x0，y0）处连续，也是没有包含四面八方的任意一条路径的。

题型：
1、求多元函数的偏导数（考试考小题）
（1）求多函数的偏导函数
解题思路：就是对x求偏导的时候，把y看成是常数，对y求偏导的时候，把x看成是常数，其实就是一个一元函数求导函数的问题。

（2）求多元函数在某一点处的偏导数。
解题思路：求对x的偏导数就把其他的等于几先带进去 。先变成一元函数，然后在看看一元函数在求这一点处的导数的时候，我是用导数的定义呢，还是直接求导代值。如果这个函数本身就是可导的函数，你就求完导代值。

理解：如果为三元函数f(x,y,z)=x+y+z的话，在某一点（1,2,3）处的关于x的偏导数。先将其他的（由于是关于x的偏导数，故这里的其他的指的是y=2，z=3先代入进去）先带进去，为f(x,2,3)=x+2+3,相当于就是为f(x)=x+2+3，就转换为了求一元函数f(x)在x=1处的导数问题，接下来考虑是用导数的定义，还是直接求导代值。

2、判断二元函数在某一点（x0，y0）处是否连续，偏导数是否存在。
（1）判断二元函数在某一点（x0，y0）处是否连续。
解题思路：首先根据总结的知识切片38中题型：判断二元函数f(x,y)在某一点（x0，y0）处的极限是否存在。如果二元函数f(x，y)在某一点（x0，y0）处的极限不存在的话，则就直接得出了二元函数f(x,y)在该点（x0，y0）处不连续；如果二元函数f(x,y)在某一点（x0，y0）处的极限存在的话，算出极限值（就是为知识切片38中的题型1，计算二元函数的极限），与f(x0,y0)相比较，如果相等的话就说明了二元函数f(x,y)在该点（x0，y0）处连续，如果不相等的话就说明了二元函数f(x,y)在该点（x0，y0）处不连续。


（2）判断二元函数在某一点（x0，y0）处偏导数是否存在。
解题思路：二元函数在某一点（x0，y0）处偏导数存在，既包含了二元函数在该点（x0，y0）处的关于x的偏导函数存在，又包含了二元函数在该点（x0，y0）处的关于y的偏导数存在。以关于x的偏导数为例，由于牵涉到了一点导数的问题，故是可以使用二元函数在某一点处的导数的定义来判断在该点处关于x的偏导数是否存在的，即如果 lim x->x0 [ f(x，y0) - f(x0，y0) ] / (x - x0) 这个极限存在的话，则说明了二元函数在该点（x0，y0）处的关于x的偏导数存在。

另一种解题思路（由于判断二元函数在某一点（x0，y0）处的偏导数是否存在常常是为小题的，故可以使用这个解题思路来快速解决）：由于这里牵涉到了多元函数在某一点处的导数问题，故在判断二元函数在某一点（x0，y0）处关于x的偏导数的时候可以将其他的先带入（二元函数就是将y=y0先代入进去），转化为f(x,y0)=关于x的表达式，即是求f(x,y0)=关于x的表达式 在x=x0处的导数是否存在的问题，如果存在的话，就说明了二元函数f(x,y)在（x0，y0）处的关于x的偏导数存在；如果不存在的话，就说明了二元函数f(x,y)在（x0，y0）处的关于x的偏导数不存在。同理对于判断二元函数在（x0，y0）关于y的偏导数是否存在也是一样的。

3、求多元函数的高阶偏导数（考察多元函数的高阶偏导数一般考察的就是求二元函数的二阶偏导数）
解题思路：二元函数的二阶偏导数只有四个，分别为 f''11，f''12，f''21，f''22，按照顺序一步一步求就可以了。这里有一个技巧，如果二元函数f(x,y)是为一个多元初等函数的话，那么这个二元函数f(x,y)的二阶偏导数（即是f'1和f'2）在定义区间D就是连续的，此时的f''12=f''21，如果题目中让你求的是f''12，那么既可以先求f'1，再求f'2，也是可以先求f'2，再求f'1的，哪个方便就先求哪个。如果题目中让你求的是f''21也是一样的。（如果题目中给你的不是具体的初等函数的话，而是抽象函数的话，让你求的是抽象二元函数的二阶偏导数，一般会告诉你f(x,y)是一个二阶连续的偏导数，此时的 f''12，f''22也是相等的）

注意：一旦题目中给出了你二元函数f(x,y)是为一个二阶连续偏导数的话（可以为具体的多元初等函数，或者是，抽象的二元连续函数告诉了你f(x,y)是为一个二阶连续偏导数），此时有两点注意事项： f''12=f''21，求 f''12，f''21时挑选合适的次序； f''12，f''21要进行合并。


4、求多元复合函数的偏导数问题。（考察多元复合函数的偏导数问题通常考察的就是二元复合函数的偏导数）
理解：二元复合函数，首先二元就是说是有两个自变量的，将这两个自变量记为u和v，则二元函数就为f(u,v)，由于是为一个复合函数，故这里的自变量u和v也是为一个函数的。当这里的自变量都是为一个一元函数的话，如u=f(t)，v=f(t)，就称二元函数f(u,v)是为一元函数与二元函数复合；当这里的自变量是为一个二元函数的话，如u=f(x,y)，v=f(x,y)，就称二元函数f(u,v)是为二元函数与二元函数复合的情形。

（1）二元函数z=f(u,v)，u和v都是关于同一个自变量的t的一元函数，求dz/dt。
解题思路：由于z是关于u和v的二元函数，故对u和v使用的是偏导；由于z是关于t的一元函数，故对t使用的是一元导 dz/dt。
方法一：直接将u=f(t)，v=g(t)代入到z=f(u,v)中，转换为z=h(t）对t求一阶导的问题。
方法二：采用链式法则，从z到t是有两条路的，则 dz/dt= 偏z/偏u * du/dt + 偏z/偏v * dv/dt，最后在将u和v代入就行了。

（2）二元函数z=f(u,v)，u和v都是关于x和y的一个二元函数，求 偏z/偏x。
解题思路：采用链式法则，从z到x有两条路，分别是 z--->u---->x 和 z--->v--->x。则 偏z/偏x = 偏z/偏u * 偏u/偏x + 偏z/偏v * 偏v/偏x。

注意：题目中给出的一个二元函数 z= 关于x和y的表达式，这个关于x和y的表达式，可 能是具体的函数与一元函数与二元函数相结合的一个式子，如果见到有f(什么)，由于只有一个自变量，就是为一元抽象函数的，如果见到有f(什么，什么)，由于有两个自变量，则就是为二元函数的。此时求 偏z/偏x，则具体函数就是按照具体函数的求导法则求，一元函数按照一元函数对x的求导法则求，其他出现的自变量当成是为常数就可以了，二元函数就求其关于x的偏导数就行了。

注意：二元函数f(u,v)求关于u的偏导数的时候可以记为f'1，或者f'1(u,v)。带不带这个括号都是可以的，但是如果在此基础上在往上求f''11或者f''12的话，则一般求出的f'1(u,v)带上这个括号，因为方便观察，在求f''11或者f''12的时候不容易出错。
