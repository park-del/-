 
n阶线性微分方程的引入:

将 f(x) 看成是为常数（即是将关于x的一个函数，不包含y），由高阶依次到低阶，最后再到常数 所构成的方程（到达的最低阶为0阶，即y）。

一阶线性微分方程：y' + p0(x) y = f(x).
二阶线性微分方程：y'' + p1(x) y' + p0(x) y = f(x).
三阶线性微分方程：y''' + p2(x)y'' + p1(x)y' +p0(x)y = f(x).
……………………………………………………
n阶线性微分方程：y^(n) + pn-1(x)y^(n-1) + pn-2(x)y^(n-2) + …… + p1(x)y' + p0(x)y = f(x)。


1、二阶线性微分方程的定义
方程 y''(x) + p(x)y' +q(x)y = f(x) 叫做二阶线性微分方程。当方程右端 f(x)≡0时，称为二阶齐次线性微分方程，否则称为二阶非齐次线性微分方程。


2、线性微分方程解的结构
（1）定理1：如果 y1(x)，y2(x) 均是 y'' + p(x)y' +q(x) = 0 的解，则 c1y1(x) + c2y2(x) 也是该方程的解，其中 c1，c2 为任意常数。


理解：即 齐次线性微分方程（定理1中是以二阶齐次线性微分方程为例） 的解的线性组合仍然是这个齐次线性微分方程的解。将“c1y1(x) + c2y2(x)”代入到“y'' + p(x)y' +q(x) = 0”中，得到“[ c1y1(x) + c2y2(x) ]'' + p(x)[ c1y1(x) + c2y2(x) ]' + q(x) = 0”,即“c1(  y1'' + p(x)y1' +q(x) ) + c2(  y2'' + p(x)y2' +q(x) ) = 0”。

注意：“线性齐次微分方程”解的线性组合仍然为“齐次线性微分方程”的解。（这里的解可以是为齐次线性微分方程的通解，也可以是为齐次线性微分方程的特解的）


函数相关、无关的定义：
设 y1(x)，y2(x)，……，yn(x) 为定义在区间I上的n个函数，如果存在n个不全为零的常数 k1，k2，……，kn ，使得当 x∈I 时有恒等式 “k1y1 + k2y2 + …… +knyn = 0”成立，那么就称这n个函数在区间I上线性相关，否则称线性无关。

理解：存在不为0的常数，假设为k1，则 y1能够由其他的函数来线性表示出来。线性相关的定义指的就是“我们能够找到一个函数，时的这个函数能够由其他的函数来线性表示出来”，如果我们不能够找到一个函数，使其由其他函数线性表示出来的话，则这些函数就是线性无关的。

（2）定理2：如果函数 y1(x)，y2(x) 是二阶齐次线性微分方程  y'' + p(x)y' +q(x) = 0 的两个线性无关的特解，则 y=c1y1(x) + c2y2(x) （c1，c2位任意常数）是该方程的通解。

理解：根据定理1，函数 y1(x)，y2(x) 是方程 y'' + p(x)y' +q(x) = 0 的两个线性无关的特解，则它们的线性组合 y = c1y1(x) + c2y2(x) 也是为该方程 y'' + p(x)y' +q(x) = 0 的解的。由于这是一个二阶的微分方程，且这个解中又是含有两个任意常数 c1，c2 的，故 y = c1y1(x) + c2y2(x) 也是为该方程 y'' + p(x)y' +q(x) = 0 的通解。（两个线性无关的解 类比于 线性代数中的基础解系）

推论（可以类比推广到n阶）：如果 y1(x)，y2(x)，……，yn(x) 是n阶齐次线性微分方程的n个线性无关的解，那么该方程的通解为 y≡c1y1(x) + c2y2(x) + …… +cnyn(x)，其中c1，c2，……，cn为任意常数。

（3）定理3：设y1(x)，y2(x) 是二阶非齐次线性微分方程 y'' + p(x)y' +q(x) = f(x) 的两个解，则 y1(x)-y2(x)是方程 y'' + p(x)y' +q(x) = 0 的解。

理解：将“y1(x)与y2(x)”带入到“y'' + p(x)y' +q(x) = f(x)”得到“ y1'' + p(x)y1' +q(x) = f(x) ” 和“y2'' + p(x)y2' +q(x) = f(x)”,相减化简之后为“f(x)-f(x)=0”。因此“非齐次的解 - 非齐次的解 =齐次的解”，反过来就是“非齐次的解=齐次的解+非齐次的解”。


（4）定理4：设 y* 是二阶非齐次线性方程 y'' + p(x)y' + q(x)y = f(x) 的一个特解，y~ 是方程 y'' + p(x)y' + q(x)y = 0  的通解，则 y = y~+y* 为非齐次线性微分方程的通解。

注意：非齐通解=齐次通解+非齐次特解。


（5）定理5：设非齐次线性方程 y'' + p(x)y' + q(x)y = f1(x) + f2(x)，若 y1* 是 y'' + p(x)y' + q(x)y = f1(x) 的解， y2* 是 y'' + p(x)y' + q(x)y = f2(x) 的解，则 y1*+y2*是原方程的解。



题型：

y'' + p(x)y' + q(x)y = f(x)只考解的结构，不考求解（考察的是小题）。
y'' + py' + qy = f(x) 才会考察求其通解，这是后一个知识切片中的“二阶常系数微分方程”。


1、告诉你 抽象的线性无关的函数 y1、y2、y3 是为非齐次线性方程组“ y'' + p(x)y' + q(x)y = f(x)”的特解，让你这个非齐次线性方程组的通解。
解题思路：首先对各选项进行变形，化为 C1()+C2()+yi 的形式，即是将所有具有相同任意常数Ci的项给放在一起。然后观察 Ci() 中（）里面的，如果是为类似于 y1-y2，2y1-2y2 的，则对应的就是齐次线性方程组“ y'' + p(x)y' + q(x)y = 0”的特解；如果是为类似于 4y1+5y2  的，则对应的就是非齐次线性方程组“ y'' + p(x)y' + q(x)y = 4f(x) + 5f(x)”的特解。找到为 齐次通解+非齐次特解 的选项就是为要选的。

知识储备：
①根据将“特解或者通解”代入到对应的“齐次线性微分方程”或者“非齐次线性微分方程”中后“方程=”右边的值为多少来理解“齐次到齐次、非齐次到齐次、非齐次到非齐次的转化关系”。

②假设 y1，y2，y3是齐次线性方程的“y'' + p(x)y' + q(x)y = 0”特解，则就说明了y1代入“y'' + p(x)y' + q(x)y”后为0，y2代入“y'' + p(x)y' + q(x)y”后为0。
此时 ，y1- y2 就是“y'' + p(x)y' + q(x)y = 0”的解。
此时， y1+y2 就是“y'' + p(x)y' + q(x)y = 0”的解。
此时， k1y1+k2y2+k3y3 就是“y'' + p(x)y' + q(x)y = 0”的解。
这里，对于通解 y=c1y1+c2y2 （这里要求y1与y2是线性无关的）也是满足的，将通解“y=c1y1+c2y2”代入到“y'' + p(x)y' + q(x)y”后为0。

注意：以上这些“y1- y2、y1+ y2、k1y1+k2y2+k3y3”不仅仅只是针对于“齐次线性微分方程”，只要是齐次方程，即只要“=右边为0”则都是满足的。（对应线性代数里面的齐次方程）

③假设 y1，y2，y3是非齐次线性方程的“y'' + p(x)y' + q(x)y = f(x)”特解，则就说明了y1代入“y'' + p(x)y' + q(x)y”后为f(x)，y2代入“y'' + p(x)y' + q(x)y”后为f(x)。
此时 ，y1- y2 就是“y'' + p(x)y' + q(x)y = 0”的解。
此时， y1+y2 就是“y'' + p(x)y' + q(x)y = 2f(x)”的解。
此时， k1y1+k2y2 就是“y'' + p(x)y' + q(x)y = k1f(x)+k2f(x)”的解。
这里，如果y1与y2线性无关，如果“y=c1y1-c2y2”为齐次线性微分方程“y'' + p(x)y' + q(x)y = 0”通解，即代入后得到“0”，如果y3是非齐次线性微分方程“y'' + p(x)y' + q(x)y = f(x)”的特解，即代入后得到“f(x)”，此时将“y=c1y1-c2y2+y3”代入到非齐次线性微分方程“y'' + p(x)y' + q(x)y = f(x)”后得到的就是“f(x)”，因此“y=c1y1-c2y2+y3”可以看成是非齐次线性微分方程的一个通解。

注意：以上这些“y1- y2、y1+ y2、k1y1+k2y2”不仅仅只是针对于“非齐次线性微分方程”，只要是非齐次方程，即只要“=右边不为0”则都是满足的。（对应线性代数里面的非齐次方程）

④结论：如果 y1、y2、y3 是线性无关的话，则 y1-y2 与 y1-y3，y2-y3 与 y2-y1 也都是线性无关的。此时两个线性无关的函数又是为二阶的齐次线性微分方程的特解的话，则 y=c1y1+c2y2 就是这个二阶的齐次线性微分方程的通解。

常用：非齐次解-非齐次解=齐次解。

 
2、告诉你 具体的（即函数 y1，y2，y3是有具体的表达式的）函数 y1、y2、y3 是为 抽象的（只是知道有这样一个二阶微分方程，没有给你具体的方程的表达式）二阶非齐次微分方程 的特解，让你这个二阶非齐次微分方程的通解。

解题思路：可以利用非齐次微分方程解的结构来做这道题。
由于是为二阶的，首先找出对应的两个二阶齐次微分方程的特解“y1-y2”“y2-y3”（可能不唯一，多次尝试，选择最简单的）；

然后判断 （y1-y2）/（y2-y3） 是否为一个常数（由于y1，y2，y3都是有具体的表达式的，故是 y1-y2和y2-y3 都是可以写出具体的函数表达式的），
如果是为一个常数的话，则说明所找出来的两个二阶齐次微分方程的特解“y1-y2”“y2-y3”是线性相关的，此时就需要重新在找两个，可以为“( y1-y3 )/( y2-y3)”；
如果不太方便判断（y1-y2）/（y2-y3）是否为一个常数的话，此时也可以在重新找两个函数表达式相除方便判断的，可以为“( y1-y3 )/( y2-y3)”；
如果不是为一个常数（即是得出来的结果是为一个函数），则就说明了“y1-y2”“y2-y3”是对应的二阶齐次微分方程的两个线性无关的特解的。

写出这个齐次的通解（两个线性无关的特解的线性组合）为“y=c1 ( y1-y2 ) + c2 ( y2-y3 )”；
非齐次的特解很容易就可以找到，为“y1，y2，y3”中的任意一个；
写出这个抽象的二阶非齐次线性微分方程的通解“y = c1 ( y1-y2 ) + c2 ( y2-y3 ) + y3”。

由于抽象的二阶非齐次线性微分方程的通解“y = c1 ( y1-y2 ) + c2 ( y2-y3 ) + y3”中“（y1-y2）、（y2-y3）、y3”都是有具体的函数表达式的，故此时只需要确定出 c1和c2的值就可以解出通解；
利用题目中给出的初始条件（ 常为 y(x0) = 多少，y'(x1) = 多少 ）求出通解“y = c1 ( y1-y2 ) + c2 ( y2-y3 ) + y3”中的c1与c2，此时就求出了这个二阶非齐次微分方程的通解了。

结论：非齐次解的线性组合仍然为非齐次的解，只要组合系数相加为1；非齐次解的线性组合为对应的齐次的解，只要组合系数相加为0。
