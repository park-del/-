1、可分离变量的微分方程

（1）定义：如果一个一阶微分方程能写成 g(y)dy = f(x)dx 的形式，那么原方程就称为可分离变量的微分方程。

理解：一个微分方程如果能够变成 “x在等式的一遍，y在等式的另一边”，这样的微分方程就是可分离变量的微分方程。

（2）一阶可分离变量微分方程“g(y)dy = f(x)dx”解法：
①在微分方程“g(y)dy = f(x)dx ”的两边同时求不定积分，得到“∫ g(y)dy = ∫ f(x)dx”。
②假设“∫ g(y)dy”对应的一个原函数为 G(y)，“∫ f(x)dx”对应的一个原函数为 F(x)，于是就有 G(y) = F(x) + C，其中C为任意常数。

理解：最后求得到的“G(y) = F(x) + C”就是为一个“y关于x的函数，只不过可能是以隐函数的形式展现出来的”，所求得到的这个函数“G(y) = F(x) + C”就可以当成是这个微分方程“g(y)dy = f(x)dx”的通解。（其中任意常数C的个数可以任意，由于是为通解，故C的个数此时就是微分方程“g(y)dy = f(x)dx”中 y 的最高阶的阶数）


2、齐次方程
（1）如果一阶微分方程可以化为 dy/dx = f( y/x ) 的形式，那么就称这方程为齐次方程。

理解：就是方程的左边是 y'，方程的右边是为一个 关于y/x 的函数。 

（2）一阶齐次微分方程“dy/dx = f( y/x )”解法：
① 令“u=y/x”，则“y=ux”，方程两边同时对x求导（此时的u也是一个关于x的函数）得到“dy/dx = du/dx x + u”；
② 令“u=y/x”，此时“dy/dx = f( y/x )”就是为“dy/dx = f(u)”，将“dy/dx = f(u)”代入到①中的“dy/dx = du/dx x + u”中，得到“du/dx x + u = f(u)”;
③ 此时的“du/dx x + u = f(u)”就是为一个可分离变量的微分方程，接下来就按照可分离变量的微分方程解法就可以求解出齐次方程“ dy/dx = f( y/x )”的通解（一个y关于x的函数，且任意常数只有一个）。
④ 分离变量u和x，得到“1/( f(u)-u )  du = 1/x dx”;
⑤ 在“1/( f(u)-u )  du = 1/x dx”两边同时积分得到 G(u) = F(x) + C；
⑥ 把 “u = y/x ”代入之后“G(u) = F(x) + C”就变成了一个 y关于x的函数，这个 y关于x的函数 就是齐次方程“dy/dx = f( y/x )”的通解。

 
3、一阶线性微分方程
（1）定义
方程 y'+p(x)y=q(x) 叫做一阶线性微分方程。如果 q(x)≡0 时称为一阶齐次线性微分方程，否则称为一阶非齐次线性微分方程。

理解：
①将微分方程中的 x的组合看成是常数、y看做是自变量、y的最高阶导数看做是因变量，将这个一阶线性微分方程转化为函数表示就是 y'（代表因变量）=（x的组合，代表常数）（y的组合，代表自变量）。
②一阶齐次，一阶表明了这个微分方程中的y的最高阶导数是为1的，即因变量是为y'的；齐次表明了这个微分方程中的 x与y的次数是一样的，即可以转化为f(y/x)的形式，最后为“y'=f(y/X)”。
③一阶线性，一阶表明了这个微分方程中的y的最高阶导数是为1的，线性表明了从 最高阶（1阶）---->y（0阶）---->x（常数）都是线性变化的，即“y' + f1(x)y + f2(x) = 0”。如果是为一阶线性齐次的话，则f2(x)=0，即“y'=f1(x)y”；如果是为一阶线性非齐次的话，则f2(x)≠0，即“y'=f1(x)y+f2(x)”。

 

（2）一阶线性微分方程的解法。
一阶齐次线性微分方程“y'+p(x)y=0”的解法：
将 y' 变成 dy/dx，则一阶齐次线性微分方程为“dy/dx = -p(x)y”,其是可以将变量x和y进行分离的，故“一阶齐次线性微分方程”可以采用可分离变量的方式来求解出其通解。

一阶非齐次线性微分方程“y'+p(x)y=q(x)”的解法：
方法一：套用公式“y=e（ -∫ p(x) dx ）[ q(x)   e（ ∫ p(x) dx）+C ]”，求出来的 y 就是为这个一阶非齐次线性微分方程“y'+p(x)y=q(x)”的通解。（常数变易法）

方法二：积分因子法。

注意：在解一阶微分方程（导函数只牵涉到了y'）的时候，在解之前要将所有的 y' 变成 dy/dx 的形式；然后将所有关于y（包含了dy）的放在等式的一边，将所有关于x（包含了x）放在等式的另一边。
对于一阶微分方程来说，通解就是一个y关于x的函数（可以是为显函数，可以为隐函数），这个通解（y关于x的函数）中的任意常数只有一个C（因为是为1阶的）。

题型：
1、求一阶微分方程的通解（注意，这里求的是一阶微分方程，最高阶的导数的阶数是为1的）。
解题思路：首先将这个微分方程中的 y' 全部变成 dy/dx 的形式，如果这个微分方程中 “所有关于x的东西（包括了dx）”与“所有关于y的东西（包括了dy）”都能够全部分离出来移到等式的一边，则这个微分方程就属于“可分离变量的微分方程”，就采用“可分离变量微分方程的解法”；如果“所有关于x的东西（包括了dx）”与“所有关于y的东西（包括了dy）”都不能够全部分离出来移到等式的一边，接下来考虑能否化成“dy/dx = f(y/x)”或者“dx/dy = f(x/y)”的形式，如果能的话，则这个微分方程就属于“一阶齐次微分方程”，就采用“一阶齐次微分方程的解法”（即是换成y'=f ( y/x ) 或者 y'=f( x/y) ） 。

（1）可分离变量微分方程的解法。
将 y' 全部转变为 dy/dx 的，即此时这个微分方程中不会再含有y'了，此时这个微分方程中只会含有 x，y，dy，dx。
将微分方程中“所有关于x的东西（即是dx、x）”与“所有关于y的东西（即是dy、y）”分别移动等式的一边，即变成“（）dy = （）dx”的形式。
对“（）dy = （）dx”的两边同时取不定积分，求解出来隐函数 G(y)=F(x)+C1。
最后将这个隐函数“G(y)=F(x)+C1”变换成 显函数，即“y=（）”的形式，所求出来的这个显函数“y=（）”就是为这个“可分离变量微分方程”的通解。


（2）一阶齐次微分方程的解法。
将 y' 全部转变为 dy/dx 的，即此时这个微分方程中不会再含有y'了，此时这个微分方程中只会含有 x，y，dy，dx。
对这个微分方程进行变换，看满足“dy/dx = f(y/x)”或者“dx/dy = f(x/y)”中的哪一种。
①  “dy/dx = f(y/x)”的解法。
令u=y/x，得到 y=ux。
将 y=ux 代入到原微分方程“dy/dx = f(y/x)”中，得到关于u与x的一个微分方程，即是“d(ux)/dx = f(u)”，d(ux)对x求导后变成“du/dx x + u = f(u)”。
得到的“du/dx x + u = f(u)”是为一个可分离变量的微分方程，对变量u（包括du）与变量x（包括dx）进行变量分离，得到“du / ( f(u)-u ) = dx / x”。
对“du / ( f(u)-u ) = dx / x”两边同时取定积分，得到隐函数“G(u) = F(x) + C”。
将 u=y/x 代入到隐函数“G(u) = F(x) + C”中得到隐函数“H(y) = M(x)”。
最后将隐函数“H(y) = M(x)”化成显函数“y=（）”的形式，所得到的“y=（）”就是为这个一阶齐次微分方程的通解。

②“dx/dy = f(x/y)”的解法。
令u=x/y，得到 x=uy。
将 x=uy 代入到原微分方程“dx/dy = f(x/y)”中，得到关于u与y的一个微分方程，即是“d(uy)/dy = f(u)”，d(uy)对y求导后变成“du/dy y + u = f(u)”。
得到的“du/dy y + u = f(u)”是为一个可分离变量的微分方程，对变量u（包括du）与变量y（包括dy）进行变量分离，得到“du / ( f(u)-u ) = dy / y”。
对“du / ( f(u)-u ) = dy / y”两边同时取定积分，得到隐函数“G(u) = F(y) + C”。
将 u=x/y 代入到隐函数“G(u) = F(y) + C”中得到隐函数“H(x) = M(y)”。
最后将隐函数“H(x) = M(y)”化成显函数“y=（）”的形式，所得到的“y=（）”就是为这个一阶齐次微分方程的通解。

常规思路：
①求解“一阶齐次微分方程”我们一般是按照①的思路的。
②当我们遇到的一阶齐次微分方程“dy/dx = 分子/分母”的时候（此时分词和分母是可以同时除以x^2变成 f(y/x) 的形式的 ），
如果是分子比分母复杂，此时可以将“等号右边的 分子/分母”同时除以x^2变成 f(y/x) 的形式，此时就转化为了“dy/dx = f(y/x)”,接下来按照“一阶齐次微分方程dy/dx = f(y/x)”的解题思路进行求解就可以了；
如果是分母比分子复杂，此时可以将“等式两边颠倒一下”，变成“dx/dy = 复杂分子/分母”，由于分子比较复杂，此时往往可以对其进行将其分成多个项的和，把该约的约掉，最后“复杂分子/分母”就会自动的变成f(x/y)的形式了，此时再进行分离变量积分的时候就会变得简便些。

 
提示：通过“dy/dx = f(y/x)”求出来的是为 u关于x，即y关于x的隐函数的；通过“dx/dy = f(x/y)”求出来的是为 u关于y，即x关于y的隐函数的；无论是 y关于x 还是 x关于y，都是为这个一阶齐次微分方程的通解的。
