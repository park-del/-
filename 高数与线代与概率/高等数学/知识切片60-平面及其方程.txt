
三个问题：
平面方程的表达式
点到平面的距离
平面的位置关系

1、平面及其方程
（1）平面的点法式方程
已知平面上的一点 M0(x0，y0，z0) 及其一个法向量 n=(A，B，C)，则方程  A（x-x0）+B（y-y0）+c（z-z0）=0，称为平面的点法式方程。

推导：假设平面上一点为 M（x，y，z），则平面上的一个向量 M0M=（x-x0，y-y0，z-z0）与法向量n=(A，B，C)垂直，数量积为0，即 M0M · n = A（x-x0）+B（y-y0）+c（z-z0）=0。此时，我们就得到了这个平面方程为“  A（x-x0）+B（y-y0）+c（z-z0）=0”。

理解：顾明思义，点法式，只要知道了这个平面的一个法向量，并且知道了这个平面上的一个点，此时我们就可以写出这个平面方程。

（2）平面的一般方程
方程 Ax+By+Cz+D=0 称为平面的一般方程，其中 x、y、z 的系数是该平面的一个法向量 ，即 n=( A，B，C )。


（3）平面的截距式方程（了解）
 方程 x/a + y/b + z/c =1 （abc ≠ 0）称为平面的截距式方程，其中 a、b、c 依次叫做平面在 x、y、z轴上的截距。


2、点到平面的距离
平面外一点（x0，y0，z0）到平面 Ax+By+Cz+D=0 的距离 “d= | Ax0 + By0 + Cz0 + D | / 根号（ A^2+B^2+C^2 ）”。

3、两平面的位置关系
（1）两平面夹角
两平面的法向量的夹角（通常指锐角或直角）称为两平面的夹角。

注意：两个平面的夹角α的取值范围为“0 ≤ α ≤ π/2”（计算两个平面夹角的时候取得是较小的那个夹角，因为两个平面的夹角只够为锐角）。

（2）两平面的夹角的计算
设平面 P1，P2 的法向量分别为 n1=(A1，B1，C1) 和 n2=(A2，B2，C2)，则两平面的夹角θ的余弦为
cos θ = | n1 · n2 | / | n1 | | n2 | = | A1A2+B1B2+C1C2 | / 根号（ A1^2+B1^2+C1^2 ）根号（A2^2+B2^2+C2^2）。

注意：cos（θ）= | cos（π-θ）| 。

理解：由于两个平面的夹角就是两个法向量n1和n2的夹角，故这里其实就是在求两个法向量n1，n2之间的夹角。利用“n1 · n2 = | n1 | | n2 | cos θ”，这里可以求出两个法向量夹角的余弦 
cos θ = n1 · n2 /  | n1 | | n2 | 。由于两个平面之间的夹角α的范围为 0≤α≤π/2，故这里 θ 对应的余弦只能够为正的，即 cos θ = | n1 · n2 | / | n1 | | n2 |。


（3）两平面的位置关系
两平面垂直《====》n1 垂直 n2《====》A1A2+B1B2+C1C2=0 。
两平面平行《====》n1 平行 n2《====》A1/A2 = B1/B2 = C1/C2 。

特别的，两平面重合《====》 A1/A2 = B1/B2 = C1/C2 = D1/D2。

理解：两个平面的位置关系其实就是两个平面对应的法向量的位置关系。
如果两个法向量 n1=（A1，B1，C1）、n2=（A2，B2，C2） 垂直的话，则有 n1 · n2=0，即“A1A2+B1B2+C1C2=0 ”。
如果两个法向量 n1=（A1，B1，C1）、n2=（A2，B2，C2） 平行的话，则有 n1=k n2，即“A1/A2 = B1/B2 = C1/C2 ”。
 

题型：
1、求出这个平面方程的表达式。
解题思路：找到两个东西，第1找出平面的方向量n是谁，第2找出平面过哪一点，然后根据“点法式”写出这个平面方程就可以了。

找平面的法向量 n：
①如果给出的是平面的一般方程 Ax+By+Cz+D=0，则这个平面的法向量  n=( A，B，C )。
②法向量n与向量 M0M1垂直，法向量n与 向量 M2M3垂直，则法向量n就是这两个向量的向量积（叉乘），即“n= M0M1 × M2M3”。（这两个向量确定的平面根据右手法则大拇指指向的就是为法向量）

2、求出一个点（x0，y0，z0）到平面 Ax+By+Cz+D=0 的距离。
解题思路：直接套用点到平面的距离公式“d= | Ax0 + By0 + Cz0 + D | / 根号（ A^2+B^2+C^2 ）”。

3、求两个平面P1，P2 的夹角α。
解题思路：平面 P1 与 平面 P2 的夹角α，其实就是P1的法向量n1与P2的法向量n2之间的夹角。找出平面P1的法向量n1，找出平面P2的方向量n2，计算“n1与n2”之间的夹角为
“cos θ = | n1 · n2 | / | n1 | | n2 | = | A1A2+B1B2+C1C2 | / 根号（ A1^2+B1^2+C1^2 ）根号（A2^2+B2^2+C2^2）”。

4、判断两个平面 P1，P2 的位置关系。
解题思路：平面 P1 与 平面 P2 的位置关系（有两种，分别是 垂直、平行，其中平行有一种特殊情况就是“重合”），其实就是P1的法向量n1与P2的法向量n2之间的位置关系。

两平面垂直《====》n1 垂直 n2《====》A1A2+B1B2+C1C2=0 。
两平面平行《====》n1 平行 n2《====》A1/A2 = B1/B2 = C1/C2 。

特别的，两平面重合《====》 A1/A2 = B1/B2 = C1/C2 = D1/D2。
