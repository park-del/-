思想：如果一个级数不方便求出 前n项和 ，即是不方便通过 前n项和 来判断出这个级数的敛散性的话，我们可以先研究一些特殊的级数，已知这些特殊级数的敛散性，通过某种方式来确定出级数的敛散性。

1、正项级数的基本概念
定义：常数项级数中，各项都是正数或零的级数称为正项级数。

理解：由于常数项级数的各项都是正数或零，故有 Sn ≥ Sn-1，即 前n项和Sn 这个数列是为一个单调递增的数列。由数列的单调有界原理可以知道，如果数列 { Sn } 有上界的话，则数列Sn在n-->∞的时候必收敛，即 lim(n---->∞) Sn 极限存在。因此正项级数级数“ ∑(n=1----n=∞) un” 前n项和Sn满足 lim(n---->∞) Sn  存在，故这个正项级数收敛 。

2、正项级数的审敛法
定理1：正项级数 ∑(n=1----n=∞) un 收敛的充要条件是：它的部分和数列 { Sn } 有界。（这里应该是有上界）

定理2：设 ∑(n=1----n=∞) un 与  ∑(n=1----n=∞) vn 都是正项级数，且 un ≤ vn（n=1,2，……）。若 正项级数 ∑(n=1----n=∞) vn 收敛，则 正项级数 ∑(n=1----n=∞) un 收敛；若正项级数 ∑(n=1----n=∞) un 发散，则 正项级数 ∑(n=1----n=∞) vn 发散。

记忆：大收则小收；小发则大发。

推论：设 ∑(n=1----n=∞) un 与  ∑(n=1----n=∞) vn 都是正项级数，且存在正整数N，使当 n ≥ N时，有 un ≤ vn 。若 正项级数 ∑(n=1----n=∞) vn 收敛，则 正项级数 ∑(n=1----n=∞) un 收敛；若正项级数 ∑(n=1----n=∞) un 发散，则 正项级数 ∑(n=1----n=∞) vn 发散。

理解：这里是比较判别法的弱化形式，只要在某一个N之后满足 un ≤ vn 就可以了，不需要级数中的每一项都满足  un ≤ vn。


定理3（比较判别法的极限形式）：
设两个正项级数 ∑(n=1----n=∞) un 与  ∑(n=1----n=∞) vn（vn ≠ 0），若 lim(n---->∞) un/vn = m，则：

理解：由知识切片52中关于数项级数的性质可以知道，如果数项级数的通项 un 满足 lim(n---->∞) u n≠ 0，则这个数项级数就是发散的；如果数项级数 ∑(n=1----n=∞) un 是收敛的，则  lim(n---->∞) un = 0。即我们想要进一步判断 两个正项级数 ∑(n=1----n=∞) un 与  ∑(n=1----n=∞) vn，则它们的一般项必须先趋近于0，即 lim(n---->∞) un = 0，lim(n---->∞) vn = 0，这样就变成了一个 0/0 式的极限问题。

① 当 0<m<+∞ 时，则正项级数 ∑(n=1----n=∞) un 与  ∑(n=1----n=∞) vn 同时收敛同时发散；
理解：说明了 un 与 vn 差不多，在n---->∞这个变化过程中，un 与 vn 是为同阶无穷小的。既然 un 与 vn 差不多，则它们两个是同收敛，同发散的。

② 当 m=0 时，如果 正项级数 ∑(n=1----n=∞) vn 收敛，则 正项级数 ∑(n=1----n=∞) un 收敛；若正项级数 ∑(n=1----n=∞) un 发散，则 正项级数 ∑(n=1----n=∞) vn 发散；

理解：m=0 则相当于是在说明 un 是 vn 的高阶无穷小，说明了 un小，vn大，则根据“大收则小收”“小发则大发”很容易就能够推导出结论。

③ 当 m=+∞，如果 正项级数 ∑(n=1----n=∞) un 收敛，则 正项级数 ∑(n=1----n=∞) vn 收敛；若正项级数 ∑(n=1----n=∞) vn 发散，则 正项级数 ∑(n=1----n=∞) un 发散。
理解： m=+∞ 则 un 大，vn 小。抓住“大收则小收，小发则大发”很容易就能够推导出结论。


当我们要判断一个正项级数 ∑(n=1----n=∞) un 的敛散性的时候，可以选择正项级数比较判别法的极限形式，此时我们就需要选择1个正项级数 ∑(n=1----n=∞) vn 作为比较对象。
这个比较对象 ∑(n=1----n=∞) vn 在 n---->∞ 时的敛散性是已知的，且选做作为比较对象的通项vn 在n---->∞ 这个变化过程中与 un是同阶无穷小的。
如果我们选择的这个比较对象 ∑(n=1----n=∞) vn 中的通项vn 与 ∑(n=1----n=∞) un 中的通项 un 在n---->∞ 这个变化过程中是同阶无穷小的，则正项级数∑(n=1----n=∞) un 与 
正项级数∑(n=1----n=∞) vn 就具有相同的敛散性（正项级数∑(n=1----n=∞) vn 的敛散性是已经知道的）。

利用“正项级数的比较审敛法的极限形式”判断一个正项级数敛散性时被选做比较对象的正项级数 ∑(n=1----n=∞) vn ：
① p级数 
∑(n=1----n=∞)  1/ ( n^p )  ：收敛（p>1）；发散（p≤1）

②等比级数/几何级数（借助指数函数的性质来记忆）
∑(n=1----n=∞) aq^(n-1) ：收敛（ | q | <1 ）；发散（ | q | ≥ 1 ）

③类p级数：
∑(n=1----n=∞)  1/ [ n ( ln n )^p ] ：收敛（ p>1 ）；发散（p≤1）


定理4：（比值审敛法）
设正项级数 ∑(n=1----n=∞) un，如果 lim(n---->∞) u(n+1)/un =m 。
当 m<1时，级数 ∑(n=1----n=∞) un 收敛；
当 m>1(或者 m=+∞ ）时，级数 ∑(n=1----n=∞) un 发散；
当 m=1 时，级数 ∑(n=1----n=∞) un 可能收敛也可能发散。

理解：比值判别法（比值审敛法）是自己和自己比较（就是拿自己后一项u(n+1)去除以自己un，然后在取极限），比较判别法（比较审敛法）是自己和它人比较。
理解：后一项比上前一项，为大于1，说明了后一项是 前一项 × 大于1的数，说明了数是越来越大的，故是发散的；后一项比上前一项，为小于1，说明了后一项是 前一项 × 小于1的数，说明了数是越来越小的，故是收敛的。

定理5：（根值审敛法）
设 ∑(n=1----n=∞) un 为正项级数，如果 lim 根号n ( un ) = m。
当 m<1时，级数 ∑(n=1----n=∞) un 收敛；
当 m>1(或者 m=+∞ ）时，级数 ∑(n=1----n=∞) un 发散；
当 m=1 时，级数 ∑(n=1----n=∞) un 可能收敛也可能发散。


何时用：一般项带有n次形式的时候，考虑是不是可以用根值判别法来去处理它。


定理6：（积分判别法）
设 f(x) 在 [1，+∞)上非负减函数，那么正项级数 ∑(n=1----n=∞) f(n) 与反常积分 ∫(1----+∞) f(x) dx 同时收敛同时发散。

理解：f(x) 在 [1，+∞)上非负减函数 保证了


3、交错级数的概念机器审敛法
（1）定义：见教材 P176
（2）莱布尼茨判别法：见教材 P176



题型：
1、判断一个正项级数的敛散性。
提示：前一个知识切片中是让我们判断数项级数，这里是让我们判断正项级数，即满足 通项un≥0 的就是为正项级数。

解题思路：
（1）首先看这个正项级数是否是 p级数“∑(n=1----n=∞)  1/ ( n^p )”，等比级数“∑(n=1----n=∞) aq^(n-1)”，类p级数“∑(n=1----n=∞)  1/ [ n ( ln n )^p ]”，如果是的话，就可以直接根据结论得出这个级数的敛散性了。
（2）看这个级数的通项 un 是否满足 lim(n---->+∞) un ≠ 0，如果满足的话，则这个级数就是发散的。
（3）接下来就是一些技巧了：
①如果这个级数中出现了等价无穷小的式子“如 sin x、1-cosx、ln (1+x )”或者“n的什么什么次方的式子”，此时考虑使用“比较判别法的极限形式”。 
选择与这个等价无穷小的式子，n的什么什么次方的式子，同阶或者等价的一个式子v(n)，则级数∑(n=1----n=∞) un 的敛散性 与 级数 ∑(n=1----n=∞) vn 的敛散性相同，接下来就转化为了判断级数
∑(n=1----n=∞) vn的敛散性的问题。
常常被选择进行比较的式子为“1/ ( n^p )”“aq^(n-1)”““∑(n=1----n=∞)  1/ [ n ( ln n )^p ]””，分别对应了p级数、等比级数、类p级数。

②如果这个级数的通项un能够容易得出一个不等式关系的话，此时考虑使用“比较判别法的不定式形式”
即级数∑(n=1----n=∞) un 的通项 un，满足 un ≤ vn，此时根据 “大敛则小敛”的原则，若级数 ∑(n=1----n=∞)  vn 收敛，则级数 ∑(n=1----n=∞) un收敛。（常常利用放缩的思想来构造不等式关系，关于放缩的思想见总结的高数笔记本）

③如果这个级数中出现了“阶乘式子”，如 n！，（n+1），此时考虑使用“比值判别法”。
即转化为了计算  lim(n---->+∞) u(n+1)/un 这个极限的值，如果为 >1 （包括了+∞,因为+∞也是＞1的）则这个级数就是收敛的，如果为 <1 则这个级数就是发散的，如果 =1 的话则这个级数是收敛还是发散不能够确定。

④如果这个级数中出现了“n的n次方”的式子，此时考虑使用“根值判别法”。
即转化为了计算  lim(n---->+∞) ( un )^( 1/n ) 这个极限的值，如果为 >1 （包括了+∞,因为+∞也是＞1的）则这个级数就是收敛的，如果为 <1 则这个级数就是发散的，如果 =1 的话则这个级数是收敛还是发散不能够确定。



⑤如果判断出 f(x)【f(x)就是通项un】是单调递减的话，且这个级数的通项比较方便求出不定积分的话，则就可以利用“积分判别法”。
即转化为了计算 ∫(1----+∞) f(x) dx 这个反常积分的值，如果这个反常积分是收敛的，那么这个级数就是收敛的，如果这个反常积分是发散的，那么这个级数就是发散的。
（提示：判断一个函数f(x)的单调性的问题【可以直接根据单调性复合法判断出】，求反常积分的的问题，判断反常积分的敛散性的问题（常常采用定积分+极限，算出来值的方式），前面都有总结过）

⑥如果这个级数的通项是为两项相加的的形式，即“un+vn”，则可以拆分开分别判别两个级数的敛散性，进而判断出两个级数相加的敛散性。（相减也是一样的）


（4）如果上述都不能够判断出级数的敛散性的话，此时就考虑：求出级数的前n项和Sn，计算极限值 lim(n---->+∞) Sn，如果极限存在，则级数收敛；如果极限不存在，则级数发散。
常见的可以求出前n项和的：等比数列，等差数列，能裂项求和的（如 根号(n+1) - 根号n 、ln(n+1) - ln(n)、1/n(n+1)）

（5）可以通过数项级数的绝对收敛的来判断出这个数项级数收敛。即是 判断出这个级数 ∑(n=1----n=∞) un 所对应的正项级数 ∑(n=1----n=∞) | un | 是收敛的话，则此时原来的数项级数 ∑(n=1----n=∞) un 就是收敛的。

2、解决有关正项级数的选择题。
解题思路：可以采用举反例的方法，举反例只有两种，就是举“p级数”“类p级数”。如果一个级数收敛，我们可以举收敛的p级数，即是“1/n^2”，我们可以举收敛的类p级数“1/n ( ln n)^2”；如果一个级数发散，我们可以发散的p级数“1/n”，我们可以举发散的类p级数“1/n ln n”。首先举p级数，如果p级数没有办法解决的话，就立即去举类p级数。


3、判断交错级数“∑(n=1----n=∞) (-1)^n un”的敛散性。
解题思路：利用莱布尼茨判别法判别即可。即是“un”为单调递减（ un > u(n+1) ），且 lim(n---->+∞) un=0，则此时这个交错级数就是收敛的。

注意：通项可以为  (-1)^n un ，也可以为  (-1)^(n+1) un，只要满足正负交替就可以了；交错级数的通项中的 un >0 的，不满足 un > 0 的不是交错级数。
