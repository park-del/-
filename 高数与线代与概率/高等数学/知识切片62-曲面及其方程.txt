把握住3个：
旋转曲面方程
柱面方程
常见的二次型曲面


引入：空间的曲面方程为 F(x，y，z)=0，也可以表示为“z=F（x，y）”，即空间的曲线方程对应的是一个二元函数的，这个二元函数的定义域为一个平面，平面的一点（x0，y0）就是自变量的取值，对应了一个z，相当于是确定了空间中的某一点。我们这里所研究的就是一些特殊的“空间曲面方程----二次型曲面方程（通过旋转得到的旋转曲面，通过移动得到的柱面）”。

1、旋转曲面
（1）旋转曲面的定义：以一条平面曲线绕其平面上一条直线旋转一周所成的曲面叫做旋转曲面，旋转曲线和定直线依次叫做旋转曲面的母线和轴。

理解：
①在空间直角坐标系中，一般的平面不好研究，故我们研究的是特殊的平面，即“xoy面、yoz面、xoz面”。我们通常研究的是“xoy面、yoz面、xoz面”这些特殊平面上的曲线的，对于“xoy面”，曲线方程为 f（x，y）=0；对于 “yoz面”，曲线方程为 f（y，z）=0；对于“xoz面”，曲线方程为 f（x，z）=0。

注意：这些特殊的平面中，我们研究 xoz面上的曲线f（x，z）=0 研究的最多，其次就是研究 xoy面上的曲线 f（x，y）=0。（xoz面是和我们正对着的那一个面，xoy面是底下的那一个面）

②在空间直角坐标系中，曲线绕着一般的直线旋转构成的旋转曲面不好研究，故我们研究的是特殊的直线，即“x轴，y轴，z轴”。我们通常研究的是平面上的曲线绕着“x轴，y轴，z轴”旋转所构成的旋转曲面的。

 

（2）旋转曲面的方程
设在 yOz 坐标面上有一已知曲线C，它的方程为 f(y，z)=0，把这曲线绕 z 轴旋转一周，就得到一个旋转曲面，方程为 f (  ± 根号 (x^2+y^2)，z ) = 0。

理解：
我们在旋转曲面上任取一点（x，y，z），我们要找的就是该点处的“x，y，z”的关系式。
该点（x，y，z）所对应的原yOz面上的曲线 f（y，z）=0 上的点记为（0，y0，z0）。
由于是绕着z轴旋转的，故我们可以得到以下两个条件：
z0=z；
（x，y，z）点距离z轴的距离d的平方“x^2+y^2”与（x0，y0，z0）点距离z轴的距离d的平方“y0^2”相等，即“y0^2 = x^2+y^2”,得到“y0 = ± 根号（x^2+y^2）”。
因为点（y0，z0）满足曲线方程，将“y0和z0”代入到曲线方程中，就可以得到这个曲线绕着z轴旋转所构成的曲面方程“f（± 根号（x^2+y^2），z）”了。


设在 yOz 坐标面上有一已知曲线C，它的方程为 f(y，z)=0，把这曲线绕 y 轴旋转一周，就得到一个旋转曲面，方程为 f (  ± 根号 (x^2+z^2)，y ) = 0。

记忆：
曲线方程是已知，绕哪个轴旋转哪个坐标不变，另外一个坐标变成不包含这个坐标的 ± 根号 ( )^2+( )^2，将这两个坐标代入到曲线方程中就可以得出这个曲面方程；
绕z轴旋转z不变，另外一个变为“± 根号 (x^2+y^2)”；
绕y轴旋转y不变，另外一个变为“± 根号 (x^2+z^2)”。

 
2、柱面
（1）柱面的定义：直线L沿曲线C平行移动形成的轨迹叫做柱面，定曲线C叫做柱面的准线，动直线L叫做柱面的母线。



（2）柱面方程的特征
x，y，z 三个变量中缺其中之一（如缺y则表示母线平行于y轴的柱面）如 y^2=2x 表示母线平行于z轴的柱面，它的准线是xOy面上的抛物线 y^2=2x，该柱面叫做抛物柱面。

注意：在空间曲面的方程中，缺少一个变量则这个空间曲面方程所表示的就是柱面，缺少哪一个则表示的就是沿着哪一个平行移动的柱面（如缺少z，就是xOy上的曲线上下延伸）。


3、常见的二次曲面
（1）圆锥面： x^2 / a^2 + y^2 / b^2 = z^2。
（2）旋转抛物面：z=x^2+y^2。

区分：圆锥面“z^2= x^2 / a^2 + y^2 / b^2 ”与旋转抛物面“z=x^2+y^2”
圆锥面是由 z=y 这条直线绕着z轴旋转得到的，绕着z轴旋转则z不变，y变成“± 根号 (x^2+y^2)”，即“z=± 根号 (x^2+y^2)”，平方一下得到“z^2 = x^2+y^2”。
旋转抛物面是由 z=y^2 这条抛物线绕着z轴旋转得到的，绕着z轴旋转则z不变，y变成“± 根号 (x^2+y^2)”，即“z=x^2+y^2”。

（3）椭球面：x^2 / a^2 + y^2 / b^2 + c^2 / z^2 = 1。
（4）球面：x^2 + y^2 + z^2 = 1。


（5）单叶双曲面：x^2 / a^2 + y^2 / b^2 - c^2 / z^2 = 1。
（6）双叶双曲面：x^2 / a^2 - y^2 / b^2 - c^2 / z^2 = 1。

区分：单叶双曲面“x^2 / a^2 + y^2 / b^2 - c^2 / z^2 = 1”与 双叶双曲面“x^2 / a^2 - y^2 / b^2 - c^2 / z^2 = 1”
在yOz面上的双曲线 y^2 / a^2 - z^2 / b^2 = 1，
绕着z轴旋转所得到的曲面就是单叶双曲面“x^2 / a^2 + y^2 / b^2 - c^2 / z^2 = 1”。
绕着x轴旋转所得到的曲面就是双叶双曲面“x^2 / a^2 - y^2 / b^2 - c^2 / z^2 = 1”。
减一个的为“单叶”，减二个的为“双叶”。

记忆：
只含有两个变量的是柱面，看是什么形式就是什么柱面（为椭圆形式就是“椭圆柱面”，为双曲线形式就是“双曲柱面”，为抛物线形式就是“抛物柱面”）。
带有3个变量的，如果 x，y，z 的次方都为2，就是由椭圆“y^2 / a^2 + z^2 / b^2 =1”或者双曲线“y^2 / a^2 - z^2 / b^2 =1”旋转得到的。（因为绕着某一个轴，该坐标不动仍然能够保证这个坐标的次方为2）
带有3个变量的，如果 x，y 的次方都为2，z 的次方为1（即是 x，y，z 3个变量中两个次方为2，一个为1），则就是由抛物线 z=y^2 旋转得到的。（因为绕着z轴旋转能够保证z不变，即是保证有一个变量的次方为1）
