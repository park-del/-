
引入：幂级数 ∑(n=0，n=∞) an x^n 在其收敛域上具有和函数S( x )。
理解：
（1）幂级数 ∑(n=0，n=∞) an x^n 的收敛域只可能是有3种情况的，一种是全闭区间“[ -R，R]”，一种是半开半闭区间“(-R，R] 或者 [-R，R)”，一种是全开区间“（-R，R）”。 
（2）假设幂级数 ∑(n=0，n=∞) an x^n  的收敛域为“（-R，R）”的话，则幂级数在这个收敛域（-R，R）上有和函数 S(x)。
（3）由于幂级数∑(n=0，n=∞) an x^n 的收敛域（-R，R），这也就说明了对于区间（-R，R）内的任意一个点x0所确定的常数项级数都是收敛的，即对于区间（-R，R）内的任意一个点x0所确定的数项级数∑(n=0，n=∞) an x0^n 都是能够计算出一个常数值的，这就是一种函数关系，我们就将这种函数关系定义为幂级数∑(n=0，n=∞) an x^n 在收敛域（-R，R）上的和函数 S（x）。


对 常数项级数（数项级数）与 函数项级数（典型的是幂级数）之间的关系的理解：
类比于 函数f(x) 与 常数 的关系，函数f(x)当自变量x确定为x0后所得到的结果f(x0)就是一个常数。在无穷级数中，函数项级数 ∑(n=0，n=∞) an x^n 与 数项级数 ∑(n=0，n=∞) an x0^n 的关系就是“当函数项级数 ∑(n=0，n=∞) an x^n 的自变量x确定为x0后所得到的结果 ∑(n=0，n=∞) an x0^n 就是为一个常数项级数”（级数中的函数与常数的关系）。

1、幂级数的运算
设 ∑(n=0，n=∞) an x^n 收敛半径为Ra，∑(n=0，n=∞) bn x^n 收敛半径为Rb，则 ∑(n=0，n=∞) an x^n (+-) ∑(n=0，n=∞) bn x^n = ∑(n=0，n=∞) [ an (+-) bn ] x^n，收敛半径为
R = min { Ra，Rb } ( Ra ≠ Rb ).

理解：
假设  级数∑(n=0，n=∞) an x^n 的收敛半径Ra ＜ 级数∑(n=0，n=∞) bn x^n 收敛半径为Rb，
①则在区间（-Ra，Ra）内部的一点x0，幂级数 ∑(n=0，n=∞) an x^n 对应的常数项级数  ∑(n=0，n=∞) an x0^n 是收敛的，幂级数 ∑(n=0，n=∞) bn x^n 对应的常数项级数  ∑(n=0，n=∞) bn x0^n 是收敛的。因此，相对应的两个幂级数相所构成的一个新的幂级数 ∑(n=0，n=∞) [ an (+-) bn ] x^n 在x0这一点处仍然是收敛的，即在这一点x0处的常数项级数 ∑(n=0，n=∞) [ an (+-) bn ] x0^n 能够求出具体的数值的。

②则在区间 （-Rb，-Ra）或者（Ra，Rb）内的一点x0，幂级数 ∑(n=0，n=∞) an x^n 对应的常数项级数  ∑(n=0，n=∞) an x0^n 是发散的，幂级数 ∑(n=0，n=∞) bn x^n 对应的常数项级数  ∑(n=0，n=∞) bn x0^n 是收敛的。因此，相对应的两个幂级数相所构成的一个新的幂级数 ∑(n=0，n=∞) [ an (+-) bn ] x^n 在x0这一点处仍然是发散的，即在这一点x0处的常数项级数 ∑(n=0，n=∞) [ an (+-) bn ] x0^n 为∞)  。


2、幂级数和函数的性质

注意：性质1和性质2，一个是收敛域，一个是收敛半径。

性质1：幂级数  ∑(n=0，n=∞) an x^n  的和函数 S( x )在其收敛域I上连续。


性质2：幂级数∑(n=0，n=∞) an x^n 的和函数 S( x ) 在其收敛区间内可导，且有逐项求导公式 S'( x ) = [ ∑(n=0，n=∞) an x^n ] ' = ∑(n=0，n=∞) ( an x^n )' = ∑(n=1，n=∞) n an x^(n-1)（| x |<R，R为收敛半径），逐项求导后所得到的幂级数和原级数有相同的收敛半径。

理解：对于收敛区间（-R，R）上任意一点x0，都有 S(x0) = ∑(n=0，n=∞) an x0^n 。对“和函数S(x)”求到就相当于是对函数项级数“∑(n=0，n=∞) an x^n”求导，函数项级数“∑(n=0，n=∞) an x^n”求到相当于是函数项级数“∑(n=0，n=∞) an x^n”中的每一项分别求到相加，即“∑(n=0，n=∞) [ an x0^n ]' ”，化简之后就得到了一个新的级数“∑(n=0，n=∞) an n x^n-1”。这个新的级数“∑(n=0，n=∞) an n x^n-1”与原来的级数“∑(n=0，n=∞) an x0^n”具有相同的收敛半径 。


性质3：幂级数 ∑(n=0，n=∞) an x^n 的和函数S( x )在其收敛域上可积，并有逐项积分公式 
∫(0---x) S(t) dt = ∫(0---x) ( ∑  an t^n  ) dt = ∑ ∫(0---x) an t^n dt = ∑ an/(n+1) x^(n+1) （x∈I）。
逐项积分后所得到的幂级数和原级数有相同的收敛半径。 

理解：x是收敛域I（假设收敛域I为（-R，R）) 上的任意一个点，对原级数  ∑(n=0，n=∞) an x^n 在 [ 0，x ]上进行积分，等于分别对级数的每一项在（0----x）上进行积分然后求和的结果，即“ ∑ ∫(0---x) an t^n dt ”，所构成的一个新级数为“∑ an/(n+1) x^(n+1) ”，这个新的级数与原来的级数具有相同的收敛半径。

记忆 性质2、性质3：对原级数（ 原级数就是和函数S(x) ）逐项求到，逐项积分，后所得到的一个新的级数，与原来的级数具有相同的收敛半径。（注意，不是收敛域，而是收敛半径）

理解：先是求完和后在积分，现在变成了先每项积完分之后再求和。

性质2，性质3：在幂级数的收敛区间内，可以逐项积分，逐项求导，进行逐项积分，逐项求导后所得到的新的级数不改变原级数的收敛区间（或者叫不改变原级数的收敛半径）。


3、求幂级数的和函数
（1）等比形式的幂级数 借助于“等比求和”来去解决幂级数的和函数（最常用）
① ∑(n=0，n=∞)  x^n = 1 / ( 1-x )                  | x | < 1（这里的x的取值范围，就是幂级数 ∑(n=0，n=∞)  x^n 的收敛区间，幂级数求收敛区间的方法见知识切片57）
② ∑(n=0，n=∞) (-1)^n x^n = 1 / ( 1+x )       | x | < 1

理解：
①∑(n=0，n=∞)  x^n 就相当于是一个公比为 x 的等比数列求和，首项为x^0=1，利用等比数列求和的公式为“ 1 ( 1-x^n ) / ( 1-x )”，由于 -1<x<1，故当n--->+∞时，为“1/(1-x)”。 
②∑(n=0，n=∞) (-1)^n x^n 就相当于是一个公比为 -x 的等比数列求和，首项为 (-1)^0 x^0=1，利用等比数列求和的公式为“ 1 ( 1-(-x)^n ) / ( 1+x )”，由于 -1<x<1，故当n--->+∞时，为“1/(1+x)”。
③上述①中的“∑(n=0，n=∞)  x^n = 1 / ( 1-x )”，当  -1<x<1 时，幂级数“∑(n=0，n=∞)  x^n ”的和函数就是“ 1 / ( 1-x )”；同理，上述②中的“∑(n=0，n=∞) (-1)^n x^n = 1 / ( 1+x ) ”，当  -1<x<1 时，幂级数“∑(n=0，n=∞) (-1)^n x^n”的和函数就是“ 1 / ( 1+x )”。
④注意，①②中是在n从0开始满足的，不要死记。

（2）对幂级数在收敛区间内“逐项积分，逐项求导”来将“幂级数”变成“等比形式的幂级数”，进而利用“等比求和”求出其和函数。
①∑(n=0，n=∞)  x^n/n        （这个幂级数的收敛区间为 lim(n--->∞) | a(n+1)/an | = | x |，因此收敛区间为 | x | <1，故x的取值范围 -1<x<1 ）
记 S(x) = ∑(n=0，n=∞)  x^n/n，则 S ' (x) = ∑(n=0，n=∞)  x^(n-1)，发现此时 S'(x)变成了等比形式的幂级数，故其可以利用“等比求和”求出其和函数；
为 S'(x) = ∑(n=0，n=∞)  x^(n-1) = 1/(1-x) （ | x | < 1 ）;
对 S'(x) 使用牛莱公式来求出 S(x)，即“ S(x) - S(0) = ∫(0---x) S'(t) dt ”。

注意：如果为“ S(x) - S(1/3) = ∫(1/3---x) S'(t) dt ”也是可以的，但是 S(1/3) 这个数项级数“∑(n=0，n=∞)  (1/3)^n/n”不太容易求出这个数项级数的和，故采用 S( 0 )。

②∑(n=0，n=∞)  x^(n+1) / n (n+1)        （这个幂级数的收敛区间为 lim(n--->∞) | a(n+1)/an | = | x |，因此收敛区间为 | x | <1，故x的取值范围 -1<x<1 ）
记 S(x) = ∑(n=0，n=∞) x^(n+1) / n (n+1)，则 S ' (x) = ∑(n=0，n=∞)  x^n/n，S''(x) =  ∑(n=0，n=∞)  x^(n-1)；
发现此时 S''(x) 变成了 等比形式的幂级数，故其可以利用“等比求和”求出其和函数；
S''(x) = ∑(n=0，n=∞)  x^(n-1) = x^-1 / (1-x )；（这里把x^-1给提取出来了）
使用一次牛莱，得到“S'(x) - S'(0) = ∫(0---x) S''(t) dt”====> S'(x) = S'(0) + ∫(0---x) S''(t) dt ；
再使用一次牛莱，得到“S(x) - S(0) = ∫(0---x) S'(t) dt”====> S(x) = S(0) + ∫(0---x) S'(t) dt 。

③∑(n=0，n=∞)  x^(n+1) / n
设 S(x) = ∑(n=0，n=∞)  x^(n+1) / n = x ∑(n=0，n=∞)  x^n / n ；
记 S1(x) = ∑(n=0，n=∞)  x^n / n ；
求 S1(x) 就转化为了上述中的②，最后再将求出来的结果 × x就可以了。

④∑(n=0，n=∞)  x^(n-1) / n
凑出通项为 x^n/n 的形式，设 S(x) = ∑(n=0，n=∞)  x^(n-1) / n = 1/x ∑(n=0，n=∞)  x^n / n   （ x ≠ 0 ）；
记 S1(x) = ∑(n=0，n=∞)  x^n / n；
求 S1(x) 就转化为了上述中的②，最后再将求出来的结果 / x 就可以了；
最后 x=0 代入到原级数 ∑(n=0，n=∞)  x^(n-1) / n 中去算一下就可以了。


⑤∑(n=0，n=∞)  x^n / ( n+1 ) ( n-1 )
对于这种通项比较复杂的，要有拆分的思想，即“1/( n+1 )( n-1 ) = 1/2 ( 1/(n-1) - 1/(n+1) )”；
设 S(x) = ∑(n=0，n=∞)  x^n / ( n+1 ) ( n-1 ) = 1/2 [ ∑(n=0，n=∞)  x^n/( n-1) - ∑(n=0，n=∞)  x^n/(n+1) ]；
则 ∑(n=0，n=∞)  x^n/( n-1) = x ∑(n=0，n=∞)  x^(n-1) / ( n-1) 就转化为了③中求和函数的方式；∑(n=0，n=∞)  x^n / (n+1)  = 1/x ∑(n=0，n=∞)  x^(n+1) / (n+1) （x≠0）就转化为了④中求和函数的方式。 


下面的为通过“求导”求出幂级数的和函数的：

⑥∑(n=0，n=∞) n x^(n-1)
∑(n=0，n=∞) n x^(n-1) = [ ∑(n=0，n=∞) x^n ] ' ；
即是我们可以先求出 ∑(n=0，n=∞) x^n 的和函数，然后再对其求1阶导，就得到了幂级数“∑(n=0，n=∞) n x^(n-1)”的和函数。

⑦∑(n=0，n=∞) n (n+1) x^(n-1)
∑(n=0，n=∞) n (n+1) x^(n-1) = [ ∑(n=0，n=∞) x^(n+1) ] '' ；
即是我们可以先求出 ∑(n=0，n=∞) x^(n+1) 的和函数，然后再对其求2阶导，就得到了幂级数“∑(n=0，n=∞) n (n+1) x^(n-1)”的和函数。

⑧∑(n=0，n=∞) n x^n
将通项“n x^n”凑出最基本的“n x^(n-1)”的形式，为 ∑(n=0，n=∞) n x^n = x ∑(n=0，n=∞) n x^(n-1)  = x [ ∑(n=0，n=∞) x^n ] ' ；
即是 求出 幂级数 ∑(n=0，n=∞) x^n 的和函数，然后求导，再 × x 就得到了幂级数“∑(n=0，n=∞) n x^n”的和函数。

⑨∑(n=0，n=∞) n x^(n-2）
将通项“n x^(n-2)”凑出最基本的“n x^(n-1)”的形式，为 ∑(n=0，n=∞) n x^(n-2) = 1/x ∑(n=0，n=∞) n x^(n-1)  = 1/x [ ∑(n=0，n=∞) x^n ] '   （ x≠0 ）；
即是 求出 幂级数 ∑(n=0，n=∞) x^n 的和函数，然后求导，再 / x 就得到了幂级数“∑(n=0，n=∞) n x^n”的和函数。
最后x=0在代入原幂级数中进行验证。

⑩∑(n=0，n=∞) n^2 x^(n-1)
我们希望通项中凑出“n (n+1) x^(n-1) ”，因此“n (n+1) x^(n-1) - n x^(n-1)”；
原级数 ∑(n=0，n=∞) n^2 x^(n-1) = ∑(n=0，n=∞) n (n+1) x^(n-1) - ∑(n=0，n=∞) n x^(n-1) = [ ∑(n=0，n=∞) x^(n+1) ] ''  -   [ ∑(n=0，n=∞) x^n ] ' 。
