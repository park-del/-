函数项级数引入：
级数 ∑(n=1，n=∞) un(x) 称为函数项级数。

理解：级数就是无穷多项相加，如果是无穷多个数相加（一般项是常数un），则这个级数就叫做数项级数；如果是无穷多个函数相加（ 一般项是函数un(x) ），则这个级数就叫做函数项级数。

讨论问题：
（1）该函数项级数在哪有和。（收敛域问题）
（2）求出该函数项级数和。（和函数问题）

1、函数项级数的概念
（1）定义
设函数列 un(x)（n=1,2,3,……）在 I 上有定义，称
   u1(x)+u2(x)+u3(x)+……+un(x)+……
为定义在I上的一个函数项级数。

收敛点：若数项级数 ∑(n=1，n=∞)  un(x0) 收敛，则称 x0 是 ∑(n=1，n=∞)  un(x) 的一个收敛点。
收敛域：所有收敛点构成的集合称为级数的收敛域。

理解：函数项级数 ∑(n=1，n=∞)  un(x) 的通项 un(x) 是含有两个参数“n和x”的，当我们确定了某一点 x=x0 后，这个函数项级数就变成了“ ∑(n=1，n=∞)  un(x0)”，即此时就成为了一个数项级数。如果这个数项级数收敛的话，我们就称“这个函数项级数 ∑(n=1，n=∞)  un(x) 在 x=x0 这一点处是收敛的”。找到所有的函数项级数收敛的x0点，此时这些所有点构成的集合就是收敛域。
 

（2）和函数
设级数∑(n=1，n=∞) un(x) 的收敛域为I，对于任意的 x∈I ，存在唯一的实数 S(x)，使得 ∑(n=1，n=∞) un(x)=S(x) 成立，则定义域为I的函数 S(x) 称为函数项级数 ∑(n=1，n=∞)  un(x) 的和函数。

说明：研究函数项级数的收敛域，求在这个收敛域上的和函数时不太方便研究，因此我们只研究一种特殊的函数项级数，就是通项为幂函数的幂级数。我们只讨论幂级数求收敛域，以及求其在这个收敛域上对应的和函数。


2、幂级数
（1）定义
设 {an}（n=0,1,2,3）是无穷数列，则形如 ∑(n=0，n=∞) an x^n 的函数项级数称为幂函数，其中常数 a0，a1，a2，……，an，……叫做幂级数的系数。

注意：∑(n=0，n=∞) an ( x-x0 )^n 也是属于幂级数的，此时我们只需要进行一次变量替换 u=x-x0，则其就可以变换成 ∑(n=0，n=∞) an u^n 就可以转化为标准的形式了。 
注意：幂级数“∑(n=0，n=∞) an x^n”是从n=0开始取的。
理解：幂级数 ∑(n=0，n=∞) an x^n = a0+a1x+a2x^2+……+anx^n+……，幂级数就是在多项式函数“a0+a1x+a2x^2”的基础上进行了推广，使其变成了无穷多项相加。

（2）敛散性及收敛半径
阿贝尔定理：
若幂级数 ∑(n=0，n=∞) an x^n 在x=x0（x0≠0）处收敛，则当 | x | < | x0 | 时，幂级数绝对收敛（带入x0就是数项级数，这里就是数项级数的敛散性）；若级数 ∑(n=1，n=∞) an x^n 在 x=x0 时发散，则当 | x | > | x0 | 时，幂级数发散。
若幂级数 ∑(n=0，n=∞) an x^n 在（-∞，+∞）上每一点都收敛，就规定 R=+∞；若幂级数 ∑(n=0，n=∞) an x^n 仅在x=0处收敛，就规定R=0。

理解：
①收敛中心
当 x=0 时，幂级数 ∑(n=0，n=∞) an x^n = a0+a1x+a2x^2+……+anx^n+……，对应的值为a0（此时无穷多项级数只有一项，其他项都是为0的，故一定是收敛的），是收敛的，x=0也叫作是这个幂级数“∑(n=0，n=∞) an x^n”的收敛中心；
当 x=x0 时，幂级数 ∑(n=0，n=∞) an ( x-x0 )^n = a0 + a1 ( x-x0 )^1 + a2 ( x-x0 )^2 +……+ an ( x-x0 )^n +……，对应的值为a0，是收敛的，x=x0也叫作是这个幂级数“∑(n=0，n=∞) an ( x-x0 )^n”的收敛中心；
②收敛半径
讨论幂级数“∑(n=0，n=∞) an x^n”，根据阿贝尔定理可以得到，当我们从收敛中心 x=0 处往两边走，遇到一个点x=x0，幂级数在该点处收敛，则幂级数在区间 -x0<x<x0 处是绝对收敛的； 当我们从收敛中心 x=0 处往两边走，遇到一个点x=x0，幂级数在该点处发散，则幂级数在区间 x＜-x0，x>x0 处是发散的。
因此，我们可以找到这样一个点x=R，使得幂级数在 “-R<x<R”这个区间内是绝对收敛的，使得幂级数在“x<-R，x>R”这个区间内是发散的，此时找到的这个区间 (-R，R) 就是这个幂级数的收敛半径。
③收敛域
我们已经知道了幂级数“∑(n=0，n=∞) an x^n”的收敛半径为 (-R，R) ，则幂级数在这个区间内的点都是收敛的（绝对收敛能够推导出收敛），在这个区间之外的点都是发散的。
要想考虑收敛域，还剩下端点的情况，接下来我们单独考虑幂级数在这两个端点处 -R，R 处的敛散性，接下来就可以写出这个幂级数的收敛域了（收敛半径+两个端点考虑=一个新的区间），即这个幂级数的收敛域可能是  开区间、闭区间 或 半开半闭区间。
④收敛区间
收敛区间是与收敛半径相对应的，收敛区间是为一个开区间的，这个开区间就是为（-R，R）。幂级数在这个开区间（-R，R）内的每一个点都是绝对收敛的，在这个开区间（-R，R）外的每一个点都是发散的。换句话说，就是“幂级数条件收敛的点只能够是收敛区间的端点 R 或 -R 处”。

（3）幂级数 ∑(n=0，n=∞) an x^n 的收敛半径的求解方法
定理：设幂级数 ∑(n=0，n=∞) an x^n，当 n≥N时（an ≠ 0），存在极限 lim(n-->∞) | a(n+1)/an | = ρ，
则收敛半径为 R=
① 1/ρ   ，0<ρ<+∞
② +∞   ，ρ=0（算出来的极限ρ为0，1/ρ = 1/0 = +∞，即收敛半径R本质上还是 1/ρ ）
③ 0       ，ρ=+∞（算出来的极限ρ为+∞，1/ρ = 1/+∞ = 0，即收敛半径R本质上还是 1/ρ）

理解： 
当幂级数 ∑(n=0，n=∞) an x^n 中的 x=0 时为 a0，显然这个幂级数是收敛的。
当幂级数 ∑(n=0，n=∞) an x^n 中的 x≠0 时，幂级数 ∑(n=0，n=∞) an  x^n 在其收敛区间内不仅是收敛的，而且还是绝对收敛的，即加上绝对值后构成的正项级数“∑(n=0，n=∞) | an x^n |”收敛。
《1  利用正项级数的比值判别法得到“lim (n--->∞) | a(n+1) x^(n+1) / an x^n | = | x | lim (n--->∞) | a(n+1) | / | an |”, 记“lim (n--->∞) | a(n+1) | / | an | = ρ”，
        则 “lim (n--->∞) | a(n+1) x^(n+1) / an x^n | = | x | ρ”。（由于带有绝对值，最后求出来的这个ρ一定是一个正值）

《2  分类讨论 | x | ρ 的情况（根据正项级数比值判别法的那3种情况进行讨论，由极限的保号性可知，| x | ρ >0，即 ρ>0 ）：
①当 | x | ρ < 1 时，即 -1/ρ < x < 1/ρ 时，幂级数 ∑(n=0，n=∞) an x^n 收敛，即 (-1/ρ，1/ρ) 为这个幂级数的收敛区间，这个幂级数的收敛半径R=1/ρ。
②当 | x | ρ > 1 时，即  x < -1/ρ  或者 x > 1/ρ 时，幂级数 ∑(n=0，n=∞) an x^n 发散，这里则验证了这个幂级数的收敛半径为R=1/ρ。
③当 | x | ρ = 1 时，幂级数 ∑(n=0，n=∞) an x^n 的敛散性不能够确定。


题型：
1、当在题目中出现下面的提示信息的时候，则就是在考察你“阿贝尔定理”。
提示信息：
（1）已知幂级数 ∑(n=0，n=∞) an x^n 在某一点 x=x1 处收敛，即“幂级数在某一个点处收敛”这个信息。
（2）已知幂级数 ∑(n=0，n=∞) an x^n 在某一点 x=x2 处发散，即“幂级数在某一个点处发散”这个信息
（3）已知幂级数 ∑(n=0，n=∞) an x^n 在 x=x0 处条件收敛，即“幂级数在某一个点处条件收敛”这个 信息。

条件反射（信息获取）：
对于（1）：我们能够得到幂级数 ∑(n=0，n=∞) an x^n 在（-x1，x1）内都是绝对收敛的，由绝对收敛能够推导出收敛，故在（-x1，x1）内也都是收敛的（包括已知的在 x=x1 处收敛）。
对于（2）：我们能够得到幂级数 ∑(n=0，n=∞) an x^n 在（-∞，-x2），（x2，+∞）内都是发散的（包括已知的在 x=x2 处发散）。
对于（3）：我们能够得到幂级数 ∑(n=0，n=∞) an x^n 的收敛区间为（-2，2）、收敛域半径为R=2。（条件收敛点就是幂级数绝对收敛，即幂级数收敛与发散的分解点）。

解题思路：当在选择或者填空题中见到了有上面提示信息的时候，则就是再考你阿贝尔定理。利用获取到的信息在进一步处理即可。

注意：当给出的幂级数为 “ ∑(n=0，n=∞) an ( x (+-) x0 )^n”这种形式时，也是一样的。此时只需要将“x-x0”看成一个整体“u”，就变成了标准形式的幂级数“∑(n=0，n=∞) an u^n”。
如果已知幂级数为 “ ∑(n=0，n=∞) an ( x+x0 )^n”在某一点 x=x0 处收敛，因 u=x+x0，先算出u，则对应的幂级数“∑(n=0，n=∞) an u^n”就在（-u，u）处绝对收敛，也即是收敛。
同理， 幂级数“ ∑(n=0，n=∞) an ( x+x0 )^n”在某一点 x=x0 处发散，在某一点 x=x0 处条件收敛也可类比。


2、求幂级数 ∑(n=0，n=∞) an x^n 的收敛区间，收敛半径，收敛域。
解题思路：
（1）对于幂级数 ∑(n=0，n=∞) an x^n 求收敛域。
当 x=0 时，级数收敛。
当 x≠0时，计算出 lim (n-->∞)  | a(n+1)/an |  的极限值ρ（是为一个关于x的表达式），此时这个幂级数 ∑(n=0，n=∞) an x^n 的收敛半径R就为 1/ρ，收敛区间就为 (-1/ρ，1/ρ) ：
①若求出的极限值 ρ=关于x的一个表达式：
《1  令 ρ<1 ,求出x的取值范围“x1 < x < x2”，则当“x1 < x < x2”，这个幂级数是收敛的。
《2  令 ρ>1 ,求出x的取值范围“x < x1”或“ x > x2”，则当“x < x1”或“ x > x2”，这个幂级数是发散的。
《3  接下来讨论幂级数在端点 x=x1，x=x2 处的敛散性，将 x=x1 或者 x=x2 代入到幂级数 ∑(n=0，n=∞) an x^n 中后就变成了一个数项级数，接下来利用数项级数判断敛散性的方法判断这个数项级数是收敛的，还是发散的，就能够得到幂级数在该点处是收敛的，还是发散的。
《4  最后，幂级数 ∑(n=0，n=∞) an x^n 的收敛域为“收敛域 = （收敛区间 + 两个端点中收敛的）所确定的一个新的区间”。 

②若求出的极限值 ρ=0：
《1 此时 ρ是一定满足 ρ<1 的，故当x为“-∞ < x < +∞”，这个级数是收敛的。
《2 最后，幂级数 ∑(n=0，n=∞) an x^n 的收敛域为（-∞，+∞）。

③若求出的极限值 ρ=∞（准确说应该是 +∞）：
《1 此时 ρ是一定满足 ρ>1 的，故当x为“-∞ < x < +∞”，这个级数是发散的，这个幂级数的收敛域为（-∞，+∞）。
《2 最后，幂级数 ∑(n=0，n=∞) an x^n 的收敛域为 x=0。

（2）扩展：同理，幂级数 ∑(n=0，n=∞) an ( x-x0) ^n ，幂级数∑(n=0，n=∞) an ( x-x0) ^2n，求收敛区间、收敛半径，求收敛域的方法是一样的。

区分：题型1是告诉了幂级数在某一点处的敛散性（收敛，发散，条件收敛），来让你解决问题，也可以求收敛域；而题型2是只给了你一个幂级数的式子，其他什么也没有给你来让你求收敛域的。
收敛区间、收敛域的关系：收敛区间是为一个开区间的，假设收敛区间为（x1，x2），则在这个收敛区间内部的点都是绝对收敛的（也是收敛），在这个区间外的点都是发散的，但是，在区间端点 x=x1，x=x2处，幂级数的敛散性是不确定的；收敛域包含了所有收敛的点，只有在求出了收敛区间（x1，x2）之后，确定了端点x1、x2处是否收敛后，才能够得到收敛域，收敛域是一个 开区间、闭区间、半开半闭区间。
