1、二阶常系数齐次线性微分方程
（1）方程形式：y'' + a y' +by = 0，其中a，b是常数。

理解：观察发现，“ y''、y'、y”前面都是为常数的，其中一个是另外两个常数倍的关系。什么样的函数求完导后会是常数倍的关系，函数 y=e^(λx) 求一阶导为 y'=λe^(λx) ，刚好与y是为常数倍的关系，求二阶导为 y'' = λ^2 e^(λx)，其与y'，y 都是为常数倍的关系。因此，这个二阶常系数齐次线性微分方程的解就是为 y=e^(λx)。


特征方程引入：
将方程的解“y=e^(λx)”代入到方程“y'' + a y' +by = 0”中得到：（ λ^2 +aλ +b ）e^(λx) = 0；
显然，e^(λx) 肯定不会为0，故（ λ^2 +aλ +b ）= 0 ，这个“ λ^2 +aλ +b = 0 ”就是为 二阶常系数齐次线性微分方程 y'' + a y' +by = 0 的特征方程；
即只要参数 λ 满足“ λ^2 +aλ +b = 0 ”这个特征方程的话，则 “y=e^(λx)” 就是为这个 二阶常系数齐次线性微分方程 y'' + a y' +by = 0 的解。

我们只需要找到满足这个一元二次方程“ λ^2 +aλ +b = 0 ”的解λ，然后将这个解λ按照“y=e^(λx)”形式写出来，则“y=e^(λx)”就是为这个微分方程 y'' + a y' +by = 0 的特解。
解一元二次方程“ λ^2 +aλ +b = 0 ”：
① △>0，解出两个不相等的解 λ1，λ2。二阶常系数齐次线性微分方程 y'' + a y' +by = 0 的特解为“y1=e^(λ1x)，y2=e^(λ2x)”，由于 y1/y2 = e^(λ1x) / e^(λ2x) = e^(λ1-λ2)x，由于 λ1≠λ2，故y1/y2 不是一个常数，说明这两个特解是线性无关的。知道二阶微分方程的两个线性无关的特解y1，y2，则这个二阶微分方程的通解为 “y=c1e^(λ1x) + c2e^(λ2x)”。

② △=0，此时解出两个相等的解 λ1=λ2。此时只能够写出 y'' + a y' +by = 0 的一个特解“y1=e^(λ1x)”，我们要想求出这个二阶微分方程的通解的话，则应该还要找到一个与y1线性无关的特解y2。
既然y2与y1是线性无关的，则 y2/y1 = u(x)，此时只需要确定出这个函数u(x)，就可以求出 y2=u(x)y1 了，此时的y2与y1线性无关。将 y2= u(x)y1 = u(x)e^(λ1x) 代入微分方程“y'' + a y' +by = 0”，进行化简之后，最后可以得到 u''(x)=0，即只要满足二阶导为0的u(x)都是可以取的，我们一般选取 u(x)=x。此时 y2=xy1=x e^(λ1x)，此时这个微分方程的两个线性无关的解就是“y1=e^(λ1x)，y2= x e^(λ1x)”，求出这个微分方程的通解为“y = c1y1 + c2y2 = c1 e^(λ1x) + c2 x e^(λ1x) ”。

③ △<0，解出两个虚根 α + i β，α - i β。二阶常系数齐次线性微分方程 y'' + a y' +by = 0 的特解为“y1=e^(α + i β)x，y2=e^(α - i β)x”。
利用欧拉公式 e^(i x) = cos x + i sin x 对特解“y1、y2”进行变形：

y1 = e^(α + i β)x =  e^(α x+ i β x) = e^(α x) e^(i β x) = e^(α x) [ cos(βx) + i sin(βx) ]。
y2 = e^(α -  i β)x =  e^(α x - i β x) = e^(α x) e^(-i β x) = e^(α x) [ cos(-βx) + i sin(-βx) ] = e^(α x) [ cos(βx) - i sin(βx) ]。

齐次解的线性组合仍然为齐次的解，故我们可以 y1+y2 来消去“i sin(βx)”，得到“y1+y2 = 2e^(α x) cos βx”====》“( y1+y2)/2 = e^(α x) cos βx”，记为 y1* = e^(α x) cos βx。
齐次解的线性组合仍然为齐次的解，故我们可以 y1- y2 来消去“i sin(βx)”，得到“y1- y2 = 2ie^(α x) sin βx”====》“( y1-y2)/2i  = e^(α x) sin  βx”，记为 y2* = e^(α x) sin βx。
故“y1* = e^(α x) cos βx、 y2* = e^(α x) sin βx”是为这个齐次线性微分方程“ λ^2 +aλ +b = 0 ”的两个特解，由于“y1*/y2* = cot βx ≠ C”，故“y1*、y2*”是为这个齐次方程的两个线性无关的解，故这个齐次线性微分方程的通解为“y = e^(αx) (c1 cos βx + c2 sin βx )”。

2、二阶常系数非齐次线性微分方程
（1）方程形式：y'' + ay' + by = f(x)，其中a，b是常数。
理解：由于“非齐通解=齐通+非齐特”，我们已将找到齐次的通解，故接下来关键就是找出“非齐次特解”。

（2）解法
非齐次线性方程组  y'' + ay' + by = f(x) 中的

①如果 f(x) = x^2 e^( 0x ) = x^2，设特解:

瞄着右边的f(x)设，右边包含一个二次多项式，我们就给它设全了（设成 Ax^2 + Bx +C ）；右边包含的 e^( 0x ) 不用设，直接乘以就行（就是×1）；最后不要忘了乘以 x^k，即 × x^k。
设特解 y* = ( Ax^2 + Bx +C ) · x^k （k=0,1,2）
0不是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的根，则 k=0
0是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的单根（λ1 ≠ λ2，且 λ1=0），则 k=1
0是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的重根（λ1 = λ2 = 0），则 k=2 

②如果 f(x) = x^2 e^( αx ) （α ≠ 0），设特解:

瞄着右边的f(x)设，右边包含二次多项式，我们就给它设全了（ 设成Ax^2 + Bx +C ）；右边包含 e^( αx )，不用设，直接乘以就可以了；最后不要忘了乘以 x^x，即 × x^k。
设特解 y* = ( Ax^2 + Bx +C ) · e^( αx ) · x^k （k=0,1,2）

α不是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的根，则 k=0
α是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的单根（λ1 ≠ λ2，且 λ1=0），则 k=1
α是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的重根（λ1 = λ2 = 0），则 k=2 


③如果 f(x) = x^2 e^( αx ) cos βx，设特解：
瞄着右边的f(x)设，右边是包含二次多项式，我们就给它设全了（设成 Ax^2 + Bx +C ）；右边包含的 e^( αx ) 不用设，直接乘以就行；右边包含 cos βx，我们就需要把 cos 和 sin 都给设出来；最后不要忘了乘以 x^x，即 × x^k。
设特解 y* = e^( αx ) [ ( A1x^2 + B1x +C1 )cos βx + ( A2x^2 + B2x +C2 )sin βx ] · x^k（k=0，1），cos βx 和 sin βx 前面的系数就是所设置的二次多项式 Ax^2 + Bx +C，。

α (+-) i β 不是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的根，则 k=0；
α (+-) i β 是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的根，此时就已经确定了是为两个不同的根，就一定是单根的，故k就已经定了，k=1。

④如果 f(x) = x^2 e^( αx ) cos βx + x e^( αx ) sin βx，即f(x)含有多项时，设特解：
按照所包含的多项式中的次数最高的那一项来设，这两项分别包含的多项式的次数为 2、1，选择次数为2的那一项来设，
特解 y* =  e^( αx ) [ ( A1x^2 + B1x +C1 )cos βx + ( A2x^2 + B2x +C2 )sin βx ] · x^k（k=0，1）

3、n阶常系数齐次线性微分方程（注意是齐次的，不是非齐次的）


注意：一般只考到3阶，最多只考到4阶。

题型：
1、求二阶常系数齐次线性微分方程“y'' + a y' +by = 0”的通解。
解题思路：
首先找出这个微分方程对应的特征方程“λ^2 + a λ +b = 0”。（y''对应λ^2，y'对应λ^1，y对应λ^0）
判断这个特征方程的△：
①如果△>0，则特征方程求出来两个不相等的实根 λ1、λ2，此时微分方程通解就为“y = c1e^(λ1x) + c2e^(λ2x)”。
②如果△=0，则特征方程求出来一个实根 λ（二重根），该二重根λ对应微分方程特解为“y1=e^(λx)”，找到微分方程另一个线性无关的特解为“y2=x e^(λx)”，此时微分方程通解为“y = c1 e^(λx) + c2 x e^(λx) = [ c1+c2x ] e^(λx)”。
③如果△<0，则特征方程求出来两个虚根  α + i β，α - i β，此时微分方程的通解为“y = e^(αx) (c1 cos βx + c2 sin βx )”。


2、已知二阶常系数齐次线性微分方程的通解，求出这个二阶常系数齐次线性微分方程。
解题思路：根据通解的表达式中确定出特征方程的解，由特征方程的解确定出特征方程（就是由一元二次方程的解确定出这个一元二次方程），由特征方程确定出微分方程。

①如果给出你的通解的形式为“y = c1e^(λ1x) + c2e^(λ2x)”，则我们就可以得知“特征方程有两个不相等的实根 λ1 和 λ2”；由“λ1 和 λ2”可以确定这个特征方程，“λ1 + λ2 = -a”“λ1 λ2 = b”，写出特征方程“λ^2 + a λ +b = 0”（这里也是可以直接为  (λ-λ1 ) (λ-λ2) =0 ，这个就是特征方程）；由特征方程写出对应的二阶常系数齐次线性微分方程为“y'' + a y' +by = 0”。

②如果给出你的通解的形式为“y = c1 e^(λ1x) + c2 u(x) e^(λ1x)”，则我们就可以得知“特征方程有两个相等的实根 λ1 和 λ2”；由“λ1 和 λ2”可以确定这个特征方程，“λ1 + λ2 = -a”“λ1 λ2 = b”，写出特征方程“λ^2 + a λ +b = 0”（这里也是可以直接为  (λ-λ1 ) (λ-λ2) =0 ，这个就是特征方程）；由特征方程写出对应的二阶常系数齐次线性微分方程为“y'' + a y' +by = 0”。

③如果给出你的通解的形式为“y = e^(αx) (c1 cos βx + c2 sin βx )”，则我们就可以得知“特征方程有两个虚根 λ1= α + i β 和 λ2 =  α - i β”；由“λ1 和 λ2”可以确定这个特征方程 (λ-λ1 ) (λ-λ2) =0，即是“( λ-(α + i β) ) ( λ+(α + i β) ) =0”；由特征方程写出对应的二阶常系数齐次线性微分方程为“y'' + a y' +by = 0”。


3、求n阶常系数齐次线性微分方程“y(n) + p1y(n-1) + …… + p(n-1)y' + pny = 0”的通解，常见的就是3阶，4阶，由于题目考察最高不会超过4阶，故下面以
4阶的常系数齐次线性微分方程“y(4) + p1 y(3) + p2 y''+ p3 y' + p4 =0”为例 来求通解。
解题思路：
①首先找到这个微分方程对应的特征方程“λ^(4) + p1 λ^(3) + p2 λ^(2) + p(3) λ +p4 = 0”。（4阶导则λ就是λ^4，3阶导则λ就是λ^3，没有导（0阶导）则λ就是λ^0）
②求出这个特征方程的解“λ1，λ2，λ3，λ4”。（一元4次方程，可以看成 ( x^2)^2，最终是会求出4个根的；同样，一元3次方程最终是会求出3个根的）
③求出的解分成三种，单根的，重根的，共轭复根的。（一元4次方程的重根最常见的就是2重根，有时候会出现3重根，但一般不会出现4重根的情况）
④单根 λ 的通解形式为 y1= c e^(λx)；2重根 λ 的通解形式为 y2 = (c1+c2 x) e^(λx)；3重根 λ 的通解形式为 y3 = (c1+ c2 x + c3 x^2) e^(λx)；共轭复根 α+βi，α-βi 的通解形式为 y3 = (c1 cos βx +c2 sin βx) e^(αx)。
⑤最后，将特征方程的每个根对应的通解加在一起，就构成这个4阶常系数齐次线性微分方程的通解了。（从④中可以看出，单根对应1个任意常数，2重根对应2个任意常数，3重根对应3个任意常数，共轭复根对应2个任意常数。故最后这些根的通解加在一起，任意常数的个数一定是为4的，即是这个4阶非齐次线性微分方程的通解）
 

扩展题型：已知n阶常系数齐次线性微分方程的通解，让你反过来写出这个n阶常系数齐次线性微分方程，由于不会超过4阶，故我们重点关注3阶和4阶的怎么求就可以了，这里以4阶为例。
已知4阶常系数齐次线性微分方程的通解，让你反过来写出这个4阶常系数齐次线性微分方程。
解题思路：
①由通解的形式找到特征方程对应的各根：
单根 λ 的通解形式为 y1= c e^(λx)；2重根 λ 的通解形式为 y2 = (c1+c2 x) e^(λx)；3重根 λ 的通解形式为 y3 = (c1+ c2 x + c3 x^2) e^(λx)；共轭复根 α+βi，α-βi 的通解形式为 y3 = (c1 cos βx +c2 sin βx) e^(αx)。
②假设找到了 2重根  λ1=2，共轭复根 λ2,3 = α (+-) βi，则我们就可以写出这个特征方程为“ ( λ - 2 )^2  ( λ - α -iβ ) ( λ - α + iβ ) ”。(注意，2重根λ=2 对应 ( λ-2 )^2 )
③对特征方程“ ( λ - 2 )^2 ( λ - α -iβ ) ( λ - α + iβ ) ”进行化简“λ^(4) + p1 λ^(3) + p2 λ^(2) + p(3) λ +p4 = 0”，此时就可以对照着写出4阶齐次线性微分方程“y(n) + p1y(n-1) + …… + p(n-1)y' + pny = 0”。

4、已知一个二阶常系数非齐次线性微分方程“y'' + a y' +by = f(x)”，问你这个二阶常系数非齐次线性微分方程的特解形式，就是问你这个微分方程的特解可以怎样设？
解题思路：
首先找出这个微分方程“y'' + a y' +by = f(x)”所对应的齐次线性微分方程的特征方程“λ^2 + aλ + b = 0”，求出这个特征方程的根，可能为“λ1，λ2”“λ1 = λ2”“λ1=α+βi，λ2=α-βi”。然后根据f(x)设特解，f(x)应该是为一个乘积式，这个乘积式中可以包含3部分，分别为 多项式（如 x^2+7x）、e的指数式 e(^αx)、三角式 sin βx 或者 cos βx。
①f(x)乘积式中的“多项式”决定了非齐次特解中相乘的“多项式”。
多项式给设全了（为 x^2+4 就设为“Ax^2+Bx+C”,为 1 就设为“A”）；

②f(x)乘积式中的 “e^(αx)” 确定了非齐次特解中相乘的“e^(αx) x^k”。
确定 x^k，看 α 是 齐次特征方程“λ^2 + aλ + b = 0”的什么根来确定出 k的值；
确定e^(αx)，就是f(x)乘积式中的e^(αx)。

补充：
α不是根，k=0；α为单根，k=1；α为重根，k=2。
如果f(x)的乘积式中带有三角，则需要由e^(αx) 与  sin βx 或者 cos βx 共同确定，即是看 α+βi，看 α-βi 是特征方程的什么根。

③f(x)乘积式中的“sin βx 或者 cos βx” 确定了非齐次特解中相乘的“（ sin βx + cos βx ）”。

④最后将①②③设出来的上面三个相乘就得到了非齐次的特解。（注意，这里为了统一，将带有三角sin βx + cos βx 也当成是 × (Ax^2+B^x+C) ，其实应该是分别 × (A1x^2+B1^x+C1)，× (A2x^2+B2^x+C2)   ）

（1）当f(x)为标准形式时可以直接设，如：
① f(x) = x^2 e^( αx ) 。
设特解：y* = ( Ax^2+Bx+C ) e^(αx) x^k 
（k=0、1、2，由k是特征方程的什么根决定）

② f(x) = x^2 e^( αx ) cos βx 。
设特解：y* = ( Ax^2+Bx+C )（sin βx + cos βx）e^(αx)  x^k =  [  ( A1x^2+B1x+C1 ) sin βx + ( A2x^2+B2x+C2 ) cos βx）] e^(αx) x^k。
（k=0、1、2，由k是特征方程的什么根决定）

③ f(x) = x^3 e^( αx ) cos βx + x^2 e^( αx ) sin βx。（有多项时选择“多项式次数最高”的那一项设）
设特解：选择“f(x) = x^3 e^( αx ) cos βx ”来设特解，为 
y* =   ( Ax^3+Bx^2+Cx +D )（sin βx + cos βx）e^(αx)  x^k =  [  ( A1x^3+B1x^2+C1x +D1 ) sin βx + ( A2x^3+B2x^2+C2x +D2 ) cos βx）] e^(αx) x^k。
（k=0、1、2，由k是特征方程的什么根决定）

如：微分方程 y''+y = x sin x + x^2 cos x 的特解，可设为?
解：
齐次特征方程为“λ^2+1=0”,特征方程的根为“λ1 = i，λ2 = -i”。
选择多项式次数最高的“f(x) = x^2 cos x e^(0x)”来设。
设特解：y* = ( Ax^2+Bx+C )（sin βx + cos βx）e^(αx)  x^k =  [  ( A1x^2+B1x+C1 ) sin βx + ( A2x^2+B2x+C2 ) cos βx）] e^(αx) x^k 
	  = [  ( A1x^2+B1x+C1 ) sin βx + ( A2x^2+B2x+C2 ) cos βx）]  x^k。
由于“f(x) = x^2 cos x e^(0x)”带有三角，故看 0+i 、0-i 是不是特征方程“λ^2+λ=0”的根，两个都为单根，故 k=1，因此 y* =  [  ( A1x^2+B1x+C1 ) sin βx + ( A2x^2+B2x+C2 ) cos βx）] x。
所以微分方程“y''+y = x sin x + x^2 cos x”特解可设为“y* =  [  ( A1x^2+B1x+C1 ) sin βx + ( A2x^2+B2x+C2 ) cos βx）] x”。


（2）当f(x)不是为标准形式时不可以直接设，必须将其转化为标准形式在设（常常利用叠加原理）：
①f(x) = ( cos x )^2
可以利用降幂公式“( cos x )^2 = 1/2 - cos 2x / 2”,在利用叠加原理得到“y'' + a y' +by = 1/2”和“y'' + a y' +by = - cos 2x / 2”。此时就可以分别对这两个式子设特解 y1* 和 y2* 了，最后“y1* + y2*”就是为“y'' + a y' +by = 1/2 - cos 2x / 2”的特解，即为“y'' + a y' +by = ( cos x )^2”的特解。

②f(x) = e^(λx) + e^(-λx)
利用叠加原理将其拆分成“y'' + a y' +by = e^(λx)”和“y'' + a y' +by = e^(-λx)”，转化为了标准的形式，加下来就可以分别对这两个式子设处特解，分别记为 y1* 和 y2*，则根据叠加原理“y1* + y2*”就是为“y'' + a y' +by = e^(λx) + e^(-λx)”的特解。



5、求二阶常系数非齐次线性微分方程“y'' + a y' +by = f(x)”的通解。
解题思路：因为要求非齐次通解，非齐通=齐通+非齐特，因此要分别求出齐通、非齐特。

（1）求出齐次特征方程的根，求出齐次线性微分方程的通解 ym。 
首先找出这个微分方程对应的齐次的特征方程“λ^2 + a λ +b = 0”。
求解出这个齐次特征方程的根，并求出这个齐次线性微分方程的通解 ym。（题型1的解题思路）

（2）设非齐次特解为 y*：
①如果 f(x) = x^2 e^( αx ) ，瞄着右边的f(x)设，右边包含二次多项式，我们就给它设全了（ 设成Ax^2 + Bx +C ）；右边包含 e^( αx )，不用设，直接乘以就可以了；最后不要忘了乘以 x^x，即 × x^k。
设特解  y* = ( Ax^2 + Bx +C ) · e^( αx ) · x^k （k=0,1,2）

②如果 f(x) = x^2 e^( αx ) cos βx，瞄着右边的f(x)设，右边是包含二次多项式，我们就给它设全了（设成 Ax^2 + Bx +C ）；右边包含的 e^( αx ) 不用设，直接乘以就行；右边包含 cos βx，我们就需要把 cos 和 sin 都给设出来；最后不要忘了乘以 x^x，即 × x^k。
设特解 y* = e^( αx ) [ ( A1x^2 + B1x +C1 )cos βx + ( A2x^2 + B2x +C2 )sin βx ] · x^k（k=0，1），cos βx 和 sin βx 前面的系数就是所设置的二次多项式 Ax^2 + Bx +C，。

③如果 f(x) = x^2 e^( αx ) cos βx + x e^( αx ) sin βx，即f(x)含有多项时， 按照所包含的多项式中的次数最高的那一项来设，这两项分别包含的多项式的次数为 2、1，选择次数为2的那一项来设，
特解 y* =  e^( αx ) [ ( A1x^2 + B1x +C1 )cos βx + ( A2x^2 + B2x +C2 )sin βx ] · x^k（k=0，1）

如果为①情况，则就判断 α 与齐次特征方程“λ^2 + a λ +b = 0”的根的关系：
α不是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的根，则 k=0
α是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的单根（λ1 ≠ λ2，且 λ1=0），则 k=1
α是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的重根（λ1 = λ2 = 0），则 k=2 
此时非齐次特解  y* = ( Ax^2 + Bx +C ) · e^( αx ) · x^k （k=0,1,2）中，α（非齐次等号右边可以确定），k都是确定的，只有参数 A，B，C 不确定。

如果为②情况，则就判断 α (+-) i β 与齐次“λ^2 + a λ +b = 0”的根的关系：
α (+-) i β 不是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的根，则 k=0；
α (+-) i β 是对应的齐次特征方程“ λ^2 +aλ +b = 0 ”的根，此时就已经确定了是为两个不同的根，就一定是单根的，故k就已经定了，k=1。
此时非齐次特解 y* = e^( αx ) [ ( A1x^2 + B1x +C1 )cos βx + ( A2x^2 + B2x +C2 )sin βx ] · x^k（k=0，1）中，α、β、k都是确定的，只有参数 A，B，C不确定。

（3）将非齐次特解y*代入到二阶常系数齐次线性微分方程“y'' + a y' +by = f(x)”中，利用待定系数法求出参数，最后得到特解 y*。
已知非齐次特解 y*，
求 ( y* )'' ，
求 ( y* )'  ，
将 y，( y* )''，( y* )'  代入到“y'' + a y' +by = f(x)”中，利用待定系数求出A、B、C（对于情况①）来说，

（4）非齐次通解=齐次通解+非齐次特解，求出了齐次通解ym，非齐次特解y*，写出非齐次特解。
写出 y = ym + y*。
此时的 y 就是所要求的这个二阶常系数非齐次线性微分方程的通解。


6、已知二阶常系数非齐次线性微分方程的通解“y =  c1e^(2x) + c2e^(3x) - ( 1/2 x^2 + x ) e^(2x)”，请找出这个非齐次线性微分方程。
解题思路：由于非齐次的通解=齐次通解+非齐次特解。先找出对应的齐次通解，为“y =  c1e^(2x) + c2e^(3x)”，根据这个齐次通解确定出对应的齐次的特征方程的两个根，为 λ1=2，λ2=3。
写出特征方程“ ( λ-2 ) ( λ-3 ) = 0”，即“λ^2 - 5 λ + 6 = 0”。根据特征方程找出对应的齐次线性微分方程“ y'' -5y' + 6y = 0 ”，接下来只需要找到“=右边的f(x)”就可以找到非齐次线性微分方方程了，由于 当将非齐次特解“y* = - ( 1/2 x^2 + x ) e^(2x)”代入到齐次线性微分方程“y'' -5y' + 6y ”后，其就是为f(x)的，即“y'' -5y' + 6y = f(x)”，这样我们就找出了这个非齐次线性微分方程了“y'' -5y' + 6y = f(x)”。
