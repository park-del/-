1、二重积分的概念
二重积分的理解：定积分表示的是曲边梯形的面积，而二重积分表示的是曲顶柱体的体积。二重积分和定积分的本质是一样的，也是为一个极限，这个极限为 lim λ->0 ∑(i=1---n) f(xi，yi) △σ，即是为一个具体的值。定积分的被积函数是为一元函数的，积分区域也是为一元函数的定义区间的，而二重积分的被积函数是为二元函数的，积分区域也是为二元函数的定义区间D的。因此，可以说，二重积分是由 二元函数f(x,y) 和 积分区间D 唯一决定的。

二重积分表示的几何意义的理解：二重积分表示的是为一个曲顶柱体的体积的。二重积分是 二元函数f(x,y) 在一个积分区间D 上进行积分的结果。f(x,y)表示的是为一个曲面的，而积分区间D是为xoy面中的一个平面的。任意取 xoy面 上的一块小区域 △σ（也可以认为是在平面D上所取的一个小平面），在这个小平面△σ 上任意取一点（x0，y0）(在平面上取点是为一个坐标的)，则z=f(x0，y0)就是为这个小平面△σ上（x0，y0）这一点所对应的高的。如果这个小平面△σ足够小的话，即是这个小平面△σ的面积足够小的话，又由于二元函数f(x,y)在区域D上是连续的，故f(x0,y0)就可以近似看成是这个小平面△σ的高了，用 f(x0,y0)△σ 就是这个小的曲顶主体的体积。用来描述小平面△σ的面积非常小的是“在△σ上距离最远的两点（x1，y1）和（x2，y2）的距离都趋向于0”，二重积分极限式子中的λ就是所有△σ上距离最远的两点之间的距离，如果这个λ-->0的话，就说明了所有的△σ都是非常小的。 即 lim λ->0 ∑(i=1---n) f(xi，yi) △σ 表示的就是对应积分区间D上的曲顶柱体的体积。

二重积分的存在性定理：
和定积分的存在性定理类似，先回顾一下定积分的存在性定理：
（1）函数f(x)在闭区间[a，b]上连续，则f(x)在区间[a，b]上可积。
（2）函数f(x)在闭区间[a，b]上有界，且只有有限个间断点，则f(x)在区间[a，b]上可积。
二重积分的存在性定理：若f(x，y)在有界闭区域D上连续，则 ∬D f(x，y) dσ 存在。


2、二重积分的性质（类比于前面学过的定积分的性质）
（1）二重积分的线性性质
 ∫∫ D  [ af(x，y) + bg(x，y) ] dσ =  a∫∫ D f(x，y) dσ + b∫∫ D g(x，y) dσ。
理解：二重积分本身就是一个极限的，这个线性性质就是根据极限四则运算的准则得来的。如果 ∫∫ D f(x，y) dσ 存在， ∫∫ D g(x，y) dσ 存在，根据极限四则运算的准则，和差的极限就可以拆分成极限的和差。（将∫∫ D求积分，看成是为一个极限符号，求积分本质上也是求极限的）

（2）二重积分的积分区域的可加性（与定积分的积分区间的可加性相似，类比着来记忆）
区域D被分成了两个区域D1 和 D2，则
∫∫ D  f(x，y)  dσ = ∫∫ D1  f(x，y)  dσ + ∫∫ D2  f(x，y)  dσ。
理解：二重积分的几何意义表示的是曲顶柱体的体积，将积分区域D分为了两部分，相当于是将曲顶主体的体积分成了两部分来求，结果是一样的。

何时用：和定积分的积分区间的可加性一样，都是当被积函数为分段函数的时候会用到这个积分区间的可加性的。

（3）若在D上，f(x，y)=1，A为区域D的面积，则∫∫ D  1 dσ = A 。
理解：高为1的平顶柱体的体积在数值上等于柱体的底面积。

何时用：以后但凡要计算一个平面图形的面积的，我们可以借助定积分来计算出这个平面图形的面积（直角坐标的、极坐标的怎么算面积，有几个公式的）；也可以从二重积分的角度入手来计算这个平面图形的面积，以后但凡要计算一个平面图形的面积的话，可以将这个平面图形当成是积分区域D，计算二重积分∫∫ D  1 dσ，算出来的结果就是区域D的面积，即要计算的平面图形的面积 。

（4）二重积分 由积分区域D上的f(x，y)与g(x，y)的大小关系得到，对应二重积分∫∫D f(x，y) dσ与∫∫D g(x，y) dσ的大小关系。

先回顾一下于定积分的性质：
若在积分区间[a，b]上，有f(x)<=g(x)，则∫(a----b) f(x) dx <= ∫(a----b) f(x) dx 。 
若在积分区间[a，b]上，有f(x) <= g(x)，且f(x)不恒等于g(x)，则∫(a----b) f(x) dx <= ∫(a----b) f(x) dx。 
理解
《1》当 f(x)>=0，g(x)>=0，f(x)<=g(x)时：
将两个曲边梯形分别记为A1和A2，且这两个曲边梯形的底相同（对应的就是两个定积分的积分区间相同），曲边梯形A1的高 <= 曲边梯形A2的高（对应的就是二重积分中的f(x)<=g(x)，其中f(x)为曲边梯形A1的高，g(x)为曲边梯形A2的高），则 曲边梯形A1的面积 <= 曲边梯形A2的面积（即 ∫(a----b) f(x) dx <= ∫(a----b) f(x) dx ）。
《2》当 f(x)<=0，g(x)<=0，f(x)<=g(x)时：
将两个曲边梯形分别记为A1和A2，且这两个曲边梯形的底相同（对应的就是两个定积分的积分区间相同），曲边梯形A1的高 >= 曲边梯形A2的高（对应的就是二重积分中的 -f(x)>=-g(x)，其中-f(x)为曲边梯形A1的高，-g(x)为曲边梯形A2的高），则 曲边梯形A1的面积 >= 曲边梯形A2的面积，即-曲边梯形A1的面积 <= -曲边梯形A2的面积（即 ∫(a----b) f(x) dx <= ∫(a----b) f(x) dx ,此时的定积分表示的是曲边梯形面积的相反数）。

二重积分也是有这个性质的：
若在积分区域D上，有f(x，y)<=g(x，y)，则 ∫∫D f(x，y) dσ <= ∫∫D g(x，y) dσ。
若在积分区域D上，有f(x，y)<=g(x，y)，且f(x，y)不恒等于g(x，y)，则 ∫∫D f(x，y) dσ <= ∫∫D g(x，y) dσ。
理解：
《1》当f(x,y)>=0，g(x,y)>=0，f(x，y)<=g(x，y)时：
将两个曲顶柱体分别记为A1和A2，这两个曲顶柱体的底面积都是相同的（即对应了两个二重积分的积分区域D相同），如果曲顶柱体A1对应区间上的高f(x,y) <= 曲顶柱体A2对应区间上的高g(x,y) 的话，则就说明 曲顶柱体A1的体积 <= 曲顶柱体A2的体积（即是二重积分∫∫D f(x，y) dσ <= ∫∫D g(x，y) dσ）。
《2》当f(x,y)<=0，g(x,y)<=0时，f(x，y)<=g(x，y)时：
将两个曲顶柱体分别即为A1和A2，这两个曲顶柱体的底面积都是相同的（即对应了两个二重积分的积分区域D相同），根据 f(x,y)与g(x,y)都小于0，则说明了 曲顶柱体A1对应区间上的高f(x,y) >= 曲顶柱体A2对应区间上的高g(x,y) （由于曲顶柱体的高是为一个正数的，此时-f(x,y)，-g(x,y)才是为高的），则就说明  曲顶柱体A1的体积 >= 曲顶柱体A2的体积，即是 -曲顶柱体A1的体积 <= -曲顶柱体A2的体积（即是二重积分∫∫D f(x，y) dσ <= ∫∫D g(x，y) dσ，此时的二重积分表示的是曲顶柱体体积的相反数）。

注意：和定积分一样，从 被积函数之间的关系 可以推导 积分之间的关系，但是从 积分之间的关系 不能够推导出 被积函数之间的关系。即是知道 ∫∫D f(x，y) dσ <= ∫∫D g(x，y) dσ，不能够推导出 f(x，y) <=  g(x，y)。
理解：
《1》当f(x,y)>=0，g(x,y)>=0时：
此时就相当于曲顶柱体A1的体积 <= 曲顶柱体A2的体积，且这两个曲顶柱体A1和A2的底面积相等，此时是可以推处曲顶柱体A1的高 <= 曲顶柱体A2的高 的，即是由 ∫∫D f(x，y) dσ <= ∫∫D g(x，y) dσ，能够推导出 f(x，y) <=  g(x，y)。
《2》当f(x,y)<=0，g(x,y)<=0时：
此时就相当于 -曲顶柱体A1的体积 <= -曲顶柱体A2的体积，且这两个曲顶柱体A1和A2的底面积相等。此时说明了 曲顶柱体A1的体积 >= 曲顶柱体A2的体积，且这两个曲顶柱体A1和A2的底面积相等，此时推导出的应该是 f(x，y) >=  g(x，y)。

 
（5）和定积分那里一样，二重积分也是绝对值符号取在外面小于等于绝对值符号取在里面的。

（6）二重积分补充性质：
补充：若f(x,y)>=0，且 D1包含于D2（即是D1面积小于D2面积），则 ∫∫D1 f(x，y) dσ < ∫∫2 D f(x，y) dσ。
理解：f(x,y)>=0说明了如果高为非负的话，且高相同的情况下（被积函数相同的情况下），底面积越大的话则对应的二重积分就越大。

补充：若f(x,y)>=0，则 ∫∫D f(x，y) dσ>=0；若f(x,y)>=0，且f(x，y)不等于0，则 ∫∫D f(x，y) dσ>0。
理解：在一元函数中这个成立的前提是积分下限小于积分上限，只有在这个前提下一元函数才满足上面的式子；而二元函数只是说了积分区域D，至于这个积分区域D到底有没有正负则是没有展开说的，因此现在先记住，二重积分的正负是由被积函数f(x,y)决定的。

题型：
1、比较二重积分的大小。
（1）如果这两个二重积分的积分区域D一样的话。
解题思路：此时需要比较的就是在这个积分区域D上的被积函数（为一个二元函数）的大小就可以了。  
（2）如果积分区间不一样，而被积函数一样的话。
解题思路：利用积分区域的可加性，将积分区域一样，被积函数一样的那部分给变出来，然后看多出来的那一块是正的，还是负的，还是等于0的。然后就可以比较这两个二重积分的大小了。

注意：如果考察我们二重积分比较大小，考察我们的不是将这两个二重积分算出来看谁大谁小，这里是在考察二重积分的性质的，考察二重积分比较大小的问题一般考察的是为小题的。
注意：以后只要看到二重积分这涉及不等式，一定要看一下这是不是能够用到二重积分的性质，这个很重要。
