3个问题：
①会求直线方程
②会判断直线与直线的位置关系
③会判断直线与平面的位置关系

1、空间直线方程
直线的方向向量：平行于空间直线L的非零向量s称为直线L的方向向量。

（1）直线的点向式方程（对称式方程，标准式方程）
设 s=（m，n，p）是直线L上的一个方向向量，M0（x0，y0，z0）是直线上一定点，则 “(x-x0)/m = (y-y0)/n = (z-z0)/p” 称为直线的点向式方程。

理解：
①假设直线L上有一点 M0（x0，y0，z0），直线的方向向量为 s=（m，n，p），在直线上任意找一点 M（x，y，z），则 M0M = （x-x0，y-y0，z-z0），因为向量 M0M 与 方向向量s平行，故 M0M=k s，即“(x-x0)/m = (y-y0)/n = (z-z0)/p”，这个 x，y，z 的等式关系就称为是直线的点向式方程。
②“点向式”方程顾明思义，就是我们只要知道了直线L上的一个点 M0=（x0，y0，z0），知道了这个直线L的方向向量 s=（m，n，p），我们就可以写出这个直线L的方程了。

注意：由于直线的方向向量s可以包含0的，如 s=（3，0，0），故写出的直线方程分母位置上也是可以为0，分母只是标识了这条直线的方向向量，方向向量为 s=（3，0，0）的直线方程为
“(x-x0)/3 = (y-y0)/0 = (z-z0)/0”

提示：从直线的点向式方程“(x-x0)/m = (y-y0)/n = (z-z0)/p”可以得到这条直线过“（x0，y0，z0）”这个点，这条直线的方向向量  s=（m，n，p）。

（2）直线的参数方程（很容易看出直线的方向向量s，与该直线过的一个点）
            {  x = x0+mt
方程组  {  y = y0+nt  ，其中 t 为参数，称为直线的参数方程，其中直线经过点 M0（x0，y0，z0），方向向量为  s=（m，n，p）。
            {  z =  z0+pt

推导：令直线的点向式方程“(x-x0)/m = (y-y0)/n = (z-z0)/p”右边“=t”，就可以得到“x=x0+mt，y=y0+nt，z=z0+pt”，即直线的参数方程。 


（3）直线的一般方程（平面P1的法向量n1=（A1，B1，C1），平面P2的法向量n2=（A2，B2，C2），则直线的一般方程的方向向量为 s = n1 × n2）
      {  A1x+B1y+C1z+D1=0，
称			 为直线的一般方程，它是由平面 A1x+B1y+C1z+D1=0 与 A2x+B2y+C2z+D2=0 相交得到的。
      {  A2x+B2y+C2z+D2=0，

理解：两个平面相交可以得到一条直线。

2、点到直线的距离
 点M0是直线L外一点，M是直线L上任意一点，直线L的方向向量为s，则点M0到直线L的距离 d=| M0M × s | / | s | 。

理解：求点M0到直线L的距离，我们先在直线L上任取一点M，假设向量 MM0 与 直线L的方向向量s之间的夹角为θ，则 | MM0 | sin θ 就是为M0到这条直线L的距离。sin θ是在叉乘中见到的，
M0M × s = | MM0 | | s | sin θ，因此“| MM0 | sin θ = M0M × s / | M0M |”，即点M0到直线L的距离 d=| M0M × s | / | s | 。

3、直线与直线的位置关系
（1）两直线的夹角
两个直线方向向量的夹角（通常指钝角或直角）叫做两直线的夹角，即两直线夹角φ的取值范围为“0≤φ≤π/2”。

（2）两直线夹角的计算
设直线L1与L2的方向向量依次为 s1=(m1，n1，p1) 和 s2=(m2，n2，p2)，则两直线的夹角φ的余弦为：
cos φ = | s1 · s2 | / | s1 | | s2 | = | m1m2+n1n2+p1p2 | / 根号（ m1^2+n1^2+p1^2 ）根号（m2^2+n2^2+p2^2）。


理解：两个直线夹角的计算其实就是两个直线对应的方向向量s1和s2之间夹角的计算，只不过要对 cos φ 加上绝对值，因为 0≤φ≤π/2。

（3）两直线的位置关系

两直线L1和L2垂直《====》s1 垂直 s2《====》m1m2+n1n2+p1p2=0 。
两直线L1和L2平行《====》s1 平行 s2《====》m1/m2 = n1/n2 = p1/p2 。

理解：两个直线的位置关系其实就是两个直线对应的方向向量的位置关系。
如果两个方向向量 s1=（m1，n1，p1）、n2=（m2，n2，p2） 垂直的话，则有 s1 · s2=0，即“m1m2+n1n2+p1p2=0”。
如果两个方向向量 s1=（m1，n1，p1）、n2=（m2，n2，p2） 平行的话，则有 s1=k s2，即“m1/m2 = n1/n2 = p1/p2 ”。
 
 
4、直线和平面的位置关系
（1）直线和平面的夹角
 
当直线与平面不垂直时，直线与它在平面上的投影直线的夹角φ（0≤φ≤π/2）称为直线与平面的夹角，当直线与平面垂直时，规定直线与平面的夹角为 π/2。（即直线与平面之间的夹角为φ为 0≤φ≤π/2）

（2）直线和平面夹角的计算

设直线的方向向量为 s=（m，n，p），平面的法向量为 n=（A，B，C），直线与平面的夹角为φ，则
sin φ = | s · n | / | s | | n | = | Am+Bn+Cp | / 根号 ( A^2+B^2+C^2 )  根号 ( m^2+n^2+p^2 )。

理解：脑海中想象一个图形，直线的方向向量s与平面的法向量n之间的夹角θ 与 直线与平面之间的夹角的关系为 θ+φ=π/2，故 sin θ = cos φ。直线的方向向量s 与 平面的法向量n 之间的夹角θ为 cos θ = | s · n | / | s | | n |，由于 θ 为 0≤θ≤π/2，故要加上绝对值，最后得到 sin φ =   | s · n | / | s | | n | 。

（3）直线和平面的位置关系
直线与平面平行《====》s ⊥ n《====》Am+Bn+Cp =0.
直线与平面相交《====》s和n不垂直《====》Am+Bn+Cp ≠ 0 .

特别的，直线与平面垂直《====》s // n 《====》A/m = B/n = C/p .

理解：假设直线的方向向量 s=（m，n，p），平面的法向量 n=（A，B，C）
①直线的方向向量s 与 平面的法向量n 垂直（数量积 s · n = 0，即“Am+Bn+Cp =0”）则说明了 直线 与 平面 平行；（如果在直线与平面平行的基础上，直线上一点在在平面上 或者 平面上一点在直线上，则说明了直线在平面上）
②直线的方向向量s 与 平面的法向量n 不垂直（数量积为 s · n ≠ 0，即“Am+Bn+Cp ≠ 0”）则说明了 直线 与 平面 不平行，直线与平面不平行的话则就说明了直线与平面是相交的。
③直线的方向向量s 与 平面的法向量n 平行（s = k n，即“A/m = B/n = C/p”），则说明了 直线 与 平面 垂直。



题型1：
1、求直线的方程。
解题思路：关键就是找出这个直线过哪一点M0，找出这个直线的方向向量s，然后就可以根据“M0，s”写出这个直线的点向式方程了。

方向向量s的找法：
如果方向向量s与两个向量 n1、n2 都垂直的话，那么这个方向向量s就是 n1与n2 的向量积，即“s=n1 × n2”。
如果给出的是一般形式的直线方程，两个平面的法向量分别为 n1 和 n2，则这个一般形式的直线方程的法向量为 s=n1 × n2。


2、求某一点 M0（x0，y0，z0）到直线（一般给出你的是点向式方程）的距离。
解题思路：从这个直线的点向式方程中可以看出这个直线过哪一点（假设为M点（x1，y1，z1）），以及这个直线的方向向量s=（m，n，p）。接下来就可以代入公式 d=| M0M × s | / | s | 求出
点M0到这条直线的距离了。
 

3、求两个直线L1，L2 的夹角α。
解题思路：直线 L1 与 直线 L2 的夹角α，其实就是L1的方向向量s1与L2的方向向量s2之间的夹角。找出直线L1的方向向量s1，找出直线L2的方向向量s2，计算“s1与s2”之间的夹角为
“cos φ = | s1 · s2 | / | s1 | | s2 | = | m1m2+n1n2+p1p2 | / 根号（ m1^2+n1^2+p1^2 ）根号（m2^2+n2^2+p2^2）”。

4、判断两个直线 L1，L2 的位置关系。
解题思路：直线 L1 与 直线 L2 的位置关系（有两种，分别是 垂直），其实就是L1的方向向量s1与L2的方向向量s2之间的位置关系。

如果两个方向向量 s1=（m1，n1，p1）、n2=（m2，n2，p2） 垂直的话，则有 s1 · s2=0，即“m1m2+n1n2+p1p2=0”。
如果两个方向向量 s1=（m1，n1，p1）、n2=（m2，n2，p2） 平行的话，则有 s1=k s2，即“m1/m2 = n1/n2 = p1/p2 ”。


5、判断直线L与平面P的位置关系。
解题思路：直线与平面的位置关系有3种，分别是“平行”“垂直”“相交”。找出直线L对应的方向向量 s=（m，n，p），找出平面P对应的法向量 n=（A，B，C），判断向量s 与 向量n的位置关系，如果 s · n = Am+Bn+Cp = 0，则说明了 s⊥n，即是“直线L // 平面P”；如果 s · n = Am+Bn+Cp ≠ 0，则说明“直线L 与平面P 不平行”，只能够为“相交”；如果 s 与 n 满足“A/m = B/n = C/p ”，则说明了 s//n，即是“直线L ⊥ 平面P”。
