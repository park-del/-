导数的定义:
1、函数f(x)在x0这一点处导数的定义
理解：函数f(x)在x=x0处这一点可导则说明了函数在x=x0这一点处的切线斜率存在，用极限（极限是高等数学中的一个工具，可以使用它来研究导数的一些问题）来表示函数在x=x0这一点处的切线斜率就是为lim △x->0 △y/△x，其中△x=x-x0，△y=f(x0+△x)-f(x0),这个极限值若存在的话就说明函数f(x)在x0这一点处的导数值存在，且导数值等于lim △x->0 △y/△x。 （导数是用来描述因变量随着自变量的变化程度的，即就是当自变量在进行变化的时候，如自变量增加1，因变量变化多少）。

函数f(x)在x0这一点处的导数的极限表示方式：
（1）lim △x->0 △y/△x 
理解：其中△x=x-x0，△y=f(x0+△x)-f(x0)，△x->0表示x无限趋近于x0，即x0左右的一个小变化范围内，△y/△x就表示在x0左边这个小变化范围内y关于x的变化率，在x0右边这个小变化范围内y关于x的变化率。如果lim △x->0 △y/△x极限值存在的话（包含了△x->0+和△x->0-两边的极限值都存在），就说明了函数f(x)在x0这一点处可导，且函数f(x)在x0这一点处的导数值就是为这个极限值lim △x->0 △y/△x。

（2）lim △x->0 [ f(x0+△x)- f(x0) ] / △x
理解： 函数f(x)的自变量x在x0的一个小变化范围内的变化量为 △x,对应的函数值（即是因变量）的变化量为[ f(x0+△x)- f(x0) ]，函数f(x)在x0的一个小变化范围内的变化率为[ f(x0+△x)- f(x0) ] / △。极限lim △x->0 [ f(x0+△x)- f(x0) ] / △的值就是函数f(x)在这一点x0的导数值。

（3）lim x->x0 [ f(x)-f(x0) ] / ( x-x0 )
理解：其中的x->x0，就相当于是 x0+△x，x在x0右边的一个小变化范围内，就相当于是x0-△x，x在x0左边的一个小变化范围内。 
理解：x在x0的一个小变化范围内（左边和右边），lim x->x0 [ f(x)-f(x0) ] / ( x-x0 )极限值就是函数f(x)在x0这一点处的导数值。其中lim x->x0 [ f(x)-f(x0) ] 也就是x这个自变量变化时所对应的因变量的变化量，( x-x0 )就是这个自变量的变化量，[ f(x)-f(x0) ] / ( x-x0 )就是函数f(x)在x->x0这个变化过程中的变化率。
这里x->x0其实包含了两部分，分别为x->x0+和x->x0-,只要看到x->x0+，就要知道x的值是为x0+什么，是为x0右边的一个值，只要看到x->x0-，就要想到x是为x0-什么，是为x0左边的一个值。 

导数的本质：导数其实就是一个极限，就是函数增量/自变量的增量，当自变量的增量趋向于0时的极限值。

判断函数在一点x0处是否可导：
判断函数在一点x0处是否可导只需要判断函数f(x)在x0这一点处“函数值增量/自变量增量的极限值”是否存在即可，即是计算lim △x->0 [ f(x0+△x)- f(x0) ] / △x 或者lim x->x0 [ f(x)-f(x0) ] / ( x-x0 )，如果极限值存在的话，则就说函数f(x)在x0这一点处是可导的。
注意：在计算极限的时候包括了左右两边，如果只是左边极限存在的话，则只能够说明该函数f(x)在x0处是有左导数的，即是lim △x->0+ [ f(x0+△x)- f(x0) ] / △x 或者lim x->x0+ [ f(x)-f(x0) ] / ( x-x0 )；如果只是右边边极限存在的话，则只能够说明该函数f(x)在x0处是有右导数的，即是lim △x->0- [ f(x0+△x)- f(x0) ] / △x或者lim x->x0- [ f(x)-f(x0) ] / ( x-x0 )。函数f(x)在x0这一点处可导的充要条件是函数f(x)在x0这一点处的左导数=右导数（由于函数f(x)在某一点的导数值本质上就是一个极限值，这里要求的就是左极限等于右极限）。



可导与连续的关系：可导---->连续。
（1）根据蕴含表达式的关系很容易就能够得到可导与连续的关系，可导一定连续，但是连续不一定可导。
（2）函数f(x)在x0这一点处是可导的，则说明了函数f(x)在x0这一点是光滑的，如果题目中告诉了你函数f(x)在一个区间内是光滑的，就相当于是告诉了你函数f(x)在这个区间内的每一点都是为可导的。
（3）函数f(x)在x0这一点处的导数值，也叫作是函数f(x)在x0这一点处的变化率。


总结：
（1）观察 lim △x->0 [ f(x0+△x)- f(x0) ] / △x 和 lim x->x0 [ f(x)-f(x0) ] / ( x-x0 )这两个式子可以看出，函数f(x)在哪一点的导数，对应的极限式子中所减去的就是为在这一点的函数值，所减去的不能够是为一个变化的量的，减去的为一个变化量的话则就不是导数的定义。
（2）lim △x->0 [ f(x0+△x)- f(x0) ] / △x中的△x是为一个中间过渡变量也是可以的，只要这个中间过渡变量是--->0就可以；lim x->x0 [ f(x)-f(x0) ] / ( x-x0 )中的x0也可以是为一个中间过渡变量，只要这个中间过渡变量是--->x0就可以。
（3）何时用导数定义？
《1》涉及一点导数请考虑用导数定义。
如判定函数在这一点处是否可导；求函数在这一点处的导数；已知函数在这一点的导数为多少，让我们去解决问题。
《2》涉及抽象函数导数问题，请考虑用导数定义。
（4）带有绝对值的，则不可导点就是使得绝对值为0的点。如函数f(x)=| (x+1)(x+2)(x-3)(x-2) |，则此时这个函数f(x)的不可导点就是为x=-1，x=-2，x=3，x=2。
结论：若g(x)在x=x0处连续（前提条件，一般所给出的函数都是满足这个条件的），则g(x0)=0是f(x)=g(x) | x-x0 |在x=x0处可导的充要条件。
结论理解:上述中的结论就是g(x0)=0是f(x)=g(x) | x-x0 |在x=x0处可导的充要条件。如果已知了f(x)=g(x) | x-x0 |，则求出使得g(x)为0的点，如果这些点又是为函数f(x)的不可导点的话（使得绝对值为0的点），则此时这些点将会变成可导点，可以将g(x)的功能看成是使得绝对值对应的不可导点变为可导点的；反之，如果告诉了你函数f(x)=g(x) | x-x0 | 在x=x0这一点是可导的，则也就说明了g(x0)=0。
补充题型：f(x)= (x-2) | ( x+1 ) ( x+2 ) ( x-3 ) (x-2) | ,问f(x)的不可导点个数为多少？
解答：首先由绝对值处为0得到x=-1、x=-2、x=3、x=2处应该都是为不可导点的，但是由于x-2=0使得x=2变为了可导点，故f(x)的不可导点的个数为3。


考察题型：
（1）直接让你求函数f(x)在这一点x0处的导数或者让你判断函数f(x)在x0这一点处是否可导。（导数问题本身就是极限问题，考察的就是让你求极限的问题，判断函数f(x)在x0这一点处是否可导就是让你判断函数f(x)在x0这一点处的变化率所对应的极限值是否存在）
（2）已知函数f(x)在一点x0处的导数，反过来让你求函数f(x)中的一些参数。（导数本身就是极限，考察的就是让你根据极限值求极限式子中的参数）
