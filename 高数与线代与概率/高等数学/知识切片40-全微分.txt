1、全微分的定义
区分三个概念△x、△y、△z：（由于二元函数是有两个自变量的，故对应的就有关于两个自变量的增量）
（1）二元函数f(x,y)在点（x0，y0）处关于x的自变量增量为△x。（注意△x是包含了x0左边的范围和右边的范围的）
（2）二元函数f(x,y)在点（x0，y0）处关于y的自变量增量为△y。（注意△y是包含了y0左边的范围和右边的范围的）
（3）二元函数f(x,y)在某一点（x0，y0）处的自变量增量对应的因变量增量为△z，即△z=f(x0+△x，y0+△y)-f(x,y)。


可微的定义（全微分的概念）：
上述中的二元函数在某一点（x0，y0）处的因变量增量△z=f(x0+△x，y0+△y)-f(x,y)，如果能够写成△z=A*△x+B*△y+o(p)的话（其中 p=根号 △x^2+△y^2），就说二元函数f(x,y)在这一点（x0，y0）处是可微的。函数f(x,y)在这一点（x0，y0）处的全微分就为“A*△x+B*△y”，记作dz，即是“dz=A*dx+B*dy”。（类比于一元函数在某一点x0处的微分为 dy=A*dx，全微分dz=A*dx+B*dy中的 A 为 偏z/偏x， B 为 偏z/偏y）


可微的等价定义：（就是判断二元函数f(x,y)在（x0，y0）这一点处可微的话，需要满足哪些条件，是可微定义的变形，因此说和可微的定义是等价的）
如果二元函数f(x,y)在点（x0，y0）处的偏导数存在（指的是在这一点（x0，y0）处的 偏z/偏x 和 偏z/偏y 都存在），且 lim p->0 [ △z- 偏z/偏x *△x - 偏z/偏y *△y ] / p = 0的话，则就说明了函数f(x,y)在（x0，y0）这一点处可微。反过来，也是成立的，即是如果判断出了二元函数z=f(x,y)在某一点（x0，y0）处可微的话，则二元函数z=f(x,y)在该点处的偏导数存在，且 lim p->0 [ △z- 偏z/偏x *△x - 偏z/偏y *△y ] / p = 0。

理解：
由于是为可微的等价定义的，故最终的落脚点也是要落在可微的定义上面的。可微的定义说明了二元函数f(x，y)在某一点（x0，y0）处可以处的增量△z可以表示成 “△z=A*△x+B*△y+o(p)”。故当A存在，B存在（即是 对x的偏导存在，对y的偏导存在）时，在满足 △z- 偏z/偏x *△x - 偏z/偏y *△y 是 p 的高阶无穷小的话（偏z/偏x就是A，偏z/偏y就是B，自变量△x和△y就是dx和dy），即满足  lim p->0 [ △z- 偏z/偏x *△x - 偏z/偏y *△y ] / p = 0 的话，就能够说明二元函数z=f(x,y)在该点（x0，y0）处的微分dz存在了。（注意，p->0就是△x->0、△y->0） 


可微的必要条件：（就是告诉了你二元函数f(x,y)在（x0，y0）这一点处可微的话，你能够得到什么信息）
如果二元函数f(x,y)在（x0，y0）这一点处可微的话，就说明了二元函数f(x,y)在（x0，y0）这一点处的偏导数存在。（即是二元函数f(x,y)在（x0，y0）这一点处 偏z/偏x 存在，偏z/偏y 存在）
注意：由于是必要条件，故当二元函数在这一点（x0，y0）处的偏导数都不存在的话，则该二元函数在该点（x0，y0）处就一定是不可微的。
     

可微的充分条件：（就是用来判断二元函数f(x,y)在某一点（x0，y0）处是否可微）
如果二元函数z=f(x,y)的偏导函数 偏z/偏x 和 偏z/偏y 均在点（x0，y0）处连续的话，那么二元函数z=f(x，y)在该点（x0，y0）处可微。

注意：二元函数z=f(x,y)的偏导函数 偏z/偏x 和 偏z/偏y 均在点（x0，y0）处连续只是二元函数z=f(x，y)在该点（x0，y0）处可微的一个充分条件。如果二元函数z=f(x，y)在该点（x0，y0）处可微，那么二元函数z=f(x,y)的偏导函数 偏z/偏x 和 偏z/偏y 在点（x0，y0）处可能连续，也可能不连续。


总结：
二元函数f(x,y)在某一点（x0，y0）处 偏导连续、可微、偏导存在、函数连续、极限存在。

理解：上述中的函数连续指的是二元函数f(x,y）在某一点处（x0，y0）处是连续的，上述中的极限存在指的是二元函数f(x,y）在某一点处（x0，y0）处极限存在。上述中的可微指的是二元函数f(x,y）在某一点处（x0，y0）处是可微的。上述中的偏导连续指的是二元函数f(x,y)在某一点（x0，y0）处的偏导数（即 偏z/偏x 和 偏z/偏y）是连续的。上述中的偏导连续指的是二元函数f(x,y)在某一点（x0，y0）处的偏导数（即 偏z/偏x 和 偏z/偏y）是存在的。

（1）由 偏导连续（二元函数f(x,y)在某一点（x0，y0）处的 偏z/偏x 和 偏z/偏y 都是连续的）是可以推出 二元函数f(x,y)在该点（x0，y0）处是可微的。
（2）由 可微 （二元函数z=f(x,y)在某一点（x0，y0）处可微，即具有全微分dz）是可以推出 二元函数f(x,y)在某一点（x0，y0）处的偏导数（偏z/偏x 和 偏z/偏y）是存在的；也是可以推出二元函数f(x,y)在某一点（x0，y0）处是连续的。
（3）由 函数连续（二元函数f(x,y)在某一点（x0，y0）处是连续）是可以推出 二元函数f(x,y)在某一点（x0，y0）处的极限值存在。

图形： 偏导连续 ====》可微====》函数连续====》极限存在
                                        可微====》偏导存在
                                         


题型：
1、让你计算二元函数z=f(x,y)在某一点（x0，y0）处的全微分 dz | (x0,y0)。（注意，由于自变量x和y都是确定的，故最后求得到的 偏z/偏x 和 偏z/偏y 都是可以代入具体的值的，即最后求出的 偏z/偏x 和 偏z/偏y 都是为一个具体的数值的，都是不含有任何未知数x和y的。故最后求出的二元函数z=f(x,y)在某一点（x0，y0）处的全微分都是为 dz=具体数值*dx+具体数值*dy）（由于抽象的二元函数是没有具体的表达式的，故也就不可能具体的算出一个值，因此计算二元函数z=f(x,y)在某一点（x0，y0）处的全微分 dz| (x0,y0) 都是针对于一个具体函数来说的）

（1）如果题目中给出的与可微的等价定义式很像的话（即分母是为 根号 (△x)^2+(△y)^2，且分母中的△x和△y都是趋向于0的，注意这里的△x和△y也可以是为一个中间过渡变量的，即为一个方框，只要这个方框趋向于0就可以了 ），则可以考虑通过凑出二元函数f(x，y)在该点(x0，y0)全微分的等价定义式来求二元函数z=f(x,y)在该点(x0，y0)处的全微分dz。

解题思路：首先写出二元函数f(x，y)在该点（x0，y0）处的全微分的等价定义式，即 lim △x->0，△y->0  [ △z- 偏z/偏x *△x - 偏z/偏y *△y ] / 根号 (△x)^2+(△y)^2  = 0，注意这里的△x和△y也可以是为一个中间过渡变量的，即为一个方框，只要这个方框趋向于0就可以了（如当x-->4时，x-4 就是趋向于0的，x-4 就可以充当方框，即△x）。lim △x->0，△y->0  [ △z- 偏z/偏x *△x - 偏z/偏y *△y ] / 根号 (△x)^2+(△y)^2 = 0 中的 △z=f(x0+△x，y+△y) - f(x0，y0)，就转化为了 lim △x->0，△y->0  [ f(x0+△x，y+△y) - f(x0，y0) - 偏z/偏x *△x - 偏z/偏y *△y ] / 根号 (△x)^2+(△y)^2 = 0。然后将题目中给出的式子向这个式子进行转化，转化后就可以得出 偏z/偏x 和 偏z/偏y 分别是多少了，知道了 偏z/偏x 和 偏z/偏y 后，就可以写出二元函数z在（x0，y0）处的全微分dz= 偏z/偏x *dx + 偏z/偏y *dy了。（注意，偏z/偏x 和 偏z/偏y 都是为一个具体的数值的）

解题技巧：当题目中给出的是为一个抽象函数时，我们可以将抽象化为具体，即采用取特殊值的方法来解决问题。根据离散数学中所学到的知识，命题语句“若p，则q”，如果p为真的话，则q一定是为真的。如果我们能够将一个抽象函数化为具体函数后使得“若后面”的条件成立的话，则这个具体函数一定也是满足“则后面”的结论的。

（2）可以先对二元函数z=f(x,y)求偏导，求出了二元函数z=f(x,y)的偏导 偏z/偏x 和 偏z/偏y 之后，，直接写出二元函数z=f(x,y)在该点处的全微分dz= 偏z/偏x *dx + 偏z/偏y *dy。（注意，偏z/偏x 和 偏z/偏y 都是为一个具体的数值的）

（3）由于牵涉到的是为某一点（x0，y0）。在对x求偏导的时候是把y看做是常数的，故在求 偏z/偏x 的时候，可以向把y=y0代入，将求 偏z/偏x 转化为求 一元函数对x在x=x0处求导的问题；同理，将求 偏z/偏y 转化为求 一元函数对y在y=y0处求导的问题。求出了二元函数z=f(x,y)的偏导 偏z/偏x 和 偏z/偏y 之后，，直接写出二元函数z=f(x,y)在该点处的全微分dz= 偏z/偏x *dx + 偏z/偏y *dy。（注意，偏z/偏x 和 偏z/偏y 都是为一个具体的数值的）

（4）利用全微分形式的不变性，即是直接求dz，最后将x=x0，y=y0代入dz的表达式中就可以了。

2、让你判断二元函数f(x，y)在某一点（x0，y0）处是否可微。（这一点常常是为分段函数的分段点的。多元初等函数的偏导数在点（x0，y0）处一定是连续的，根据可微的充分条件，多远初等函数在点（x0，y0）处一定是可微的，即多元初等函数在某一点（x0，y0）处是否可微已经确定了，不需要你再判断；如果为抽象函数f(x,y)，一般不会让你判断抽象函数在某一点（x0，y0）是否可微，而是直接给你“f(x,y)具有一阶连续偏导函数”这个条件，即告诉了你二元函数f(x,y)是可微的）

（1）利用可微的等价定义来判断二元函数z=f(x,y)在某一点（x0，y0）处是否可微。
解题思路：首先判断二元函数z=f(x,y)在某一点（x0，y0）处偏导数是否存在的问题，这类问题已经在前面总结过如何解决了。确定了二元函数z=f(x,y)在某一点（x0，y0）处的偏导数都存在后（即是二元函数z=f(x,y)在该点（x0，y0）处的 偏z/偏x 和 偏z/偏y 都存在）。接着写出 △z=f(x0+△x，y0+△y) - f(x0，y0)，然后将 △z=f(x0+△x，y0+△y) - f(x0，y0) 代入到 lim △x->0，△y->0  [ △z- 偏z/偏x *△x - 偏z/偏y *△y ] / 根号 (△x)^2+(△y)^2  这个式子中算极限（由于（x0，y0）是为一个具体的数值的，故代入之后得出的 偏z/偏x 和 偏z/偏y 也是为一个具体的数值的 ），如果这个极限的值为0的话就说明了二元函数z=f(x,y)在该点(x0，y0)处是可微的，如果这个极限的值不为0的话就说明了二元函数z=f(x,y)在该点(x0，y0)处是不可微的。


（2）利用可微的充分条件来判断二元函数z=f(x，y）在某一点（x0，y0）处是否可微。
解题思路：求出二元函数z=f(x,y)的偏导函数 偏z/偏x 和 偏z/偏y（由于（x0，y0）常常是为分段函数的分界点，故这里求出的偏导函数 偏z/偏x 和 偏z/偏y 常常是为（x，y）!=（x0，y0）这个条件下的）。求出了偏导函数 偏z/偏x 和 偏z/偏y，接下来就转化成了判断 偏z/偏x 在点（x0，y0）处是否连续，偏z/偏y 在点（x0，y0）处是否连续 的问题。一个一个来判断，首先判断 偏z/偏x ，如果 lim
x->x0 y->y0 偏z/偏x = 偏z/偏x (x=x0,y=y0)，则说明了偏z/偏x 在点（x0，y0）处连续，否则说明不连续；同理，判断，偏z/偏y 在点（x0，y0）处是否连续也是一样的。 只有当 偏z/偏x 与 偏z/偏y都在点（x0，y0）处都连续的时候，才能够说明二元函数z=f(x，y）在（x0，y0）处可微，否则的话就说不可微。

提示：多元初等函数的一阶偏导数在其定义域内都是连续的，如果给出的是为一个抽象的二元函数的话，则一般会告诉你这个二元函数具有一阶连续偏导数。

3、让你计算一个具体的二元初等函数，或者是一个二元的抽象函数的全微分。（这里的（x，y）都是没有给出一个确定的值的，这类题优先使用微分形式的不变性，即接下来就只是考虑计算微分的问题了，而且计算量一般也比直接求 偏z/偏x 和 偏z/偏y 要小）
（1）先求出 偏z/偏x 和 偏z/偏y，最后直接写出全微分 dz=偏z/偏x *dx + 偏z/偏y *dy。

（2）利用微分形式的不变性。
解题思路：直接求dz，根据 “d什么”求微分的法则，最后算出来的一个表达式 dz=……dx+……dy 就是所要求的全微分了。（利用这种方式求可以将求 偏z/偏x 和 偏z/偏y 两步合成一步，即是只需要求微分就行了，而且最后在求出微分的时候dx前面的就是 偏z/偏x，dy前面的就是 偏z/偏y，即仅仅知识需要进行求全微分dz，就能够将偏导全部求出来了。这种方法常常适用于求偏z/偏x 和 偏z/偏y非常麻烦的题目）

注意：在利用微分形式的不变性时，d(x+y)=dx+dy（利用到的是求微分中的加法法则）。d f( e^x siny，x^2+y^2)求微分，即是都抽象函数求微分时，与抽象函数求导 d f( e^x siny，x^2+y^2)/dx 是类似的，先对外层求微分，即是  f'1 d( e^x siny) + f'2 d( x^2+y^2)，d( e^x siny)就可以利用求微分的乘法法则了，d( x^2+y^2)利用求微分的加法法则，d(x/y)就可以利用求微分的除法法则了。
