补充知识：

向量的维数：
我们中学中已经学过了二维向量，就是β=(x,y)=xi+yj，二维向量在一个平面上的有大小有方向的量；类似的还有三维向量，即α=(x,y,z)=xi+yj+zj，三维向量就是空间上的一个有大小有方向的量。

向量的两种坐标表示：由于向量是为平面（二维）或者空间（三维）上的一个有大小，有方向的量，我们常用坐标来表示向量。
（1）α=(x,y,z)。
（2）α=xi+yj+zj。

由空间中的两点 M1(x1,y1,z1) M2(x2,y2,z2) 所构成的向量：终点坐标减去起点坐标
M1M2=（x2-x1，y2-y1，z2-z1）
M2M1=（x1-x2，y1-y2，z1-z2）
| M1M2 | = 根号 (x2-x1)^2+(y2-y1)^2+(z2-z1)^2


1、关于向量α的一些概念（下面都是以三维向量为例的）：
（1）向量α的模 | α | 。
 | α | =根号 x^2+y^2+z^2

（2）向量α的方向角“α、β、γ”与方向余弦“cos α、cos β、cos γ ”
向量α的方向角：非0向量α分别于x，y，z轴正向（要注意，这里是与坐标轴正向的夹角的，将一个向量投影到xoy面上，这条直线与x轴正方向的夹角就是为向量与x轴的夹角的，这条直线与x轴负方向的夹角不是为向量与x轴的夹角的，这一点要注意，类似的可以定义该向量与其他坐标轴之间的夹角）的夹角 α、β、γ 称为向量α的方向角（注意，π>= 方向角 >=0）。
向量α的方向余弦：非0向量α的方向角对应的余弦 “cos α、cos β、cos γ”称为向量α的方向余弦。



2、求非0向量α所对应的单位向量 
将非0向量 α=(x,y,z) 单位化，即求非0向量α的单位向量 α / | α |。
《1》单位向量：模为1的向量就是单位向量。
《2》非零向量的单位化：将模不为1的向量化为单位向量（0向量除外，0向量无法单位化）的过程，用这个向量除以它的单位向量就可以得到这个向量的单位向量了（前提是这个向量为非0向量）。
《3》非零向量的单位化： α / | α | = ( x/根号 x^2+y^2+z^2 ， y/根号 x^2+y^2+z^2 ， z/根号 x^2+y^2+z^2 )

理解：α为一个向量，是既有大小，又有方向的一个量；而向量α的模 | α | 是只有大小的，即  | α | 是为一个数的，用向量α去除以这个数所得到的还是为一个向量的，将所得到的这个向量称之为 α 的单位向量。


3、向量的基本运算
（1）向量的加减运算、向量的数乘运算
向量的加减运算：α=(x1，y1，z1)，β=(x1，y1，z1)，则 α + β =(x1+x2，y1+y2，z1+z2)。
向量的数乘运算：α=(x，y，z1)，λ为实数，则 λα = (λx，λy，λz)。 


（2）两个向量进行数量积运算（内积或点积）：既然叫向量的数量积，则就说明了这两个向量相乘的结果就是为一个数的。
两个向量的数量积（内积或点积）定义：设有两个向量 α、β，则称 “α · β = | α | | β | cos θ” 为向量 α与β的数量积，其中θ为向量α与β的夹角。

注意：从这个式子中我们也可以看出来，乘出来的一定是为一个数的，因为| α | 、| β |、 cos θ 三者均是为一个数的，是没有一个向量的。

向量的坐标表示形式下数量积的计算：如果给出的两个向量 α、β 是用坐标表示的，如 α=(x1，y1，z1)，β=(x1，y1，z1)，则 “α · β = (x1 x2，y1 y2，z1 z2)”，这也是计算两个向量内积的另外一个公式。

两个向量数量积的性质：
《1》α · α= | α |^2。
理解： 根据 α · α = x^2+y^2+z^2，可以得到两个结论。即  α · α=0 《====》 α=0；若 α · α  != 0（由于α · α = x^2+y^2+z^2，故不是为0就一定是大于0）《====》α != 0。

《2》两个向量 α、β垂直的充分必要条件为：α · β=0。
理解：由于“α · β = | α | | β | cos θ”，当 α 、β都为非0向量时，则cos θ为0，因此就能够得到 θ=π/2，即这两个非0向量α 与 β垂直 。
应用：常常利用两个非0向量积的这个性质来判定这两个非0向量是否垂直。

《3》两个向量数量积运算的分配率：
（α + β)  · c = c  · α + c · β 

《4》两个向量数量积运算的λ数结合律：
（λα） · β= λ (α · β)


（3）两个向量的向量积运算（外积或差积）：既然叫向量的向量积，则就说明了这两个向量相乘的结果就是为一个向量的。
两个向量向量积的定义：向量c是向量a与向量b进行向量积运算的结果，即 a × b = c。c的模 |c| = |a| |b| sin θ，其中θ为向量a与向量b的夹角；向量c既垂直于a，也垂直于b，c的指向按右手规则从a转向b来确定，向量c叫做向量a与b的向量积。

向量的坐标表示形式下向量积的计算：如果给出的两个向量 a、b 是用坐标表示的，如 a=(ax，ay，az)，b=(bx，by，bz)，则“a × b  = ()i + j() + ()k”,其中的（）里面依次对应的就是a × b所对应的三阶行列式按  第1行中的第1个元素i，第1行中的第2个元素j，第1行中的第3个元素k 展开的结果（就是线性代数里面的通过代数余子式来计算行列式的值）。

两个向量向量积的性质：
《1》 两个向量向量积运算交换率：
  a × b = -b  × a。
理解：按照 a × b 的运算法则，如果将 a × b 交换位置的话，相当于是行列式交换了两行，在线性代数里面行列式交换两行和交换两列都会增加一个负号。
 
《2》两个向量向量积运算的分配率：
（a + b）× c= a × c + b × c。

《3》两个向量向量积运算的λ数结合律：
（λa）× b = a ×（λb) =λ (a×b)。

《4》a × a=0。
理解：a × a = |a| |a| sin θ。自己与自己的夹角是为0的，故 a × a =0，由于两个向量进行向量积运算得出的结果也是为一个0向量的，故 a × a 是为一个0向量的。

《5》两个向量a与b平行的充分必要条件为： a × b=0。（结合两个向量向量积为，即 两个向量垂直的充分必要条件为 a · b = 0  来一起记忆，数量级和向量积）
理解：由于“α × β = | α | | β | sin θ”，当 α 、β都为非0向量时，则sin θ为0，因此就能够得到 θ=0或π，即这两个非0向量α 与 β平行（其中θ=0表示这两个向量的方向相同，θ=π表示这两个向量的方向相反） 。



区分：向量的数量积 a·b 可以看成是 向量a在b上的投影乘以b的模的（ a·b=|a| |b| cos θ=|a| cos θ |b| ）；向量的向量积 a·b 的大小为以向量a和向量b为邻边所组成的平行四边形的面积，即是 a × b = |a| |b| sin θ= |a| sin θ |b|。


（4）三个向量的混合积运算。（考试考的少）
三个向量混合积的定义：设 a，b，c 为三个向量，称（a×b) · c 为 a，b，c 的混合积，记为 [a，b，c]。
理解：a × b 是为两个向量的向量积，算出来的仍然是为一个向量的，向量与向量点乘的结果是为一个数的，故3个向量混合积的结果得到的是为一个数的。

向量的坐标表示形式下混合积的计算：如果给出的3个向量 a、b、c 是用坐标表示的，如 a=(ax，ay，az)，b=(bx，by，bz)，c=(cx，cy，cz)，那么这3个向量的混合积 [a，b，c] 就是为
{  ax  ay  az  }
{  bx  by  bz } ，算出来的这个3阶行列式的值就是混合积“[a，b，c]”。（这个3阶行列式的值是为一个数的，刚好符合混合积的运算结果是为一个数的）
{  cx  cy  cz  }

3个向量混合积的性质：（了解）
《1》[ a，b，c ] = [ b，c，a ] = [ c，a，b ]，即轮换混合积中三个向量的顺序，其值不变。
《2》交换混合积 [ a，b，c ] 中任意两个向量的位置，混合积变号。
理解：行列式中交换两行或者两列，行列式的符号改变，交换偶数次行列式不变，交换奇数次行列式的符号改变。

《3》三个向量 a，b，c 共面的充分必要条件是 [ a，b，c ] = 0。


题型：
1、求非0向量 α=(x,y,z) 的方向余弦。
解题思路：首先求出非0向量α的单位向量，即 α / | α | = （ x/根号 x^2+y^2+z^2 ， x/根号 x^2+y^2+z^2 ， x/根号 x^2+y^2+z^2 ）。此时对应的 x/根号 x^2+y^2+z^2 就是 cos a；y/根号 x^2+y^2+z^2 就是 cos β；z/根号 x^2+y^2+z^2 就是 cos γ。即 一个非0向量 的 单位向量 的坐标依次就是 cos α、cos β、cos γ。

结论：由x/根号 x^2+y^2+z^2 就是 cos a；y/根号 x^2+y^2+z^2 就是 cos β；z/根号 x^2+y^2+z^2 就是 cos γ 可知：(cos α)^2 + (cos β)^2 + (cos γ)^2 =1。


2、计算两个向量之间的夹角。
解题思路：根据“α · β = | α | | β | cos θ”来推导出求两个向量夹角的公式。即 “cos θ = α · β / | α | | β | ”，由于我们一般是使用坐标来表示向量之间的夹角的，故这个公式可以变成“cos θ = αx · βx + αy · βy +αz · βz / （）（）”。（ 其中向量 α=(αx，αy，αz)，β=(βx，βy，βz) ）

注意：将两个向量之间的夹角 θ 与向量的方向角  α、β、γ  相区分开。向量的方向角  α、β、γ  指的是向量与x轴、y轴、z轴的夹角的，而两个向量之间的夹角指的就是两个向量之间的夹角的。


3、计算向量 α 在 向量 β 上的投影。
解题思路：向量 α 在 向量 β 上的投影就是“|α| ·  cos θ”。将“|α| · cos θ”与数量积相关联，即与“α · β”就可以推导出向量 α 在 向量 β 上的投影的公式了。“α · β=|α|  |β|  cos θ  ”，则“|α| ·  cos θ”分子分母同时乘以“|β|”，就得到了“|α| ·  cos θ = α · β / |β| ”，因为向量经常使用坐标表示的，将其写成坐标形式为“|α| ·  cos θ = αx · βx + αy · βy +αz · βz / 根号 βx^2+βy^2+βz^2”。（在谁上的投影就除以谁上的模长,由于投影是为模长乘以cos θ，故投影最后算出来的是为一个数的）


4、判断两个非0向量 α、β是否垂直，是否平行。
解题思路：若判断 α、β是否垂直，则使用的是向量的数量积，看  α · β的结果是否为0，如果为0的话则这两个向量垂直，如果不为0的话则这两个向量不垂直；若判断 α、β是否平行，则使用的是向量的向量积，看  α x β的结果是否为0，如果为0的话则这两个向量平行，如果不为0的话则这两个向量不平行。

注意：我们规定了，0向量是与任何一个向量都是平行的，0向量是不与任何一个向量垂直的。如果向量 α、β其中有一个为0向量的话，则这两个向量是平行还是垂直一目了然，就没有考察的价值了，因此题目中给我们的常常是为两个非0的向量的。

 

5、判断3个向量（或者是 4个点）是否共面。
解题思路：
（1）如果是为3个向量 MA、MB、MC，让你判断其是否共面。
计算这3个向量的混合积 [  MA  MB  MC  ]，即是计算由这3个向量构成的“3阶行列式”，如果这个3阶行列式是为0的话，则这3个向量“ MA、MB、MC”就是共面的，反之这3个向量“ MA、MB、MC”就不是共面的。

（2）如果是为4个点 A=（a1，b1，c1），B=（a2，b2，c2），C=（a3，b3，c3），D=（a4，b4，c4）。
从这4个点“A，B，C，D”所构成的向量中任意挑选3个向量，然后转化为了（1），即判断这3个向量是否共面的问题。假设挑选的 3个向量分别为“AB，AC，AD”，则接下来就转化为了判断“AB，AC，AD”这3个向量是否共面的问题，转化为了（1）。

扩展题型：
已知3个向量，或者4个点，共面，让你去解决一些问题。
解题：利用这3个向量的混合积为0，或者这4个点构成的任意3个向量的混合积为0，去解决一些问题。
