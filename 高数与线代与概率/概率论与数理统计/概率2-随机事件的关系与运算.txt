一、随机实验E
定义：满足如下三个条件的试验称为随机试验：
（1）可以在相同的条件下重复地进行；
（2）进行一次实验之前不能确定哪一个结果会出现；
（3）每次实验的可能结果不止一个，并且能事先明确试验的所有可能结果。

记忆：可重复性、事先结果未知、所有可能结果已知，满足这3个条件的实验就是随机试验（如抛硬币，掷骰子，买彩票，抛硬币在相同的条件下可以重复n次，且每一次抛出的结果不知道，但是所有的结果知道只有正和反）。


二、样本空间
1、样本点w：随机试验的每一个可能的结果称为一个样本点。
2、样本空间Ω：所有样本点全体组成的集合称为样本空间。

理解：首先所进行的实验要是一个随机试验，如“抛硬币”的试验，这个每一个可能的结果“正”和“反”就是为一个样本点的；所有样本点的集合，即随机实验所有结果的集合叫做“样本空间”，如“抛硬币”这个随机实验的样本空间就是“Ω={ 正，反 }”。

三、随机事件
1、随机事件：样本空间Ω的子集称为随机事件，通常用大写字母 A，B，C 等表示。

理解：如“掷骰子”这个随机事件的样本空间Ω={ 1,2,3,4,5,6 }，其一个子集为 A={ 1,2 }，这个子集A所构成的事件“掷出的骰子数为1或者2”或者“掷出的色子数不超过2”就是随机事件。

联想：“掷骰子”刚好对应了我们概率1中所讲的“一次取一个，有放回的抽样”。投掷两次筛子，掷出两个6的概率，（分布乘法完成一次，最后乘以次序）为 6*6（这里两个6只有一种次序，故最后乘1，因为两个都是一样的，故也就没有了次序）；投掷两次筛子，掷出一个5一个6的概率，（分布乘法完成一次，最后乘以次序）为 6*6*2（这里6和5有两种次序）。

2、基本事件：由一个样本点组成的单点集。

理解：如“掷骰子”这个样本空间Ω={ 1,2,3,4,5,6 }中的单点集为“{ 1 }、{ 2 }等”，其所对应的事件就是“掷出的筛子数为1、掷出的筛子数为2”，这些由单点集所构成的事件就是基本事件。

3、事件发生：在每次试验中，当且仅当事件中有一个样本点出现时，称这一事件发生（出现）。

理解：如“掷骰子”这个随机实验中，随机事件 A={ 1,2 } 发生的情况就是“1或者2这两个样本点有且仅有一个出现”就说随机事件A发生。


4、必然事件：样本空间Ω包含所有样本点，它是Ω自身的子集，在每次试验中总是发生的，称为必然事件，记为Ω。
理解：Ω也是自身的子集的，故Ω这个子集所对应的随机事件是一定会发生的（因为Ω包含了随机试验所有的结果），我们把这种随机事件叫做“必然事件”。

理解：随机试验与随机事件的关系，进行一次随机试验，是会发生一个随机事件的，随机事件可能有很多种，是会发生其中的某一个的。

5、不可能事件：空集Ø不包含任何样本点，它也作为样本空间的子集，在每次试验中都不发生称为不可能事件，记为Ø。
理解：Ø也是为Ω的子集的，在进行随机试验的时候，是不会发生“Ø所对应的随机事件”。


四、随机事件的关系（每一种随机事件就是为一个集合，随件事件的关系说白了就是集合的关系）
1、包含关系：A 包含于 B，它表示事件A发生一定导致B发生。
2、事件相等：A 包含于 B，且B包含于A，则事件 A=B。
3、A和B的和事件：事件 A∪B={ x | x∈A 或 x∈B }称为A和B的和事件，它表示A，B两个事件至少有一个发生时事件 A∪B（一个集合就是一个事件）发生，也记为 A+B。

以后见到“A，B至少一个发生”就将其用数学语言表示成“A∪B”；“A，B，C至少一个发生”就将其用数学语言表示成“A∪B∪C”；“A，B，C至少两个发生”将其用数学语言表示成“AB∪AC∪BC”；“A发生，则B发生”将其用数学语言表示成“A 包含于 B”；“AB发生，C一定发生”将其用数学语言表示成“AB 包含于 C”。
 
注意：
隐含的包含关系：（1）A 包含于 A+B，B 包含于 B+C 这种条件以后是不会给你的。（2）AB 包含于 A，AB 包含于 B。（3）将两个隐含关系联系起来就是 AB 包含于 A 包含于 A+B，AB 包含于 B 包含于 A+B。

4、A和B的积事件：事件 A∩B={ x | x∈A 或 x∈B }称为A和B的积事件，它表示 A，B 两个事件同时是发生时事件 A∩B 发生，也记为 AB。

5、A和B的差事件：事件 A-B={ x | x∈A 或 x∈B }称为A和B的差事件，它表示A发生且B不发生时事件A-B发生，也记为 A(-)B。

记忆：借助集合的温恩图来记忆“和事件、积事件、差事件”。


6、互斥事件（互不相容）：若AB=Ø，即“A事件与B事件不能够同时发生（没有交集）”，就说着两个事件是互斥的，或者说互不相容。
补充：   相容：若AB!=Ø，即“A事件与B事件可以同时发生（有交集）”，就说着两个事件是相容的。

7、对立事件（逆事件）：若  A∪B=Ω 且 A∩B=Ø，则称 A和B 互为逆事件，也称互为对立事件。A的对立事件记为 (-)A。

注意：两个事件A，B对立（A事件包含的结果加上B事件的结果就是最终所有的结果） ====》A，B互斥，但是 A，B互斥 ====》A，B对立。

8、完全（备）事件组：若事件 【A1∪……∪An=Ω】，【AiAj=∅，1≤ i ≠ j ≤n】，则称事件 A1，……，An是一个完全（备）事件组，也称为样本空间的一个划分。
理解：首先要知道样本空间Ω，样本空间的一个集合就是为一个事件，类比于对立事件，对立事件我们相当于是将样本空间Ω一分为2成为两个集合（两个事件），而这里我们是将样本空间划分成了n块的，每一个集合（每一块）对应一个事件Ai。

作用：假设我们在样本空间Ω上有一个非常复杂的事件B，我们首先想到的就是使用事件B的对立事件来解决，如果B的对立事件仍然不好解决的话，此时我们就这个复杂事件分解成若干个简单事件，如果这若干个简单事件都好解决，那么这个复杂的事件也就解决掉了（后面的全概率公式用到的就是这个思想）。

五、随机事件的运算律
1、交换律：A∪B=B∪A；A∩B=B∩A。
2、结合律：A∪( B∪C ) = ( A∪B )∪C ；A∩( B∩C ) = ( A∩B )∩C。
3、分配率：A∪( B∩C ) = ( A∪B )∩( A∪C )；A∩( B∪C ) = ( A∩B )∪( A∩C )。
4、对偶律（德摩根率）：(-)( A∪B ) = (-)A∩(-)B；(-)( A∩B ) = (-)A∪(-)B。


何时用：“都是∩”或者“都是∪”，可以交换，可以结合；“有∩有∪”的时候，不能交换，不能结合，可以分配。
注意：对偶律 “(-)( A∪B ) = (-)A∩(-)B；(-)( A∩B ) = (-)A∪(-)B”不仅要会从左边转到右边，也要会从右边转到左边。

我们使用对偶律用的最多的就是“从右边往左边转”，即是为“ (-)A∩(-)B=(-)( A∪B ) ； (-)A∪(-)B=(-)( A∩B )”，在“通过一个事件的对立事件”来求出这个事件的概率的时候，常常会使用到“对偶律从右边往左边转的规律”。
解：通过事件A的逆事件来求事件A的概率的公式为“P(A)=1-P( (-)A )”,当我们想要求“(-)A∩(-)B”或者“(-)A∪(-)B”所对应的时间的概率“P[ (-)A∩(-)B ]”,“P [ (-)A∪(-)B ]”的时候，我们就可以利用对偶律的“从右边往左边”转化的规律，即是为“P[ (-)A∩(-)B ] = P[ (-)( A∪B ) ] = 1-P( A∪B )”、“P [ (-)A∪(-)B ] = P[ (-)( A∩B ) ] = 1-P( A∩B )”。

注意：A+B-B=A-B（这是为集合的加减的）。

题型：
1、将【“文字叙述型”的“事件”】转化为【“数学符号型”的“事件”】。

解题思路：具体的解题思想见教材“P5”。
总结：
①“至少”考虑的是和事件，如果是“至少有两个发生”，则就先所有两个事件找出来，至少则是为它们的和事件。
②要学会将“一种语言文字对事件的叙述”转化为“另一种文字语言对事件的叙述”，如“不多于一个发生”，就是“只有1个发生   +（+就是“或者”） 都不发生”，就是“至少两个不发生”（此时将两个不发生的都找出来，至少则是它们的和事件）。
③3个事件 A，B，C，区分“只有一个发生”与“只有A发生”。

作用：将“文字叙述表示的事件”转化为了“数学符号表示的事件”之后，我们就可以在这个基础之上，进一步利用后面所学习到的一些计算概率的公式来去解决这些事件所发生的一些概率的问题。


2、将【“数学符号型”的“事件”】转化为【“文字叙述型”的“事件”】。
解题思路：首先对 数学符号型”的“事件”进行化简，将化简之后的数学符号型的事件在转化为“文字叙述型”的“事件”。
