一、两个事件的独立性
1、独立的定义
设A，B是两个随机事件，若满足 P(AB) = P(A)P(B)，则称事件 A，B 相互独立，简称事件 A，B独立。

理解：
（1）两个事件A、B相互独立指的是这两个事件发不发生互不影响。
就是“当B发生时，随机事件A发生的概率还是A本身；当B不发生时，随机事件A发生的概率还是A本身”，即“P( A | B ) = P(A)；P（ A| !B ）=P(A) ”。
P( A | B ) = P(A)====》P( A B ) / P（B） = P(A) ====》P（A B）= P（A）P（B）；
P( A | !B ) = P(A)====》P( A !B ) / P（!B） = P(A) ====》P（A !B）= P（A）P（!B）==(减法公式，逆事件)==>P（A）- P（A B） =  P（A）（ 1 - P（B））====》P（A B）= P（A）P（B）；
因此，，描述两个事件发生互不影响，即相互独立的式子为“ P(AB) = P(A)P(B)”。

（2）两个事件相互独立 与 两个事件互斥（互不相容）没有一点关系。
①两个事件相互独立描述的是两个事件发生与否互不影响，但是这两个事件是可以同时发生的，如“今天会下雨”“我会生病”这两个事件相互独立，但是这两个事件却可以同时发生。
②两个事件互斥（互不相容）指的是这两个事件不能够同时发生，但是一个事件的发生对另外的一个事件可以有影响，也可以没有影响。

（3）对于两个非零概率事件A、B ，即“P(A)>0”“P(B)>0”，则有“独立一定不互斥”（两个非零概率事件是独立的，则这两个事件一定不是互斥的），“互斥一定不独立”（两个非零概率事件是互斥的，则这两个非零概率事件一定不是独立的）。
①独立一定不互斥：A，B 独立 则说明了“P(AB)=P(A) P(B)”，又因为“P(A)>0，P(B)>0”，所以“P(AB)>0”，即这两个事件A，B 一定不是互斥的（这两个事件A，B是可能同时发生的）。
②互斥一定不独立：A，B 互斥 则说明了“P( AB )=0”，又因为“P(A)>0，P(B)>0”，故“P(A) P(B) > 0”，所以一定不会满足“P(AB)=P(A) P(B)”,即这两个事件一定不会是相互独立的。

提示：如果我们要找既独立又互斥的事件，就找概率为0的事件，通常找的是不可能事件∅（不可能事件的概率一定是0，符合（4）中的独立，同时不可能事件与任何事件都不能同时发生（因为不可能事件压根就不会发生））不可能事件∅与任何事件既独立又互斥。

（4）若 P（A）=0 或 P(A) = 1，则 A与任何事件均独立。（假设这个任意事件为B）
理解：
若 P(A) = 0，因 AB 包含于 A，故 P(AB) ≤ P(A)，即 P(AB)=0，因此推出“P(AB) = P(A) P(B)”；
若 P(A) = 1，因为 A 包含于 A+B，故 P(A) ≤ P(A+B)，因此 P(A+B)=1，从而 P(A+B) = P(A)+P(B)-P(AB) ====》1= P(A)+P(B)-P(AB)====》 P(AB)=P(A)P(B)。

考点：
以后在判定事件独立性问题的时候，如果你看到这里的事件有概率为0或者概率为1的，那么这两个事件肯定就是独立的。
如果在题目中看到了“任意事件”“一定独立”，那么就去题目中看一下能不能够找到概率为0的，或者概率为1的。


2、独立性的性质
若事件A，B相互独立，则下列各对事件也相互独立：
A 与 !B，!A 与 B，!A 与 !B。

记忆：! 与 不！，不影响事件的独立性。

3、独立的等价说法
若 0<P(A)<1，则
事件 A，B独立《====》P(B) = P( B | A )《====》P(B) = P( B | !A )《====》P( B | A ) = P( B | !A )。

二、三个事件的独立性
设A、B、C是三个事件，
（1）如果满足等式
	{ P ( A B ) = P ( A ) P( B )
	{ P ( A C ) = P ( A ) P( C )
	{ P ( B C ) = P ( B ) P( C )
则称三个事件 A，B，C两两独立。

理解：如果 A与B 独立、A与C 独立、B与C 独立，则就称这三个事件是两两独立的。（俩俩独立 指的是“从这些事件中任意抓取两个”都是相互独立的）

（2）如果满足等式：
	{ P ( A B ) = P ( A ) P( B )
	{ P ( A C ) = P ( A ) P( C )
	{ P ( B C ) = P ( B ) P( C )
	{ P ( A B C ) = P ( A ) P ( B ) P( C )
则称三个事件A，B，C相互独立。


相互独立的推广（任意n个事件“A1，A2，……，An”相互独立）：（最多只考到3个事件相互独立，这个了解一下就行了）
若任意的n-1个事件是相互独立的，
如果这n个事件再满足：P( A1 A2 …… An ) = P(A1) P(A2) …… P(An)
我们就说这n个事件“A1，A2，……，An”是相互独立的。


（3）俩俩独立 与 相互独立的关系
①互推关系：
俩俩独立  ==（推不出）==》相互独立
相互独立  ====》俩俩独立

②若“A1 ……  An，B1 …… Bn”相互独立，则 f ( A1 ……  An ) 与 g ( B1 ……  Bn ) 相互独立。
 
f()，g() 表示事件的运算，如“A+B，A-B，AB，!A”（分别对应了 加、减、乘、非）。
比如：A1、A2、A3、A4 相互独立，则 A1-A2 与 A3+A4 相互独立。

注意：一个事件组“A1、A2、A3、A4”相互独立，从中任意挑选若干个事件进行相互运算所组成的一个新事件C，从中任意挑选若干个事件进行相互运算所组成的另一个事件D，如果C与D相互运算的事件中没有相同的事件的话，那么这个C事件 与 D事件 就是相互独立的；如果C 与 D相互运算的事件中有相同的事件的话，那么这个C事件 与 D事件 是否相互独立不能够确定，如 A1+A3-A2 与 A3+A4 这两个相互运算所构成的事件就不能够确定是否相互独立。


题型：
1、已知一个关于事件A、B的概率表达式（如：P( A|B ) + P( A|!B ) = 1 ），让你判断这两个事件A、B是否是相互独立的。
解题思路：对这个“关于事件A、B的概率表达式”利用我们之前总结过的处理方法来对这个概率式子进行变形，只要能够将这个“关于A、B的概率表达式”转化化为下面任何一种等价的式子，就可以说明A、B这两个事件相互独立。

A，B相互独立：（下面的都是为充要条件的）
《====》P(AB) = P(A) P(B)
《====》P( B | A ) = P(B)
《====》P( B | !A ) = P(B)
《====》P( B | A ) = P( B | !A )

提示：这里的 0< P(A) <1，如果 P(A)=0 或者 P(A) = 1，根据性质“若 P（A）=0 或 P(A) = 1，则 A与任何事件均独立”，可以得到 A，B这两个事件一定是相互独立的，此时就不需要再进行判断。
补充：概率4-概率的定义与性质中，有“由概率的关系推不出事件的关系”，有一个事件的关系可以推出，就是独立，即“由概率的关系是能够推出“事件独立”的（因为事件独立本身就是由概率来定义的）。


2、  有关概率的选择题中常常需要用到的技巧。
（1）如果我们要找 既独立又互斥 的两个事件，则就是概率为0的事件，即就是在找不可能事件∅（事件是集合）。两个事件中有一个为不可能事件的话，则这两个事件是 既独立又互斥。

理解：不可能事件∅的概率一定是0，概率为0的事件与任何的事件都是独立的，接下来判断概率为0的事件与其他事件是否是互斥的。由于不可能事件∅是一定不会发生的，既然不会发生就更不可能出与其他的事件同时发生的说法，因此，不可能事件∅与其他事件是互斥的。即不可能事件∅与其他事件是既 独立又互斥。

（2）如果题目中出现“任意几个事件”，问你下列哪些事件“一定相互独立”的。
解题：利用性质“概率为0 或者 概率为1 的事件 与 任何事件 都是相互独立的”，如果我们能够判断出某两个事件中，有一个概率为0 或者 概率为1，那么这两个事件就一定是相互独立的。

（3）题目中含有信息“A、B、C 是3个相互独立的事件”，问你下列哪些事件是“相互独立”“可能相互独立”。
解题：
利用性质“任意n个事件相互独立，则 从其中挑选出来若干个事件通过运算 构成了事件1，再 从其中挑选出来的若干个事件通过运算 构成了事件2，如果这两个通过运算构成的事件1和事件2中没有相同的基本事件，则这两个通过运算构成的事件1和事件2仍然是相互独立的；如果这两个通过运算构成的事件1和事件2中含有相同的基本事件，则这两个通过运算构成的事件1和事件2可能是相互独立的，可能不是相互独立的”。
这里的若干个事件通过运算构成了一个新的事件，这里的运算可以是“A+B，A-B，AB，!A”（分别对应了 加（∪）、减（-）、乘（∩）、非（-））。

注意：区分（2）和（3），（2）题目中给出的信息是“任意几个事件，并没有说这几个事件是相互独立的”，（3）中给出的是“任意n个相互独立的事件，即这n个事件是相互独立的”。


（4）如果题目中说了 事件A、B、C 相互独立的话，则如果我们在计算概率的过程中如果遇见了 P( ABC )，则就有“P( ABC ) = P(A) P(B) P(C)”；但是，如果题目中没没有说明“事件A、B、C 相互独立”（事件A、B、C俩俩独立也不行，必须相互独立），则就不会有“P( ABC ) = P(A) P(B) P(C)”。

（5）如果题目中有说这两个事件是独立的，选项中有说这两个事件是互斥的，先排除掉；如果题目中有说这两个事件是互斥的，选项中有说这两个事件是独立的，先排除掉。
理解：由于既相互独立又互斥的两个事件，必有一个事件的概率为0。而如果题目中给出的两个事件的概率都不是0的话，则就一定是满足“独立一定不互斥”“互斥一定不独立”。

（6）在判断具体的3个事件（给出详细的文字叙述这是一个什么事件）是否是相互独立的时候，如果判断出两个事件不能够同时发生的话，即这两个事件是互斥的话，则这两个事件就一定不是相互独立的，即这3个具体的事件也不会是相互独立。利用定义判断A、B、C是否相互独立的时候，需要求出 P(A)、P(B)、P(C)、P(AB)、P(AC)、P(BC)、P(ABC)，然后再去逐一验证那4个式子，只有那4个式子都满足的时候这3个具体的事件才是相互独立的。
