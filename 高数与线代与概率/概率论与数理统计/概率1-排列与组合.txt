一、两个基本原理

1、乘法原理
完成某事需要k个步骤，每一步分别有 n1，n2，……，nk 种方法，则完成此事共有 n1n2……nk 种方法。

理解：重点看完成这件事，这里是通过“k个步骤”才能完成一件事情。

2、加法原理
完成某事有k类方法，每一类分别对应有 n1，n2，……，nk 种方法，则完成此事共有 n1+n2+……+nk 种方法。

理解：重点看完成这件事，这里是有k个方法来完成这件事的，“每一个方法”都是可以“独立地完成这件事”。


二、排列、组合

3种抽样方式：
① 一次取一个，有放回取r次。（排列问题，有放回的排列---->考虑次序）
②一次取一个，不放回取r次。（排列问题，不放回的排列----->考虑次序）
③一把抓r个。（组合问题）

1、排列
（1）排列的定义
【从n个不同的元素中任取r个】（0<r<=n），【按照一定顺序排成一列】，则称从n个元素中取出r个元素的一个排列，其个数记为 A(n---r)。



（2）排列的种类及计算公式
①【不放回抽样】（不放回的排列）
选择列----【从n个不同的元素中一次取一个】【不放回的取r次】，一共的取法数：若 0<r<n，则 A(n----r) = n ( n-1 ) …… ( n-r+1 )。

理解：“不放回的取r次”说明了完成这件事需要r步，对应的是乘法原理。第1步有n种取法，第2步有 n-1 种取法，……，第r步有 n-(r-1) 种取法，则完成这件事总共有 n ( n-1 ) …… ( n-r+1 ) 种取法，记为 A(n----r)。
 
全排列：若 r=n ，则 A(n----n)=n!，此时也称为全排列。

②【有放回抽样】（有放回的排列）
有重复的排列----从n个不同元素中一次取一个有放回的取r次，一共的取法数：U(n----r)=n^r。

理解：“有放回的取r次”说明了完成这件事需要r步，对应的是乘法原理。第1步有n种取法，第2步有 n 种取法，……，第r步有 n 种取法，则完成这件事总共有 n^r 种取法，记为 U(n----r)。


2、组合
（1）组合的定义
【从n个不同的元素中任取r个】（0<r<=n），【不计顺序拼成一组】，称为从n个元素中取出r个元素的组合，记为 C(r---n)。 

理解：组合指的是仅仅只要从n个元素中取出r个就可以了，计算公式为 C(r----n) = A(n----r)/n!，即我们由于不管顺序，就相当于是在排列的基础上，将其打乱顺序就得到组合了。1个元素有1种排列顺序，4个元素有 4*3*2*1 种排列顺序，n个元素有 n! 种排列顺序，这也就是组合公式的由来。

（2）组合的计算公式：C(n----r) = n! / (n-r)! r! 。

理解：不要记忆这个组合公式，记忆 C(r----n) = A(n----r)/n! 这个公式。


（3）性质：C(n----r) = C(n ---- n-r)

题型：
1、共有20件产品，其中有3件次品。

（1）若一次取一件不放回地取3次，问有两件正品一件次品的取法有多少种？（一次取一件，不放回地取样，为排列问题）

解题思路：
①首先判断出这是“一次取一件，不放回地取样”问题，是为“不放回的排列问题”（要考虑次序，所谓的考虑次序的意思就是“在完成这件事之后，再乘以一个次序”）。 
    完成取“两件正品一件次品”这件事是需要3步的，先完成这件事（不管先取到的是啥，假设是为 正正次），为“17*16*3”。
    总的取的次序有“两件正品（由于两件正品完全一样，故这两个排列次序不影响）一件次品”对应的排列次序有3个，分别为“正正次、正次正、次正正”。
    因为，排列问题要考虑次序，故是需要在“完成一次这件事”后，再乘以一个次序3的。
    最后的结果为：17*16*3*3。

②完成这件事有3种分类方法，每种分类方法有3步，故是可以采用 分类加法（内部 分类乘法）的思想求解这道题的。总共是有3种分类方法可以完成这件事，分别为“正正次、正次正、次正正”，每一种分类方法是包含有3步的，故总结的结果为： 17*16*3*3。

（2）若一次取一件有放回地取3次，问有两件正品一件次品的取法有多少种？

解题思路：首先判断出这是“一次取一件，有放回地抽样”问题，是为“有放回地排列问题”（要考虑次序，所谓的考虑次序的意思就是“在完成这件事之后，再乘以一个次序”）。完成这件事需要3步，先完成一次这件事，假设为“正正次”，为：17*17*3，由于是为排列问题，故最后是要考虑次序的，最后的结果再乘以一个3，最后的结果为：17*17*3*3。


总结：（下面的 “一次取一件，不放回地取样”也是可以采用 分类+分步 的解题思路的，不过不推荐，故下面没有写）
“一次取一件，不放回地取样”的解题思路：先采用分步乘法完成一次这件事情（任何次序都行），最后将采用分步乘法完成这件事的结果（取法的种数）乘以次序，就是最后的结果（取法的种数）。
“一次取一件，有放回地取样”的解题思路：先采用分步乘法完成一次这件事情（任何次序都行），最后将采用分步乘法完成这件事的结果（取法的种数）乘以次序，就是最后的结果（取法的种数）。


2、共有20件产品，其中有3件次品，现从中任取3件，问：
（1）共有多少种不同的取法？

解题思路：首先判断出这是“一把抓r个”的问题（题目中的叙述常常是为“从n个不同的元素种任取r个”），是为“组合问题”。完成这件事是只需要一步的，就是“从20个产品中一次性取3个”，结果为：C(20----3)。

（2）恰有一件次品的取法？

解题思路：分步（每一步是组合问题）

首先要将题目中“恰有”的说法进行分步，每步都对应有一个“n个不同的元素中取r个”的叙述。
这里将“从20件产品中，任取3件，恰有1件次品的取法”分成了“从17件正品中任取2个，从3件次品中任取1个”，总共分成了两步，这里的“从17件正品中任取2个”就是为“从17件正品中一次性取2个”，这里的“从3件次品中任取1个”就是“从3件次品中一次性取1个”，都是为组合问题的（这2步每一步都是组合问题）。
完成这件事需要两步，从“从17件正品中任取2个”为：C(17----2)，从“从3件次品中任取1个”为：C(3----1)，根据分步乘法，最后的结果为：C(17----2) C(3----1)。

提示：这里还是“从20件中一把抓3个”，只不过我们分成了两步来做，分别是“从17件正品中任取2个“，“从3件次品中任取1个”。

（3）至少有一件次品的取法？
解题思路：
① 分类（内部 分步（每一步是组合问题））
首先要将题目中“至少、至多”的说法进行分类，每步都对应有一个“n个不同的元素中取r个”的叙述。
   这里是将“从20件产品中，任取3件，至少有1件次品的取法”分为了“取出的3件中有1个次品，取出的3件中有2个次品，取出的3件中有3个次品”，总共分成了3类。每一类都可以独立完成这件事，在对每一类进行分步，“取出的3件中有1个次品”对应的是“从17件正品中任取2个，从3件次品中任取1个”；“取出的3件中有2个次品”对应的是“从17件正品中任取1个，从3件次品中任取2个”；“取出的3件中有3个次品”对应的是“从17件正品中任取0个，从3件次品中任取3个”。这3类都是为2步完成的，且每一步都是为组合问题的。
总的结果为：C(17----2) C(3----1) + C(17----1) C(3----2) + C(17----0) C(3----3)。

②从逆命题考虑
当题目中出现了“至少，至多”类似的字样，我们可以从其逆命题来进行考虑。
“从20件产品中，任取3件，至少有1件次品的取法”的逆说法就是“从20件产品中，任取3件，每一件都是正品”，即“从17件正品中任取3件”。
我们可以用总的取法，即“从20件产品中，任取3件”减去“从17件正品中任取3件”的取法，最终结果为：C(20-----3) - C(17----3)。


总结：“一把抓r个”的解题思路：这是为一个组合问题，采用 C(n----r)的方法来求出。当题目中含有“恰有”的字样的时候，采用“分步来完成”这件事，其中每一步常常又是为一个组合问题，对应的就是 C C C。当题目中含有“至少，至多”的字样的时候，我们可以采用 分类（内部 分步（每一步常常又是一个组合问题）），对应的就是  C C + C C +CC，或者从其逆命题出发，用总的取法数减去逆命题对应的取法数。
