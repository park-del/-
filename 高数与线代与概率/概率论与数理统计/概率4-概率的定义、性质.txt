一、概率的公理化定义
首先做了一个随机实验，然后这个随机实验所有可能的结果构成了一个集合，就是样本空间Ω。
这个样本空间Ω的子集就是随机事件，用A、B、C表示。
然后在这个随机事件A，B，C之上给它定义一种函数关系，叫P(*)。
若P(*)这个函数满足：
（1）P(Ai)>=0；
（2）P(Ω)=1；
（3）若 A1，A2，……，An 两两互斥，则 P( A1+A2+……+An)=P(A1)+P(A2)+……+P(An)。
即只要P()这个函数满足上述三条，我们就将P(A)这个函数叫做随机事件A的概率，将P(B)这个函数叫做随机事件B发生的概率。


二、概率的性质
性质1（非负性）设A为随机事件，则 0<= P(A) <=1
性质2（规范性）P(∅)=0，P(Ω)=1

注意：（下面情况反过来则可以，即不可能事件的概率一定为0，必然事件的概率一定为1）
（1）P(A)=0 ==（不能）==》  A=∅。即是概率为0的事件不一定是不可能事件。（例如，在 [ 0，1 ] 区间随机取一个数记为x，则 P(x=1/3)=0/1=0，但是x=1/3不是不可能事件（不可能事件的样本空间为∅））
（2）P(A)=1 ==（不能）==》  A=Ω。即是概率为1的事件不一定是必然事件。（例如，在 [ 0，1 ] 区间随机取一个数记为x，则 P(x≠1/3)=1/1=1，但是x≠1/3不是必然事件（必然事件的样本空间为Ω））

注意：由概率的信息推不出事件的关系（这里所说的事件的关系就是我们前面所讲过的那8种事件关系，即 包含，相等，和事件，积事件，差事件，互斥事件，对立事件，完全事件组）
如
① P(A)=0 ====》 A=∅。这里是由概率信息（带有P(*)函数的就是为概率信息），推导事件A信息（一个集合就是一个事件，这里是推导事件A是不可能事件），推不了。
② P(A)=1 ====》 A=Ω。这里是由概率信息，推导事件A信息，推不了。
③ P(A)=P(B) ====》 A=B。这里是由概率信息，推导事件A与事件B相等，推不了。

即：以后一见到题目中是“由概率信息来推导事件关系”的选项，直接不用看，其就是错误的。（老师说到的规律）


性质3（有限可加性）设A1，A2，……，An 两两互斥，则 P( A1+A2+……+An)=P(A1)+P(A2)+……+P(An)。
注意：有限可加性（事件是有限个）与 可列可加性（事件是无数个），它们都是一样的，只要“A1，A2，……，An 两两互斥”，都是满足P( A1+A2+……+An)=P(A1)+P(A2)+……+P(An)。 


性质4（逆事件的概率）P( !A ) = 1- P(A)

性质5（可比性）
（1）设 A，B 是两个事件，若 A 包含于 B，则有 P(A)<=P(B)，且 P(B-A)=P(B)-P(A)。
（2）一般地，设 A，B是两个事件（A，B两个事件没有明确的什么关系），则 P(B-A)=P(B)-P(AB)，这个就是减法公式。

对减法公式的理解：P（ B-A ）= P（ B(-)A ） = P（ B-AB ）= P（B）- P（AB）。减法公式其实就是用 B减去B与A相交的，如果A包含在B里面，此时 AB 就是为A的，即此时 P(B)-P(BA)=P(B)-P(A)。 

注意：涉及概率的不等式问题，能对应的：
① 0<= P(A) <=1。
② 若 A 包含于 B，则 P(A) <= P(B)。


性质6（加法公式）
对于任意两个随机事件A与B，有 P(A+B)=P(A)+P(B)-P(AB)。
对于任意三个随机事件A，B，C，有 P(A+B+C)=P(A)+P(B)+P(C)-P(AB)-P(BC)-P(AC)+P(ABC)。

理解：对于两个随机事件的加法公式，P(A+B) 相当于就是A并B，P(A)+P(B)相当于是把 A与B 公共的部分加了两次，故要再减去一个P(AB)。



题型：
1、题目中给出你概率的信息（即是 P(*) 函数），让你判断下列哪些说法是正确的。
解题思路：题目中给出的是概率的信息，如果选项中很肯定地说了事件的信息，则这个选型就是错误的，直接排除掉；如果选项中不是很确定的说了事件的信息，则这个选项是正确的还是错误的，还需要进行推理验证。（可以画出随机事件的文氏图来帮助理解，随机事件本质上就是一个集合）

提示：
①题目中给出的是概率信息指的是题目中给出的是  P()什么什么，而题目中给出的是事件信息指的是题目中给出的是  集合的信息（或者是集合运算的信息，集合运算后得到的还是一个集合，集合就是一个事件）。（②③就是一些题目中可能会提到的关于事件的信息（已知是概率的信息），遇到的话就直接排除掉）
②题目选项中常常是说“  集合A 或 若干个集合运算结果 是  必然事件、不可能事件”或者“  若干个集合运算结果  与 若干个集合运算结果 是 必然事件、不可能事件、对立事件、互斥事件”。
③题目选项中有时会说：若A发生，则B一定发生（集合A 包含于 集合B），事件A=事件B。

（这里所说的事件的关系就是我们前面所讲过的那8种事件关系，即 包含，相等，和事件，积事件，差事件，互斥事件，对立事件（互为逆事件），完全事件组）

思路：以后见到  “!A + !B”  或者  “!A !B”，可以利用逆事件将它们变成只有一个帽子的，即分别对应为“! ( AB )”“！( A+B )”。变成了只有一个帽子之后，就可以利用求逆事件的概率的方法来求出 P( !A + !B )  P( !A !B ) 了。

补充：由概率信息不能够得到事件的关系，但是有一个除外，就是“两个事件相互独立”，由概率信息是可以推导得出“两个事件相互独立的”（因为两个事件相互独立就是通过概率来去定义的）。

补充题型：如果题目中给出你的是事件的关系，让你去判断事件的关系（此时采用文氏图很方便做）；如果题目中给出的是事件的关系，让你去判断一些概率的信息（此时就根据所给出的关系，写出对应的表达式，在进一步去解决）

2、判断带有概率的不等式的关系的。
解题思路：涉及到跟0和1比大小的，则概率就在0和1之间；如果不是涉及到跟0和1比大小的，就看一下事件是否有包含关系，如果事件有包含关系，则概率就有大小关系，例如事件 A 包含于B，则概率就会有 P(A)≤B。接下来进一步去处理。

 
要注意题目中所隐含的包含关系（即是题目中所隐含的概率的不等式）：
（1）A 包含于 A+B，B 包含于 B+C 这种条件以后是不会给你的。（对应到概率上就是 P(A)≤P(A+B)，P(B)≤P(B+C)）
（2）AB 包含于 A，AB 包含于 B。（对应到概率上就是 P(AB)≤P(A)，P(AB)≤P(B)）（这里和两个矩阵相乘的结论是一样的）
（3）将两个隐含关系联系起来就是 AB 包含于 A 包含于 A+B，AB 包含于 B 包含于 A+B。 (对应到概率上就是 P(AB)≤P(A)≤P(A+B)，P(AB)≤P(B)≤P(B+C)）


3、题目中给出了一些概率的信息，让你去确定一个概率是多少。
解题思路：
①题目中或者推导过程中出现了“P( !() )”,考虑使用逆事件的公式，即“1-P( () )”。（式子中“（）”是为一个整体看做，如 （AB）、（A+B））。
②题目中或者推导过程中出现了“P( A-B )”,考虑使用减法公式，即“P( A-B ) = P( A ) - P( AB )”。
③题目中或者推导过程中出现了“P( A+B )”,考虑使用加法公式，即“P( A+B ) = P( A ) + P( B ) - P( AB )”。
记住：当为3个事件的时候，加法公式为“ P(A+B+C)=P(A)+P(B)+P(C)-P(AB)-P(BC)-P(AC)+P(ABC)”。
④题目中或者推导过程中出现了“P( !A !B )”或者“P( !A+!B )”,考虑到使用对偶律将它们变成“P( !(A+B) )”或者“P( !(AB) )”，接下来就可以转化为了①的形式，考虑使用逆事件的公式。
记住：当为3个事件的时候，也是一样的，即“P( !A !B !C ) = P( !( A+B+C ) )”,“P( !A+!B+!C ) = P( !( ABC ) )”，接下来就考虑使用逆事件的公式就可以了。

⑤题目中给出了“AB=!A !B”的信息：
《1》 考虑 在“AB=!A !B”两边同时乘以A，得到“AB=∅”。 即“AB=!A !B ====》AB=∅”。
《2》 考虑 AB=∅，故 !A !B=∅，利用对偶律得到“!( A+B )=∅”，故“A+B=Ω”。即“AB=!A !B ====》!( A+B )=∅”，“AB=!A !B ====》A+B=Ω”。
《3》 考虑 “AB=!A !B”能够推导得到“ AB=∅，A+B=Ω”，即是“A和B这两个事件是为对立事件的”；反过来，A和B这两个事件是对立的话，则 !A=B，!B=A，能够得到 “AB=!A !B”，且“A+B=Ω”。即“AB=!A !B”《====》A与B对立。
⑥隐含的包含关系，推导出的概率（解题时可能会用到）：
设 A 包含于 B，
《1》若 P(B)=0，则 P(A)=0；
《2》若 P(A)=1，则 P(B)=1。
即是当题目中有包含关系或者隐含的包含关系的时候，小的概率 ≤ 大的概率，若小的概率是1，则大的概率也为1；若大的概率是0，则小的概率是0。

 
4、带有应用色彩的求概率问题（带有应用色彩指的就是实际生活中的一些求概率的问题）。
解题思路：
可以利用我面前面学到过的古典概型的知识来直接去相像求概率，如果直接去想象求概率时，想不清楚怎么办，此时有两种思路：
①从这个事件的对立事件的角度入手；
②不妨尝试把事件去设一设，设成事件，然后结合计算概率事件的一些性质公式来帮助去求出事件的概率。
