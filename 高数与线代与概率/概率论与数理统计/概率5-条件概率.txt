一、条件概率
1、条件概率的定义：设A，B是两个随机事件，且P(A)>0，称 P( B|A )= P(AB)/P(A) 为在事件A发生的条件下事件B发生的条件概率。

2、条件概率的性质
（1）0≤  P（ B|A ）≤1
（2）P( ∅|A )=0，P(Ω|A)=1
（3）P( !B | A ) = 1 - P( B|A )
（4）P( B+C | A ) = P( B|A ) + P( C|A ) - P( BC |A )

记忆：这里关于条件概率的性质与前面我们讲过的概率的性质是一样的，只不过这里加上了“| A”。
注意：概率与条件概率没有明确的大小关系，具体谁大，具体谁小是不确定的。

二、乘法公式

设A，B是两个随机事件，若P(A)>0，则有 P(AB) =P(A) P(B|A) 。
设A，B，C 是三个随机事件，若P(AB)>0，则有 P(ABC) = P(A) P( B|A ) P( C | AB )。

推导：P(A)>0，则有 P( B|A ) = P(AB)/P(A)；P(B)>0，则有 P( A|B )=P(AB)/P(B)。根据“P( B|A ) = P(AB)/P(A)，P( A|B )=P(AB)/P(B)”这两个公式可以推导出乘法公式，即 P(AB)=P(A)P( B|A ) 或者 P(AB)=P(B)P( A|B )。

理解：
乘法公式就是用来求多个事件同时发生的概率的。如果求的是两个事件A和B同时发生的概率，那么就是“A发生的概率 × A发生的条件下B发生的概率”或者“B发生的概率 × B发生的条件下A发生的概率”; 如果求的是3个事件A，B，C同时发生的概率，那么就是“A发生的概率 × A发生的条件下B发生的概率 × A与B同时发生的条件下C发生的概率”。


题型：
1、求条件概率
（1）套用条件概率公式“P( A|B ) = P(AB)/P(B)”来计算出条件概率。
（2）采用缩小样本空间的方式来计算出条件概率，求“P( A|B ) ”就将样本空间缩小到集合B，在集合B里面求对应的事件A的概率。

2、题目中给出了一些概率的信息，让你去确定一个概率是多少（这里题目中给出的，或者让你确定的一个概率，包含了条件概率的信息的）。
解题思路：与概率4中的题型3结合在一起，在概率4中的题型3上进行补充如下：
①题目中或者推导过程中出现了“P( A | B )”,想到使用条件概率的公式，即“P( A|B ) = P(AB)/P(B)”。
②题目中或者推导过程中出现了“P( A !B )”,想到使用减法公式，即“P( A !B ) = P( A ) - P( AB )”，即是“前一个，减去，前一个×后一个的非”。
③题目中或者推导过程中出现了“P( A|B )”，写出连等式“P(B) P( A|B ) = P(A) P( B|A ) = P(AB) ”,知道几个概率的信息，利用这个连等式很容易就能够求出其他的概率。


3、条件概率 与 乘法公式 的求概率问题？
（1）问你“在某种情况A发生（或者未发生）的情况下，B发生的概率”。
解题思路：由于已经事先知道事件A发生（或者未发生），故这是一个条件概率的问题，见题型1的解题方法。

（2）问你“B发生的概率”。
解题思路：如果经过分析发现事件B要发生，则必须要先发生一个事件A，此时并不知道这个时间A有没有发生，则此时要求的就是 事件A与事件B同时发生的问题，利用乘法公式，得到“P(AB)=P(A)P( B|A)”。


结论：抽签原理，“总共有3根签，只有1个是正签，其于两个是次签”，则“第1次抽到正签或者次签 与 第2、3次抽到正签或者次签”的概率是一样的。即“不放回地抽样，一次抽一个，则第n次抽到与第1次抽到的概率是一样的”，统统转化为求第1次的概率就可以了。


区分：
①条件概率指的是在一个事件A发生的情况下事件B发生的概率，前提是已经知道了事件A发生了（事件A发生会导致事件B发生的样本空间发生变化），即事件A发生的概率 P(A)为1；
 乘法公式指的是A和B这两个事件同时发生的概率，即我们事先是不知道事件A有没有发生的，即事件A发生的概率P(A)不为1，需要我们计算。
②对应到“有10个正品，2个次品，任意抽取2次，每次取一个，取出后不放回”的问题，
则条件概率问的方式为“在第1次取出次品的条件下，第2次取出次品的概率”，第1次取出次品是已经发生的，概率为1，为条件概率。
则乘法概率问的方式为“第2次取出次品的概率”，此时第1次不知道取出的是次品还是正品，则根据分类加法原理，是“第1次取出正品与第2次取出次品同时发生了”+“第1次取出正品与第2次取出次品同时发生了”。
③条件概率与乘法公式相当于就是2步完成这件事情，这两步的概率分别相乘就得到条件概率与乘法概率。只不过是条件概率的第1件事是为1的，而乘法概率中的第1个概率不不确定的，需要我们自己去计算。
