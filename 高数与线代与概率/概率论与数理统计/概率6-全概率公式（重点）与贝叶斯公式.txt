一、全概率公式（五颗星，几乎每年都会考察，尤其在大题中）
当我们遇到一个复杂事件B的概率不好求的时候，此时我们先考虑的是这个事件B的逆事件，如果这个事件B的逆事件也不好求的话，此时我们可以考虑将这个复杂事件B拆分成若干个简单的事件，通过求这几个简单事件的概率来达到求事件B的概率的目的。

我们首先有一个完备事件组 A1，A2，……，An （满足 ∑(i=1--n) Ai =Ω，且 AiAj = 0 这两个条件的才是完备事件组  ），事件B位于这个完备事件组里面。根据全概率公式，有 P( B )=P( BΩ )=P( B ∑ Ai ) = P( A1B+A2B+……+AnB )，由于 Ai 之间都是互斥的，故 AiB 之间也都是互斥的，故“P(B) = P( A1B+A2B+……+AnB ) = P( A1B ) +  P( A2B ) +……+ P( AnB )”。即此时我们就把求B的概率P(B)的问题转化成了求“P( A1B ) +  P( A2B ) +……+ P( AnB )”。进一步利用乘法公式展开得到“P(B)=P( A1B ) +  P( A2B ) +……+ P( AnB )=P( A1 )P( B|A1 )+P( A2 )P( B|A2 )+……+P( An )P( B|An )”。


何时用全概率公式：
①从思维层面
解决复杂事件概率（你遇到一个概率问题的时候，不会算）的两个重要思想
（1）逆事件思想。
（2）全概率思想。
当我们遇到一个复杂事件B的概率不好求的时候，此时我们先考虑的是这个事件B的逆事件，如果这个事件B的逆事件也不好求的话，此时我们可以考虑将这个复杂事件B拆分成若干个简单的事件，通过求这几个简单事件的概率来达到求事件B的概率的目的。

②从具体实验的角度
若一个试验可以看成两个阶段完成（或者分两步完成），第一个阶段的具体结果未知，但所有可能结果已知，现求第二个阶段某结果发生的概率，用全概公式。
关键：找到完全事件组。第1个阶段的所有可能结果就是完全事件组。
