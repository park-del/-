1、矩阵的加法
（1）规定：只有同型的两个矩阵才可以相加，两个矩阵对应元素对应相加，相加后得到一个新的矩阵。

注意：矩阵的加法与行列式加法的不同。在理解行列式的加法的时候要注意两点，其一就是只有一行不同的而两个行列式我们才能够进行相加；行列式相加的时候相同的那些行是保持变的，只有不同的那一行的元素才需要你去相加。

理解：矩阵加法做的其实就是这个容器里面的数字的加法，即矩阵加法本质上就是数字的加法，显然数字加法满足的一些运算规律在矩阵加法中也是满足的。

（2）矩阵加法满足的运算规律（简单了解一下即可）
《1》A+B=B+A ;
《2》(A+B)+C=A+(B+C) 
《3》A-B=A+(-B)

二、矩阵的数乘
（1）规定：矩阵的数乘，顾明思义，就是用数λ去乘以一个矩阵，或者用一个矩阵去乘以一个数λ，即λA，将λ依次乘以原矩阵中的每一个元素，得到一个新的矩阵，矩阵的数乘得到一个新的矩阵。 

注意：与行列式的不同，λ乘以一个行列式时只需要去乘以这个行列式中的某一行就行了。

（2）矩阵的数乘满足下列运算规律：（了解即可）
《1》（λ+μ）A = λA + μA。
《2》λ（A+B）=  λA+λB。

矩阵的加法和矩阵的数乘统称为矩阵的线性运算。

3、矩阵的乘法
3个问题：什么样的两个矩阵可以相乘？    两个矩阵要怎么乘？   两个矩阵成完后得到的新矩阵的形状是什么样？

规定：设A=（aij）m*s，B=（bij）s*n，则可以 C=AB=（cij）m*n，其中，cij=ai1+b1j+ai2+b2j+……+ais+b1s（i=1,2，……，m；j=1,2，……，n）。
理解（能否乘）：由规定可以知道，只有前面的这一个矩阵的列数与后面的这一个矩阵的行数相等，这两个矩阵才能相乘（即是当把两个矩阵写出来时，挨在一起的下小标一定是一样的，才能相乘）。

理解（乘完后的形状）：A*B=C=（cij）m*n，可以看出矩阵A与矩阵B中间的两个下标 决定能否乘，可以看出矩阵A与矩阵B两边的两个小标m、n决定了乘完之后的形状，即A*B得到的是一个m*n（m行n列）的矩阵。

理解（怎么乘）：矩阵C中的第1行第1个元素是为矩阵A中的第1行与矩阵B中的第1列分别相乘相加得到的；矩阵C中的第1行第2个元素是为矩阵A中的第1行与矩阵B中的第2列分别相乘相加得到的；矩阵C中的第2行第1个元素是为矩阵A中的第2行与矩阵B中的第1列分别相乘相加得到的；即矩阵中的第i列第j列的元素是由矩阵A中的第i行元素与矩阵B中的第j列元素分别相乘相加得到的。（矩阵相乘时的基本单位是为矩阵中的一行或者一列的，准确的说矩阵的乘法就是矩阵一行乘以一列这个运算；A*B，是从A矩阵中挑选行，是从B矩阵中挑选列，最后得到的C矩阵中这个元素所处的行就为A矩阵挑选的第i行，这个元素所处的列就为B矩阵中挑选的第j列）


矩阵乘法的运算规律：
（1）(AB)C=A(BC)。
理解：这个运算规律也叫作矩阵的结合律，当你有一大堆的矩阵放在一起来乘的时候，你可以随意打乱它们的运算顺序，只要不把它们的顺序交换就可以。
（2）λ（AB）= ( λA )B = A ( λB )。
理解：这个运算规律也叫作矩阵的数乘结合律。在矩阵相乘的时候，数字可以随意移动，可以放在最前面，放在中间，也可以放在后面。
（3）（A+B）C = AC + BC，C ( A + B ) = CA + CB。
理解：
《1》这个运算规律也叫作矩阵的分配率。
《2》从左往右看是在分配；
《3》但是从右往左看，是在告诉你当我们有一个非常非常长的矩阵相乘的表达式，我希望对它进行化简的时候，有公共的部分，我们是可以提出公因子的，但是提取公因子的时候要注意C的位置，如果C在左侧的话，那么只能在左侧提取C，C做右侧的话，那么我们只能在右侧提取。

（4）EA=AE=A。

注意：
（1）一般地，AB!=BA（若AB=BA，则称A与B可交换）。
理解：即矩阵相乘没有交换律，不能随便交换两个矩阵的位置，即矩阵谁在前，谁在后都是有规定的。
（2）由AB=O，推导不出来A=O或者B=O。
（3）当A!=O，由AB=AC，推不出B=C。
理解：AB=AC   ===》  AB-AC=0  ===》   A (B-C) = 0，根据（2），我们是推导不出来A=O或者B-C=O的。  即矩阵没有消去律，当等式的两边有两个相同的矩阵的话，我们是不能够随随便便的将这个相同的矩阵给约掉的。


3、矩阵的转置
规定：和行列式中的转置运算一样，对一个矩阵A进行转置运算，就是将这个矩阵A中的第1行写在空白纸上的第1列，将这个矩阵中的第2行紧接着第1列写在空白纸上的第2列，依次类推，这样最终空白纸上得到的矩阵就是对矩阵A进行转置运算得到的结果，是为一个矩阵，记为 AT。

由于矩阵的转置也是为对矩阵的一种运算的，故其也是满足一些运算规律的：
（1）( AT )T = A；
如：
     { 1 2 }              { 1 3 }                    { 1 2 }    
A=           ，AT=              ，(AT)T=
     { 3 4 }              { 2 4 }                    { 3 4 }    

注意：若A为一个m*n的矩阵，则AT是为一个n*m的矩阵。

（2）( A+B ）T = AT+BT；

记忆：和的转，等于，转的和，即先加再转，还是先转，再加都是一样的。

（3）（λA）T=λAT；
记忆：是先成乘了一个数再转，还是先转了，再乘以一个数都是一样的。
提示：当我在转置符号T里面遇到了常数的时候，我们可以先把这个常数先提出去。

（4）(AB)T=BT AT。 


根据转置的定义，引入了对称矩阵与反对称矩阵的概念：
对称矩阵：若A=AT，则称A为对称矩阵。
理解：
（1）对形状的要求：假设我的A是为一个m*n矩阵，则我的AT就是为一个n*m的矩阵，这两个矩阵要相等的话，就必须要是同型的，即m=n，即对称矩阵一定是为一个方阵的。
                                              { a b }              { a c }             
（2）对元素的要求，假设 A=           ，AT=              ， A=AT的话则说明了“b=c”，即对角线两边的元素一定是相等的。
                                              { c d }              { b d }                     
（3）关于对角线完全对称的一个矩阵（首先是方阵，只有方阵才会有对角线）就是为对称矩阵的。

反对称矩阵：若A=-AT，则称A为反对称矩阵。
理解：
（1）对形状的要求：反对称矩阵也一定是为一个方阵的。
		               { a b c }	               { -a -d -g }
（2）对元素的要求：假设 A= { d e f  } ，则 -AT=  { -b -e -h } ，若有 A = -AT,则“a=-a” ===》a=0，即是对角线上的元素为0；则有 b=-d，即对角线两边的元素互为相反数。
		               { g h i }	               { -c -f   -i }
（3）对角线两边的元素互为相反数，且对角线上的元素全为0的矩阵就是为一个反对称矩阵的。

题型：
1、计算两个矩阵相乘的结果。
解题思路：首先判断这两个矩阵能否相乘，即是写出这两个矩阵Ams Bsn，看A与B中靠近的两个下标是否相等，如果相等则说明这两个矩阵可以相乘，如果不相等则不可以相乘。A与B中外边的两个下标决定了乘除出来的矩阵的形状是为一个m*n的矩阵。矩阵相乘运算的基本单位是行和列，假设C=AB，则C矩阵中第i行第j列的元素，就是 A中第i行分别乘以B中第j列相加求和（矩阵相乘运算的基本单位是行和列）。


2、考察有关矩阵乘法运算律的一些选择题。（问你下面哪些包含了矩阵乘法的等式正确是正确的）
解题思路：准确把握住矩阵乘法的3条运算规律以及3条注意点就行了。利用矩阵乘法的3条运算规律和3点注意，去将题目中给出的包含矩阵乘法的等式的一边作恒等变形，看能否变成等式右边的，如果能，则这个包含矩阵乘法的等式是正确的，如果不能，则这个包含矩阵乘法的等式就不是正确的。

3、判断某一个矩阵是否为对阵矩阵，或者是否为反对称矩阵。（抽象矩阵就是没有告诉你A={ }的矩阵，常常告诉你的是为一个表达式，即A=H+E；而具体的矩阵就是告诉了你A={}的矩阵）
（1）如果题目中给出的是为一个抽象的矩阵A，让你判断A是否为对称矩阵。
解题思路：计算AT，利用转置的那4条运算律 和 一些矩阵的运算律 进行推导，如果为A的话就说明了矩阵A为对称矩阵。 

（2）如果题目中给你的是为一个完全具体的矩阵，让你判断矩阵A是否为对称矩阵。
解题思路：就去看这个矩阵对角线两边的元素是不是都对应相等，如果都对应相等的话，则这个矩阵就是为一个对称矩阵的。

（1）如果题目中给出的是为一个抽象的矩阵A，让你判断矩阵A是否为反对称矩阵。
解题思路：计算AT，利用转置的那4条运算律 和 一些矩阵的运算律 进行推导，如果为-A的话就说明了矩阵A为对称矩阵。 

（2）如果题目中给你的是为一个完全具体的矩阵，让你判断矩阵A是否为反对称矩阵。
解题思路：就去看这个矩阵对角线两边的元素是不是都互为相反数，如果都互为相反数，且对角线上的元素都为0的话，满足这两点的矩阵就是为一个反对称矩阵的。
