一、实对称矩阵的特性

实对称矩阵：如果一个矩阵中的元素都是为实数，且这个矩阵是为一个对称矩阵（AT=A，则说明矩阵A是为对称矩阵）的话，此时这个矩阵就是实对称矩阵。

设A为实对称矩阵，则
（1）A的特征值全是实数（了解）

（2）A的属于不同特征值的特征向量必正交（内积为0）；
理解：A的属于不同特征值的特征向量不仅会线性无关，而且它们会相互正交。

证明：假设矩阵是为一个对称矩阵，且有 Ax1=λ1x1，Ax2=λ2x2，λ1≠λ2，证明  x1与x2的内积，即是证明 x1T x2=0.
在“Ax1=λ1x1”的两边同时转置，得到“( Ax1 )T = ( λ1x1 )T”，因为“( Ax1 )T = x1T AT =  x1T A，( λ1x1 )T =  λ1x1T”，故“ x1T A = λ1x1T”。在“ x1T A = λ1x1T”的右边同时乘以 x2，得到“ x1T A x2 = λ1x1T x2”，将“Ax2=λ2x2”代入，得到“x1T λ2x2 = λ1x1T x2”，即“ ( λ2-λ1 ) x1T x2 =0”。
因“ λ2  ≠ λ1”，故“x1T x2=0”，即“A的属于不同特征值的特征向量必正交”。

（3）A的k重特征值λ必有k个线性无关的特征向量，即 r( λE-A ) = n-k；
理解：A的k重特征值λ必有k个线性无关的特征向量，则说明了“A的k重特征值λ所对应的齐次线性方程组 | λE-A | = 0 的基础解系中解向量的个数为k”，即“n - r( λE-A ) = k”，移项后得到“ r( λE-A ) = n-k”。

（4）A必可以相似对角化，并且存在正交矩阵Q，使 Q^-1 A Q = QT A Q = Λ.

题型：
1、求一个具体矩阵A的正交矩阵，并把这个矩阵A对角化。
解题思路：
（1）求出n阶矩阵A的全部互不相等的特征值 λ1，……，λn，它们的重数依次为 k1，……，ks（k1+……+ks=n）；
（2）对每个ki重特征值λ，求出对应的ki个线性无关的特征向量，再把它们正交化，单位化，得ki个两两正交的单位特征向量，因 k1+……+ks=n，总共可得n个两两正交的单位特征向量；
（3）用这n个两两正交的单位特征向量构成正交阵Q，n个特征值构成对角阵Λ，则有 QTAQ=Λ。
