
1、向量组A的极大线性无关组定义：
设向量组A（A中可以有无限个向量），若
（1）A的部分组 A0：α1，α2，……，αr 线性无关，
（2）A中任意 r+1 个向量（若存在）都线性无关，

则称A0为向量组A的一个极大线性无关组，r称为向量组A的秩，只含零向量的向量组没有极大线性无关组，规定它的秩为0.


理解：从一个向量组A中挑选出了若干个向量（注意是不能够挑选重复的）组成了一个新的向量组A0，若这个新的向量组A0是线性无关的（新的向量组A0是线性无关的也就要求了从向量组A中挑选向量的时候是不能够挑选重复的向量的，因为如果有重复的向量的话，则向量组A0就会满足有两个向量成比例，则这个向量组A0就是线性相关的了），此时如果在从向量组A中任意挑选一个向量（此时所挑选出来的这个向量可以是向量组A0中已经有过的，也可以是没有的），这个新的向量与向量组A0所组成的新的向量组是线性相关的话，此时就将向量组A0称作是为向量组A的极大线性无关组。

注意：
① 极大线性无关组可能不唯一（即是一个向量组的极大线性无关组可能有多个，也可能是只有一个），但一个向量组的不同的极大线性无关组中所包含的向量个数一定是一样的，将一个向量组的极大线性无关组中所包含的向量的个数称为是这个向量组的秩（一个向量组的秩一定是唯一的）。

② 一个向量组 A：α1，α2，……，αs，若 r ( α1，……，αs ) =r，则 α1，……，αs 中任意的r个无关的向量均可以作为极大线性无关组。

 
③ 一个向量组 A：α1，α2，……，αs，则 r( α1，α2，……，αs ) <= s。

r( α1，α2，……，αs ) = s    《====》向量组 A：α1，α2，……，αs 线性无关；
r( α1，α2，……，αs ) < s    《====》向量组 A：α1，α2，……，αs 线性相关；

例子：
 r ( α1，α2，α3 ) = 2，则 向量组 α1，α2 线性无关。（×）
 r ( α1，α2，α3 ) = 2，则 向量组 α1，α2 线性相关。（√）

理解：r ( α1，α2，α3 ) = 2 只是说明了这个向量组的极大线性无关组有2个向量，但具体是由哪两个向量所组成的向量组是不确定的，即此时是不能够说明向量组 α1，α2 线性无关。
 

④ 向量组A中的任一向量都能由极大线性无关组A0唯一地线性表示。

理解：从向量组A中挑选任意一个向量Ai（可以是A0中已经有的，也可以是A0中没有的），其与向量组A0所组成的向量组都是线性相关的，而向量组A0是线性无关的，根据上一个知识切片中所讲到的结论，可以知道向量Ai可以由向量组A0来线性表示，且表示方式唯一。


2、定理：矩阵的秩等于它的行向量组的秩，也等于它的列向量组的秩。

例1：矩阵 A4*3 ，r(A)=3，则 这个矩阵的行向量组线性相关，这个矩阵的列向量组线性无关。

理解：矩阵A的秩等于其行向量组的秩，等于其列向量组的秩，都是为3的。矩阵A的行向量组有4个向量，由于这个 行向量组的秩（为3）小于行向量组中向量的个数（4），故这个行向量组是线性相关的；矩阵A的列向量组有3个向量，由于这个 行向量组的秩（为3）等于列向量组中向量的个数（3），故这个列向量组是线性无关的。

结论：列满秩的矩阵列向量组线性无关，行满秩的矩阵行向量组线性无关。

3、定理：若矩阵A做【初等行变换】化为B，则A与B的【列向量组】有完全相同的线性相关性。

应用：通过这个定理可以将“求一个向量组秩的问题”转化为“求一个矩阵的秩的问题”。

题型：
1、求一个 列向量组A：α1，α2，α3 的秩；写出一个它的极大线性无关组；并将向量组A中不属于极大线性无关组的向量用极大线性无关组线性表示出来。

解题思路：
（1）求向量组A：α1，α2，α3的秩。
将给出的向量组按列拼接成矩阵，为（α1，α2，α3），对向量组A对应的矩阵做初等行变换，将其化为行阶梯形矩阵。
根据定理2，这个 向量组A：α1，α2，α3 的秩其实就是其所对应的行阶梯形矩阵的秩。

（2）写出向量组A：α1，α2，α3的一个极大线性无关组。
知道了这个向量组A的秩之后，就知道了向量组A的极大线性无关组中的向量的个数。
根据定理3，向量组A所对应的矩阵 与 向量组A所对应的行阶梯形矩阵  的列向量组 具有完全相同的线性相关性，就可以通过向量组A所对应的行阶梯矩阵来挑选出一个向量组A的极大线性无关组。首先是从向量组A所对应的行阶梯矩阵中挑选出“向量组A所对应的行阶梯矩阵所对应列向量组”的极大线性无关组，然后按照位置对应的关系就可以从“向量组A所对应的矩阵”中来挑选出向量组A的极大线性无关组了。


从“行阶梯形矩阵”中选出“这个行阶梯形矩阵所对应的向量组”的极大线性无关组的关键：每层台阶选出一个非零元所对应的列向量可作为极大线性无关组。

从一个“行阶梯形矩阵”中挑选出“这个行阶梯形矩阵所对应的列向量组”中的3个线性无关的列向量组的方法（类似的可以推广到挑选n个）：
当这个行阶梯形矩阵的秩为3的时候，我们知道这个行阶梯形矩阵对应的列向量组的秩是为3的，即是这个列向量组的极大线性无关组是为3的，即是要想得到该列向量组的一个极大线性无关组最终是要挑选出3个列向量的。我们可以在行阶梯线的上边或者右边来进行挑选3个行相邻的非0元素，这3个元素非0所在列分别对应了3个列向量，所挑选的这3个列向量就是“这个行阶梯形矩阵所对应的列向量组”的极大线性无关组的。（如果挑选出来的第1个非0元素位于第i行，挑选出来的第2个非0元素位于第i+1行，挑选出来的第3个非0元素位于第i+3行，则这3个非0元素所在列构成的列向量组就是线性无关的，即这3个非0元素必须是行相邻的）

解释：
这3个非0元所构成的3*3的行列式是为一个主对角线上元素都不为0的上三角矩阵（主对角线下方的元素都为0），则矩阵的值就是主对角线上元素的乘积，一定是不为0的，这也就说明了这个3*3的行列式所对应的3个列向量所构成的列向量是组线性无关的，这3个列向量所构成的列向量组的延伸组就是原来从矩阵中挑选出来的列向量组，说明了原来的从行阶梯形矩阵中挑选出来的列向量组也是线性无关的，这个列向量组（包含了3个列向量）就是为原来向量组的一个极大线性无关组。 

（3）将向量组A中不属于极大线性无关组的向量用极大线性无关组线性表示出来。
将向量组A所对应的行阶梯矩阵中极大线性无关组所对应的矩阵的列一起化为行最简形，这样就方便的看出矩阵的其他列（即是向量组中不属于极大线性无关组的向量）如何由行最简形的这些列（即是向量组的极大线性无关组）给表示出来了。

注意：如果题目中所给出的向量组是为一个行向量组A：α1，α2，α3，则就将其向量的转置拼接成一个矩阵（α1T，α2T，α3T），求出的这个矩阵的秩就是这个向量组 α1T，α2T，α3T 的秩（向量组α1T，α2T，α3T 的秩 也即是 向量组 α1，α2，α3 的秩），从（α1T，α2T，α3T）矩阵中对应的行阶梯形矩阵中可以挑选出来向量组A的极大线性无关组（从行阶梯形矩阵中挑选出来的向量对应了 αiT，而 αiT 对应了 αi，如 α1T，α2T 为矩阵（α1T，α2T，α3T）的列向量组所对应的极大线性无关组的话，即是 α1T，α2T 为向量组 α1T，α2T，α3T的极大线性无关组，即是 α1，α2 为向量组 α1，α2，α3的极大线性无关组）。
