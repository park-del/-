一、相似对角化的定义
   若存在可逆矩阵P，使 P^-1 A P = Λ 为对角矩阵，则称矩阵A可相似对角化，Λ称为A的相似对角矩阵。（充要条件，反过来说 n阶矩阵A可相似对角化，则可以推导出 P^-1 A P =Λ）

理解：Λ为对角矩阵，当A可以和一个对角矩阵Λ相似的时候，我们就称这个矩阵A可相似对角化。
注意：矩阵A可以相似对角化的前提是矩阵A为方阵。


研究：什么样的A可以对角化？；在A可以对角化的时候，P、Λ怎么求？


二、相似对角化的条件

定理：n阶矩阵A可相似对角化《====》A有n个线性无关的特征向量.

证明：n阶矩阵A可相似对角化《====》则有“P^-1 A P = Λ”。(下面以P和Λ都是为3阶为例来进行说明)
													         { λ 0 0 }
P^-1 A P = Λ 《==（同时左乘P）==》A P = P Λ《==（将P按列分块，得到 P=(P1，P1，P3) ）==》A（P1，P2，P3）=（P1，P2，P3）{ 0 λ 0 }《====》（AP1，AP2，AP3）
													         { 0 0 λ }
=（λ1P1，λ2P2，λ3P3）《==（利用矩阵相等）==》AP1=λ1P1，AP2=λ2P2，AP3=λ3P3。
根据相似矩阵的定义，从“AP1=λ1P1，AP2=λ2P2，AP3=λ3P3”中可以看出来，λ1是为矩阵A的特征值，P1是为矩阵A的特征值λ1所对应的特征向量，λ1 P2 和 λ3 P3 也是一样的。
注意：由于矩阵P是可逆的，故满足 | P | != 0，即矩阵P中的任何一列 P1，P2，P3 也是不为0的，故是符合特征向量 Aα=λα 中α不为0的定义的，且由 | P | != 0 也是可以推导出矩阵P1，P2，P3所构成的向量组是线性无关的。

因此，n阶矩阵A可相似对角化《====》AP1=λ1P1，AP2=λ2P2，AP3=λ3P3《====》A有n个线性无关的特征向量。
线性无关说明：P可逆《====》| P1 P2 P3 | != 0《====》向量组：P1，P2，P3 线性无关。 

应用：判定一个n阶方阵是否可以相似对角化。（n阶矩阵有n个线性无关的特征向量的话，则这个n阶矩阵就可以相似对角化）

扩展：
（1）n阶矩阵A可以相似对角化的3个充要条件。
n阶矩阵A可以相似对角化
《====》A有n个线性无关的特征向量。
《====》A的k重特征值λ对应有k个线性无关的特征向量。
 理解：k重特征值为λ，则说明了矩阵A完全一样的特征值λ有k个，又由于n阶矩阵A是有n个特征值的，且k重特征值中对应的线性无关的特征向量的个数是 <= k的。故只有当这个k重特征值对应有k个线性无关的特征向量的时候，n阶矩阵A所对应的线性无关的向量个数才是为n的。

《====》n-r(  λE-A ) =  λ的重数。
理解：因为一个k重特征值λ所对应的特征向量就是为 齐次线性方程组 ( λE-A ) x = 0的解的（这个齐次线性方程组的通解就是这个 k重特征值λ 所对应的 全部的特征向量的），而齐次线性方程组  ( λE-A ) x = 0 的线性无关的解，即是 基础解系中的解向量 就是为这个k重特征值λ所对应的线性无关的特征向量，而齐次线性方程组 ( λE-A ) x = 0 中线性无关的解向量的个数（基础解系中解向量的个数）就是为“n-r( λE-A )”的。即这个k重特征值λ所对应的线性无关的特征向量的个数为n-r(  λE-A )。联系上面的理解，只有当矩阵A的所有的特征值 λi 所对应的重数ki，都满足  n-r( λiE-A ) = ki 的时候，这个n阶矩阵A才可以相似对角化。

注意：由于1重特征值 λ 所对应的特征向量一定是只有1个的，而1个特征向量本身就是线性无关的，因此对于1重特征值 λ 来说，是一定会满足 n-r( λiE-A ) = ki。故我们在判断n阶矩阵A是否可以相似对角化的时候，只需要考虑大于等于2的重根，看其是否满足 n-r( λiE-A ) = ki 就行了。

（2）n阶矩阵A可以相似对角化的1个充分条件。
n阶矩阵A有n个不同的特征值λ  ====》 n阶矩阵A可以相似对角化。

理解：由于1重特征值 λ 所对应的特征向量一定是只有1个的，而1个特征向量本身就是线性无关的，因此对于1重特征值 λ 来说，是一定会满足 n-r( λiE-A ) = ki。即是 A的所有k重特征 λi，都是满足 n-r( λiE-A ) = ki，故n阶矩阵A可以相似对角化。



题型：
1、判断n阶矩阵A（给出的常常为具体的矩阵）是否可以相似对角化 ？
解题思路：
求出A的n个特征值 λ1、λ2、…… 、λn（由于A为具体的矩阵，故求出 | λE-A | = 0 的所有λ的值）。如果这n个特征值 λi（i=1~n）都是为单根的话，则就说明n阶矩阵A可以相似对角化；如果这n个特征值 λi（i=1~n）中有重根，找出特征值中所有的重根 λm、λn、…… ，分别得到每一个重根对应的 ( λmE-A )、( λnE-A )、…… ，分别求出每一个重根对应的 n-r( λmE-A )、n-r( λnE-A )、…… ，判断出 每一个重根“λm、λn、……”的重数 与 其对应的“ n-r( λmE-A )、n-r( λnE-A )、…… ”是否相等，若相等，则n阶矩阵A可以相似对角化，若只要有一个不等，则n阶矩阵A就不可以相似对角化。

2、已知一个n阶矩阵A（给出的常常为具体的矩阵）可以相似对角化，让我们求出矩阵A中所含有的参数？
解题思路：假设矩阵A的k重特征值为λi，我们常常根据“n-r( λiE-A ) = k”这个等式来求出矩阵A中所含有的参数。先根据 | λE-A | =0 求出所有的特征值λi（此时可能会根据行列式的计算方法将参数给消掉，得到的λi是为具体的数的），找出特征值 λi 中的k重特征值 (  k>=2 ) λt ，得到“n-r( λt E-A ) = k”，接下来就可以根据这个等式关系来求出矩阵A中的参数了。

3、如何找出一个 可相似对角化的n阶矩阵A（给出的常常为具体的矩阵） 对应的可逆矩阵P，以及对应的对角矩阵Λ？
提示：如果矩阵A可以相似对角化，就说明了存在可逆矩阵P，存在对角矩阵Λ，使得 P^-1 A P = Λ，这里我们要找的就是矩阵A的 P 和 Λ。

提示：根据 3阶矩阵A可相似对角化《====》AP1=λ1P1、AP2=λ2P2、AP3=λ3P3，且P1，P2，P3 是线性无关的（前面证明过程中间一步）。观察发现，P按列分块之后的每一个向量 P1，P2，P3 是为3阶矩阵A的线性无关的特征向量的，而 λ1、λ2、λ3 又是为3阶矩阵A的特征值的。因此，相似对角矩阵A所满足的“P^-1 A P = Λ”这个式子中的“P”其实就是为A的线性无关特征向量Pi所拼接构成的，这个式子中的“ Λ”其实就是为A的特征值在对角线位置上依次排列所构成的矩阵。 

解题思路：根据 “| λE-A | = 0 ”找出矩阵A的n个特征值 λ1、λ2、…… 、λn 。既然n阶矩阵A是可相似对角化的，这也就说明了这n个特征值一定是满足题型1里面条件的，即“这n个特征值要么都是为单根；这n个特征值如果有重根 λi 的话，则“特征值 λi 的重数一定是 ＝ n-r( λiE-A )”的。我们就是要找出矩阵A的特征值所对应的n个线性无关的特征向量来拼接成矩阵P的，特征值λi为单根的话，则只需要找到λi对应的齐次线性方程组 | λiE-A | =0 的一个解向量就可以了；特征值λi为k重根的话，我们就需要找到k重根λi对应的齐次线性方程组 | λiE-A | =0的k个线性无关的解向量就可以了。
由于矩阵A的不同特征值对应的特征向量是线性无关的，我们只需要使得找到的k重特征值λi对应的k个特征向量也是线性无关的就可以了（因为矩阵A可以相似对角化，则根据上面扩展的知识可以知道“A的k重特征值 λi 对应有k个线性无关的特征向量”，即是“A的k重特征值 λi 所对应的齐次线性方程组 | λiE-A | = 0 的基础解系中解向量的个数为k”，我们此时要找的就是“A的k重特征值 λi 所对应的齐次线性方程组 | λiE-A | = 0 的基础解系”），要找的就是k重特征值λi对应的齐次线性方程组| λiE-A | = 0 的基础解系（基础解系中就含有了k个线性无关的解向量，就是k个特征无关的特征向量） ，则最后将所找到的这n个特征向量拼接在一起也一定线性无关的，即这n个线性无关的特征向量拼接在一起构成的矩阵就是为“P^-1 A P = Λ”中的P。最后，将n阶矩阵A的n个特征值按照P中列向量的排列次序进行排列，所得到的对角矩阵就是为Λ。

简化：
用矩阵A的n个线性无关的特征向量拼接成可逆矩阵P，n个特征向量拼接成对角阵Λ；
找到是特征值对应的齐次线性方程组的基础解系，最后将所找到的特征值对应的所有基础解系放在一起，基础解系中所有解向量拼接构成的矩阵就是可逆举着P。

注意：Λ中主对角元的排列次序应与P中列向量的排列次序相对应。

4、告诉了你一个n阶矩阵A的n个特征值 λ1、λ2、……、λn ，这n个特征值分别对应的n个特征向量 α1、α2、……、αn ， 
解题思路：由这n个特征值  λ1、λ2、……、λn 可以得到对角阵Λ，由这n个特征值对应的n个特征向量  α1、α2、……、αn 可以得到可逆矩阵P。由“P^-1 A P = Λ”可以得到“A = P Λ P^-1”。
我们可以根据n阶矩阵A的n个特征值 λ1、λ2、……、λn，这n个特征值对应的n个特征向量反求n阶矩阵A。
进一步，在求出了A的基础上，我们可以求 “A^n = P Λ P^-1 P Λ P^-1 …… P Λ P^-1 = P Λ^n P^-1”。
