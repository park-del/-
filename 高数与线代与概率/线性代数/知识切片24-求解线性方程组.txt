
r(A)表示的是非齐次线性方程组中“等号左边有效方程的个数”；
r(A，b)表示的是非齐次线性方程组中“等号右边常数的个数”；
n是为系数矩阵A的列数，表示的是非齐次线性方程组中“等号左边未知数的个数”；


理解：前面一节中所讲的只是判断对齐次线性方程组或者非齐次线性方程组的解的情况的，即是齐次线性方程组是“只有零解（有唯一解）”“有非零解（有无穷多解）”中的那一个的，即是非齐次线性方程组“无解”“有唯一解”“有无穷多解”中的哪一个的。这一节所讲的就是具体求出线性方程组的解的，即是当齐次线性方程组“有无穷多解”时，求出所有的解，当非齐次线性方程组“有唯一解”，求出这个唯一解，当非齐次线性方程组“有无穷多解时”，求出这个“无穷多解”。

 


题型：

1、求齐次线性方程组所有的解（即是这个齐次线性方程组的通解）。
解题思路： 
（1）如果r(A)=n，这个齐次线性方程组有唯一的解0。
（2）如果r(A)<n，这个齐次线性方程组有无穷多解，就会存在通解。
首先将系数矩阵A化为行阶梯形，接着将其化为行最简形。选取这个行最简形矩阵中每一行中的第1个非0元选取作为非自由变量，则这个行最简形矩阵中有几个非0行就会有几个非自由变量，没有选择作为非自由变量的为自由变量，自由变量决定了非自由变量，自由变量的个数为 n-行最简形矩阵中非0行的个数（即 总变量个数-非自由变量个数）。如果自由变量只有一个，就对这个自由变量赋值任意的常数k（其中k为任意的常数），如果自由变量为两个，则就分别对这两个自由变量赋值任意的常数k1、k2，依次类推。通过自由变量来表达所有的非自由变量，最后将所有的变量写成向量的形式（x1，x2，x3，k1，k2），注意，写成向量形式中的x1、x2、x3是为非自由变量的，是用k1和k2代替了的，所写出的这个向量就是这个齐次线性方程组的通解。
 

2、求非齐次线性方程组所有的解。
解题思路：
（1）如果r(A)<r(A，b)，则这个非齐次线性方程组没有解。
（2）如果r(A)=r(A，b)，则这个非齐次线性方程组有解。
①如果 r(A)=r(A，b)=n，此时这个非齐次线性方程组有唯一解。

将增广矩阵（A，b）化为行最简形，此时通过这个行最简形矩阵就可以直接的看出方程组的唯一解了。
					             { 1   0  0 1   }
非齐次线性方程组有唯一解，此时化为行最简形的增广矩阵如 { 0  1  0  2  }  ，由于是只有唯一解，故没有自由变量，行最简形矩阵中每行第1个非0元依次代表了 非自由变量x1，x2，x3，可以看出来
                                                                                             {  0  0  1  3  }
x1=1，x2=2，x3=3，将其写成向量的形式，为（1，2,3)T，故这个非齐次线性方程组的解为（1，2,3)T。

②如果 r(A)=r(A，b)<n，此时这个非齐次线性方程组有无穷解。
将增广矩阵（A，b）化为行最简形。行最简形矩阵中每行第1个非0元依次代表了 非自由变量x1，x2，x3，则不是非自由变量的变量就是为自由变量。通过对自由变量赋值任意的常数k1，k2，就可以写出这个非齐次线性方程组的通解为（x1，x2，x3，k1，k2），其中 x1，x2，x3是为 k1和k2的表达式的。
