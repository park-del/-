理解：
（1）向量是用来表示一系列有次序的数的，这些有次序的数排列成一行，或者排成一列。其中，排成一行时将这一系列有次序的数（即向量）称为是行向量，排成一列时将这一系列有次序的数（即向量）称为是列向量。其中，所进行排列的数的个数（即 行向量中一行中元素个数 或者 列向量中一列中的元素个数）称为是向量（行向量或者是列向量）的维度。
（2）向量是有两种的，分别是行向量或者是列向量，其中行向量是为 1行n列的，列向量是为 n行1列的。
（3）向量的 行数或者列数 中有一个一定是要为1的，行数为1的向量称为是行向量，列数为1的向量称为是列向量，是不存在 m行n列 （其中m和n均不为1）的向量的（由向量表示的是有次序的数，即数的排列有关）。
（4）向量可以看成是一种特殊的矩阵的， 行向量就相当于是只含有1行的特殊矩阵，列向量相当于是只含有1列的特殊矩阵，向量一般是用希腊字母如α、β、γ来进行表示的。


 2、向量组
规定：若干个同维数的行向量 或者 若干个同维数的列向量 所组成的集合叫做向量组。向量组中的向量个数可以是有限个，也可以是无限个。

理解：
（1）向量组，向量组，顾名思义就是向量的集合，包含有n个向量（可以理解为向量组的每一个元素都是为一个向量的）。
（2）这n个向量可以组合成一个向量组要求了  这n个向量全部都是为行向量，且每一个行向量的维度要一样，或者，这n个向量要么全部都是列向量，且每一个列向量的维度都要一样。
（3）n个相同维度行向量可以组合成1个列向量组，n个相同维度列向量可以组合成1个行向量组。
（4）行向量组为1行n列，可以看成是为m*n的矩阵的；列向量组为1列n行，可以看成是为m*n的矩阵的。

如：3个5维的行向量可以组成一个列向量组，这个列向量组（列向量组是3维的）是为3行1列的，这个列向量组中的每一个元素都是为一个5维的行向量的；3个5维的列向量可以组成一个行向量组，这个行向量组（行向量组是为3维的）是为1行3列的，这个行向量组中的每一个元素都是为一个5维的列向量的。

向量组与矩阵的关系：
将一个矩阵Amn“按行来进行分块”之后，这个矩阵就转化为了列向量组（列向量组有n个元素，由于向量组中的每一个元素都是为一个向量的，这里的列向量组就是由n个m维的行向量组成的）；
将一个矩阵Amn“按列来进行分块”之后，这个矩阵就转化为了行向量组（行向量组有m个元素，由于向量组中的每一个元素都是为一个向量的，这里的行向量组就是由m个n维的列向量组成的）。

总结注意事项：
（1）题目中所给出的 向量如果没有指明是行向量还是列向量时，均当作列向量来进行处理。题目中给出的向量一般为 α=( a1，a2，……，an )T 的形式，此时转置T之后就会变为列向量了，即题目中给出的是为列向量的。
（2）题目中所给出的 向量组如果没有指明是行向量组还是列向量组时，均当做列向量组来进行处理。
（3）行向量可以看成是1行n列的矩阵，列向量可以看成是1列m行的矩阵；行向量组可以看成是n个1列m行的矩阵，就是m*n矩阵，列向量组可以看成是m个1行m列的矩阵，就是m*n矩阵。


二、向量的线性运算
设向量 α=（ a1，a2，……，an ) T，β=（b1，b2，……，bn )T，则
（1）向量的加法：α+β=（a1+b1，a2+b2，……，an+bn）;
（2）向量的数乘：λα=（λa1，λa2，……，λan )T。

注意：
（1）0向量，则该向量中的每一个元素都是为0的。
（2）两个向量相等则这两个向量中的每一个元素都是对应相等的。

例题：
给出了向量α=( 1,2,3 )，β=（4,5,6 ），γ=（7,8,9 ），如果 x1α+x2β+x3γ=0，求x1、x2、x3？

解：
x1α+x2β+x3γ=x1（1,2,3）+x2（4,5,6）+x3（7,8,9）=（x1+4x2+7x3，2x1+5x2+8x3，3x1+6x2+9x3）=0
得出
{   x1 +4x2+7x3=0
{  2x1+5x2+8x3=0
{  3x1+6x2+9x3=0

将这个方程系数矩阵写出来的话，为
{ 1 4 7 }
{ 2 5 8 }
{ 3 6 9 }
发现刚好为（αT，βT，γT）拼接在一起构成的，即是它们的列向量拼接在一起构成的，因此题目中一般给出的是列向量。


理解：由于向量本身就是为一种特殊的矩阵（行数或者列数为1），故向量的线性运算本质上就是矩阵的线性运算。向量的加法本质上就是矩阵的加法，向量的数乘本质上就是矩阵的数乘。
