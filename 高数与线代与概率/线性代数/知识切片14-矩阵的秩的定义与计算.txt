一、子式
规定：在m*n矩阵A中，任取k行和k列（k<=m，k<=n），位于这些行列交叉处的k^2个元素构成的k阶行列式，称为矩阵A的k阶子式。

注意：一个矩阵A的k阶子式是为一个k阶的行列式的。

如：
              {  1  1  1  }
矩阵A=  {  2  2  2  } ，在这个矩阵中取一行一列构成的行列式就称为是矩阵A的1阶子式，矩阵A的1阶子式有3个，分别为1、2、0；在这个矩阵中取2行2列构成的行列式就称为是矩阵A的2阶子式，矩
              {  0  0  0  }		{  1  1  }	{  2  2  }										{  1  1  1  }
阵A的2阶行列式有3个，分别为              、             ；在这个矩阵中取3行3列构成的行列式就称为是矩阵A的3阶子式，矩阵A的3阶行列式有1个，为 {  2  2  2  }。
			{  2  2  }	{  0  0  }										{  0  0  0  }

二、矩阵的秩
规定：如果一个矩阵A的最高阶非0子式的阶数为k的话，此时这个k就是这个矩阵A的秩。

规定：0矩阵的秩为0（因为0矩阵中连一个1阶的行列式都为0）。

例. 
假设矩阵A是为一个3*4的矩阵，r(A)=3。

理解：矩阵A的秩为3，只是说明了矩阵A存在3阶的非0行列式（子式） ，比3阶高的行列式，如4阶行列式、5阶行列式等都是为0的。

① 任意的3阶子式全非0； （×）
理解： 矩阵A的秩为3说明了矩阵A存在的最高阶非0行列式是为3阶的。这里只是说明了矩阵A存在3阶行列式非0的，并不是矩阵A的所有3阶行列式都是非0的，矩阵A存在的若干个3阶行列式中只要有一个不是0就可以了。因此① 的说法是错误的。

② 存在不为0的二阶子式；（√）

理解：假设矩阵A的二阶行列式都是为0的话，此时根据三阶行列式与二阶行列式的关系可知（根据代数余子式求行列式的知识，三阶行列式的值就是为若干个二阶行列式的值相加的，如果矩阵A的二阶行列式都是为0的话，则对应的3阶行列式也是都为0的，与已知条件矩阵A的秩不符合），由于矩阵A的秩为3，即是矩阵A的3阶行列式存在非0的，则矩阵A的2阶行列式也是一定存在非0的，即存在不为0的二阶行列式。

③ 任意的四阶子式全为0。（×）

理解：题目中给出的是为一个3*4的矩阵的，是根本没有办法从这个矩阵中找出一个4阶行列式的，因此③的说法是不对的，但是如果能够找到一个4阶行列式的话，则③的说法就是正确的。



三、矩阵秩的计算
定理：若矩阵A与B等价，则 r(A)=r(B)，即初等变换不改变矩阵的秩。
求一个矩阵的秩的方法：将矩阵通过初等变换化为行阶梯形矩阵，矩阵的秩就等于它的行阶梯形矩阵的非0行的行数。


题型：
1、给你一个矩阵A，让你计算出这个矩阵的秩。
解题思路：
（1）定义法：在这个矩阵A中找出一个1阶行列式，如果这个1阶行列式不为0的话，接下来就在这个矩阵中找出一个2阶行列式，如果这个2阶行列式不为0的话，接下来就在这个矩阵中找出一个3阶行列式，依次类推，在这个矩阵中找出一个m阶行列式，如果这个m阶行列式为0的话，接下来就继续在这个矩阵中寻找其他的m阶行列式，如果其他的m阶行列式都为0的话，则说明这个矩阵的最高阶非0行列式是为m-1阶的，即这个矩阵的秩就是为m-1。 

 （2）行阶梯形矩阵法：将这个矩阵A通过初等行变换变为行阶梯形矩阵，此时矩阵A的秩就是为这个行阶梯形矩阵的秩的，行阶梯形矩阵的秩又是位该行阶梯形矩阵中非0行的行数的，故这个矩阵A所对应的行阶梯形矩阵中非0行的个数就是为这个矩阵A的秩的。 


2、已知矩阵A的秩是为多少，让你反过来求这个矩阵中的参数k。
解题思路：
（1）定义法：如果已知矩阵A的秩为3，此时可以知道，矩阵A的四阶行列式是为0的，可以根据这个四阶行列式为0的信息来得到一个包含未知参数k的方程，通过这个方程就可以解除这个位置参数k的值了。注意，矩阵A的秩为3 ====》| 四阶行列式 | = 0 ====》k=a或k=b，注意“k=a或者k=b”只是为“矩阵A的秩为3的一个必要条件”，根据离散数学中“蕴含”的知识可以知道，当“k=a或k=b”不成立，即“ k != a 且 k != b ”时，“矩阵A的秩为3”也是不成立的；当“k=a 或 k=b”成立时，“矩阵A的秩为3”是可能成立，也可能不成立的，故此时就需要代入验证，即是当k=a时，看矩阵A的秩是否为3，如果是的话就保留，不是的话就舍去，当k=b时，看矩阵A的秩是否为3，如果是的话就保留，不是的话就舍去。（注意，如果得到了两个参数k的取值a和b的话，这里只要验证出k为a时矩阵A的秩不为3的话，则此时k=b时矩阵A的秩就一定是3的，此时就不需要再对k=b进行验证了）

注意：如果矩阵中是带有两个参数a和b的话，针对于本题矩阵A的秩为3来进行说明，则根据两个四阶行列式为0就可以列出两个方程，就可以解出a和b了，解出a=t1，b=t2。接下来就需要代入a和b来验证看矩阵A的秩是否为3的，如果矩阵A的秩为3的话则保留，如果不为3的话就需要对其进行舍去。由于这里是为两个参数的，故这里是分为了4种情况来进行考虑的，分别为a=t1，a=t2；a=t1，b！=t2；a=t1，b != t2；a !=t1，b !=t2。分别将a的值和b的值代入到原矩阵A中，如果矩阵A的秩为3的话就保留，不过矩阵A的秩不是为3的话就将其舍去。

（2）行阶梯形矩阵法：将矩阵A化为行阶梯矩阵，令所画出来的行阶梯线右边和上边的元素都为0，找出所有可能的参数k的取值范围，如果找出的所有可能的参数k的取值范围为k=a或k=b，则此时分为了3种情况来进行考虑，当k=a时代入到原矩阵A中，看矩阵A的秩是否为3，如果是的话就保留，如果不是的话就将其舍去；当k=b时代入到原矩阵中，看矩阵A的秩是否为3，如果是的话就保留，如果不是的话就将其舍去；当k!=a且k!=b的时候，看矩阵A的秩是否为3，如果是的话就保留，如果不是的话就将其舍去（一般题目中如果让你求出参数k的话，这种情况一般是排除在外的，即是这种情况下矩阵A的秩不是为3的）。

注意：如果矩阵A中带有两个参数的话也是一样的，将矩阵A化为行阶梯矩阵之后，根据行阶梯线上边和右边的元素为0找出所有可能的参数k的取值范围。如果找出来的是这两个参数x和y的取值范围为：x=a或b，y=c，则此时要分为 x=a，y=c；x=b，y=c；x != a，y=c；x !=b，y=c；x != a，y !=c；x !=b，y !=c 这6种情况来进行讨论。
