线性无关性：
定义：设向量组A：α1，α2，……，αm，如果存在不全为0的数k1，k2，……，km，使得 k1α1+k2α2+……+kmαm=0，则称向量组A是线性相关的，否则称它是线性无关。

注意：对于只含一个向量α的向量组，当α=0时是线性相关的，当α != 0 时是线性无关的。


理解：
①对与一个向量组（是若干个向量的集合的），不管你含有多少个向量，这个向量组只有两种情况的，要么是线性相关，要么是线性无关，没有第3种可能性，这两种状态是一种对立的状态，相关的话就不可能是无关的，无关的话就不可能是相关的。
②对于一个向量组A：α1，α2，……，αm，先写出 k1α1+k2α2+……+kmαm=0，接下来判断满足这个式子时“k1，k2，……，km”中是否有不为0的，如果有的话，则就说这个向量组是线性相关的，如果“k1，k2，……，km”全部都是0的话，则就说这个向量组是线性无关的。


借助5个例子来帮助理解向量组的线性相关与线性无关：

（1）例1：
        { 1 }            { 2 }           { 5 }
α1=         ，α2=       ，α3=        ，这个向量组A：α1，α2，α3 是线性相关的。
        { 2 }            { 4 }           { 6 }

发现：观察发现，想向量组A中的向量α1和α2是成比例的，此时这两个向量α1和α可以凑成 -2α1+α2 来使其为0，其他的向量前的系数都为0，可以看出来向量组A是线性相关的。

启示：如果一个向量组之间有某两个向量成比例的话，则这个向量组是线性相关的。因为可以根据这两个成比例的向量得到不为0的常数k，其他向量前的系数都取0就可以了。

（2）例2：
        { 0 }            { 2 }           { 5 }
α1=         ，α2=       ，α3=        ，这个向量组A：α1，α2，α3 是线性相关的。
        { 0 }            { 4 }           { 6 }

发现：观察发现，这个向量组A中有一个向量为0向量。则可以将这个0向量前面取一个不为0的常数k，向量组中的其他向量前的系数都取0，此时说明了这个向量组A是线性相关的。

启示：如果一个向量组之间有一个向量为0向量的话，则这个向量组是线性相关的。因为可以将这个向量组中的0向量前面的系数取任何一个非0的数，向量组中的其他向量前的系数取0就可以了。


（3）例3：
给出你一个抽象的向量组A：α1-α2，α2-α3，α1-α3，你这个抽象的向量组A是线性相关的。

发现：这个抽象的向量组中 第1个向量加上第2个向量 刚好为第3个向量，即第1个向量加上第2个向量与第3个向量成比例，此时这个向量组是线性相关的。

启示：对于抽象的向量组，如果这个抽象的向量组中有某多个向量加起来后与向量组中另外某多个向量加起来成比例的话，则此时这个向量组是线性相关的。

启示：给出你一个向量组A：α1，α2，……，αm，当无法直接判断出（向量组A中有2个向量成比例，或者，向量组A中有1个向量为0向量）向量组A是线性相关的还是线性无关的时候，可以将判断向量组A是否线性相关的问题转化为判断方程组是否有非0解的问题。

即是：
假设存在k1，k2，，km，使得 k1α1+k2α2+……+kmαm=0，此时这个向量方程对应有一个方程组，解出这个方程组的解“k1，k2，……，km”，这个方程组的解中如果有一个为非0的话，则就说明这个方程组对应的向量A是线性相关的，如果这个方程组的解都是为0的话，则就说明这个方程组对应的向量A是线性无关的。

注意：利用方程组法来判断一个向量组是线性相关，还是线性无关的时候，这个向量组必须要是为一个具体的向量的，不能够为一个抽象的向量。

（5）例5：
若  0 α1+0 α2+……+0 αm = 0，则 α1，……，αm线性无关。 （×）

理解：一个向量组无论是线性相关还是线性无关，都是满足0 α1+0 α2+……+0 αm = 0这个式子的。如果一个向量组A：α1，α2，……，αm，当使得“α1，α2，……，αm”这些向量的线性组合的式子为0时，各个向量前面的系数必须都取0才能够使得线性组合式子为0时，我们才说这个向量组A是线性无关的。


向量组A：α1，α2，……，αm，向量组A线性无关的3种表述（可能出现在题目中）：
（1）不存在不全为0的数k1，k2，……，km，使 k1α1+k2α2+……+kmαm = 0；
（2）对任意不全为0的数k1，k3，……，km，都有 k1α1+k2α2+……+kmαm != 0；
（3）若 k1α1+k2α2+……+kmαm = 0，则必有 k1=k2=……=km=0。


题型：本知识切片题的题型与知识切片19的题型差不多。


1、判断一个具体的向量组B：β1，β2，……，βt的线性相关性（即是判断这个向量组B是线性相关的还是线性无关的）。

解题思路：
（1）首先判断这个向量组B中是否有2个向量成比例，或者，是否有一个向量为零向量。如果这个向量组B中有2个向量成比例或者有一个向量为0向量的话，此时向量组B就是线性相关的，否则向量组B就是线性无关的。
（2）当向量组B中既没有2个向量成比例，又没有一个向量为0向量时，此时可以用定义法来判断向量组B的线性相关性（所谓的定义法其实就是方程组法）。

定义法判断这个向量组B的线性相关性。
思路：
设存在常数k1，k2，……，kt（首先将“k1，k2，……，kt”给设出来），使得“k1β1+k2β2+……+ktβt=0”。这里的“k1β1+k2β2+……+ktβt=0”是为一个关于k1，k2，……，kt的线性方程组，这个线性方程组“k1β1+k2β2+……+ktβt=0”一定是为一个齐次线性方程组（因为方程组“=”的右边都是为0），接下来就可以根据这个齐次线性方程组解的情况来判断向量组B是线性相关的还是线性无关的。由于是为具体的向量组B的，故这个齐次线性方程组也是为具体的，即“未知数k1、k2、……、kt”前面的的系数都是已知的，接下来判断这个齐次线性方程组的解的情况是有3种方式的：

①直接求出k1、k2、……、kt的值，判断k1、k2、……、kt是否全部都为0，如果“k1=k2=……=kt=0”，则向量组B就是线性无关的；如果“k1、k2、……、kt”中有一个不为0的话，则向量组B就是线性相关的。

②利用系数矩阵来讨论这个齐次线性方程组解的结构，如果这个齐次线性方程组只有0解，则向量组B就是线性无关的；如果这个齐次线性方程组有非0解，则这个齐次线性方程组就是线性相关的。（具体如何利用齐次线性方程组的系数矩阵来讨论这个齐次线性方程组的解的结构后面的章节中会有讲述，这里先知道有这种方法就行）

③利用克拉默法则来判断齐次线性方程组解的结构。 

克拉默法则： 
如果一个方程是为齐次线性方程组，其系数行列式为D，则克拉默法则有以下结论：
如果有 D !=0     《====》   齐次线性方程组只有0解 《====》即这个齐次线性方程组所对应的向量组是线性无关的。
如果有 D  =0     《====》   齐次线性方程组有非0解 《====》即这个齐次线性方程组所对应的向量组是线性相关的。
 

注意：要判断的是哪一个具体的向量组的线性相关性，就设谁，如要判断具体的向量组B：β1，β2，……，βt的线性相关性，就设“k1β1+……+ktβt=0”。



2、证明一个抽象的向量组B：β1，β2，……，βt线性无关。
解题思路：
要证明的是向量组B的线性相关性，就设B，即是设“k1β1+k2β2+……+ktβt=0”，接下来就可以通过“重组” 或者“同乘”这两种方法中的其中一个来判断出“k1，k2，……，kt”是只有0解的，进而判断出向量组B是线性无关  的。

①.重组： 

此时题目中的已知条件中一般会有“向量组A：α1，α2，……，αm 是线性无关的”。向量组B中的每一个向量βi都是由向量组A中的向量来线性组合的，此时我们写出的“k1β1+k2β2+……+ktβt=0”式子就可以进行重组，转化为“ ( ) α1 + ( ) α2+ …… + ( ) αm”，其中“（）”是为“k1，k2，……，kt”的线性组合的，通过向量组“α1，α2，……，αm”线性无关，就可以得到m个“（）= 0”的式子，这是m个“关于未知数k1，k2，……，kt”的方程，即是为一个“关于未知数k1，k2，……，kt”的齐次线性方程组的，接下来就转换为了判断这个齐次线性方程组是只有0解的（解题思路见题型1中的①②③），如果这个齐次线性方程组只有0解，就证明出了抽象的向量组B是线性无关的。

②.同乘：下面是结合具体的例子来说明同乘的思路的。 

题目中的已知条件为“A^m-1 α != 0，A^m α = 0”，证明向量组“α，A α，A^2 α，……，A^m-1 α”线性无关。

结论：A^m α =0 ====》A的所有>=m的幂 * α 都是为0的。（A^(m+k) α = A^k * A^m α，因为 A^m α = 0，故A^(m+k) α=0）

解题：要证明谁就设谁，这里设“k1α + k2 A α + k3 A^2 α + …… + km A^(m-1) α = 0”。根据“ A^m α =0 ====》A的所有>=m的幂 * α 都是为0的”的原则，当方程左右两边同时左乘A^(m-1)的时候（注意是只能够左乘的，不能够右乘，因为右边有一个向量α）得到“k1 A^(m-1) α + k2 A^m α + k3 A^2 α + …… + km A^(2m-2) α = 0”，发现原来的式子中 比“k2 A α”中的A的幂高的，即是“k2 A α”右边的项（包括了“k2 A α”），左乘A^(m-1)后所包含的A的幂都>=m的，故这些项都是为0的，此时就变成了“k1 A^m-1 α = 0”，又由于 A^m-1 α !=0，故k1=0；将k1=0代入最开始设的式子“k1α + k2 A α + k3 A^2 α + …… + km A^m-1 α = 0”中得到“k2 A α + k3 A^2 α + …… + km A^m-1 α = 0”，此时方程两边同时左乘A^(m-2)，得到“k2 A^(m-1) α + k3 A^m α + …… + km A^(2m-3) α = 0”,比A的幂次>=m的都是为0的，故为“k2 A^(m-1) α = 0”，因为“A^m-1 α != 0”，故“k2=0”；同理可以得到“k3、k4、km都是为0的”，故可以证明出向量组“α，A α，A^2 α，……，A^m-1 α”线性无关。

 注意：以后在判断谁的线性相关性的时候，证明谁的线性相关性就设谁。如，要证明α1、α2、α3是线性相关的，就需要设“k1α1+k2α2+k3α3=0”；要证明α1、α2、α3是线性无关的，就需要设“k1α1+k2α2+k3α=0”。

3、判断一个抽象的向量组B：β1，β2，……，βt是线性相关还是线性无关的。（或者是判断一个抽象的向量组的线性相关性）
解题思路：
（1）如果能够在这个抽象的向量组B中找到n个向量（n任意）相加后得到的向量与m个向量（m任意）相加后得到的向量成比例的话，此时这个向量组B就是线性线性相关的。
（2）如果没有办法找到的话，就按照下面的思路来进行求解：
要证明的是向量组B的线性相关性，就设B，即是设“k1β1+k2β2+……+ktβt=0”，接下来就可以通过“重组”（既适用于证明线性相关组线性相关的题，又适用于证明向量组线性无关的题） 来判断出“k1，k2，……，kt”是只有0解的，还是有非0解的，进而判断出向量组B是线性相关还是线性无关的。

 此时题目中的已知条件中一般会有“向量组A：α1，α2，……，αm 是线性无关的”。向量组B中的每一个向量βi都是由向量组A中的向量来线性组合的，此时我们写出的“k1β1+k2β2+……+ktβt=0”式子就可以进行重组，转化为“ ( ) α1 + ( ) α2+ …… + ( ) αm”，其中“（）”是为“k1，k2，……，kt”的线性组合的，通过向量组“α1，α2，……，αm”线性无关，就可以得到m个“（）= 0”的式子，这是m个“关于未知数k1，k2，……，kt”的方程，即是为一个“关于未知数k1，k2，……，kt”的齐次线性方程组的，接下来就转换为了判断这个齐次线性方程组是只有0解，还是有非0解的（解题思路见题型1中的①②③），如果这个齐次线性方程组只有0解，就说明了抽象的向量组B是线性无关的，如果这个齐次线性方程组有非0解，就说明了这个抽象的向量组B是线性相关的。


注意：以后在判断谁的线性相关性的时候，证明谁的线性相关性就设谁。如，要证明α1、α2、α3是线性相关的，就需要设“k1α1+k2α2+k3α3=0”；要证明α1、α2、α3是线性无关的，就需要设“k1α1+k2α2+k3α=0”。

注意：重组既可以判断一个向量组是线性相关的，又可以判断一个向量是线性无关的；而同乘只可以证明一个向量组是线性无关的。
