2、矩阵的初等变换。
（1）交换矩阵的两行（列）。
（2）用一个常数k（k!=0）去乘以矩阵某一行（列）的所有元素。
（3）把某一行（列）的所有元素乘以k倍加到对应的行（列）上去。

理解：方程组的增广矩阵对应的是矩阵的初等行变换，由于对这个方程组的增广矩阵进行上面（1）（2）（3）中关于行的变换时，是不会改变方程组的解的，即是变换过后所得到的新矩阵与原来的矩阵是等价的，因此我们将这种变换称为是初等行变换。（将进行变换之后所对应的方程组的解不变的变换就成为是矩阵的初等行变换）

初等变换：初等行变换和初等列变换统称为初等变换。
矩阵A与矩阵B等价：如果矩阵A经过有限次初等变换变成矩阵B，则称矩阵A与矩阵B等价。
理解：有限次可以是次、2次、8次等；这里只是提到了初等变换，没有提到是行变换还是列变换，这里无论是行变换还是列变换都是可以的；说明了和A等价的B有很多很多，和A等价的B1与和A等价的B2也是等价的，等价具有传递性；矩阵A与矩阵B是等价的，但不是相等的。



3、行阶梯形矩阵与行最简形矩阵
（1）非0行在0行的上面；非0行的首非0元素所在列在上一行（若存在）的首非0元素所在列的右面，则称A为行行阶梯形矩阵。
理解：
① 非0行在0行的上面：意思就是如果这个矩阵有全0行（该行元素都是0）的话，则这个全0行一定是在矩阵的最下面的。
② 非0行的首非0元素所在列在上一行（若存在）的首非0元素所在列的右面：就是在这个矩阵中可以找到一个阶梯，使得阶梯下方的元素都是为0元素，与阶梯挨着的上方或者右方的元素不是非0元，注意每1层阶梯只包含一行。（换一种说法就是，第1行的首非0元，就是第2行的第1个非0元所在列，一定要在第1行的第1个非0元所在列的后面，隔多少列都是可以的；同理，第n行的第1个非0元所在的列一定在第n-1行的第1个非0元所在列的后面。将这样的矩阵就叫做行阶梯形矩阵）

如
{  1  2  3  4  }
{  0  1  2  3  } 这个矩阵就是为一个行阶梯形矩阵。
{  0  0  0  0  }

{  1  2  3  4  }
{  0  0  2  3  } 这个矩阵也是为一个行阶梯形矩阵。
{  0  0  0  0  }

{  1  2  3  4  }
{  0  0  2  3  } 这个矩阵就不是为一个行阶梯形矩阵。可以从两个方面来看，一个就是根据文字叙述，观察到矩阵第3行的第1个非0元所在列并不在矩阵第2行的第1个非0元的后面，因此这个矩阵不是一
{  0  0  7  0  }
个行阶梯形矩阵；另一个就是,找到一个阶梯，使得这个阶梯阶梯下面的所有元素（包括紧挨着的和不是紧挨着的）都是0，使得这个阶梯紧挨着的上面和右面的元素都不是0，找到了这个阶梯后，发现该阶梯的每一层台阶并不都是只包含一行的，有一层台阶包含了两行，包含了第2、3两行，故这个矩阵不是行阶梯形矩阵。


（2）如果一个矩阵为行阶梯形矩阵的话，并且还满足下面的两个条件，则就将这样的行阶梯形矩阵称为是行最简形矩阵。
① 行阶梯中每一个非0行的第1个非0的元素都是为1。
② 每一个非0行的第1个非0元素（这个元素就是为1的）所在列的其他元素都是为0的。（即是这个元素所在列上面的元素要都为0，所在列下面的元素也要都为0）

{  0  0  0  0  }				    {  1  0  3  4  }
列中的2变为0之后才是行最简形矩阵，行最简形矩阵为 {  0  1  2  3  } 。
					    {  0  0  0  0  }

如

{  0  1  3  }

{  0  1  0  }


（4）两个结论。
① 任何一个非0矩阵总是可以经过有限次初等行变换化为行阶梯形矩阵或者行最简形矩阵。
② 任何一个非0矩阵总可经过有限次初等变换化为标准形矩阵。（如果是要变换到一个标准形矩阵的话，则就一定要掺杂列的初等变换了）

总结：由“行阶梯形--->行最简--->标准型”束缚程度是依次加强的，即要想得到一个矩阵的行最简形矩阵，首先要将这个矩阵化为行阶梯形，然后在将每一行第1个非0元化为1，将这个1所在列的其他元素都化为0，行最简一定是行阶梯；要想将一个矩阵化为标准型，首先要将这个矩阵化为行阶梯，然后化为行最简，然后在朝着左对角为单位矩阵，其他位置上元素都为0的方向转化，标准形一定是行最简形，一定是行阶梯形。

1、将一个m*n矩阵化为行阶梯形矩阵。
解题思路：首先通过初等变换将矩阵中第1行的第1个非0素变为1（为了方便通过第1行中的第1个非0元素来将这个元素下面的元素，即第1行中的第1个非0元所在列的第2个元素、第3个元素、……、第m个元素，消为0），可以通过交换矩阵的两行来将使得第1行中的第1个非0元素变为1，可以通过第1行乘以一个数来将第1行中的第1个非 0元素变为1，可以通过其他某一行乘以一个倍数加到第1行上来将第1行中的第1个非0元素变为1。第1行中的第1个非0元素变为1后，就可以通过第1行中的第1个非0元素来将这个非0元素所在列的第2个、第3个、第4个、……、第m个元素都变为0，这个非0元素所在列中的第2个、……、m个元素都变为0之后，接下来对第2行进行操作；找到第2行中的第1个非0元素，如果第2行中的第1个元素本身就很简单的话就不用在对第2行中的第1个非0元素进行化简了，如果第2行的第1个非0元素比较复杂的话，可以先对第2行中的第1个非0元素进行化简，即是可以通过第2行元素乘以一个数，交换第2行和第2行下面的某一行（注意，一定要是第2行下面的某一行，不能够是第2行上面的某一行的），将第2行下面的某一行乘以一个倍数加到第2行上（注意，也是要为第2行下面的某一行的，不能够是第2行上面的某一行的）这3中方式来将第2行的第1个非0元素变得简单一些，第2行的第1个非0元素变简单之后（第2行的第1个非0元素可以不变成1，只要简单方便对其下面的元素进行消就可以了），就可以通过第2行中的第1个非0元素来将其所在列（这个列是任意的，可以是第2列，也可以不是）中的第3个、第4个、……、第m个元素变为0了；依次类推；最后通过第m-1行的第1个非0元素来将其所在列的第m个元素化为0。这样就将这个矩阵化为行阶梯形矩阵了。

提示：将一个矩阵化为行阶梯形的思路就是，用第1行的第1个非0元来将这个非0元所在列下面的元素给消掉；用第2行中的第2个非0元来将这个非0元所在列下面的元素给消掉；直到最后出现一个阶梯（由于每一行的第1个非0元所在列下面的元素都为0，故一定是，倒数第2行用其第1个非0元来将这个非0元所在列的其他元素都给消掉之后，这个矩阵才会出现阶梯，才会化为行阶梯形的矩阵的）。

注意：将一个矩阵化为行阶梯形矩阵的时候是只牵涉到了初等行变换的，是没有牵涉到初等列变化的。（一个矩阵的行阶梯形矩阵是不唯一的）

2、将一个m*n的矩阵化为行最简形矩阵。
解题思路：首先先将这个m*n的矩阵化为行阶梯形矩阵，由行阶梯形矩阵化为行最简形矩阵是由最后1行逐次往上划的，即是由下往上的。首先通过初等变换将最后一行的第1个非0元化为1（为了方便通过第1行的最后一个非0元来将这个非0元所在列上面的元素消为0的），可以采用最后一行乘以一个数的方式来将最后一行的第1个非0元化为1（注意，这里是不能够通过交换两行或者将最后一行上面的某一个数乘以一个数加到最后一行，来将最后一行的第1个非0元化为1的）。将最后一行中的第1个非0元化为1之后就可以通过这个非0元来将这个非0元所在列的上面的元素化为0；然后通过倒数第2行中的第1个非0元来将导数第2行中的第1个非0元所在列的上面的元素化为0（注意，如果倒数第2行中的第1个非0元比较复杂的话，也是可以先将导数第2行乘以一个数，来将倒数第2行中的这个非0元变得简单一点的）；依次类推，直到将第2行中的第1个非0元所在列上面的那一个元素为止。最后，第1行乘以一个数使得第1行中的第1个非0元变为1，第2行乘以一个数使得第2行中的第1个非0元变为1，第3行乘以一个数使得第3行中的第1个非0元变为1，……，第m行乘以一个数使得第m行中的第1个非0元变为1。最后所得到的这个矩阵就是行最简形矩阵了。

提示：将一个矩阵化为行最简形矩阵的思路就是（首先这个矩阵要是一个行阶梯形矩阵），用最后一行的第1个非0元来将这个非0元所在列上面的元素给消掉；用倒数第2行中的第1个非0元来将这个非0元所在列上面的元素给消掉；依次类推，直到用第2行中的第1个非0元将这个非0元所在列上面的那个元素给消掉为止。最后通过每一行乘以一个数的方式来将将每一行的第1个元素变为1，得到的这个矩阵就是行最简矩阵了。

注意：将一个行阶梯形矩阵化为行最简形矩阵的时候也是只牵涉到了初等行变幻的，是没有牵涉到初等列变换的。（一个矩阵的行最简形矩阵是唯一的）

3、将一个m*n的矩阵化为标准型矩阵的方式。
解题思路：首先将这个m*n的矩阵化为行最简形矩阵，由于化为的是为一个标准型，既然是标准型的话则一定是只有第1列中的第1个位置，第2列中的第2个位置，第3列中的第3个位置，第4列的第4个位置上有元素的，这一列的其他位置上都是没有元素的，依次类推。因此，通过行最简形矩阵的第1列的第1个位置上的元素（如果这个元素比较复杂的话也是可以对第1行乘以一个数的）来将这个元素右边的每一个元素都给消掉（即是第一行中的除第一个元素之外的所有元素）；通过第2列的第2个位置上的元素来将这个元素右边的每一个元素都给消掉；通过第3列的第3个元素来将这个元素右边的每一个元素都给消掉；依次类推，直到划出了一个单位矩阵为止。如果接下类要找的第n列的第n个位置上没有元素的话，则可以通过将矩阵中的该行与该行一下的某一行进行交换来使的第n列的第n个位置上有元素；也可以通过将第n列与第n列右边的某一列进行交换使的这一列的第n个位置上有元素。

注意：将一个行最简形矩阵化为标准型矩阵是通过列变换得到的。（一个矩阵的标准型矩阵是唯一的）

4、带有参数λ的m*n矩阵化为行最简形矩阵。
解题思路：首先将第1行中的第1个非0元素化为1（通过那3种初等行变换的任意一种），然后通过第1行中的第1个非0元将这个非0元所在列下面其他元素变为0，通过第2行中的第1个非0元来将这个非0元所在列下面的其他元素变为0，依此类推，通过第m-1行中的第1个非0元来将这个非0元所在列下面的其他元素变为0，这样就将这个矩阵化为了一个行阶梯形矩阵。接下来找出这个行阶梯形矩阵的阶梯，根据这个阶梯紧挨着的右边和上边不为0来进行讨论，即是找出所有紧挨着这个阶梯右边和上边的带参数λ的式子，分别计算出这些式子等于0时参数λ的值，假设这些值有λ=a，λ=b。接下来就分类讨论，当λ=a时，由于这个参数λ已经是为一个具体的值a了，当把λ=a代入到这个矩阵中后这个矩阵就是一个不带参数的纯数值型的矩阵了，且是为一个行阶梯形矩阵的，接下来就转换为了纯数值形的行阶梯形矩阵求行最简形矩阵的问题中，就是题型2，按照题型2的解题思路就可以解出λ=a这种情况下所对应的行最简形矩阵了；当λ=b时，和λ=a的求解过程是一样的；当λ !=a 且 λ !=b时，此时需要求的就是一个带有参数λ的行阶梯形矩阵的行最简形矩阵，按照行最简形矩阵的求解思路（即是题型2）依次进行求解就可以了，即是首先找到最后一行的第1个非0元，通过矩阵的初等变换（常用的就是将这一行直接乘以一个数）将这一行的第1个非0元变得简单一些，同过最后一行的这个非0元来将这个非0元上面的所有元素都给消掉。然后找到矩阵中倒数第2行中的第1个非0元，进行矩阵的初等变换来使的这一行中的这一个非0元变得简单些，通过矩阵中的倒数第2行中的第1个非0元来将这个非0元上面的所有元素都给消掉，依次类推，直到将矩阵中的第2行的第1个非0元上面的所有元都给消掉为止 。
