矩阵的秩的性质：

补充：
若矩阵A是为一个n*n的矩阵，则 “矩阵A的秩r(A)=n  <====>  | A | !=0”，“矩阵A的秩r(A)<n  <====>  | A | =0”。

理解：当矩阵A是为一个n阶方阵，r(A)又是为n的话，此时矩阵A的n阶行列式是只有一个的，就是其本身所对应的行列式，根据矩阵的秩的定义，可以知道 | A | !=0；若矩阵A的秩r(A)<n，此时可以得出矩阵A的n阶行列式是为0的，即 | A | = 0。

（1）0<=r( A m*n )<=min{ m,n }
解释：如果一个矩阵A是为m*n阶矩阵的话，则此时这个矩阵A的秩r(A)一定是大于等于0的，小于等于m与n中的较小者的。

理解：
①当A为0矩阵的时候，有r(A)=0；
②当A != O 时，此时在矩阵A中一定是存在非0数的，即一定满足r(A)>=1；
③当矩阵A是为一个m*n的矩阵的时候，如果m小于n的话（长方形），则在矩阵A中是只能够找到m阶子式的，是没有办法找出n阶子式的，此时矩阵r(A)<=m，同时也肯定是r(A)<=n的，即一个矩阵A是为m*n的话，则r(A)<=m，r(A)<=n。

（2）r (A) = r (AT)=r(AT A)=r(A AT)=r(kA)    ( k!=0 )
解释：5个矩阵的秩是相等的，这5个矩阵分别是为“A、AT、AT A、A AT、kA”。

理解：
① 借助行列式与其转置行列式相等来理解“r (A) = r (AT)”，r(A)就是矩阵A中的最高阶非0行列式的，r(AT)也是为矩阵AT中的最高阶非0行列式的。

② r(AT A)=r(A AT)，在直播课中对其进行证明。
③ 借助初等变换来理解 r(A)=r(kA)，kA是可以进行初等变换的变为A的，即是令矩阵kA中的每一行都乘以一个1/k，这样就将kA通过初等变换变成了A，由于对矩阵进行初等变换时是不会改变矩阵的秩的，故r(A)=r(kA)。

（3）max { r(A)，r(B) } <= r( A，B )<= r(A)+r(B)
解释：若A是为一个m*n的矩阵的话，则 r(A,B)>=r(A)，r(A,B)>=r(B)，此时肯定是 r(A,B)>=max { r(A)，r(B) }；r( A，B )<= r(A)+r(B)见下面的理解。

（4）r ( A + B ) <= r( A ) + r( B )
理解：由于部分的秩肯定是小于等于整体的秩的，故是一定有 r( A+B ) <= r( A+B ,B )，对矩阵（A+B，B）进行初等列变换可以得到矩阵（A，B），由于对矩阵进行初等变换时是不会改变矩阵的秩的，故 r( A+B ,B )=r( A,B )。根据性质（3）可以知道，r（A，B）<= r（A）+ r（B），即就有 r ( A + B ) <= r( A+B ,B ) = r( A,B ) <= r( A ) + r( B )，即 r ( A + B ) <= r( A ) + r( B )。

（5）r(AB)<=min { r( A ),r( B ) }

理解：第（5）个性质不再进行证明，直接将其背下来。说明了r(AB)小于等于r(A),r(B)小于等于r(B)，如果是为3个矩阵相乘的话也是一样的，如 r(ABC)<=min { r( A )，r( B )，r( C ) }。

理解：
① 假设A是为一个n阶方阵的话，我们可以根据矩阵A的秩，即r(A)，来得到矩阵A*的秩，即r(A*)；反过来，我们可以根据矩阵A*的秩，即 r(A*)，发过来得到矩阵A的秩，即r(A)，或者是矩阵的秩的范围（当r(A*)=0的时候），即 r(A)<n-1。

② （8）中的A只是一过渡矩阵的，可以为其他的任何一个矩阵，只要这个矩阵是为一个n阶方阵就可以。如假设A为A*的话（r(A*)也是可以根据r(A)求出来的），由于A*是为一个n阶矩阵的，故接下来是根据r(A*)可以接着求 r（A**）的。

③证明过程：
a.
A为n阶方阵，r (A) = n ====> | A | != 0 ====> | A* | = | A |^(n-1) !=0 ====>  r(A*)=n。

理解：A为n阶方阵，r(A)=n说明了矩阵A中存在n阶的非0行列式，由于矩阵A本身对应的行列式就是为n阶的行列式，故 | A | != 0。| A | !=0，由于 | A |是为一个数的，故 | A |^(n-1) != 0，由于| A* | = | A |^(n-1) ，故 | A* | != 0 ，根据最前面补充的性质（一个n阶的矩阵，该矩阵对应的行列式非0《=====》该矩阵的秩为n），故可以得到 r(A*)=n。

b. 
证明：A是为一个n阶方阵， r( A ) = n-1 ====> r( A* ) = 1
理解：r(A) = n-1 ,说明了矩阵A中存在n-1阶非0行列式，矩阵A本身所对应的n阶行列式 | A | = 0，又由于 AA*= | A | E，故AA*=0。根据性质（7），有 r（A）+  r（A*）<=n（这里的n是为矩阵A的列数，矩阵A*的行数的），由于r（A）= n-1，故 r（A*）<=  1；
