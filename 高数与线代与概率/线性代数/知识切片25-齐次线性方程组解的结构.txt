一、齐次线性方程组解的结构

性质1：若ξ1，ξ2是 Ax=0的解，则 ξ1+ξ2 也是Ax=0 的解。


性质2：若 ξ 是 Ax=0的解，k∈R，则 kξ 也是Ax=0 的解。


二、解的结构
  设Ax=0 的解集S的一个极大线性无关组为 ξ1，ξ2，……，ξt，称为 Ax=0 的一个基础解系，则 Ax=0 的通解为
x = k1ξ1 + k2ξ2 + …… + ktξt（k1，k2，……，kt为任意常数）。

理解：线性方程组 Ax=0 的一个解是为一个向量的，因此 Ax=0 的解集就是为一个向量组的，这个向量组的一个极大线性无关组（极大线性无关组的意思就是它自己本身是线性无关的，从向量组中任意在找一个向量加入到极大线性无关组中后就是线性相关的）就是 Ax=0 一个基础解系（极大线性无关组是为一个向量组的，该向量组中的每一个向量都可看成是 Ax=0 的一个解，因此极大线性无关组，即 基础解系 就是Ax=0的一个解的集合）。

定理：设r(Amn)=r<n，则方程 Ax=0 有基础解系，且基础解系含n-r个解向量。

对齐次线性方程组 Ax=0 的基础解系的理解：基础解系别是为解集中一个极大的线性无关组的，极大线性无关则表明了只要从解集中再任意地挑选出一个解向量就构成线性相关的了，即是解集中的任意一个解向量都是可以用这个基础解系别表示出来的，这也就表示出了齐次线性方程组的所有解，即是齐次线性方程组的通解是可以通过基础解系来表示出来的。基础解系的意思就是只要从解集中挑选 若干个基本的解 就可以通过这若干个基本解的线性组合表示出所有解了，挑选出的这若干个解能够通过线性组合来表示线性方程组解集中所有的解的话，则这若干个解构成的向量组就是基础解系，如果挑选出的这若干个解不能够通过线性组合来表示出线性方程组所有的解的话，则这若干个解构成的向量组就不是基础解系。




题型：

1、求一个具体的齐次线性方程组 Ax=0  的通解。
提示：具体的 齐次线性方程组Ax=0 的意思指的是这个齐次线性方程组的系数矩阵A是为具体的。

解题思路：
（1）通过行最简形矩阵求齐次线性方程组的通解。
首先将系数矩阵A化为行阶梯形，接着将其化为行最简形，通过这个行最简形矩阵写出有效方程组。选取这个行最简形矩阵中每一行中的第1个非0元选取作为非自由变量（这个行最简形矩阵中有几个非0行就会有几个非自由变量）没有选择作为非自由变量的为自由变量（自由变量的个数为 n-行最简形矩阵中非0行的个数（即 总变量个数-非自由变量个数）），接下来对自由变量进行赋值，如果自由变量只有一个，就对这个自由变量赋值任意的常数k（其中k为任意的常数），如果自由变量为两个，则就分别对这两个自由变量赋值任意的常数k1、k2，依次类推。通过自由变量来表达处所有的非自由变量，最后将所有的变量写成向量的形式（x1，x2，x3，k1，k2），注意，写成向量形式中的x1、x2、x3是为非自由变量的，是用k1和k2代替了的，所写出的这个向量就是这个齐次线性方程组的通解。

（2）通过基础解系求齐次线性方程组的通解。

将系数矩阵A化为行最简形，写出有效方程组，找出r(A)，然后算出 n-r(A)。算出来的 n-r(A) 就是基础解系中解向量的个数，也是自由变量的个数，过对自由变量进行赋值得到n-r(A)个线性无关的向量（自由变量的取值可以任意，只要保证所得到的向量组最后是线性无关的就可以了），常见的对自由变量进行赋值并使其线性无关的赋值方式为：如果有两个自由变量，就赋值 { 1 0 }T，{ 0 1}T，如果有3个自由变量，就赋值 { 1 0 0 }T，{ 0 1 0 }T，{ 0 0  1 }T。最后将自由变量的值代入到有效方程组中，得到非自由变量的值，最后就可以写出 n-r(A) 个线性无关的解向量了，这 n-r(A) 个线性无关的解向量的任意线性组合的式子就是为这个齐次线性方程组的通解的（即是设置参数 k1，k2，……，kn）。


注意： 如果题目中没有明确说明采用哪种方式来求的这个齐次线性方程组的通解的时候，我们一般采用的是通过行最简形矩阵来求的这个齐次线性方程组的通解（更加简单方便些）；而不采用通过基础解系来求齐次线性方程组的通解。


2、求一个 抽象 或者 半抽象半具体 的齐次线性方程组 Ax=0  的通解。

提示：一个抽象的齐次线性方程组Ax=0指的是这个齐次线性方程组的系数矩阵是为抽象的，半抽象半具体指的是这个齐次线性方程组的系数矩阵是为半抽象半具体的（即给出的具体的矩阵式子A中带有参数）。

解题思路：此时我们需要使用的就是“通过基础解系来求齐次线性方程组的通解”，而不能够采用“通过行最简形矩阵来求齐次线性方程组的通解”（通过行最简来求齐次线性方程组的通解仅仅只适用于系数矩阵A是为具体的，系数矩阵A为抽象的，或者半抽象半具体的时候则是不适用的）。“通过基础解系来求齐次线性方程组的通解”的关键步骤就是“找到r(A)，进而确定出 n-r(A)”，确定出 n-r(A) 之后我们就确定了这个齐次线性方程组的基础解系中解向量的个数了，此时我们只需要找到任意 n-r(A) 个线性无关的解向量，就可以表示出这个抽象的齐次线性方程组 Ax=0 的通解。由于这是一个抽象的齐次线性方程组 Ax=0，故我们是无法通过将系数矩阵化为行阶梯形来求出r(A)的，如果题目中没有没明确的告诉你系数矩阵A 的秩为多少的话，接下来就转化为了求系数矩阵A的秩的方法，见前面知识切片14中总结的求矩阵的秩的方法（有两种方式，行阶梯形法以及定义法）。从题目中我们一般很容易知道系数矩阵的n，故只要找到r(A)之后就能很容易的知道 n-r(A)为多少 了。此时只需要找到 n-r(A) 个线性无关的解就行了，此时是根据题目中所给出的已知信息来找到这n-r(A)个线性无关的解向量的，有时题目中会直接给你n-r(A)个解向量，我们如果验证了这n-r(A)个解向量是线性无关的话（转化为了判断一个向量组线性无关的题型，见前面总结的题型），则此时题目中所给出的这 n-r(A) 个解就是可以作为基础解系的。知道了这个齐次线性方程组的一个基础解系后，这个基础解系的任意线性组合就是这个齐次线性方程组的通解。

关键：找r(A)，确定 n-r(A)。

思路：只要是齐次线性方程组求通解的问题，就需要先找到r(A)，如果是从基础解系入手来求通解，则接下来就需要确定出 n-r(A)，即是基础解系中含有多少个解向量。确定了n-r(A)之后则任意n-r(A)个线性无关的解都可以作为基础解系。

3、 让你判断向量组 β1，β2，β3，β4 是否为齐次线性方程组 Ax=0 的一个基础解系。
解题思路：
题目中见到了 α1，α2，α3，α4 为一个齐次线性方程组Ax=0的基础解系，
想当于就是告诉了你下面的条件：
《====》这些向量α1，α2，α3，α4一定是Ax=0的解，即是有 Aα1=0，……
《====》由向量α1，α2，α3，α4所构成的向量组一定是线性无关的。
《====》基础解系中的向量个数S（这里是4）=n-r(A)

同样，如果我们判断一个向量组 β1，β2，β3，β4 是否为一个齐次线性方程组的基础解系的时候也是要从这3个条件入手的，只有向量组 β1，β2，β3，β4 依次满足上面的3个条件的时候，我们才能够判定出向量组 β1，β2，β3，β4 是为齐次线性方程组 Ax=0 的一个基础解系的。首先判断向量组 β1，β2，β3，β4 是否满足第1个条件，即 β1，β2，β3，β4是否都是为齐次线性方程组 Ax=0 的一个解，就是看 是否满足 Aβ1=0，Aβ2=0，Aβ3=0，Aβ4=0；满足的话接下来看向量组 β1，β2，β3，β4 是否满足第2个条件，即向量组β1，β2，β3，β4 是否满足线性无关（利用知识切片19中向量组线性相关性的判定方法来判断是否线性无关）；满足线性无关的话接下来看第3个条件，即向量组β1，β2，β3，β4中的向量个数S（这里为4）是否等于 n-r(A)，等于的话则满足第3个条件。只有上面的3个条件都满足的时候我们才可以说向量组 β1，β2，β3，β4 是为齐次线性方程组 Ax=0 的一个基础解系。


4、题目中含由条件 AB=O，能够得到的信息。

解题思路：如果我们能够从题目中看到 AB=O 这个条件的话，我们能够得到两个信息：
（1）r(A)+r(B) <= n，其中n为矩阵A的列数，为矩阵B的行数。
（2）B的每一个列向量都是为齐次线性方程组 Ax=0 的解。
