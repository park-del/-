
特征值λ 与 特征向量α 的性质：

（1）设 λ1，λ2，……，λn 是n阶矩阵A的n个特征值，则
① λ1 + λ2 + …… + λn = trA；

理解：trA就是矩阵A的迹的，矩阵A的迹就是“矩阵A的对角线上的元素之和”。

应用：可以利用这一条性质来验证我们所求得到一个矩阵A的特征值是否正确，即就是看求得到的特征值 λ1，λ2，……，λn ，看其是否满足“λ1 + λ2 + …… + λn = trA”。

② λ1 λ2 …… λn = | A |（ A可逆《====》0不是特征值）

理解：只要0不是矩阵A的特征值，即 λi != 0，就能够得到 | A | !=0，从而可以得到矩阵A可逆；反过来矩阵A可逆的话就会有 | A | != 0，又因为 | A | = λ1 λ2 …… λn，因此能够得到 λi != 0。


（2）设n阶矩阵A的特征值为λ，A的属于特征值λ的特征向量为α，则
     A		λ		α
① A+kE		λ+k		α
② kA		kλ		α
③ A^k		λ^k		α
④ f ( A )		f ( λ )		α
⑤ A^-1		1/λ		α
⑥ A^*		| A | / λ		α
⑦ A^T		λ		不确定
⑧ P^-1 A P	λ		P^-1 α

理解：如果我们已经知道矩阵A的特征值λ和特征向量α之后，我们就可以利用这个性质直接知道 如 A^-1，A^*，等等 的特征值和特征向量了。

推导过程（帮助记忆）：
λ为方阵A的特征值，α为A的属于特征值λ的特征向量 《====》Aα = λα ，其中α非0。 

①在 Aα=λα 的左右两边同时加上一个“kα”，得
 Aα+kα = λα+kα
因此：（ A+kE ）α  = （ λ+k ）α
即：A+kE 这个矩阵对应的特征值是 λ+k，对应的特征向量是 α

②在 Aα=λα 左右两侧同乘“k”得
  kA α = kλ α
即：kA 这个矩阵对应的特征值是 kλ ，对应的特征向量是 α


③在 Aα = λα 左右两侧同时左乘 “A”，得
  A^2 α = λAα
因：Aα = λα
所：A^2 α = λ Aα= λ^2 α
所：A^2 α = λ^2 α
即：A^2 这个矩阵对应的特征值是 λ^2 ，对应的特征向量是 α 

依次类推：得到 A^k α = λ^k α
即：A^k 这个矩阵对应的特征值是 λ^k ，对应的特征向量是 α 

④ 根据②+③，得：

  kAα+A^2 α = kλα+λ^2 α
  (  kA+A^2  )α = (  kλ+λ^1 ）α

发现：“=”左边是为 f(A)，“=”右边是为 f(λ)
因此：f(A)α = f(λ)α
即：f(A)这个矩阵对应的特征值是为f(λ)，对应的特征向量是为α

⑤若A可逆，在 Aα = λα 的左右两边同时乘以 A^-1，得
  A^-1 Aα = A^-1 λα
由：（1）中性质②知：A可逆《====》0不是特征值，故矩阵A的特征值λ不为0
所：Eα = A^-1 λα，方程两边同时除以λ，得到 A^-1 α = 1/λ α
即：矩阵 A^-1的特征值为 1/λ，特征向量为α

⑥若A可逆，在 Aα = λα 的左右两边同时乘以 A^*，得
   A^* Aα = A^* λα
化：| A | Eα =  λ A^* α
化：| A | α = λ A^* α
因：A可逆，故 λ !=0
所：A^*α = | A | / λ  α
即：A^*这个矩阵对应的特征值为“| A | / λ”，对应的特征向量为α   

⑦解释矩阵 A^T （同 -1，* 一样，也是只有方阵才会有 T的）的特征值为 λ，特征向量为 α：
A^T 的特征值为λ：
计算特征值其实就求解出 | λE - A^T | = 0 中的 λ，根据矩阵转置的性质有 ( λE )^T = λE，因此原式变成“ | ( λE )^T - A^T | = 0”,根据和差的转置的性质有“ | ( λE )^T - A^T | = | ( λE - A )^T | ”,而结合行列式的性质，有“| ( λE - A )^T | = | ( λE - A ) |”，因此，“ | ( λE )^T - A^T | = 0”就是为“ | ( λE - A ) | = 0”，即 A^T 的特征值 与 A的特征值是一样的。

A^T的特征向量不确定：
计算特征向量其实就是求解出 ( λE - A^T )x = 0 这个齐次线性方程组的通解，求出的通解（解向量）就是为特征值 λ 对应的特征向量的。结合着矩阵的性质，有“( λE - A^T ) = ( λE - A )^T”,故原齐次线性方程组就变成了“( λE - A )^T x = 0”，与齐次线性方程组“( λE - A ) x = 0”（通解为A的特征值 λ 所对应的齐次线性方程组）比较，发现两个方程组的系数刚好相反，则此时两个方程组的通解是没有关系的，即 A^T 的特征向量（对应的齐次线性方程组的通解）不确定。
 

⑧我们要研究的是矩阵 P^-1 A P 这个矩阵对应的特征值和特征向量的，我们样这个矩阵记为B，将矩阵B右乘P^-1，得到“BP^-1 = P^-1 A”。
  在 Aα = λα 的左两边同时乘以 P^-1，得到
  P^-1 A α = P^-1 λ α
化：B P^-1 α = λ P^-1 α
因此：B这个矩阵，即是“P^-1 A P”的特征值为λ，特征向量为 P^-1 α。


（3）若α1和α2都是A的属于特征值 λ 的特征向量，则 k1α1+k2α2（非零）也是A的属于 λ 的特征向量。
理解：
①α1是A的属于特征值 λ 的特征向量，则有 A α1 = λ α1，α2是A的属于特征值 λ 的特征向量，则有 A α2 = λ α2，我们想要验证 k1α1+k2α2（非零）也是A的属于 λ 的特征向量，就是让其乘以矩阵A，看其是否与 λ 乘以  k1α1+k2α2（非零）就可以了。即是“A（k1α1+k2α2）”与“λ（k1α1+k2α2）”是否相等，显然是相等的，故有“k1α1+k2α2（非零）也是A的属于 λ 的特征向量”。
② 求出齐次线性方程组 ( λ1 E-A )x=0 的通解α，通解α 就是 特征值λ1 所对应的矩阵A 的特征向量的集合的，通解α中每一个具体的解α1就是为特征值λ1 所对应的矩阵A 的一个特征向量，指的是这些特征向量的线性组合是线性相关的。
③注意，这里也是包括了重根的，因为重根对应的是同一个特征值λ。
④结论：若 α1、α2 分别是A的属于不同特征值 λ1、λ2  的特征向量，则 α1与α2的线性组合不再是 A的特征向量。（即 α1+α2 不会是 A的任何一个特征值对应的特征向量）

（4）A的对应于不同特征值的特征向量是线性无关的。

理解 ：
举例：证明 A α1 = λ1 α1，A α2 = λ2 α2，λ1 != λ2，则 α1，α2 线性无关。
解题思路：
设 k1 α1 + k2 α2 =0 ①，
在①左右两侧同时左乘A，
则有 k1 A α1 + k2 A α2 =0 ，
即 k1 λ1 α1 + k2 λ2 α2 = 0 ②，
（这里的 ①② 式就是两个关于 k1，k2的方程，通过这两个方程解出 k1和k2）将 ①λ1-② ：k2（ λ1-λ2 ）α2=0，
又 λ1 != λ2，α2非零，
故k2=0（ kα=0 ---->k=0或者α=0，即 数乘以一个向量，要么是数为0，要么是向量为0；AB=0 --不能（）-->A=0 或者 B=0，即两个矩阵相乘为0，推不出A为0或者B为0的）（这里是k2（ λ1-λ2 ）是为一个数，α2为向量）
将 k2=0 回代①：k1α1=0
又 α1非零，故 k1 =0

（5）A的k重特征值λ至多有k个线性无关的特征向量。
理解：特征向量其实就是 齐次线性方程组 ( λE-A )x=0 的解，线性无关的特征向量其实就是 齐次线性方程组 ( λE-A )x=0 线性无关的解，就是 齐次线性方程组 ( λE-A )x=0 的基础解系。这个定理“A的k重特征值λ至多有k个线性无关的特征向量”其实就是在告诉我们：齐次线性方程组 ( λE-A )x=0 的基础解系解向量的个数 n - r( λE-A ) <= λ的重数。

举例：矩阵A的特征值为   1，1，2,  2,  2,  3 
解：矩阵A关于特征值 1 的齐次线性方程组为 ( E-A )x=0， 这个矩阵关于特征值  λ=1  的重数为2，则说明了 ( E-A )x=0 的基础解系中解向量的个数小于等于2，即 n-r( E-A ) <=2；矩阵A关于特征值 2 的齐次线性方程组为 ( 2E-A )x=0， 这个矩阵关于特征值  λ=2  的重数为3，则说明了 ( 2E-A )x=0 的基础解系中解向量的个数小于等于3，即 n-r( E-A ) <=3；矩阵A关于特征值 3 的齐次线性方程组为 ( 3E-A )x=0， 这个矩阵关于特征值  λ=3  的重数为1，则说明了 ( 3E-A )x=0 的基础解系中解向量的个数小于等于1，即 n-r( E-A ) <=1，又由于一定是有解的，故 ( 3E-A )x=0 的基础解系中解向量的个数为1。

注意：矩阵A对于任何一个特征值 λ 所对应的 齐次线性方程组( λE-A )x=0一定会是有解的，即 ( λE-A )x=0 的基础解系中解向量的个数一定是大于等于1的（一个单独的解就可以作为基础解系了）。

注意：A的单重特征值λ有且仅有一个线性无关的特征向量。

题型：

1、计算一个具体的矩阵 A (A是方阵) 的特征值λ。
解题思路：前面知识切片27中已经讲过这种思路了，就是求满足 | λE-A | = 0 的所有的λ值。


2、计算一个抽象的矩阵B的特征值λ。
解题思路：
（1）题目中给出了你另外的一个抽象的矩阵A的特征值 λ1 的话。
此时往往需要根据性质（2）来求出矩阵B的特征值λ，此时矩阵B往往是嵌套了矩阵A的。通过性质（2）来逐层求出 嵌套了矩阵A 的特征值，最后就可以求出嵌套了矩阵A的矩阵B的特征值了。
如 B=( 1/3 A^2 )^-1，则就根据性质2先求出 A^2 的特征值，接着求出 1/3 A^2 的特征值，接着求出 ( 1/3 A^2 )^-1 的特征值，此时求出来的这个特征值即是矩阵B的特征值了。

（2）题目中并没有给出另外的一个抽象的矩阵的特征值，只是给了你一个条件式子的话。
此时往往需要根据特征值的定义来得到特征值λ，此时的抽象的矩阵B往往是若干个矩阵的乘积，我们将 A=B（即是将B记为A），然后结合已知的条件式子对这个等式“A=B”（可以是方程两边同时左乘一个东西，右乘一个东西），凑出 A α = k α （此时这里的A就是我们要求的特征值对应的矩阵），此时是可以根据题目中给出的条件求出k的值的，则根据特征值的定义，知道了矩阵A的特征值就是为k的。  

扩展：

一个行矩阵 A =（ α1，α2，……，αn ），一个列矩阵 B = （ β1，β2，……，βn ）T，则 B A（即是列乘行） 得到的是为一个任意两行都成比例的 n阶方阵，因此 r( B A )=1。因为 BA为n阶（n>1），又因为 r（BA）=1，所以 | B A | =0，即是 “0一定是BA这个矩阵的特征值”。

0这个特征值对应的齐次线性方程组为 （ 0E - BA ） x = 0，系数矩阵 r（0E - BA）= r（- BA ）= r（BA）=1，则这个齐次线性方程组对应的基础解系中解向量的个数为 n-r(0E - BA)=n-1，即矩阵BA中的0这个特征值，对应有n-1个线性无关的特征向量。根据性质5“矩阵BA的特征值λ的重数为k，则特征值λ最多对应有 1<= ，<=k 个线性无法的特征向量，即是 特征值λ的重数k >= λ对应的线性无关的向量个数”。这里为 矩阵BA的 特征值0 对应的线性无关的向量个数为 n-1，则 0 对应的重数 >= n-1。

反证法：假设 特征值0 对应的重数为n，则 这个n阶矩阵 BA 的n个特征值都是为 0的，即 λ1+λ2+……+λn=0，因为 AB（行乘列）得出来是为矩阵 BA 的迹的，就是为 AB=trBA=λ1+λ2+……+λn，如果AB不是为0的话（此时已知就是 λ1+λ2+……+λn != 0），则说明了假设不成立，即 特征值0 不是n重的。

又因为 特征值0 的重数 >=n-1 ，故特征值0对应的重数只能够是为 n-1的，即这个矩阵BA的n个特征值 有n-1个都是为0，只有一个不为0，这一个不为0的特征值就是为 trBA=AB的。

结论：α与β都是列向量，A=β αT，则有 r(A)=1====>特征值0对应的齐次线性方程组有n-1个线性无关的解向量====>特征值0的重数 >= n-1 。如果 trA !=0，则A的n个特征值为 0,0，……，trA。（trA就是为一个数，为 α和β 任意一个转置与另一个相乘（先转置，再相乘）的结果）。 



3、计算出一个行列式 | A | 的值。
解题思路：前面的知识切片中已经总结了一些求行列式的值的方法，这里是利用“特征值与特征向量的性质（1）中的 ②”来求出行列式的值的。即是我们知道了这个行列式 | A | 是为一个n阶的行列式的话，此时我们就知道了这个 行列式 | A | 是有n个特征值的，当我们知道了这n个特征值 λ1，λ2，……，λn，此时这个行列式的值 | A | = λ1 λ2 …… λn。


4、题目中已经给出了一个关于抽象矩阵A的多项式，这个关于矩阵A的多项式 f1(A)=0，让你证明另一个关于抽象矩阵A的多项式f2(A)是可逆的。
解题思路：前面的知识切片中已经总结了一些证明抽象矩阵是逆矩阵的方法，这里是利用“特征值与特征向量性质2的推论------> A可逆《====》0不是特征值”来证明出这个抽象矩阵 f2(A) 是可逆的。即是我们只要证明出了 0不是这个抽象矩阵f2(A)的特征值，我们就可以证明出这个抽象矩阵 f2(A)是可逆的了。由于0矩阵的特征值是为0的（  0矩阵有且只有一个特征值0 ），我们这里知道了抽象的矩阵 f1(A) 是为0矩阵的，且这个矩阵 f1(A) 的特征值 是为0的且只有一个，又根据性质2可以知道“矩阵A的特征值为λ，则关于矩阵A的多项式 f1(A) 的特征值 就是为 f1(λ)”。

因此 抽象的0矩阵 f1(A) 有且只有一个为0的特征值 f1(λ)，我们通过 f1(λ)=0 可以求出 λ 所有可能的取值范围。而抽象矩阵 f2(A) 的特征值为 f2(λ)，根据λ的所有可能的取值范围，得到 f2(λ)的所有可能的取值范围，只要这其中没有0的话，就说明了 抽象的矩阵 f2(A) 是可逆的。

提示：由于这里是证明题，故得到 f2(λ)的所有可能的取值中一定是没有0的。



5、题目中含有条件“向量α是矩阵A的特征向量的”的选择填空题。
解题思路：先假设矩阵A的特征值为λ，然后将“向量α是矩阵A的特征向量”这句话结合着定义翻译成“Aα=λα”。然后在结合着题目中已知的条件进行解题即可。



6、证明向量α是不是A的特征向量。
解题思路：利用反证法，假设向量α是A的特征向量，假设A的特征值为λ，结合着定义写出“Aα=λα”，在结合着已知条件进行推导，推导出与一个已知条件相矛盾的就可以了。

总结：计算一个矩阵A（包括具体的和抽象的）的特征值λ 。
（1）一个是通过特征多项式 | λE-A | 得到。
（2）一个是通过特征值的 λ  的定义。
（3）一个是通过特征值的 λ  的性质来做。
提示：抽象的矩阵求特征值用 特征值λ的定义 和 特征值λ的性质来做。
