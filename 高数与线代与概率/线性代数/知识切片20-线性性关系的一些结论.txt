线性相关性的一些结论：

（1）向量组线性相关或者线性无关与线性表示的关系：

向量组 A：α1，α2，……，αm 线性相关《====》至少有一个向量 αi 可由其余向量线性表示；
注意：这里又是一个关于向量组A：α1，α2，……，αm线性相关的充要条件，前面已经讲过了4个关于线性相关的充要条件了。


例1：向量组A：α1，α2线性相关《====》α1=kα2 或者 α2=kα1，即向量α1与向量α2成比例。

例2：α1，α2，α3线性相关，则α3可由α1，α2线性表示（×）
理解：向量组A：α1，α2，α3线性相关，只是说明了向量组A中有一个向量可以由其他所有的向量来线性表示，具体是哪一个向量则是没有说的。可以是α1可由向量α2，α3来线性表示，可以是向量α2可由向量α1，α2来线性表示，可以是向量α3可由向量α1，α2来线性表示。


证明： 
①充分性：已知向量组A：α1，α2，……，αm线性相关，证明至少有一个向量可由其他向量来线性表示。

根据定义，存在不全为0的数k1，k2，……，km，使得 k1α1+k2α2+……+kmαm=0。

若 k1 != 0，则 k1α1 = -k2α2 -……-kαm。由于k1 !=0 ，故是可以得到“α1 = -(k2/k1) α2 -……-(km/k1) αm”的，相当于是“α1=关于α2，α3，………，αm的线性组合的式子（注意这里α2，α3，………，αm前面的系数为0也是可以的，主要能够找到这样的一个表达式就可以）”，故向量α1可以由向量组“α2，α3，………，αm”来线性表示。

若k1  = 0，则 k1α1 = -k2α2 -……-kαm，此时k1是不能够除过去的，即是“不能够找到一个关于α2，α3，……，αm的线性组合的式子，使其等于α1”，即是“α1不能够由向量组α2，α3，……，αm来线性表示”。


②必要性：已知向量β可以由向量组A：α1，α2，……，αm来线性表示，证明由向量β和向量组A所组成的向量组 β，α1，α2，……，αm是线性相关的。

由题意，因为向量β可以由向量组A：α1，α2，……，αm来线性表示，故存在“β=关于向量α1，α2，……，αm的一个线性组合式子”，即“ β=k1α1+k2α2+……+kmαm（这里的k1，k2，k3，……，km是可以全部都为0的，只要存在这样的一个式子k1α1+k2α2+……+kmαm就行）”，因此有“β-k1α1-k2α2+……-kmαm=0”，这里的β前面的系数前面为1，不是为0，满足“存在不全为0的k0，k1，……，km，使得 k0β+k1α1+……+kmαm=0”，故向量组 β，α1，α2，……，αm 是线性相关的。


 向量组线性无关《====》任一向量都不能由其余向量线性线性表示。

（2）若向量组A：α1，α2，……，αm线性相关，则向量组B：α1，α2，……，αm，αm+1 也线性相关；反之，若向量组B 线性无关，则向量组A也线性无关。

记忆：部分相关，则整体相关（部分相关则存在不全为0的数，满足向量组线性相关性的定义式，此时只需要使得整体中剩余的全为0，则对于整体来说也是存在不全为0的数，使得满足线性相关性的定义式，即部分相关，则整体相关）；整体无关，则部分无关。
 
注意：整体相对于部分是增加了向量的个数，而下面所讲到的一个向量组的延伸组是增加了向量的维数的。

                               					                 { α1 }   { α2 }         { αm }
补充：若α1，α2，……，αm线性无关，则向量组 α1，……，αm的延伸组                       ……              线性无关。
							 { β1 }   { β2 }          { βm }
向量组A的延伸组：就是将向量组A延伸之后所得到的一个向量组，所谓的延伸的意思就是将向量组A中的每一个向量在相同的位置上（可以是为每一个列向量最开始，最结束，中间）增加一个分量使得每一个向量的维数增加，所得到的一个新的向量组仍然是线性无关的。

记忆：一个线性无关的向量组，你把它延伸之后一定是线性无关的。
理解：一个向量组A线性无关，说明了这个向量组A对应的齐次线性方程组是只有0解的（有效方程的个数等于未知数的个数），对这个向量组A进行延伸之后，相当于原来A的齐次线性方程组又多了几个方程（延伸了几维就多了几个方程），但是方程中的未知数仍然不变，因此这个新的齐次线性方程组仍然是只有0解的，故向量组A的延伸组仍然是线性无关的。

注意：一个线性相关的向量组，你把它延伸之后可能是线性相关的，也可能是线性无关的。
理解：一个向量组A线性相关，说明了这个向量组A对应的齐次线性方程组是有非0解的（有效方程的个数小于未知数的个数），对这个向量组A进行延伸之后，相当于原来A的齐次线性方程组又多了几个方程（延伸了几维就多了几个方程），此时可能会导致有效方程的个数仍然小于未知数的个数，此时这个延伸之后的向量组仍然是线性无关的；此时可能会导致有效方程的个数>=未知数的个数，说明此时这个方程有唯一解，又是齐次线性方程，故这个唯一解为0，此时这个延伸之后的向量组是线性无关的。


（3）若向量α1，α2，……，αm线性无关，而α1，α2，……，αm，β线性相关，则β可由α1，α2，……，αm线性表示，且表示法唯一。

理解： 
β可由向量组A：α1、α2、α3、……，αm线性表示，且表示唯一
《====》方程组“x1α1+x2α2+……+xmαm=β”有唯一解；
《====》方程组的系数矩阵的秩 = 方程组的增广矩阵的秩 = m（未知数个数），即“r（A）=r（A，β）= m”。

法一（从秩的角度）：
记 A=（α1，α2，……，αm），B=（α1，……，αm，β），则 部分秩<=整体秩（借助矩阵秩就是为矩阵对应的行阶梯形矩阵中非0行的个数来理解 部分秩<=整体秩 这个关系），即r（A）<= r（B）；由于向量组 A：α1，α2，……，αm 线性无关，故r（A）=m（齐次线性方程组有唯一解，矩阵的秩（矩阵的秩就是有效方程的个数）等于向量的个数m）；由于向量组 B：α1，α2，……，αm，β 线性相关，故 r（B）< m+1（齐次线性方程组有无数解，矩阵的秩小于向量的个数m+1）；故 m = r(A) =< r(B) < m+1，又由于矩阵的秩一定是为一个整数，故r（B）= m，即 r（A）= r（B）= m，即是 r（α1，α2，……，αm）= r（α1，……，αm，β）=m（参考前面总结过的一个向量可以有一个向量组唯一表示的条件），说明了向量β可以由向量组A：α1，α2，……，αm来线性表示，且表示方法唯一。

法二（从定义的角度）：
已知向量组 α1，α2，……，αm，β  线性相关，根据定义，存在不全为0的常数 k1，k2，……，km，k  ，使得 k1α1+k2α2+……+kmαm+kβ=0 。
提示：如果 k !=0 的话，则就可以得到“β=( -k1/k ) α1 + ( -k2/k )α2 + …… + ( -km/k )αm ”，就可以证明出来向量β可以由向量组 A：α1，α2，……，αm来线性表示了。

原命题：已知向量组 α1，α2，……，αm 线性无关，向量组 α1，α2，……，αm，β线性相关（即是存在不全为0的常数 k1，k2，……，km，k 使得 k1α1+k2α2+……+kmαm+kβ=0），则 存在 k !=0 ，使得 k1α1+k2α2+……+kmαm+kβ=0。

假设（利用反证法，即假设结论不成立（结论的非），利用已知条件，推导出与题目中的一个已知条件不相符的（已知的非），则就说明了原命题是正确的，这是通过推导出原命题的逆否命题（结论否定能够推导出已知否定）为真，从而说明了原命题为真的）k=0，则原式变为“k1α1+k2α2+……+kmαm=0”，又由于已知向量组 α1，α2，……，αm线性无关，故 推导出 k1=k2=……=km=0，这与已知条件“向量组k1α1+k2α2+……+kmαm+kβ=0，根据定义，即存在不全为0的常数 k1，k2，……，km，k  （注意，此时假设k是为0的，故这里就是存在不全为0的常数 k1，k2，……，km）”相矛盾（推导出了已知条件的非），故原命题正确，原命题就是“k!=0”,因此能够得到“根据定义，存在不全为0的常数 k1，k2，……，km，k  ”，即向量β可以由向量组A：α1，α2，……，αm来线性表示。

接下来证明：
向量β可以由向量组A：α1，α2，……，αm来“唯一的”线性表示。（提示：一般证明唯一性的问题时用到的也是反证法，即假设结论不成立，利用假设不成立，题目中的已知条件，来推导出一个已知条件的非，就可以证明原来的命题正确了，即反证法是用来判断一个命题正确与否的依据，尤其是唯一性的命题）
 
原命题：已知向量组 α1，α2，……，αm 线性无关，向量组 α1，α2，……，αm，β线性相关（即是存在不全为0的常数 k1，k2，……，km，k 使得 k1α1+k2α2+……+kmαm+kβ=0，即是β可以由向量组：α1，α2，……，αm线性表示），则 β由向量组：α1，α2，……，αm的线性表示式子唯一。

假设 β=L1α1+……+Lmαm，β=P1α1+……+Pmαm，两式相减得到“( L1-P1 )α1+……+( Lm-Pm )αm=0”，若存在 Li != Pi（用来说明表示法不唯一的式子），即 Li-Pi !=0，则 α1，……，αm 线性相关（推导出了已知的非），与已知条件相矛盾，故原命题正确，即是 β由向量组：α1，α2，……，αm的线性表示式子唯一。

2、告诉了你 向量组A：α1，α2，α3 的线性相关性，向量组B线性：β1，β2，β3 的线性相关性，问你下列选项中一个向量以由向量组（向量组A与向量组B中的向量的组合）的线性表示的方式中正确的是？

解题思路：解决这类问题的思路就是把握住“关于线性相关性的2个结论”。

线性相关性的2个结论。
① 若向量组A：α1，α2，……，αm线性相关，则向量组B：α1，α2，……，αm，αm+1 也线性相关；反之，若向量组B 线性无关，则向量组A也线性无关。
② 若向量α1，α2，……，αm线性无关，而α1，α2，……，αm，β线性相关，则β可由α1，α2，……，αm线性表示，且表示法唯一。

已知 向量组A：α1，α2，α3 线性无关的话，则根据结论①可以推导出（整体无关，部分必无关）：向量 α1，α2 线性无关、向量 α1，α3 线性无关、向量 α2，α3 线性无关。

已知 向量组A：α1，α2，α3 线性相关的话，则根据结论①可以推导出（部分相关，整体必相关）：向量 α1，α2，α3，α4 线性相关。

已知 向量组 α1，α2，α3 线性无关，向量组 α1，α2，α3，β 线性相关，则根据结论②可以推导出：向量β可以由向量组 α1，α2，α3 线性表示，且表示方式唯一，即是存在 β=k1α1+k2α2+k3α3（线性表示是并没有要求k1，k2，k3不全为0的，可以是k1=k2=k3=0的）。

注意：另外两种方法见讲义中P52页-第3题第II问（其中一个为反证法，其中一个为秩方法）。
