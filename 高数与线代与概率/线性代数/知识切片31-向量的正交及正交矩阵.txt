一、向量的内积
1、设n维向量 α=( α1，α2，……，αn)T 及 β=(b1，b2，……，bn)T，则 [α，β] = a1b1+a2b2+……+anbn = αTβ = βTα，称为向量α与β的内积。

理解：
（1）只有两个相同维度的行向量，或者，两个相同维度的列向量才会存在内积（因为要对应位置）。
（2）两个向量的内积指的就是这两个向量对应位置上的元素相乘，最后相加得到的一个数的。


2、性质：
（1）[ α，β ] = [ β，α ] ；

理解：“α与β对应位置上的元素相乘相加”与“β与α对应位置上的元素相乘相加”的结果都是一样的，故 α与β的内积“[ α，β ]”与β与α的内积“[ β，α ]”都是一样的。

（2）[ λα，β ] = λ[ α，β ]；

理解：λα与β的内积为 “λa1b1+λa2b2+……+λanbn”, 提取出λ为“λ（a1b1+a2b2+……+anbn）”，就是为“λ[ α，β ]”。


（3）[ α+γ，β ] = [ α，β ] + [ γ，β ]；
 理解：( α+γ ) 点乘 β = ( a1+c1 )b1 + ( a2+c2 )b2 + …… + ( an+cn )bn = ( a1b1 + a2b2 + …… + anbn ) + ( c1b1 + c2b2 + …… + bncn ) = ( α 点乘 β ) + ( γ 点乘 β )。

提示：两个向量的点乘表示的就是这两个向量的内积。
记忆：向量的内积具有分配率（相当于是为“(α+γ) 点乘 β”，（α 点乘 β）+ （γ 点乘 β））。

（4）[ α，α ] = 0《====》 α=0.

理解：α 点乘 α = a1^2 + a2^2 + …… + an^2，因此，α 点乘 α =0，当且仅当α为0时。



3、当 [α，β]=0 时，称向量 α与β 正交（就是垂直），零向量与任何向量正交。



二、向量的长度
 令 || α || = 根号[ α，α ] = 根号( a1^2+a2^2+……+an^2 ) ，|| α || 称为向量α的长度。（记住为“根号( a1^2+a2^2+……+an^2 ) ”）

 当 || α || = 1 时，称 α 为单位向量。



三、规范正交向量组
 一组两两正交的单位向量称为【规范正交向量组】（或标准正交向量组）.

理解：这个向量组是满足两个条件的，一个是“两两正交”（这个向量组中的任意两个向量都是相互垂直的，即是这个向量组中的任意两个向量的内积，点乘的结果，都是为0的），另一个是“向量组中的每一个向量都是为单位向量的”，只有满足这两个条件的向量组才是为“规范正交向量组”。

 结论：任一线性无关的向量组 α1，α2，……，αr 都可以通过以下方法规范正交化。
注意：线性相关的向量组是没有办法进行规范正交化的。


如何把一个线性无关的向量组去把它化为规范正交向量组呢（即是化为“两两正交，并且向量组中的每一个向量都是为单位向量”呢）？（施密特正交化+单位化）
①施密特正交化：
β1=α1，
β2=α2- [ α2，β1 ]/[ β1，β1 ] β1，
β3=α3- [ α3，β1 ]/[ β1，β1 ] β1 - [ α3，β2 ]/[ β2，β2 ] β2，
……
βr=αr- [ αr，β1 ]/[ β1，β1 ] β1 - …… - [ αr，βr-1 ]/[ βr-1，βr-1 ] βr-1 .


理解：将一个线性无关的向量组 α1，α2，α3 代入上述公式进行施密特正交化，得到的向量组 β1，β2，β3，此时的向量组 β1，β2，β3 就是满足“两两正交”的。

②单位化：γ1 = β1/|| β1 ||，γ2 = β2/|| β2 ||，γ3 = β3/|| β3 ||。

理解：向第①步得到“两两正交”的向量组 β1，β2，β3 分别将其单位化之后，得到的向量组 γ1，γ2，γ3 就是满足“两两正交，且每一个都是单位向量”。因此，向量组 α1，α2，α3 这个线性无关的向量组对应的 规范正交向量组 就是为 γ1，γ2，γ3 的。（所谓的将向量α进行单位化，指的就是找到与向量α同一方向上单位长度为1的向量）

四、正交矩阵
 若【n阶矩阵】A满足 【A^T A=E】，即 【A^-1=A^T】，则称【 A 为正交矩阵】。
理解：既然 A^T A = E，则就说明了矩阵A的逆矩阵A^-1与其转置矩阵A^T是一样的，我们把一个矩阵的转置与其逆矩阵相等的矩阵叫做正交矩阵。


性质：（1）A是正交矩阵《====》A的列（行）向量组是规范正交向量组；
理解：假设A是一个 3*3 的正交矩阵的话，将矩阵A按列进行分块得到（α1，α2，α3），此时向量组 α1，α2，α3 是为一个规范正交向量组的，即向量组 α1，α2，α3 中的任意两个向量都是相互正交的（即任意两个向量都是相互垂直的），且向量组 α1，α2，α3 中的每一个向量都是为单位向量的。同理，对于矩阵A的行向量组也是一样的。反之，如果我们已经知道了一个矩阵A的行向量组或者列向量组是为规范正交向量组的话，则我们可以得出这个矩阵A是正交矩阵的。（充要条件）

          （2）若A是正交矩阵，则 A^-1 = A^T也是正交矩阵，且 | A |=+1或-1。
理解：
由A是正交矩阵可以得到 AA^T=E，结合正交矩阵的定义，我们可以很清楚的知道 A^T 与 A^-1 其实是一样的，因此 ( A^-1 )^T A^-1 = ( A^T )^T A^T = A A^T = E，即 A^-1 是为正交矩阵。
在 A^T A = E 的两边同时取行列式，得到 | A^T A | = | E |，| A^T |  | A | = 1，因此，| A |^2 = 1，所以 | A | = (+-)1。

题型：
1、将一个“线性无关的向量组 α1，α2，α3”化为规范正交向量组。（题目中让我们找的往往是“两个线性无关的向量对应的规范正交组”的，最多只会让我们找“3个线性无关的向量对应的规范正交组”）。
解题思路：
①先对这个向量组 α1，α2，α3 进行“施密特正交化”将其化为两两正交的向量组“β1，β2，β3”。

β1=α1，
β2=α2- [ α2，β1 ]/[ β1，β1 ] β1，
β3=α3- [ α3，β1 ]/[ β1，β1 ] β1 - [ α3，β2 ]/[ β2，β2 ] β2，

直接套用上面的公式就可以找到向量组 α1，α2，α3 对应的 β1，β2，β3。

②再对两两正交的向量组 β1，β2，β3 进行“单位化”将其化为长度为1的单位向量组 “γ1，γ2，γ3”。
γ1 = β1/|| β1 ||，
γ2 = β2/|| β2 ||，
γ3 = β3/|| β3 ||

技巧：由于 kβ 与 β 是平行的，故将 kβ 进行单位化所得到的单位向量与将 β 进行单位化所得到的单位向量是同一个向量，故我们可以将对 kβ 进行单位化转化为对 β 进行单位化，这样有时可以简化计算。 
直接套用上面的公式就可以找到  β1，β2，β3 所对应的 γ1，γ2，γ3，向量组“γ1，γ2，γ3”就是向量组“α1，α2，α3”对应的规范正交向量组。


2、已知具体的向量 α1，α2 ，让你求与向量α1和向量α2都正交的一个向量α3。
解题思路：利用向量α3与向量α1的内积为0，向量α3与向量α2的内积为0列出两个等式，解除这两个方程所确定的方程组的通解，这个通解就是要求的解向量α3。


3、证明一个抽象的矩阵A是正交矩阵。
解题思路：我们只需要证明出 A A^T = E，就可以证明出这个矩阵A是为正交矩阵了，此时需要用到的就是我们之间所总结过的关于矩阵的性质来对式子 A A^T 进行转化，最后转化到我们想要的E就证明出了矩阵A是为正交矩阵。

注意：如果题目中告诉了我们 A 是正交矩阵，相当于就告诉了我们 A^T=A^-1 这个条件。同时也有 | A | = 1 或者 -1这个条件，即正交矩阵A对应的行列式 | A |^2=1。
