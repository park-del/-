一、分块矩阵的定义
对于一些行数和列数比较多的矩阵，我们在运算的时候一般会采用分块法，使大矩阵的运算转化为小矩阵的运算。

规定：将一个矩阵A用一些横线和竖线分成若干个小矩阵，将每一个小矩阵称为A的子块，将每一个以子块为元素的矩阵称为分块矩阵。
 
分块矩阵：将一个矩阵B先用m条行线划分出m行，再将这个矩阵用n条竖线划分出n列，这样就将这个矩阵A划分出了m*n块。将用第1条行线和第一条列线划分出的那一块记为A11，将用第i条行线和第j条列线划分出的那一块记为Aij，将由元素Aij所构成的一个新的矩阵称为是矩阵B的分块矩阵（即是用m条行线，n条列线划分出的是为m*n个子块的，可以看成划分出的是为一个m*n的矩阵的；矩阵B的分块矩阵中的每一个元素是为一个子块的）。

二、分块矩阵的运算（所谓的分块矩阵的运算就可以看成是两个矩阵进行运算的一种方法，只不过将这两个矩阵进行了分块，通过完成两个矩阵所分成的分块矩阵的运算，从而完成两个矩阵的运算）

1、分块矩阵的加法
规定：设A、B同型，且采用相同的分块法：
       { A11 …… A1r }               { B11 …… B1r }                                                   { A11 + B11 ……  A1r + B1r }
A=                              ，B =                            ，其中Aij与Bij同型，则 A+B =                                                  。
       { As1  …… Asr }               { Bs1 …… Bsr }                                                    { As1  + Bs1 ……  Asr + Bsr  }

理解：将矩阵A用s行，r列划分出了 s*r 块，这样就会得到一个新的s*r矩阵，这个新的s*r矩阵就是为矩阵A的分块矩阵的，仍然记为A；将矩阵B也采用同样的划分方法（即是相同的分块法，相同的分块法的意思是对矩阵B所划的行线要和对矩阵A中所划的行线相一致，即矩阵A划了s条行线的话，则矩阵B也要划s条行线；矩阵A在第4行划了行线，第5行没有划行线的话，则矩阵B也要在第4行划行线，第5行不划行线。同理，矩阵B对列的划分也要和对矩阵A中列的划分相一致的），得到一个新的s*r矩阵，这个新的s*r矩阵就是为矩阵B的分块矩阵的，仍然记为B。由于分块矩阵A与分块矩阵B是同型的，故它们可以进行相加，得到A+B。这就是分块矩阵的加法，通过矩阵A的分块矩阵和矩阵B的分块矩阵来完成了矩阵A与矩阵B的相加。


分块的要求：对矩阵A进行分块的行和列的 条数与位置（对应行数就是第几行，对应列数就是第几列）和对矩阵B进行分块的行和列的 条数 和 位置 都一样。 


2、分块数乘
规定：首先对矩阵A进行分块，划分出了m行n列，则划分出了m*n个子块，常数λ乘以这个分块矩阵就是将这个常数λ分别乘以这个矩阵中的每一个分块的。

分块的要求：无论对A怎么进行分块都是可以的，对矩阵A的分块没有要求。

3、分块乘法

规定：由于矩阵的乘法（以 A乘B为例）是用“矩阵A的行和矩阵B中的列”分别对应元素相乘相加的，故对A进行分块后的分块矩阵At，对B进行分块后的矩阵Bt，这两个分块矩阵相乘的运算过程是：
（1）分块矩阵At中的第1行中的各个分块（即是分块矩阵At中第1行中的各个元素，分块矩阵的元素是为分块的）和分块矩阵Bt中的第1列中的各个分块分别对应相乘作为C11；
（2）即分块矩阵At中的第1行中的各个分块素要与分块矩阵Bt中的第1列中的各个分块分别对应相乘相加；分块矩阵At中的第1行中的各个分块要与分块矩阵Bt中的第2列中的各个分块分别对应相加；即分块矩阵At中的第1行的各个分块是要依次与分块矩阵Bt中第1列、第2列、……、第n列中的各个分块分别对应相乘相加的，得到C11，C12，……，C1n。
（3）同理，分块矩阵At中的第2行中的各个分块也是要依次与分块矩阵Bt中的第1列、第2列、……、第n列中的各个分块分别对应相乘相加的，得到C21，C22，C2n；……;分块矩阵At中的第m行中的各个分块也是要依次与分块矩阵Bt中的第1列、第2列、……、第n列中的各个分块分别对应相乘相加的，得到Cm1，Cm2，Cmn；即分块矩阵At中的第1行中的各个子块第Bt中的第j列中的各个子块分别对应相乘相加得到的是C中的第i行第j列的那个子块。

（4）这也就要求了对矩阵A中的列线的划分方法要与矩阵B中的行线的划分方法相一致。即对矩阵A进行划分的列线的 条数和位置 要和对矩阵B进行划分的行线的 条数和位置相一致（保证了相乘的两个子块相挨着的两个下标相同），即就可以通过分块举着的乘法求出A*B了。

（5） 对矩阵A的行线的划分不会影响矩阵A中所划分出来的每一个子块的列数，对矩阵B中的列线的划分不会影响所划分出来的每一个子块的行数，因此，矩阵A所划分出来的分块矩阵和矩阵B所划分出来的分块矩阵能否相乘只取决于对矩阵A的列线的划分方法，和对矩阵B的行线的划分方法的；与矩阵A中的行线的划分方法和矩阵B中的列线的划分方法没有任何关系的，即矩阵A中的行线的划分方法和矩阵B中的列线的划分方法任意，矩阵A中的行线的划分方法和矩阵B中的列线的划分方法只会影响矩阵A的分块矩阵与矩阵B的分块矩阵相乘所得到的矩阵中的子块的大小的。


满足条件：矩阵A的列分法（即对矩阵A的列线的划分）与矩阵B的行分法（即对矩阵B的行线的划分）要相同。
口诀：如果A的第n列后面有线的话（列分法），则B的第n行后面就一定有线（行分法）。

4、分块转置
规定：将一个矩阵A进行分块后得到了分块矩阵A，则分块矩阵A的转置就是“向将分块矩阵A所划分出来的每一个子块进行转置；然后将这个分块矩阵A中的第1行中的各个子块按照顺序写在空白纸上的第1列上，将这个分块矩阵A中的第2行中的各个子块紧跟着写在第1列写在空白纸上的第2列上，依次类推”，最后，空白纸上所写的矩阵就是为这个分块矩阵A的转置的。

满足条件：子块要转置；行列互换。

 
5、分块对角矩阵
				  { A1                  O  }
规定：设Ai（i=1，……，s）为方阵，则A={       A2                 }  称为分块对角矩阵。
 				 {	 ……        }
                                               		 {  O                   As }

理解：对一个矩阵A进行划分后得到了一个分块矩阵，如果这个矩阵中的非0子块（即不是O的矩阵）都位于这个分块矩阵的对角线上（指的是从左上到右下这一条线），且位于对角线上的这些矩阵都是方阵（这些方阵的阶数是可以不同的），这个分块矩阵的其他位置上的元素都是为0子块（即是O矩阵）的话，则此时的这个分块矩阵就叫做是分块对角矩阵。

分块对角矩阵的性质：
（1）分块对角矩阵A的k次幂=对角线上各个子块的k次幂。
（2）分块对角矩阵A的行列式=对角线上各个子块的行列式的乘积。即是 | A | = | A1 | |A2| …… |As|。
两个推论：拉普拉斯公式（见课本）。
（3）分块对角矩阵A的逆=对角线上各个子块的逆（前提是对角线上的各个子块的逆矩阵要存在）。
推论：对与分块副对角矩阵A的逆，则是为对角线上各个子块的逆，且各个子块的逆要按照其顺序颠倒过来。


题型：（O矩阵或者说是O子块的行数和列数是不确定的，根据所求出来的其他非O子块的行数和列数确定，因此将各个子块代入还原矩阵时应该先代入非O子块，确定这个矩阵的形状，最后在代入O子块 ）
注意：下面的题型1 题型3中的一点要注意，即是在对矩阵A进行划分成四块后，只要求划分后的四个子块中不为O矩阵的那个为方阵就可以了，这四个子块中为O矩阵的那个子块是不是方阵则是没有要求的，即是所划分出来的O子块是可以为方阵，也是可以不为方阵的。  

1、利用分块矩阵来求一个行列式的值（由行列式到矩阵） 或者 利用分块矩阵来求一个矩阵A所对应的行列式的值（由矩阵当行列式）。
解题思路：首先将题目中所给出的行列式分成四块，使得每一块都是为一个方阵的（这里要注意，行列式一定是是为行数等于列数的，对于一个n阶行列式来说，只有当n为偶数的时候才是可以将这个n阶行列式分成4块都是为方阵的，当n为奇数的时候是没有办法将这个行列式分成4块都是为方阵的。因此利用分块矩阵来求行列式的值这种方法是只适合于偶数阶的行列式的，对于奇数阶的行列式这种办法是不适用的）。观察这4块（即是这四个方阵中）中是否满足“至少有一块为0矩阵（即是至少有一块的元素全为0）”这个条件，如果不满足的话，则可以利用行列式的性质对行列式进行变换，使得当划分之后这4块满足“至少有一块为0矩阵（即是至少有一块的元素全为0）”这个条件。当满足了4块中“至少有一块全为0”这个条件之后，就可以利用拉普拉斯公式来计算出这个行列式的值了。即是观察这个分成了4块的行列式，如果为主对角线上的那2块都不是0矩阵的话，此时这个行列式的值就等于“主对角线上这两块所对应的行列式的乘积”（即是相当于将四阶行列式的计算转化为了2阶行列式的计算，将8阶行列的计算转化为了4阶行列式的计算，……），如果为副对角想上的那2快的都不  是0矩阵的话，此时这个行列式的值就等于“(-1)^(m*n) 乘以 副对角线上这两块所对应的行列式的乘积（这里的m和n分别是副对角线上那两个方阵的阶数）”。最后计算出的“主对角线上这两块所对应的行列式的乘积”或者“(-1)^(m*n) 乘以 副对角线上这两块所对应的行列式的乘积”就是为这个行列式的值。

2、利用分块矩阵来求A、B两个矩阵相乘的结果，即A*B。
解题思路：对A按照列来进行划分，对B按照行来进行划分，且A的列划分的方法与B的行划分的方法一样（即是 A的第t列后有一个线的时候，B的第t行的后面也是要有一个线的，这样就保证了线的条数与位置都对应相等了）。对于A的行或者B的列则是可以任意划分的，不会影响A与B是否可乘。这样划分之后A就成为了一个 m行n列的分块矩阵（即是A中就有了m*n个子块），而B就成为了一个n行s列的分块矩阵（即是B中就有了 n*s 个子块），由于A的列划分与B的行划分一样，故A被划分为n列，则B就被划分为n行，且A的两条相邻列线之间的元素个数与对应的B中两条相邻的行线之间的元素个数相等；由于A的行的划分是任意的，而B的列划分是任意的，故A划分的m行与B划分的s列是没有任何关联的。接下来就可以进行A和B这两个分块矩阵的相乘了，用分块矩阵A中的第i行中的各个子块分别乘以B中第j列中的各个子块作为矩阵分块矩阵C（假设C矩阵就是为A矩阵 乘以 B矩阵的结果）中的第i行第j列的子块。


3、利用分块矩阵来求矩阵A的逆矩阵。
解题思路：首先将题目中所给出的矩阵化为四块，使得每一块都是为一个方阵的。如果划分出来的这四块中是为“主对角线上的两个子块不为O，副对角线上的两个子块为O的话”，则此时这个分块矩阵的逆矩阵就是为“主对角线上的两个子块分别取逆的结果”（即是A^-1中的两个非O子块为A1^-1，A2^-1），如果划分出来的这四块中是为“副对角线上的两个子块不为O，主对角线上的两个子块为O的话”，则此时这个分块矩阵的逆矩阵就是为“副对角线上的两个子块分别取逆，然后颠倒顺序的结果”（即是A2^-1中的两个非O子块为A1^-1，A2^-1）。这样，就将原来的较复杂矩阵求逆矩阵转化为了“两个相对简单矩阵求逆矩阵”，最后将求出来的两个相对简单的矩阵的逆矩阵“A1^-1、A2^-1”代入到分块矩阵A的逆矩阵的式子中A^-1，所得到的这个矩阵就是为A^-1的。

技巧：如果将矩阵A划分为4块之后，那两个非O子块A1，A2刚好为  “只有主对角线上有元素 或者 只有副对角线上有元素”，则此时就可以直接套用公式来求出“A1^-1 和 A2^-1”。当非O子块A1或者A2为“只有主对角线上有元素时”，此时A1^-1或者A2^-1为“主对角线上的元素取倒”；当非O子块A1或者A2为“只有副对角线上有元素时”，此时A1^-1或者A2^-1为“副对角线上的元素取倒，然后颠倒顺序”。

4、可能利用到分块矩阵来解决的一些小题的类型。
（1）求出一个行列式|A|的代数余子式之和。
解法一：可以利用我们前面总结过的“代数余子式的线性组合的求值问题”来解决。即是 分别求出 A11+A12+……+A1n，A21+A22+……+A2n，……，An1+An2+……+Ann，最后将其相加就可以了。
解法二：求 | A | 的所有代数余子式之和，就相当于是求 矩阵A的伴随矩阵A*（矩阵矩阵A的伴随矩阵中的所有元素相加起来就是为 | A |的所有代数余子式之和的）。
求矩阵A的伴随矩阵A*可以利用定义来求，即是求出 A11，A12，……，A1n；A21，A22，……，A2n；……；An1，An2，……，Ann。
求矩阵A的伴随矩阵A*也可以利用公式 A*=| A | A^-1，此时转化为了“求由A所决定的行列式 | A | 的值”“求由A所决定的逆矩阵A^-1”，其中“求由A所决定的行列式 | A | 的值”就转化为了题型1（利用分块矩阵来求一个行列式的值），或者利用我们前面所总结过的求行列式的值的方法来解决；其中“求由A所决定的逆矩阵A^-1”就转化为了题型3（利用分块矩阵来求一个矩阵的逆矩阵），或者利用我们前面总结过的求逆矩阵的方法来解决。

（2）证明一个矩阵A可逆的充要条件是“一个式子”。
解题思路：矩阵A可逆的冲要条件为“| A | != 0”，即 “| A | != 0 等价于 这个式子”，如果我们能够通过通过“ | A | !=0 ” 这个关系推导出这个式子的话，则就说明了“该式子”是为矩阵A可逆的充要条件。接下来的工作就是求“| A |”,这样就又转化为了求“矩阵A对应的行列式| A |”的问题，可以利用题型1（利用分块矩阵来求行列式） 或者 前面所总结过的求行列式的的各类问题 来解决。（注意，求行列式也是可以间接地来进行求的，即是知道了 | A B | = 多少，知道了 | B | = 多少，此时我们就可以通过 | A | | B | 和 | B | 来间接地求出 | A |了）。
