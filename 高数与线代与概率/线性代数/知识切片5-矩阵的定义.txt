1、矩阵的概念：
由m*n个数aij（i=1,2,3，……，m；j=1,2,3，……，n）排成的m行n列的数表称为 m*n矩阵。

理解：矩阵就是一个容器，是用来盛装数据的，一个m*n矩阵可以盛装m*n个数；矩阵就是为一张数表的。

两个矩阵A和B同型：矩阵A和矩阵B的行数相等，矩阵A和矩阵B的列数相等，则称矩阵A与矩阵B同型。
两个矩阵A和B相等：矩阵A和矩阵B必须是同型矩阵（即矩阵A和矩阵B的行数和列数相等），且矩阵A与矩阵B中对应位置上的元素相等，那么就说矩阵A与矩阵B相等，记作A=B。

2、特殊的矩阵
（1）方阵：顾明思义就是方方正正的，即若一个矩阵的行数与其列数相等，这个矩阵就是方阵，记作A或An，其中，主对角线上的各元素之和叫做方阵A的迹，记作trA。

注意：只有方阵才会有对角线，也是只有方阵才会有迹的概念。

（2）行矩阵（行向量）：若一个矩阵只有1行，则这个矩阵就叫做行矩阵。即是A=（a1,a2，……，an）。

注意：只有在行矩阵中元素间为了区分可以加“逗号”，即 A=(1,2,3,4)，当然行矩阵A写成（1 2 3 4）也是可以的。其他所有矩阵中都是不能够加“逗号的”。如 {   1, 2  }的写法是错误的，只有不加                                                        												      {   3,4   }        
逗号，即 {  1  2   } 才是正确的。
               {  3  4  }

（3）列矩阵（列向量）：若一个矩阵只有1列，则这个矩阵就叫做列矩阵。

（4）零矩阵：若一个矩阵中所有的元素都为0，则这个矩阵就是0矩阵。0矩阵用“O或者0”来表示。
注意：矩阵相等则这两个矩阵必须首先是同型的，然后对应位置上的元素相等才叫做两个矩阵相等。因此，不同型的零矩阵是不相等的。

（5）单位矩阵：首先这个矩阵必须是为一个方阵（因为只有方阵才存在对角线），这个方阵中对角线上的元素为1，其他位置上的元素都为0，我们把这样一个矩阵叫做单位矩阵。单位矩阵我们一般都用“E”来表示。

注意：
《1》这里所说的对角线指的是从左上角斜到右下角的这一条斜线的。
《2》单位矩阵就相当于是矩阵中的1，表示任何矩阵乘以单位矩阵还是其本身；0矩阵就相当于是矩阵中的0，任何矩阵乘以0矩阵得到0矩阵。

（6）数量矩阵：如果单位矩阵中的对角线上的元素不为1，而是为k的话，我们就把这个矩阵叫做数量矩阵。（因此，单位矩阵可以看成是为一种特殊的数量矩阵的）

（7）对角矩阵：首先这个矩阵必须为一个方阵（方阵才有对角线），若这个方阵中只有对角线上存在元素（对角线上只要不全为0就可以了），方阵除了对角线之外的其他位置上的元素都为0，我们把这样的一个矩阵叫做对角矩阵。（因此，可以看出，数量矩阵是为一种特殊的对角矩阵，单位矩阵是一种特殊的数量矩阵）

（8）上三角矩阵：首先这个矩阵必须是方阵（因为只有方阵中才存在对角线），这个矩阵中的非0元都集中在这个矩阵上方的这个三角形里面，所以我们把这样的矩阵叫做上三角矩阵。

（9）下三角矩阵：首先这个矩阵必须是方阵（因为只有方阵中才存在对角线），这个矩阵中的非0元都集中在这个矩阵下方的这个三角形里面，所以我们把这样的矩阵叫做下三角矩阵。
