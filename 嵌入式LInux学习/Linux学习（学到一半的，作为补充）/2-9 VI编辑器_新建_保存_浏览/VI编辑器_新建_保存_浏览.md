**针对嵌入式面试的补充扩展：**

在嵌入式开发中，通常没有图形界面，因此熟练使用像 VI 这样的命令行文本编辑器至关重要。掌握 VI 的不同模式（命令模式、插入模式、底行模式）及其切换是基本功。此外，了解文件权限、`sudo` 命令以及在没有图形界面的情况下进行文件操作的各种命令（如 `cat`, `ls`, `cp` 等）也是嵌入式面试中常考的知识点。

**经典面试问题与简洁回复：**

1. 问题：VI 编辑器有哪几种工作模式？它们之间如何切换？

   回复：VI 编辑器有三种基本模式：

   - **命令模式 (Normal Mode)**：启动 VI 时的默认模式，用于移动光标、删除字符、复制粘贴等。
   - **插入模式 (Insert Mode)**：用于输入文本。
   - **底行模式 (Last Line Mode)**：用于执行保存、退出、查找、替换等命令。
   - **切换**：
     - 从命令模式进入插入模式：按 `i` (在光标前插入)、`a` (在光标后插入) 等。
     - 从插入模式返回命令模式：按 `ESC` 键。
     - 从命令模式进入底行模式：按 `:` 键。
     - 从底行模式返回命令模式：按 `ESC` 键。

2. 问题：在 VI 编辑器中，如何保存文件并退出，以及不保存文件强制退出？

   回复：

   - 保存并退出：在底行模式下输入 `:wq` 或 `:x`。
   - 不保存强制退出：在底行模式下输入 `:q!`。

3. 问题：当你在嵌入式 Linux 系统中，需要修改一个系统配置文件（例如 /etc/environment），但发现没有写入权限时，你会怎么做？

   回复：我会使用 sudo 命令提升权限来编辑文件。例如，sudo vi /etc/environment。sudo 允许授权用户以超级用户或其他用户的身份执行命令。

4. 问题：在查看一个很长的日志文件时，如何在 VI 中快速跳转到文件的末尾、开头或指定行？

   回复：

   - 跳转到文件末尾：在命令模式下按 `G` (大写 G)。
   - 跳转到文件开头：在命令模式下按 `gg` 或在底行模式下输入 `:1`。
   - 跳转到指定行：在底行模式下输入 `:行号`，例如 `:250`。
   - 翻页：`Ctrl + F` 向前翻页，`Ctrl + B` 向后翻页。

5. 问题：如何在 VI 中显示和隐藏行号？为什么在编辑文件时可能需要显示行号？

   回复：

   - 显示行号：在底行模式下输入 `:set number`。
   - 隐藏行号：在底行模式下输入 `:set nonumber`。
   - 显示行号有助于：定位错误、与他人交流时指定代码位置、进行代码审查以及使用跳转到指定行等命令时更方便。
