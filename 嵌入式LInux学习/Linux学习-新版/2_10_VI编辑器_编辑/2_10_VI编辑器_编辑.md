## 5. 核心内容详细解释

### 5.1 使用这些命令前，要先处于一般模式

打开文件后，VI 默认处于**一般模式**。

当底部出现：

```text
-- INSERT --
```

说明<span style="color:#FF0000; background:#33FF99;">当前是编辑模式。此时按 `x`、`d`、`u`，通常会被当成普通文字，而不是命令。</span>

因此，执行删除或撤销前，先按：

```text
Esc
```

完整逻辑是：

```text
需要输入文字：一般模式 → 按 i/o 等 → 编辑模式
输入完成：编辑模式 → 按 Esc → 一般模式
需要删除或撤销：必须在一般模式执行
```

------

### 5.2 `i`：在光标前插入文字

假设原文为：

```text
Hello
```

光标位于字母 `e` 上：

```text
H[e]llo
```

按 `i` 后输入 `ABC`，结果是：

```text
HABCello
```

因为<span style="color:#FF0000;"> `i` 的含义是：</span>

> 在<span style="background:#33FF99;">当前光标所在字符的**前面**开始插入。</span>

操作流程：

```text
移动光标
按 i
输入内容
按 Esc
```

------

### 5.3 `a`：在光标后插入文字

同样是：

```text
H[e]llo
```

按 `a` 后输入 `ABC`，结果是：

```text
HeABCllo
```

区别是：

| 命令 | 从哪里开始输入 |
| ---- | -------------- |
| `i`  | 当前字符前面   |
| `a`  | 当前字符后面   |

可以<span style="color:#FF0000; background:#33FF99;">把它们记成：</span>

```text
i = insert，在前面插
a = append，在后面追加
```

------

### 5.4 `I`、`A`、`o`、`O`

视频开头的教材还展示了这些插入命令：

| 命令 | 作用                                                         |
| ---- | ------------------------------------------------------------ |
| `I`  | 跳到<span style="color:#FF0000; background:#33FF99;">当前行第一个非空字符前，</span>进入编辑模式 |
| `A`  | 跳到<span style="color:#FF0000; background:#33FF99;">当前行末尾</span>，进入编辑模式 |
| `o`  | 在<span style="color:#FF0000; background:#33FF99;">当前行下方新建一行</span>，并进入编辑模式 |
| `O`  | 在<span style="color:#FF0000; background:#33FF99;">当前行上方新建一行</span>，并进入编辑模式 |

### `o` 的具体效果

原文：

```text
第一行
第二行
```

光标位于“第一行”，按 `o`：

```text
第一行
|
第二行
```

中间会新增一行，并直接进入编辑模式，可以马上输入内容。

视频约在 **04:17-04:31** 演示了这种效果。

需要注意：

> `o` 虽然在视频笔记中写在删除命令附近，但它本身不是删除命令，而是“新增一行并开始输入”。

## 6. 删除命令详解

### 6.1 `x`：删除光标所在字符

例如：

```text
he[l]lo
```

光标在 `l` 上，按一次 `x`：

```text
hello → helo
```

<span style="color:#FF0000; background:#33FF99;">连续按三次 `x`，就会从当前光标位置开始连续删除三个字符。</span>

视频中第10行单词的字符逐渐减少，主要是在说明这种效果。

#### 容易误解的地方

`x` 删除的是：

> 光标<span style="background:#33FF99;">**当前压住的那个字符**。</span>

它<span style="color:#FF0000; background:#33FF99;">不是退格键，不是删除光标左边的字符。</span>

删除左侧字符常用：

```text
X
```

这是补充命令，本视频没有重点演示。

------

### 6.2 `dw`：从光标位置删除到下一个单词边界

视频笔记将它简写为：

```text
dw: del word
```

但严格来说，它不一定永远删除“完整的一个单词”，而是：

> <span style="color:#FF0000; background:#33FF99;">从当前光标位置开始，删除到下一个单词的起始位置。</span>

例如：

```text
This is a test
          ^
```

光标在 `test` 的 `t` 上，按 `dw`：

```text
This is a
```

但是光标如果位于单词中间：

```text
te[s]t
```

按 `dw`，可能只删除 `st` 以及后面的空格，而不是把整个 `test` 全部删除。

因此，使用 `dw` 前要先观察光标位置。

### 命令拆解

```text
d = delete，删除
w = word，移动到下一个单词
dw = 删除“向下一个单词移动”所经过的内容
```

这是 VI 很重要的组合思维：

```text
操作符 + 移动范围
```

------

### 6.3 `D`：删除从光标到当前行结尾的内容

例如：

```text
The quick brown fox
          ^
```

光标位于 `brown` 的 `b` 上，按大写 `D`：

```text
The quick
```

它会保留光标左侧内容，删除光标位置以及右侧内容。

`D` 基本等价于：

```text
d$
```

因为 `$` 表示当前行结尾。

### 与 `dd` 的区别

| 命令 | 删除范围                 |
| ---- | ------------------------ |
| `D`  | 当前光标到本行末尾       |
| `dd` | 整个当前行，包括换行位置 |

------

### 6.4 `dd`：删除当前整行

不需要先选中文字，只要光标位于目标行的任意位置，输入：

```text
dd
```

整行就会消失。

例如：

```text
第一行
第二行   ← 光标在这里
第三行
```

按 `dd` 后：

```text
第一行
第三行
```

### 为什么需要按两次 `d`？

第一个 `d` 可以理解为：

```text
我要执行删除
```

第二个 `d` 表示：

```text
删除当前整行
```

在 VI 中，`dd` 是一个完整命令，不需要输入冒号，也不需要按回车。

------

### 6.5 `ndd`：一次删除多行

这里的 `n` 不是字母 `n`，而是一个具体数字。

例如：

```text
3dd
```

表示：

> 从当前行开始，一共删除3行。

也就是：

```text
当前行 + 后面的2行
```

视频讲义中的“当前行及其后的 `n-1` 行”就是这个意思。

例如光标位于第5行：

```text
3dd
```

删除：

```text
第5行
第6行
第7行
```

并不是删除当前行之后的3行，也不是只删除后面的行。

------

# 7. `u`：撤销上一步修改

在一般模式按：

```text
u
```

会撤销最近一次修改。

例如：

```text
dd
```

误删一整行后，马上按：

```text
u
```

被删掉的行就会恢复。

视频终端底部多次出现：

```text
1 change; before #...
5 more lines; before #...
```

这说明 VI 正在回到较早的编辑状态。

### `u` 可以撤销哪些操作？

通常包括：

- `x` 删除字符；
- `dw` 删除单词；
- `D` 删除行尾；
- `dd` 删除整行；
- `ndd` 删除多行；
- 编辑模式中刚完成的一次输入。

### 补充：撤销之后反悔

<span style="color:#FF0000; background:#33FF99;">如果按 `u` 撤销后，又想恢复刚才被撤销的操作，可使用：</span>

```text
Ctrl+r
```

这相当于“重做”。视频没有重点介绍，但实际使用很有帮助。

------

# 8. 最容易混淆的命令

| 命令  | 作用                | 易错点                                     |
| ----- | ------------------- | ------------------------------------------ |
| `i`   | 在光标前输入        | 进入编辑模式后，要按 `Esc`才能执行其他命令 |
| `a`   | 在光标后输入        | 不是跳到行尾，跳到行尾应使用 `A`           |
| `o`   | 下方新建一行        | 是小写字母 `o`，不是数字零                 |
| `x`   | 删除当前字符        | 删除的不是左侧字符                         |
| `dw`  | 删除到下一单词边界  | 光标在单词中间时，不一定删除整个单词       |
| `D`   | 删除到当前行末尾    | 必须是大写 `D`                             |
| `dd`  | 删除当前整行        | 不需要冒号和回车                           |
| `3dd` | 删除当前行开始的3行 | 数字写在 `dd` 前面                         |
| `u`   | 撤销                | 要在一般模式按                             |

## 13. 重点片段精读

### 片段一：00:29-01:08

**表面发生了什么：**
视频回顾 VI 模式图，并在终端中进入 `-- INSERT --` 状态。

**更深层可能意味着：**

**重要性：**
模式判断错误，会导致后续全部命令无法正常执行。

------

### 片段二：01:30-02:07

**表面发生了什么：**
文件中的字符被删除，随后又恢复，底部出现撤销记录。

**更深层可能意味着：**
`x` 和 `u` 是最基础的一组练习：一个负责修改，一个负责纠错。先熟悉这两个命令，可以降低练习 VI 时的紧张感。

**重要性：**
帮助理解一般模式下按键是“执行动作”，而不是输入字符。

------

### 片段三：03:02-03:45

**表面发生了什么：**
一个单词从完整形式逐步变短，光标后的内容发生变化。

**更深层可能意味着：**
VI 删除命令不是只有“删除键”，而是根据范围不同选择 `x`、`dw`、`D`。操作效率来自对删除范围的精确描述。

**重要性：**
这是本节最需要区分的三个命令。

------

### 片段四：03:45-04:31

**表面发生了什么：**

**更深层可能意味着：**
数字可以控制命令作用次数，例如 `5dd`；删除出错后可以按 `u` 恢复；需要新增内容时可用 `o`直接创建新行。

**重要性：**
将删除、多行操作、新增和撤销连接成完整编辑流程。

## 14. 我应该重点看什么？

这段视频最值得反复看的不是所有命令，而是三个层次：

### 第一层：模式

```text
输入文字前按 i 或 o
输入完成后按 Esc
删除和撤销必须在一般模式
```

### 第二层：删除范围

```text

```

```text
u       撤销
```

## 15. 建议跟练示例

准备一个练习文件：

```bash
vi practice.txt
```

依次操作：

```text
按 i
输入：
apple banana cherry
line two
line three
line four

按 Esc
```

然后练习：

```text
把光标放在 apple 的 a 上，按 x
按 u 恢复

把光标放在 banana 的 b 上，按 dw
按 u 恢复

把光标放在第一行中间，按 D
按 u 恢复

把光标放到第二行，按 dd
按 u 恢复

把光标放到第二行，按 3dd
按 u 恢复

按 o
输入 new line
按 Esc
```

最后不想保留练习结果，可以输入：

```vim
:q!
```

保存结果则输入：

```vim
:wq
```
