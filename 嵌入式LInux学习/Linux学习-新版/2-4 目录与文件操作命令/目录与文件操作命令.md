我看了这个视频画面，它主要是在讲 **Linux 中目录与文件操作命令**，核心是让你掌握：**路径怎么写、目录怎么切换、文件/目录怎么创建、删除、复制、移动、查看**。

## 一、视频整体内容

视频大致围绕这几个点展开：

```text
1. 路径概念：
   绝对路径、相对路径、当前目录 .、上级目录 ..、家目录 ~、上一个目录 -

2. 目录相关命令：
   pwd、cd、mkdir、rmdir

3. 文件/目录查看与操作命令：
   ls、cp、rm、mv、cat、touch
```

其中老师是边看课件边在 Ubuntu 终端里演示，所以重点不是死记命令，而是理解“当前自己在哪里、要操作谁、结果去了哪里”。

------

## 二、路径部分：视频一开始重点讲的内容

### 1. 绝对路径

绝对路径就是 **从根目录 `/` 开始写的完整路径**。

例如：

```bash
/home/book
/home/book/1.txt
/bin/pwd
```

这里 `/` 是 Linux 的根目录，所有目录和文件都能从 `/` 开始找到。

### 2. 相对路径

相对路径就是 **相对于当前所在目录来写路径**。

假设当前在：

```bash
/home/book
```

那么：

```bash
./1.txt
```

表示：

```bash
/home/book/1.txt
```

其中：

```bash
.
```

表示当前目录。

```bash
..
```

表示上一级目录。

比如当前在：

```bash
/home/book
```

那么：

```bash
..
```

就是：

```bash
/home
```

## 三、pwd 和 cd：知道自己在哪，以及切换目录

### 1. `pwd`

```bash
pwd
```

作用：显示当前所在目录。

视频中演示：

```bash
pwd
```

输出：

```bash
/home/book
```

说明当前用户正处在 `/home/book` 目录下。

------

### 2. `cd`

```bash
cd 路径
```

作用：切换目录。

视频中演示了很多常见写法：

```bash
cd /
```

进入根目录 `/`。

```bash
cd /home/book/
```

进入 `/home/book` 目录。

```bash
cd ..
```

进入上一级目录。

```bash
cd ~
```

回到当前用户的家目录，也就是 `/home/book`。

```bash
cd -
```

回到上一次所在的目录。

这个命令很实用，比如你刚从 `/home/book` 切到 `/`，再输入：

```bash
cd -
```

就可以回到 `/home/book`。

## 四、视频中特别演示了一个容易混淆点：为什么 `hello` 不能直接运行

视频里演示了：

```bash
./hello
```

可以运行，输出：

```bash
hello, world!
```

但是直接输入：

```bash
hello
```

系统提示：

```text
Command 'hello' not found
```

原因是：

```bash
hello
```

这种写法会让系统去环境变量 `PATH` 里面找这个程序。

而当前目录一般不在 `PATH` 里面，所以找不到。

如果你明确告诉系统这个程序就在当前目录：

```bash
./hello
```

它就能运行。

也可以写绝对路径：

```bash
/home/book/hello
```

这也能运行。

所以这里的重点是：

```text
./hello 表示运行当前目录下的 hello 程序
hello 表示让系统去 PATH 路径里找 hello 程序
/home/book/hello 表示用绝对路径运行 hello 程序
```

## 五、mkdir 和 rmdir：创建目录、删除空目录

### 1. `mkdir`

```bash
mkdir 123
```

作用：创建一个名为 `123` 的目录。

课件里还提到：

```bash
mkdir -p dir1/dir2
```

作用是创建多级目录。

如果 `dir1` 不存在，使用 `-p` 可以自动创建父目录。

------

### 2. `rmdir`

```bash
rmdir 456
```

作用：删除空目录。

但是视频中演示：

```bash
rmdir 123
```

失败了，原因是：

```text
Directory not empty
```

也就是目录不为空。

所以要记住：

```text
rmdir 只能删除空目录
```

如果目录里面有文件，不能用 `rmdir` 直接删。

------

## 六、rm：删除文件或递归删除目录

视频中还演示了：

```bash
rm 2.txt
```

作用：删除普通文件。

但是如果你执行：

```bash
rm 123
```

系统会提示：

```text
Is a directory
```

因为 `123` 是目录，不是普通文件。

如果想删除目录以及目录里的内容，需要用：

```bash
rm -r 123
```

其中 `-r` 表示 recursive，递归删除。

这个命令要小心，尤其是：

```bash
rm -r
rm -rf
```

这类命令删除后通常不好恢复。

------

## 七、ls：查看目录内容

视频中重点演示了 `ls` 的几个用法。

### 1. 普通查看

```bash
ls
```

列出当前目录下的普通文件和目录。

### 2. 长格式查看

```bash
ls -l
```

会显示更详细的信息，比如：

```text
权限  链接数  所属用户  所属组  大小  修改时间  文件名
```

例如：

```text
-rw-r--r-- 1 book book 4 Aug 19 23:49 2.txt
```

这说明 `2.txt` 是一个普通文件，大小为 4 字节，所属用户和组都是 `book`。

### 3. 显示隐藏文件

```bash
ls -a
```

Linux 中以 `.` 开头的文件是隐藏文件，比如：

```bash
.bashrc
.profile
.ssh
.cache
.config
```

普通 `ls` 看不到这些文件，使用 `ls -a` 才能看到。

------

## 八、cp：复制文件

视频中演示：

```bash
cp 1.txt 2.txt
```

意思是：

```text
把 1.txt 复制一份，命名为 2.txt
```

执行后再 `ls`，可以看到目录中多了一个 `2.txt`。

如果复制到目录，也可以写成：

```bash
cp 1.txt ../
```

表示把 `1.txt` 复制到上一级目录。

------

## 九、mv：移动或重命名

`mv` 有两个常见作用：

```text
1. 重命名
2. 移动文件
```

### 1. 重命名

视频中演示：

```bash
mv 1.txt 2.txt
```

意思是把 `1.txt` 改名为 `2.txt`。

### 2. 移动文件

视频中还演示：

```bash
mv 2.txt ../
```

意思是把 `2.txt` 移动到上一级目录。

再把它移回来：

```bash
mv ../2.txt .
```

这里的 `.` 表示当前目录。

所以：

```bash
mv ../2.txt .
```

意思是：

```text
把上一级目录里的 2.txt 移动到当前目录
```

------

## 十、cat：查看文件内容

视频中演示了：

```bash
cat 2.txt
```

输出文件内容，例如：

```text
abc
```

也演示了文件名比较复杂时的写法：

```bash
cat '1 (copy).txt'
```

因为文件名中有空格和括号，所以用单引号括起来，防止 shell 把它拆开。

还演示了同时查看多个文件：

```bash
cat '1 (copy).txt' 2.txt
```

作用是依次输出两个文件的内容。

------

## 十一、touch：创建文件或更新时间

视频最后演示了：

```bash
touch 2.txt
```

如果 `2.txt` 已经存在，`touch` 会更新它的修改时间。

视频中还先用了：

```bash
date
```

查看当前时间，然后执行：

```bash
touch 2.txt
ls -l
```

可以看到 `2.txt` 的时间发生了变化。

所以 `touch` 有两个常见作用：

```text
1. 文件不存在：创建一个空文件
2. 文件已存在：更新文件的修改时间
```

## 十二、这节视频最重要的理解

这节课本质上是在教你建立 Linux 命令行的基本操作感：

```text
我现在在哪里？             pwd

我要去哪个目录？           cd

我要看当前目录有什么？      ls

我要创建目录？             mkdir

我要删除空目录？           rmdir

我要删除文件或非空目录？    rm / rm -r

我要复制文件？             cp

我要移动或重命名文件？      mv

我要查看文件内容？          cat

我要创建空文件或更新时间？  touch
```

你可以把这节视频理解为 Linux 文件系统操作的入门核心课。后面学权限、编译、运行程序、修改环境变量、写 shell 脚本，都会建立在这些命令基础上。
