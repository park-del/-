# 1.shell内置命令与外部程序

在上面视频涉及的命令中，可以这样分：

## 一、Shell 内置命令

这些命令由 **shell 自己实现**，不需要单独启动外部程序。

| 命令  | 类型                  | 说明                                                         |
| ----- | --------------------- | ------------------------------------------------------------ |
| `cd`  | Shell 内置命令        | 切换当前 shell 的工作目录                                    |
| `pwd` | 通常是 Shell 内置命令 | 显示当前目录，但系统里通常也有外部版本 `/bin/pwd` 或 `/usr/bin/pwd` |

最重要的是：

```bash
cd
```

一定是 shell 内置命令。

因为 `cd` 要改变的是 **当前 shell 进程自己的工作目录**。如果 `cd` 是外部程序，那么它只能改变它自己那个子进程的目录，退出后不会影响当前终端，所以 `cd` 必须由 shell 自己执行。

------

## 二、外部程序命令

<span style="color:#FF0000; background:#00FF80;">这些命令通常是磁盘上的可执行文件，shell 找到它们后，会启动一个新进程来运行。</span>

| 命令    | 类型     | 常见位置                         |
| ------- | -------- | -------------------------------- |
| `ls`    | 外部程序 | `/bin/ls` 或 `/usr/bin/ls`       |
| `mkdir` | 外部程序 | `/bin/mkdir` 或 `/usr/bin/mkdir` |
| `rmdir` | 外部程序 | `/bin/rmdir` 或 `/usr/bin/rmdir` |
| `rm`    | 外部程序 | `/bin/rm` 或 `/usr/bin/rm`       |
| `cp`    | 外部程序 | `/bin/cp` 或 `/usr/bin/cp`       |
| `mv`    | 外部程序 | `/bin/mv` 或 `/usr/bin/mv`       |
| `cat`   | 外部程序 | `/bin/cat` 或 `/usr/bin/cat`     |
| `touch` | 外部程序 | `/bin/touch` 或 `/usr/bin/touch` |
| `date`  | 外部程序 | `/bin/date` 或 `/usr/bin/date`   |

这些大多属于 GNU coreutils 工具集。

------

## 三、容易混淆的几个不是“命令”

<span style="color:#FF0000; background:#00FF80;">下面这些不是命令，而是路径或 shell 语法的一部分。</span>

| 写法         | 类型                 | 含义                                    |
| ------------ | -------------------- | --------------------------------------- |
| `.`          | 当前目录             | 例如 `./hello` 表示当前目录下的 `hello` |
| `..`         | 上一级目录           | 例如 `cd ..`                            |
| `~`          | shell 展开符号       | 表示当前用户家目录，例如 `/home/book`   |
| `-`          | `cd` 的参数          | 在 `cd -` 中表示回到上一次所在目录      |
| `/home/book` | 路径                 | 不是命令                                |
| `./hello`    | 执行当前目录下的程序 | `hello` 是你自己编译出来的外部程序      |

所以：

```bash
./hello
```

不是 shell 内置命令，而是让 shell 去执行当前目录下的 `hello` 这个可执行文件。

------

## 四、可以用什么命令查看类型？

最推荐用：

```bash
type 命令名
```

例如：

```bash
type cd
type pwd
type ls
type cp
```

可能看到类似结果：

```bash
cd is a shell builtin
pwd is a shell builtin
ls is /usr/bin/ls
cp is /usr/bin/cp
```

也可以用：

```bash
command -V cd
command -V ls
```

注意：`which` 主要查外部程序，不太适合判断内置命令。

------

## 五、总结一句话

这节视频里的命令可以这样记：

```text
cd 是典型 shell 内置命令；
pwd 通常既有内置版本，也有外部程序版本；
ls、mkdir、rmdir、rm、cp、mv、cat、touch、date 基本都是外部程序；
.、..、~、- 不是命令，而是路径/参数/展开符号。
```

# 3.命令深入理解

<span style="color:#FF0000; background:#00FF80;">这里的cp命令复制文件或目录是什么意思呢，如果文件或者目录不存在呢，还有cat和touch这两个命令都是怎么使用呢，如果文件不存在呢，还有ls命令是只能够列出目录内容吗，可以列出文件内容吗，就是上面这些命令可不可以给我分类下，哪些是可以对文件操作，哪些是可以对文件目录操作，哪些又是只能够对目录操作，以及操作的时候有什么注意事项呢，比如文件或者目录不存在的时候该怎么办呢？</span>

可以，这里你要抓住一个核心：

```text
Linux 命令操作对象大致分为三类：

1. 操作“文件内容”
2. 操作“文件/目录本身”
3. 操作“目录位置”
```

你现在问的 `cp`、`cat`、`touch`、`ls`，刚好容易混淆。

------

## 一、先回答你的几个具体问题

### 1. `cp` 复制文件或目录是什么意思？

`cp` 全称是 **copy**，意思是复制。

基本格式：

```bash
cp 源文件 目标位置
```

例如：

```bash
cp 1.txt 2.txt
```

意思是：

```text
复制 1.txt，生成一个新的 2.txt
```

此时 `1.txt` 还在，`2.txt` 是复制出来的新文件。

------

如果复制到目录中：

```bash
cp 1.txt test/
```

意思是：

```text
把 1.txt 复制到 test 目录里面
```

结果是：

```bash
test/1.txt
```

------

### 2. `cp` 复制目录是什么意思？

目录里面可能还有文件、子目录，所以复制目录时不能只复制“目录名字”，还要复制里面的所有内容。

因此复制目录通常要加 `-r`：

```bash
cp -r dir1 dir2
```

其中：

```text
-r = recursive = 递归
```

意思是：

```text
把 dir1 目录以及里面的所有文件、子目录都复制一份
```

例如原来是：

```text
dir1/
├── a.txt
└── sub/
    └── b.txt
```

执行：

```bash
cp -r dir1 dir2
```

如果 `dir2` 不存在，会得到：

```text
dir2/
├── a.txt
└── sub/
    └── b.txt
```

如果 `dir2` 已经存在，则通常会变成：

```text
dir2/
└── dir1/
    ├── a.txt
    └── sub/
        └── b.txt
```

------

### 3. 如果 `cp` 的文件或目录不存在怎么办？

#### 情况一：源文件不存在

```bash
cp aaa.txt bbb.txt
```

如果 `aaa.txt` 不存在，会报错：

```text
cp: cannot stat 'aaa.txt': No such file or directory
```

意思是：

```text
源文件都没有，没法复制
```

------

#### 情况二：目标文件不存在

```bash
cp 1.txt 2.txt
```

如果 `1.txt` 存在，`2.txt` 不存在，那么 `cp` 会自动创建 `2.txt`。

这个是允许的。

------

#### 情况三：目标目录不存在

```bash
cp 1.txt test/
```

如果 `test/` 不存在，会报错：

```text
No such file or directory
```

因为 `cp` 不会自动帮你创建目标目录。

你需要先：

```bash
mkdir test
cp 1.txt test/
```

------

#### 情况四：复制目录但没加 `-r`

```bash
cp dir1 dir2
```

如果 `dir1` 是目录，会报错：

```text
cp: -r not specified; omitting directory 'dir1'
```

所以复制目录要写：

```bash
cp -r dir1 dir2
```

------

## 二、`cat` 命令怎么使用？

`cat` 全称是 **concatenate**，本意是“连接文件内容”。

但是常用作用是：

```text
查看文件内容
```

### 1. 查看一个文件

```bash
cat 1.txt
```

如果 `1.txt` 里面是：

```text
hello
world
```

那么终端会显示：

```text
hello
world
```

------

### 2. 查看多个文件

```bash
cat 1.txt 2.txt
```

它会先输出 `1.txt` 的内容，再输出 `2.txt` 的内容。

所以 `cat` 原来的含义是：

```text
把多个文件内容连接起来输出
```

------

### 3. 如果文件不存在呢？

```bash
cat aaa.txt
```

如果 `aaa.txt` 不存在，会报错：

```text
cat: aaa.txt: No such file or directory
```

也就是说：

```text
cat 默认不会创建文件，它只是读取文件内容
```

------

### 4. `cat` 可以创建文件吗？

可以，但这时候要配合重定向符号 `>`。

```bash
cat > 1.txt
```

然后你输入内容：

```text
hello
world
```

输入完后按：

```text
Ctrl + D
```

结束输入。

这样就会创建 `1.txt`。

但是要注意：

```bash
cat > 1.txt
```

如果 `1.txt` 已经存在，会覆盖原来的内容。

如果想追加内容，用：

```bash
cat >> 1.txt
```

其中：

```text
>  表示覆盖写入
>> 表示追加写入
```

------

### 5. `cat` 可以查看目录内容吗？

不可以。

例如：

```bash
cat test
```

如果 `test` 是目录，会报错：

```text
cat: test: Is a directory
```

因为 `cat` 是查看**文件内容**的，不是查看目录结构的。

目录内容应该用：

```bash
ls test
```

------

## 三、`touch` 命令怎么使用？

`touch` 的意思可以理解成：

```text
轻轻碰一下文件
```

它有两个常见作用：

```text
1. 文件不存在：创建空文件
2. 文件存在：更新时间戳
```

------

### 1. 文件不存在时

```bash
touch 1.txt
```

如果 `1.txt` 不存在，会创建一个空文件：

```text
1.txt
```

这个文件内容为空，大小通常是 0 字节。

------

### 2. 文件存在时

```bash
touch 1.txt
```

如果 `1.txt` 已经存在，它不会修改里面的内容，只会更新文件的修改时间。

例如你用：

```bash
ls -l 1.txt
```

可以看到时间变化了。

------

### 3. 父目录不存在时

```bash
touch test/1.txt
```

如果 `test` 目录不存在，会报错：

```text
No such file or directory
```

因为 `touch` 可以创建文件，但不能自动创建父目录。

你要先：

```bash
mkdir test
touch test/1.txt
```

------

### 4. `touch` 能创建目录吗？

不能。

```bash
touch test
```

如果 `test` 不存在，它创建的是一个**普通文件**，不是目录。

创建目录要用：

```bash
mkdir test
```

------

## 四、`ls` 只能列出目录内容吗？能列出文件内容吗？

`ls` 的作用是：

```text
列出文件或目录的信息
```

它不能查看文件里面的正文内容。

------

### 1. 查看当前目录下有什么

```bash
ls
```

显示当前目录下的文件和目录。

------

### 2. 查看某个目录下有什么

```bash
ls test
```

显示 `test` 目录里面的内容。

------

### 3. 查看某个文件的信息

```bash
ls 1.txt
```

如果 `1.txt` 存在，它会显示：

```text
1.txt
```

如果想看详细信息：

```bash
ls -l 1.txt
```

可能显示：

```text
-rw-r--r-- 1 book book 12 May 29 10:00 1.txt
```

这个显示的是文件的：

```text
权限、所属用户、大小、修改时间、文件名
```

但不是文件内容。

------

### 4. 查看文件内容应该用什么？

应该用：

```bash
cat 1.txt
```

或者文件很长时用：

```bash
less 1.txt
```

所以区别是：

```text
ls  看文件/目录的名字和属性
cat 看文件里面的内容
```

------

## 五、这些命令按操作对象分类

## 1. 主要操作目录位置的命令

| 命令  | 作用         | 操作对象              |
| ----- | ------------ | --------------------- |
| `pwd` | 显示当前目录 | 当前 shell 的工作目录 |
| `cd`  | 切换目录     | 目录                  |

例如：

```bash
pwd
cd /home/book
cd ..
cd ~
```

注意：

```text
cd 后面必须是目录，不能是普通文件
```

例如：

```bash
cd 1.txt
```

如果 `1.txt` 是文件，会报错：

```text
Not a directory
```

------

### 2. 只用于目录操作的命令

| 命令    | 作用       | 注意事项                    |
| ------- | ---------- | --------------------------- |
| `mkdir` | 创建目录   | 父目录必须存在，除非加 `-p` |
| `rmdir` | 删除空目录 | 只能删除空目录              |

例如：

```bash
mkdir test
rmdir test
```

如果要创建多级目录：

```bash
mkdir -p a/b/c
```

如果目录不为空：

```bash
rmdir test
```

会失败。

删除非空目录要用：

```bash
rm -r test
```

------

### 3. 主要操作文件内容的命令

| 命令    | 作用                 | 文件不存在时 |
| ------- | -------------------- | ------------ |
| `cat`   | 查看/连接文件内容    | 报错         |
| `touch` | 创建空文件或更新时间 | 创建空文件   |

例如：

```bash
cat 1.txt
touch 1.txt
```

注意：

```text
cat 是读取文件内容
touch 是创建空文件或更新时间
```

------

### 4. 文件和目录都可以操作的命令

| 命令 | 文件                | 目录                 | 注意事项             |
| ---- | ------------------- | -------------------- | -------------------- |
| `ls` | 可以查看文件信息    | 可以列出目录内容     | 不能查看文件正文内容 |
| `cp` | 可以复制文件        | 加 `-r` 才能复制目录 | 目标可能被覆盖       |
| `mv` | 可以移动/重命名文件 | 可以移动/重命名目录  | 目标存在时要小心     |
| `rm` | 可以删除文件        | 加 `-r` 才能删除目录 | 删除后通常不好恢复   |

------

## 六、几个命令的“不存在”情况总结

| 命令                 | 操作对象不存在时会怎样？        |
| -------------------- | ------------------------------- |
| `ls aaa`             | 报错：找不到                    |
| `cat aaa.txt`        | 报错：找不到                    |
| `cd aaa`             | 报错：找不到目录                |
| `rm aaa.txt`         | 报错：找不到；可用 `rm -f` 忽略 |
| `cp aaa.txt bbb.txt` | 源文件不存在会报错              |
| `mv aaa.txt bbb.txt` | 源文件不存在会报错              |
| `touch aaa.txt`      | 文件不存在则创建空文件          |
| `mkdir aaa`          | 目录不存在则创建目录            |
| `rmdir aaa`          | 目录不存在会报错                |

------

## 七、最容易记混的地方

### 1. `ls` 和 `cat`

```bash
ls 1.txt
```

看的是：

```text
这个文件是否存在、文件名、文件属性
cat 1.txt
```

看的是：

```text
这个文件里面写了什么内容
```

------

### 2. `mkdir` 和 `touch`

```bash
mkdir test
```

创建的是：

```text
目录 / 文件夹
touch test
```

创建的是：

```text
普通文件
```

------

### 3. `rmdir` 和 `rm -r`

```bash
rmdir test
```

只能删除：

```text
空目录
rm -r test
```

可以删除：

```text
非空目录，包括里面的所有内容
```

所以 `rm -r` 要小心。

------

### 4. `cp` 和 `mv`

```bash
cp 1.txt 2.txt
```

复制：

```text
1.txt 还在，新增 2.txt
mv 1.txt 2.txt
```

移动/重命名：

```text
1.txt 不在了，变成 2.txt
```

------

## 八、一个总表总结

| 命令    | 对文件              | 对目录                     | 文件/目录不存在时                    |
| ------- | ------------------- | -------------------------- | ------------------------------------ |
| `pwd`   | 不操作文件          | 显示当前目录               | 不涉及                               |
| `cd`    | 不能进入普通文件    | 可以切换目录               | 目录不存在会报错                     |
| `ls`    | 显示文件名/属性     | 显示目录内容               | 报错                                 |
| `mkdir` | 不创建普通文件      | 创建目录                   | 目录不存在则创建                     |
| `rmdir` | 不能删文件          | 删除空目录                 | 目录不存在报错                       |
| `rm`    | 删除文件            | 加 `-r` 删除目录           | 默认报错，可用 `-f` 忽略             |
| `cp`    | 复制文件            | 加 `-r` 复制目录           | 源不存在报错，目标文件可自动创建     |
| `mv`    | 移动/重命名文件     | 移动/重命名目录            | 源不存在报错                         |
| `cat`   | 查看文件内容        | 不能查看目录内容           | 文件不存在报错                       |
| `touch` | 创建空文件/更新时间 | 可更新时间戳，但不创建目录 | 文件不存在会创建，父目录不存在会报错 |

------

一句话记忆：

```text
看位置用 pwd；
换位置用 cd；
看名字用 ls；
看内容用 cat；
建目录用 mkdir；
建空文件用 touch；
复制用 cp；
移动改名用 mv；
删文件用 rm；
删空目录用 rmdir；
删非空目录用 rm -r。
```





# 4.-r选项递归地创建或者删除

这里的“递归”可以先理解成一句话：

```text
遇到目录时，不只处理这个目录本身，还会继续处理它里面的文件、子目录、子目录里的子目录……
```

也就是“层层往里面处理”。

------

## 一、什么叫递归地删除？

假设有这样一个目录结构：

```text
test/
├── a.txt
├── b.txt
└── dir1/
    ├── c.txt
    └── dir2/
        └── d.txt
```

如果你执行：

```bash
rm test
```

会失败，因为 `test` 是目录，<span style="color:#FF0000; background:#00FF80;">普通 `rm` 默认只删除文件。</span>

如果执行：

```bash
rm -r test
```

意思是：

```text
删除 test 目录；
发现 test 里面有 a.txt，删除；
发现 test 里面有 b.txt，删除；
发现 test 里面有 dir1，继续进入 dir1；
发现 dir1 里面有 c.txt，删除；
发现 dir1 里面有 dir2，继续进入 dir2；
发现 dir2 里面有 d.txt，删除；
最后把 dir2、dir1、test 这些空目录也删掉。
```

所以 `rm -r test` 的效果是：

```text
整个 test 目录以及里面所有内容都会被删除
```

这里的 `-r` 就是：

```text
recursive = 递归的
```

------

## 二、什么叫递归地复制？

假设原来有：

```text
dir1/
├── a.txt
└── sub/
    └── b.txt
```

如果你执行：

```bash
cp dir1 dir2
```

通常会失败，因为 `dir1` 是目录。

要复制目录，需要：

```bash
cp -r dir1 dir2
```

意思是：

```text
复制 dir1；
发现 dir1 里面有 a.txt，复制；
发现 dir1 里面有 sub 目录，继续进入 sub；
发现 sub 里面有 b.txt，复制；
最后把整个目录结构都复制过去。
```

复制后可能得到：

```text
dir2/
├── a.txt
└── sub/
    └── b.txt
```

所以 `cp -r` 不是只复制一个空壳目录，而是把目录里面的内容也一起复制。

------

## 三、创建目录的递归不是 `-r`，而是 `-p`

这里要注意一个小区别：

```bash
rm -r
cp -r
```

这里的 `-r` 是递归删除、递归复制。

但是创建多级目录一般不是用 `-r`，而是用：

```bash
mkdir -p
```

例如你想创建：

```text
a/b/c
```

如果直接写：

```bash
mkdir a/b/c
```

但是 `a` 和 `b` 都不存在，就会报错。

应该写：

```bash
mkdir -p a/b/c
```

意思是：

```text
如果 a 不存在，先创建 a；
进入 a，如果 b 不存在，创建 b；
进入 b，再创建 c。
```

最后得到：

```text
a/
└── b/
    └── c/
```

所以：

```text
rm -r：递归删除目录
cp -r：递归复制目录
mkdir -p：递归/逐层创建父目录
```

------

## 四、用生活例子理解

你可以把目录理解成文件夹。

普通删除：

```text
只会删除一张纸
```

递归删除：

```text
删除整个文件夹；
如果里面还有小文件夹，也继续打开小文件夹，把里面的东西都删掉。
```

普通复制：

```text
只能复制一张纸
```

递归复制：

```text
复制整个文件夹；
里面的小文件夹、小文件、小文件夹里面的文件，也全部照样复制。
```

递归创建：

```text
你想创建 a/b/c；
如果 a 没有，就先建 a；
b 没有，就再建 b；
最后再建 c。
```

------

## 五、为什么叫“递归”？

因为它的逻辑是：

```text
处理当前目录
如果遇到子目录
    就用同样的方法继续处理子目录
```

比如删除目录时：

```text
删除 test
    删除 a.txt
    删除 b.txt
    删除 dir1
        删除 c.txt
        删除 dir2
            删除 d.txt
```

你会发现：

```text
删除 dir1 的方法，和删除 test 的方法是一样的；
删除 dir2 的方法，和删除 dir1 的方法也是一样的。
```

这种“自己调用同样的方法继续处理下一层”的思想，就叫递归。

------

## 六、几个常见命令总结

| 命令                | 作用                     | 是否递归     |
| ------------------- | ------------------------ | ------------ |
| `rm 文件`           | 删除文件                 | 不递归       |
| `rm -r 目录`        | 删除目录以及里面全部内容 | 递归         |
| `cp 文件1 文件2`    | 复制文件                 | 不递归       |
| `cp -r 目录1 目录2` | 复制目录以及里面全部内容 | 递归         |
| `mkdir 目录`        | 创建单个目录             | 不递归       |
| `mkdir -p a/b/c`    | 逐层创建多级目录         | 类似递归创建 |

------

## 七、注意事项

`rm -r` 要特别小心，因为它会删除整个目录树。

比如：

```bash
rm -r test
```

会删除：

```text
test 目录本身 + test 里面所有文件 + 所有子目录 + 子目录里的内容
```

使用前最好先看一下：

```bash
ls test
```

确认里面是什么，再删除。

你可以这样记：

```text
-r = 一层一层往里面处理
-p = 创建目录时，父目录没有就一起创建
```



# 5. mkdir -r 创建多级目录

<span style="color:#FF0000; background:#00FF80;">mkdir -p a/b/c 这个命令最后创建的目录在当前目录是什么样的呢，是a在当前目录还是c在当前目录呢？</span>

执行：

```bash
mkdir -p a/b/c
```

最后在**<span style="background:#00FF80;">当前目录下创建的是 `a` 目录</span>**，然后 `a` 里面有 `b`，`b` 里面有 `c`。

目录结构是这样的：

```text
当前目录/
└── a/
    └── b/
        └── c/
```

所以不是 `c` 直接在当前目录下，而是：

```text
a 在当前目录下
b 在 a 里面
c 在 b 里面
```

你可以这样理解：

```bash
mkdir -p a/b/c
```

等价于一步一步执行：

```bash
mkdir a
mkdir a/b
mkdir a/b/c
```

或者更形象地说：

```text
先在当前目录创建 a 文件夹；
再进入 a 的里面创建 b 文件夹；
再进入 b 的里面创建 c 文件夹。
```

验证一下可以用：

```bash
ls
```

你会看到当前目录下有：

```text
a
```

然后：

```bash
ls a
```

会看到：

```text
b
```

再：

```bash
ls a/b
```

会看到：

```text
c
```

如果想让 `c` 直接出现在当前目录下，那就应该执行：

```bash
mkdir c
```

或者如果想同时在当前目录下创建 `a`、`b`、`c` 三个并列目录，应写成：

```bash
mkdir a b c
```

结构就是：

```text
当前目录/
├── a/
├── b/
└── c/
```
