## 三、重点命令整理

### 1. 查看文件权限和属性

```bash
ls -l hello
```

输出示例：

```bash
-rwxrwxr-x 1 book book 8304 Aug 6 04:47 hello
```

可以拆成：

```text
- rwx rwx r-x
│  │   │   │
│  │   │   └── 其他用户权限
│  │   └────── 同组用户权限
│  └────────── 所有者权限
└───────────── 文件类型
```

其中：

```text
r = read，读权限
w = write，写权限
x = execute，执行权限
```

------

### 2. `chmod` 修改权限

数字法：

```bash
chmod 777 hello
chmod 775 hello
chmod 675 hello
```

数字含义：

```text
r = 4
w = 2
x = 1
```

所以：

```text
7 = 4 + 2 + 1 = rwx
6 = 4 + 2 = rw-
5 = 4 + 1 = r-x
```

例如：

```bash
chmod 775 hello
```

表示：

```text
所有者：rwx
同组用户：rwx
其他用户：r-x
```

------

### 3. 符号法修改权限

```bash
chmod +x hello
chmod -x hello
chmod a+x hello
chmod a-x hello
chmod u+x hello
chmod u-x hello
```

含义：

```text
u = user，所有者
g = group，同组用户
o = other，其他用户
a = all，所有用户
+ = 增加权限
- = 删除权限
```

例如：

```bash
chmod a+x hello
```

表示：给所有用户增加执行权限。

```bash
chmod u-x hello
```

表示：去掉所有者的执行权限。

------

### 4. `chown` 修改文件所有者

```bash
chown 用户名 文件名
chown 用户名:用户组 文件名
```

视频中的例子：

```bash
chown root:root hello
```

普通用户执行会失败：

```bash
Operation not permitted
```

需要使用：

```bash
sudo chown root:root hello
```

再改回来：

```bash
sudo chown book:book hello
```

------

### 5. `chgrp` 修改所属用户组

```bash
chgrp 用户组 文件名
```

例如：

```bash
chgrp hy install.log
```

意思是把 `install.log` 文件的所属用户组改成 `hy`。

注意：这个用户组必须存在，可以在 `/etc/group` 文件中查看。

------

### 6. `sudo` 和 root 权限

普通用户权限不够时，可以在命令前加：

```bash
sudo
```

例如：

```bash
sudo cp hello /bin
sudo chown root:root hello
```

视频中还提到 Ubuntu 默认不推荐直接使用 root 用户登录，更推荐：

```bash
sudo 命令
```

如果一定要启用 root 密码，可以：

```bash
sudo passwd root
su root
```

不过日常学习时，能用 `sudo` 就不要长期切换到 root。

------

## 四、这一节最核心的理解

这节的核心不是背命令，而是理解这句话：

> Linux 中每个文件都有“所有者、所属组、其他用户”三类身份，每类身份都有自己的 `rwx` 权限。

也就是说，看到：

```bash
-rwxrwxr-x
```

你要能立刻拆成：

```text
文件类型：普通文件
所有者权限：rwx
同组用户权限：rwx
其他用户权限：r-x
```

然后再能根据需要用：

```bash
chmod
chown
chgrp
sudo
```

去修改权限、所有者和所属用户组。
