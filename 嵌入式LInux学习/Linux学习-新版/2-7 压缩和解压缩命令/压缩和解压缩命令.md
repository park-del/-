# 视频总结

这个视频主要讲 **Linux 中的压缩和解压缩命令**，属于课程里的 **2.3.5 压缩/解压缩命令**。<span style="color:#FF0000; background:#00FF80;">核心内容是三个命令：</span>

```bash
gzip
bzip2
tar
```

其中：

**`gzip` / `bzip2` 主要压缩单个文件。**
**`tar` 主要用于打包目录或多个文件，也可以配合 gzip/bzip2 压缩。**

## 二、视频中的核心命令

### 1. `gzip`：压缩单个文件

视频中的命令：

```bash
gzip -k test
```

意思是：

```text
压缩 test 文件，生成 test.gz，同时保留原文件 test。
```

如果不加 `-k`：

```bash
gzip test
```

那么压缩后通常会变成：

```text
test.gz
```

原来的 `test` 会被删除。

所以视频里强调：
**建议使用 `gzip -k`，这样可以保留原文件。**

------

### 2. `gzip -d`：解压 `.gz` 文件

视频中的命令：

```bash
gzip -dk test.gz
```

拆开看：

| 部分      | 含义           |
| --------- | -------------- |
| `gzip`    | 使用 gzip 工具 |
| `-d`      | 解压缩         |
| `-k`      | 保留压缩包     |
| `test.gz` | 要解压的文件   |

所以：

```bash
gzip -dk test.gz
```

意思是：

```text
解压 test.gz，恢复出 test，同时保留 test.gz。
```

视频里出现了一个提示：

```bash
gzip: test already exists; do you wish to overwrite (y or n)?
```

意思是：

```text
test 文件已经存在了，要不要覆盖？
```

因为当前目录里已经有 `test`，所以解压时会询问是否覆盖。

------

### 3. `bzip2`：另一种单文件压缩工具

视频中的命令：

```bash
bzip2 -k test
```

意思是：

```text
压缩 test，生成 test.bz2，并保留原文件 test。
```

解压命令是：

```bash
bzip2 -dk test.bz2
```

意思是：

```text
解压 test.bz2，恢复 test，同时保留 test.bz2。
```

------

## 三、`gzip` 和 `bzip2` 的区别

| 命令    | 压缩后缀 | 主要特点                         |
| ------- | -------- | -------------------------------- |
| `gzip`  | `.gz`    | 常用，速度较快                   |
| `bzip2` | `.bz2`   | 压缩率通常更高，但速度可能慢一些 |

视频中用同一个 `test` 文件测试，结果大概是：

```bash
test       原文件，约 1048576 字节
test.gz    gzip 压缩后，约 1056 字节
test.bz2   bzip2 压缩后，约 45 字节
```

这个例子里 `bzip2` 压得更小。

不过要注意：
这是因为测试文件内容比较特殊，全是 0，所以压缩效果特别明显。

------

## 四、为什么还需要 `tar`？

因为 `gzip` 和 `bzip2` 主要压缩 **单个文件**，不能直接很好地压缩整个目录。

如果要压缩目录，比如：

```bash
abc/
```

就需要先用 `tar` 把目录打包成一个文件，再配合 `gzip` 或 `bzip2` 压缩。

可以这样理解：

```text
tar = 先把多个文件/目录装进一个包
gzip/bzip2 = 再把这个包压小
```

## 五、`tar` 常用选项

视频中课件讲了这些：

| 选项 | 含义                        |
| ---- | --------------------------- |
| `c`  | create，创建压缩包/打包文件 |
| `x`  | extract，解包/解压          |
| `t`  | 查看压缩包里的内容          |
| `z`  | 使用 gzip 方式处理          |
| `j`  | 使用 bzip2 方式处理         |
| `v`  | 显示详细过程                |
| `f`  | 指定文件名                  |
| `-C` | 解压到指定目录              |

## 六、`tar.gz` 和 `tar.bz2` 的压缩

### 1. 使用 gzip 方式压缩

视频中的命令：

```bash
tar czf test.tar.gz test
```

拆开看：

| 部分          | 含义               |
| ------------- | ------------------ |
| `tar`         | 使用 tar 工具      |
| `c`           | 创建压缩包         |
| `z`           | 使用 gzip 压缩     |
| `f`           | 后面接压缩包文件名 |
| `test.tar.gz` | 生成的压缩包名字   |
| `test`        | 要压缩的文件       |

所以这句的意思是：

```text
把 test 打包并用 gzip 压缩，生成 test.tar.gz。
```

------

### 2. 使用 bzip2 方式压缩

视频中的命令：

```bash
tar cjf test.tar.bz2 test
```

拆开看：

| 部分           | 含义            |
| -------------- | --------------- |
| `c`            | 创建            |
| `j`            | 使用 bzip2 压缩 |
| `f`            | 指定压缩包名字  |
| `test.tar.bz2` | 生成的压缩包    |
| `test`         | 被压缩对象      |

所以这句的意思是：

```text
把 test 打包并用 bzip2 压缩，生成 test.tar.bz2。
```

------

## 七、`tar` 解压命令

视频中给出的记法是：

```bash
tar xzf test.tar.gz
```

意思是：

```text
解压 gzip 格式的 tar 包。
```

对应：

```bash
tar xjf test.tar.bz2
```

意思是：

```text
解压 bzip2 格式的 tar 包。
```

可以记成：

```text
.gz  用 z
.bz2 用 j
```

------

## 八、压缩目录 `abc`

视频后半部分重点演示了压缩目录。

命令：

```bash
tar cjf abc.tar.bz2 abc
```

意思是：

```text
把 abc 目录打包并用 bzip2 压缩，生成 abc.tar.bz2。
```

然后删除原目录：

```bash
rm abc -rf
```

再解压：

```bash
tar xjf abc.tar.bz2
```

解压后，`abc` 目录又恢复出来了。

------

## 九、解压到指定目录

视频中还演示了：

```bash
tar xjf abc.tar.bz2 -C tmp
```

意思是：

```text
把 abc.tar.bz2 解压到 tmp 目录中。
```

这里的：

```bash
-C tmp
```

表示：

```text
指定解压目标目录为 tmp。
```

所以如果不加 `-C tmp`，默认解压到当前目录；
如果加了 `-C tmp`，就解压到 `tmp` 里面。

## 十、视频里的一个错误演示

视频后面出现了这个错误：

```bash
tar: abc: Cannot stat: No such file or directory
tar: Exiting with failure status due to previous errors
```

原因是执行：

```bash
tar czf abc.tar.gz abc
```

时，当前目录下没有 `abc` 目录。

也就是说，命令的意思是：

```text
我要压缩 abc 这个目录
```

但是系统发现：

```text
当前目录下没有 abc
```

所以报错。

后来视频中先用：

```bash
tar xjf abc.tar.bz2
```

把 `abc` 解压恢复出来，再执行：

```bash
tar czf abc.tar.gz abc
```

这次就成功生成了：

```bash
abc.tar.gz
```

## 十一、整体记忆版

这个视频可以这样记：

```text
gzip：压缩单个文件，生成 .gz
bzip2：压缩单个文件，生成 .bz2
tar：打包文件/目录，可以配合 gzip 或 bzip2 压缩
```

最常用命令记这几个就够了：

```bash
gzip -k 文件名
gzip -dk 文件名.gz

bzip2 -k 文件名
bzip2 -dk 文件名.bz2

tar czf xxx.tar.gz 文件或目录
tar xzf xxx.tar.gz

tar cjf xxx.tar.bz2 文件或目录
tar xjf xxx.tar.bz2
```

一句话总结：

<span style="background:#00FF80;">**`gzip` 和 `bzip2` 是“压缩单个文件”；`tar` 是“先打包，再配合 gzip/bzip2 压缩目录或多个文件”。**</span>
