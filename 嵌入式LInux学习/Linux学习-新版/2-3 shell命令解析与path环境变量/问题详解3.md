# 问题1

<span style="color:#FF0000; background:#00FF80;">我有个问题，就是视频中为什么是在修改环境变量时为什么追加的是/home/book，那个hello不应该是在桌面的吗，还有/etc/environment这个里面应该是有path的吧，~/.bashrc这个也是有path的吧，这两个又该怎么理解呢，用户的目录是在/根目录下面的吗。</span>

你这里问到了几个很关键的点，我分开解释。核心先记住一句话：

```text
PATH 里面添加的不是 hello 这个程序本身，而是 hello 所在的目录。
```

------

## 1. 为什么视频里追加的是 `/home/book`？

你看到的命令是：

```bash
export PATH=$PATH:/home/book
```

它的意思是：

```text
让 shell 以后找命令时，除了原来的目录，也去 /home/book 这个目录里找。
```

也就是说，如果你想直接输入：

```bash
hello
```

就能运行，那么 `hello` 这个可执行文件必须放在 `/home/book` 目录下面：

```bash
/home/book/hello
```

这样 shell 才能通过 PATH 找到它。

------

## 2. 如果 hello 在桌面，应该追加哪里？

如果你的 `hello` 确实在桌面，比如路径是：

```bash
/home/book/Desktop/hello
```

那么你应该追加的是：

```bash
export PATH=$PATH:/home/book/Desktop
```

而不是：

```bash
export PATH=$PATH:/home/book
```

因为 PATH 只会查找它里面列出的目录，不会自动递归查找子目录。

也就是说，如果 PATH 里面有：

```bash
/home/book
```

shell 会找：

```bash
/home/book/hello
```

但不会自动去找：

```bash
/home/book/Desktop/hello
```

所以这里要分情况：

```text
如果 hello 在 /home/book 下面，追加 /home/book 是对的。

如果 hello 在 /home/book/Desktop 下面，应该追加 /home/book/Desktop。
```

------

## 3. PATH 里面添加的是“目录”，不是“程序”

这个很重要。

假设你有一个程序：

```bash
/home/book/Desktop/hello
```

正确写法是：

```bash
export PATH=$PATH:/home/book/Desktop
```

不要写成：

```bash
export PATH=$PATH:/home/book/Desktop/hello
```

因为 PATH 的作用是告诉 shell：

```text
去哪些文件夹里找命令。
```

而不是告诉 shell：

```text
某一个具体命令在哪里。
```

你可以把 PATH 理解成“搜索目录列表”。

------

## 4. `/etc/environment` 和 `~/.bashrc` 里都可以有 PATH 吗？

<span style="color:#FF0000; background:#00FF80;">可以，但它们的作用范围不一样。</span>

## `/etc/environment`

这是一个<span style="background:#00FF80;">**系统级环境变量配置文件**。</span>

路径是：

```bash
/etc/environment
```

它<span style="color:#FF0000;">一般对整个系统、所有用户生效。</span>

里面可能有类似：

```bash
PATH="/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"
```

它的特点是：

```text
作用范围大，偏系统级；
通常需要管理员权限才能修改；
修改后一般需要重新登录或重启才能完全生效；
不建议初学者随便改。
```

------

## `~/.bashrc`

这是当前用户自己的 bash 配置文件。

如果当前用户是 `book`，那么：

```bash
~/.bashrc
```

其实就是：

```bash
/home/book/.bashrc
```

它只影响当前这个用户的 bash 终端。

你可以在里面加：

```bash
export PATH=$PATH:/home/book/Desktop
```

这样每次打开新的终端，bash 都会自动执行这句话，于是新的终端里 PATH 就包含 `/home/book/Desktop`。

它的特点是：

```text
只影响当前用户；
适合普通用户自己配置；
修改后可以用 source ~/.bashrc 立即生效。
```

例如：

```bash
source ~/.bashrc
```

意思是让当前终端重新读取 `.bashrc`。

------

## 5. `/etc/environment` 和 `~/.bashrc` 的关系怎么理解？

可以这样理解：

```text
/etc/environment 是系统先给你的默认环境变量。
~/.bashrc 是你打开 bash 后，当前用户自己再额外修改的配置。
```

比如系统一开始给你：

```bash
PATH="/usr/bin:/bin"
```

然后你的 `~/.bashrc` 里面又写了：

```bash
export PATH=$PATH:/home/book/Desktop
```

那么打开终端后，最终 PATH 可能变成：

```bash
/usr/bin:/bin:/home/book/Desktop
```

也就是：

```text
系统先设置基础 PATH；
用户自己的 bash 配置再追加一些目录。
```

------

## 6. 那到底应该改哪个？

学习阶段更推荐改：

```bash
~/.bashrc
```

比如你的 `hello` 在桌面：

```bash
/home/book/Desktop/hello
```

那么可以在 `~/.bashrc` 最后加：

```bash
export PATH=$PATH:/home/book/Desktop
```

然后执行：

```bash
source ~/.bashrc
```

这样当前终端立即生效。

不太建议初学时直接改：

```bash
/etc/environment
```

因为它是系统级配置，影响范围更大，改错了可能导致很多命令路径异常。

------

## 7. 用户目录是不是在 `/` 根目录下面？

是的，但要说准确一点。

Linux 的所有目录都从根目录 `/` 开始。

目录结构大概是：

```text
/
├── bin
├── etc
├── home
│   ├── book
│   │   ├── Desktop
│   │   ├── Documents
│   │   └── Downloads
│   └── zhangsan
├── root
├── usr
└── var
```

其中：

```bash
/
```

是整个 Linux 文件系统的根目录。

```bash
/home
```

是普通用户家目录所在的总目录。

```bash
/home/book
```

是 `book` 用户自己的家目录。

```bash
/home/book/Desktop
```

是 `book` 用户家目录下面的桌面目录。

所以可以说：

```text
用户目录 /home/book 在根目录 / 下面的 home 目录中。
```

也就是：

```text
/ → home → book
```

------

## 8. 注意区分 `/`、`/root` 和 `root 用户`

这三个很容易混。

## `/`

这是根目录，Linux 所有文件的起点。

```bash
/
```

------

## `root`

这是管理员用户的名字。

比如：

```bash
root@ubuntu:~#
```

这里的 `root` 是用户名。

------

## `/root`

这是 root 管理员用户的家目录。

普通用户 `book` 的家目录一般是：

```bash
/home/book
```

<span style="color:#FF0000; background:#00FF80;">root 用户的家目录一般是：</span>

```bash
/root
```

所以：

```text
/ 是根目录；
root 是管理员用户；
/root 是管理员用户的家目录。
```

这三个不是一个东西。

------

## 9. 用你的视频例子串起来理解

假设当前用户是 `book`。

如果你把 `hello` 编译在桌面：

```bash
/home/book/Desktop/hello
```

那么运行它有三种方式。

### 方式一：写完整路径

```bash
/home/book/Desktop/hello
```

------

### 方式二：进入桌面后写 `./hello`

```bash
cd /home/book/Desktop
./hello
```

这里 `./hello` 表示：

```text
当前目录下的 hello。
```

------

### 方式三：把桌面目录加入 PATH

```bash
export PATH=$PATH:/home/book/Desktop
```

之后你就可以直接输入：

```bash
hello
```

shell 会去 PATH 中的 `/home/book/Desktop` 里找 `hello`。

## 10. 最后总结

你这个问题可以总结成四句话：

```text
1. PATH 里面添加的是目录，不是具体程序文件。

2. 如果 hello 在 /home/book，就追加 /home/book。

3. 如果 hello 在 /home/book/Desktop，就应该追加 /home/book/Desktop。

4. /etc/environment 是系统级环境变量配置，~/.bashrc 是当前用户的 bash 配置文件。
```

再加一句目录结构：

```text
/ 是根目录；
/home 在 / 下面；
/home/book 是 book 用户的家目录；
/home/book/Desktop 是 book 用户家目录下的桌面目录。
```





# 问题2：/usr 与 /home目录区分

<span style="color:#FF0000; background:#00FF80;">这个~/.bashrc前面有个点，表示这是一个隐藏文件吗，这里~应该表示的是用户的家目录吧，即/home/用户名 这个目录，我好像在根目录下面看到一个 /usr 这个目录，这个和/home目录有什么区别呢，感觉很容易把/usr当成是用户的家目录。</span>

对，你理解得很对：

```bash
~/.bashrc
```

这里可以拆成：

```text
~        当前用户的家目录
/        路径分隔符
.bashrc  一个以点开头的隐藏文件
```

如果当前用户是 `book`，那么：

```bash
~/.bashrc
```

就等价于：

```bash
/home/book/.bashrc
```

------

## 1. `.bashrc` 前面的点是什么意思？

在 Linux 中<span style="background:#00FF80;">，**文件名或目录名如果以 `.` 开头，通常就是隐藏文件或隐藏目录**。</span>

比如：

```bash
.bashrc
.profile
.ssh
.config
.cache
```

这些都是隐藏文件或隐藏目录。

普通执行：

```bash
ls
```

一般看不到它们。

要显示隐藏文件，需要加 `-a`：

```bash
ls -a
```

比如你在家目录下执行：

```bash
cd ~
ls -a
```

就可能看到：

```text
.bashrc
.profile
.ssh
.config
```

所以：

```text
.bashrc 是隐藏文件
```

<span style="color:#FF0000; background:#00FF80;">它隐藏不是因为不能用，而是因为它属于配置文件，平时不需要频繁看到。</span>

------

## 2. `~` 是什么？

`~` 表示**当前用户的家目录**。

如果当前用户是 `book`：

```bash
~
```

等价于：

```bash
/home/book
```

如果当前用户是 `arley`：

```bash
~
```

等价于：

```bash
/home/arley
```

如果当前用户是 `root`：

```bash
~
```

通常等价于：

```bash
/root
```

所以一定要注意：

```text
~ 不是固定等于 /home/book
~ 表示“当前用户的家目录”
```

你可以用下面命令查看自己的家目录：

```bash
echo $HOME
```

或者：

```bash
cd ~
pwd
```

------

## 3. `/home` 是什么？

`/home` 是普通用户家目录的总目录。

Linux 的目录结构大概是这样：

```text
/
├── home
│   ├── book
│   ├── arley
│   └── zhangsan
├── usr
├── etc
├── bin
├── var
├── root
└── tmp
```

比如：

```bash
/home/book
```

是 `book` 用户的家目录。

```bash
/home/arley
```

是 `arley` 用户的家目录。

```bash
/home/zhangsan
```

是 `zhangsan` 用户的家目录。

所以 `/home` 里面主要放的是：

```text
普通用户自己的文件、桌面、下载、文档、个人配置等
```

例如：

```text
/home/book/Desktop
/home/book/Documents
/home/book/Downloads
/home/book/.bashrc
/home/book/.config
```

这就<span style="color:#FF0000; background:#00FF80;">类似 Windows 里的：</span>

```text
C:\Users\用户名
```

------

## 4. `/usr` 是什么？

你看到根目录下面还有一个：

```bash
/usr
```

这个<span style="color:#FF0000; background:#00FF80;">确实很容易误会成 “user”。</span>

但是在现代 Linux 中，你<span style="color:#FF0000; background:#00FF80;">不要把 `/usr` 理解成“用户家目录”。</span>

更准确地说：

```text
/usr 主要存放系统安装的软件、命令、库文件、共享资源等。
```

比如：

```text
/usr/bin      很多普通命令程序
/usr/lib      程序运行需要的库文件
/usr/include  C/C++ 头文件
/usr/share    共享数据、文档、图标等
/usr/local    本地手动安装的软件
```

例如你输入：

```bash
which gcc
```

可能看到：

```bash
/usr/bin/gcc
```

说明<span style="color:#FF0000; background:#00FF80;"> `gcc` 这个程序放在：</span>

```bash
/usr/bin
```

再比如：

```bash
which python3
```

可能看到：

```bash
/usr/bin/python3
```

这说明 `/usr` 更像是：

```text
系统软件安装区域
```

而<span style="color:#FF0000; background:#00FF80;">不是用户自己的家目录。</span>

------

## 5. `/home` 和 `/usr` 的区别

可以这样对比：

| 目录    | 主要作用                         | 类比理解                |
| ------- | -------------------------------- | ----------------------- |
| `/home` | 普通用户的个人目录               | 用户自己的房间          |
| `/usr`  | 系统软件、命令、库文件、共享资源 | 公共工具库 / 系统软件区 |

例如：

```bash
/home/book
```

里面放的是 `book` 用户自己的东西。

比如：

```text
桌面文件
下载文件
个人文档
用户配置文件
自己写的代码
```

而：

```bash
/usr/bin
```

里面放的是很多系统命令程序。

比如：

```text
gcc
python3
vim
nano
ssh
make
```

所以你可以这样记：

```text
/home/用户名      用户自己的家
/usr             系统软件和资源的位置
```

------

## 6. 为什么 `/usr` 容易被误认为是用户目录？

因为 `/usr` 看起来像 `user` 的缩写。

但是初学时你可以强行记成：

```text
/usr 不是 /user
/usr 不是普通用户的家目录
/usr 是系统软件资源目录
```

普通用户家目录一般在：

```bash
/home/用户名
```

不是：

```bash
/usr/用户名
```

所以：

```bash
/home/book
```

是用户 `book` 的家。

但：

```bash
/usr/bin
```

是系统命令程序的目录。

------

## 7. `.bashrc` 为什么在家目录下？

因为 `.bashrc` 是**当前用户自己的 bash 配置文件**。

比如用户 `book` 的配置文件是：

```bash
/home/book/.bashrc
```

用户 `arley` 的配置文件是：

```bash
/home/arley/.bashrc
```

不同用户可以有不同配置。

比如 `book` 的 `.bashrc` 里面可以写：

```bash
export PATH=$PATH:/home/book/Desktop
```

而 `arley` 的 `.bashrc` 里面可以写：

```bash
export PATH=$PATH:/home/arley/mytools
```

这样每个用户打开终端时，就会加载自己的配置。

------

## 8. 用路径把它串起来

假设当前用户是 `book`。

那么：

```bash
~
```

表示：

```bash
/home/book
```

所以：

```bash
~/.bashrc
```

表示：

```bash
/home/book/.bashrc
```

如果你的 `hello` 在桌面：

```bash
/home/book/Desktop/hello
```

那么你可以在：

```bash
/home/book/.bashrc
```

里加入：

```bash
export PATH=$PATH:/home/book/Desktop
```

或者写成：

```bash
export PATH=$PATH:~/Desktop
```

不过在配置文件里，为了清楚，初学时更推荐写完整路径：

```bash
export PATH=$PATH:/home/book/Desktop
```

## 9. 最后总结

你可以这样记：

```text
. 开头        表示隐藏文件或隐藏目录
~             表示当前用户的家目录
~/.bashrc     表示当前用户家目录下的 .bashrc 配置文件
/home         普通用户家目录的总目录
/home/book    book 用户的家目录
/usr          系统软件、命令、库文件、共享资源目录，不是用户家目录
```

最关键的一句话：

```text
/home 是“用户的家”，/usr 是“系统软件资源区”。
```

所以不要把 `/usr` 当成用户家目录，真正的普通用户家目录一般是：

```bash
/home/用户名
```
