## 4. 最值得你理解的第一部分：UART 到底是什么

视频开头给出了：

**UART = Universal Asynchronous Receiver/Transmitter**

中文通常叫：

**通用异步收发传输器。**

<span style="background:#00FF80; color:#FF0000;">你暂时可以把 UART 理解成板子内部一个专门负责**把数据一位一位发送出去、或者一位一位接收进来**的硬件模块。</span>

视频画的关系大概就是：

```text
Linux开发板
┌────────────────────┐
│                    │
│      UART           │
│       │             │
└───────┼─────────────┘
        │
        │ TXD
        │ RXD
        │ GND
        │
        ▼
     外部模块
```

其中<span style="color:#FF0000; background:#00FF80;">最重要的是三个信号：</span>

```text
TXD = Transmit Data
      发送数据

RXD = Receive Data
      接收数据

GND = Ground
      公共参考地
```

例如<span style="color:#FF0000; background:#00FF80;">开发板要给 GPS 模块发送一个字节：</span>

```text
应用程序
   ↓
Linux内核
   ↓
UART驱动
   ↓
UART硬件
   ↓
TXD引脚
   ↓
GPS模块
```

反过来 GPS 返回数据：

```text
GPS模块
   ↓
开发板 RXD
   ↓
UART硬件
   ↓
UART驱动
   ↓
Linux内核
   ↓
应用程序
```

### 一个很容易混淆的地方

真正两块设备接线时一般是：

```text
板子 TX  ─────→ 模块 RX

板子 RX  ←───── 模块 TX

板子 GND ────── 模块 GND
```

<span style="color:#FF0000; background:#00FF80;">也就是常说的：</span>

**TX 接对方 RX，RX 接对方 TX，共地。**

视频里的箭头主要是在表达“数据发送/接收方向”。

## 5. 为什么视频说串口经常用来“调试”

课件在开头明确提到，移植：

- U-Boot
- Linux 内核
- 应用程序

时，经常通过串口查看打印信息。

这个特别重要。

<span style="color:#FF0000; background:#00FF80;">开发板刚开机的时候：</span>

```text
开发板启动
   ↓
U-Boot打印
   ↓
Kernel启动日志
   ↓
Linux Shell
   ↓
程序printf输出
```

<span style="color:#FF0000; background:#00FF80;">这些信息很多时候都可以通过 UART 发送给电脑。</span>

所以<span style="color:#FF0000; background:#00FF80;">你之前看到开发板连接电脑后，Windows 上打开串口工具，然后看到：</span>

```text
U-Boot ...
Starting kernel ...

Linux ...
login:
```

<span style="color:#FF0000; background:#00FF80;">本质就是：</span>

```text
开发板 UART
     ↓
TX/RX
     ↓
USB转串口芯片
     ↓
USB
     ↓
Windows
     ↓
串口软件
```

所以<span style="background:#00FF80;"> **UART 不只是拿来连接 GPS、蓝牙之类模块，也非常重要的一项用途就是开发调试。**</span>

## 7. 你现在最应该建立起来的知识链

这其实可以和你前面学的 Linux 文件 IO 连起来。

以后<span style="color:#FF0000; background:#00FF80;">你学串口应用程序时，大致会形成这条链：</span>

```text
用户APP
   │
   │ open("/dev/ttyXXX")
   ▼
得到 fd
   │
   │ 配置波特率等参数
   │ termios
   │
   ├── write(fd, ...)
   │
   └── read(fd, ...)
          │
          ▼
       系统调用
          │
          ▼
      Linux TTY 子系统
          │
          ▼
       UART 驱动
          │
          ▼
       UART 控制器
          │
      ┌───┴────┐
      TXD      RXD
       │        │
       ▼        ▲
       外部设备
```

这条链非常值得你记住。

因为以后你会发现：

> <span style="background:#00FF80; color:#FF0000;">**Linux 串口应用编程，本质上还是你之前学的“设备文件 + fd + read/write”体系，只不过串口额外需要配置通信参数。**</span>

比如以后可能出现：

```c
fd = open("/dev/ttymxc1", O_RDWR);
```

那么<span style="color:#FF0000; background:#00FF80;">这个 `fd` 的思想和你之前学普通文件时是一样的：</span>

```text
open()
 ↓
fd
 ↓
read/write
 ↓
内核找到对应设备
```

<span style="color:#FF0000; background:#00FF80;">只是它背后最终不是磁盘文件，而是：</span>

```text
TTY
 ↓
UART驱动
 ↓
UART硬件
```

<span style="color:#FF0000; background:#00FF80;">这部分是为了帮你把当前内容接到之前的 Linux 文件 IO 知识上，并不是本节视频已经正式讲到的内容。</span>

```text

    ↓
```
