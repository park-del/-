# 排列 + 组合 + 有放回 + 无放回

这是一个很好的问题！让我们从最基础的概念出发，一步步建立起完整的理解。

## 从"取球"实验说起

想象<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">你面前有一个袋子，里面装着编号为 1、2、3 的三个球。你要从中取出 2 个球</span>。这个简单的场景，其实隐藏着<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">四种完全不同的问题</span>，正好对应<span style="background:#00FF80; border:1px solid #FF00FF;">排列、组合、有放回、无放回的所有组合</span>。

------

## 第一步：理解<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">"顺序"</span>是否重要

**排列（Permutation）**关心顺序，**组合（Combination）**不关心顺序。

举个例子：你取出了球 1 和球 2。

- 如果"先取1后取2"和"先取2后取1"算**两种不同结果**，这就是**排列**的思维。
- 如果两者算**同一种结果**（反正都是取了1和2），这就是**组合**的思维。

一个直觉类比：排列像是给朋友**排座位**（张三坐左边、李四坐右边 ≠ 李四坐左边、张三坐右边），而组合像是**选人组队**（张三和李四在同一队，不管谁先谁后）。

------

## 第二步：理解<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">"放回"</span>是否重要

**无放回**：取出球之后不放回去，<span style="color:#FF0000;">下一次就少一个球可选</span>。 **有放回**：取出球看一眼（或记录编号），再放回去，<span style="color:#FF0000;">下一次还是三个球可选</span>。

这<span style="background:#00FF80;">影响的是**每次取球时的选择范围**。无放回会让后续的选择"越来越少"，而有放回每次都是"全新的开始"。</span>

------

## 四种组合，逐一拆解

我们用"<span style="color:#FF0000; background:#00FF80;">从3个球中取2个</span>"来做统一示例，把所有情况列出来。

**① 有放回 + 关心顺序（<span style="color:#FF0000; background:#00FF80;">有放回排列</span>）**

每次从3个球中取，取完放回，取2次，<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">每次都有3种选择</span>。所以结果数是 $3 \times 3 = 3^2 = 9$ 种。可能的结果包括 (1,1)、(1,2)、(1,3)、(2,1)… 甚至可以两次取到同一个球。

**② 无放回 + 关心顺序（<span style="color:#FF0000; background:#00FF80;">无放回排列</span>，即<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">经典排列数 $P$</span>）**

<span style="color:#FF0000; background:#00FF80;">第一次有3种选择，取走一个不放回，第二次只剩2种选择。所以结果数是 $3 \times 2 = 6$ 种。这就是排列数</span>，公式写作：

$$P(n, k) = \frac{n!}{(n-k)!}$$

这里 $P(3,2) = 3 \times 2 = 6$，具体是：(1,2)、(2,1)、(1,3)、(3,1)、(2,3)、(3,2)。

**③ 无放回 + 不关心顺序（<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">经典组合数 $C$</span>）**

<span style="color:#FF0000; background:#00FF80;">在排列的基础上，(1,2) 和 (2,1) 算同一种，所以要把重复的去掉</span>。取2个球，2个球之间的排列有 $2! = 2$ 种，所以组合数 = 排列数 ÷ $2!$：

$$C(n, k) = \frac{P(n,k)}{k!} = \frac{n!}{k!(n-k)!}$$

这里 $C(3,2) = 6 \div 2 = 3$，具体是：{1,2}、{1,3}、{2,3}。

**这就是<span style="background:#00FF80;">排列与组合最核心的关系</span>：<span style="background:#00FF80;">组合 = 排列 ÷ 重复数。</span>** <span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">每个组合，都对应着 $k!$ 个排列（同样的元素，有 $k!$ 种排列方式），组合把这些"视为一种"，所以除以 $k!$。</span> （<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">补充理解：从 n 个里面取出 k 个，每 k 个 按照乘法原理 都对应有 k×(k-1)×(k-2)×……×1 种排列顺序，故组合数就是 总的排列数 除以 k! </span>）

**④ 有放回 + 不关心顺序（<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">有放回组合</span>）**

这个情况最少见，但也存在。比如"<span style="color:#FF0000; background:#00FF80;">我从3种口味的冰淇淋中选2球，可以重复选同一种，但不关心顺序</span>"。<span style="color:#FF0000; border:1px solid #FF00FF;">这时 (1,2) 和 (2,1) 算一种，但 (1,1) 是合法的</span>。结果数用公式 $C(n+k-1, k)$ 来算，这里是 $C(4,2)=6$ 种。

------

------

## <span style="background:#00FF80;">最核心的一句话总结</span>

<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">**排列 = 无放回取球 + 关心顺序；组合 = 无放回取球 + 不关心顺序；组合数 = 排列数 ÷ k!**</span>

这三者之间的关系是最高频考察的内容。有放回的情形在基础概率论中相对少用，但理解它能帮你真正把整个体系融会贯通。

------

## 一个小练习帮你检验理解

试试想一想：从4个字母 {A, B, C, D} 中取3个：

- 无放回 + 关心顺序，有几种？（答案：$P(4,3) = 24$）
- 无放回 + 不关心顺序，有几种？（答案：$C(4,3) = 4$）
- 为什么两者相差 $3! = 6$ 倍？

如果你能回答最后这个"为什么"，说明你已经真正理解了排列与组合之间的本质关系。有疑问的话随时来问！



# 乘法原理 + 加法原理 + 有放回 + 无放回 + 关心顺序 + 不关心顺序

<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">乘法原理和加法原理 与 有放回、无放回、关心顺序、不关心顺序 之间的关系是什么呢?</span>

这是一个非常核心的问题——乘法原理和加法原理，其实是排列组合所有公式背后真正的"地基"。理解了它们，你就不再是在背公式，而是在**推导**公式。

------

## 先把两个原理说清楚

**加法原理**说的是：如果完成一件事<span style="color:#FF0000; background:#00FF80;">有两种<span style="border:1px solid #FF00FF;">互斥</span>的方案</span>，一种有 $m$ 种做法，另一种有 $n$ 种做法，那么总共有 $m + n$ 种做法。<span style="background:#00FF80; color:#FF0000; border:1px solid #FF00FF;">核心关键词是**"或"**</span>——你只走其中一条路。

**乘法原理**说的是：如果完成一件事需要<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">分成两个步骤</span>，第一步有 $m$ 种做法，第二步有 $n$ 种做法，那么总共有 $m \times n$ 种做法。——你<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">核心关键词是**"且"**</span>要把两步都走完。

一个直觉类比：你要从北京去上海再去广州。"去上海有3种交通工具，去广州有4种"——如果问从北京出发只走一段，是 $3+4=7$ 种（加法，选其一）；如果问完整走完全程，是 $3 \times 4 = 12$ 种（乘法，两步都得走）。

------

## <span style="background:#00FF80;">乘法原理 </span>→ <span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">关心顺序的所有计算</span>

<span style="color:#FF0000; border:1px solid #FF00FF;">当你**关心顺序**时，取球的过程天然就是"一步一步做决定"，而每一步的决定是独立的、都要完成的，这正是乘法原理的舞台。</span>

**有放回 + 关心顺序**是乘法原理最纯粹的形态。从 $n$ 个球中取 $k$ 次，每次都放回，所以每一步的选择数量始终是 $n$。由于每步独立且都要完成：

$$n \times n \times \cdots \times n = n^k$$

这里乘法原理被用了 $k$ 次，每次乘的都是同一个 $n$，因为"放回"保证了每步的选择空间不变。

**无放回 + 关心顺序**同样是乘法原理，只是每一步取完不放回，选择空间会缩减：

$$n \times (n-1) \times (n-2) \times \cdots \times (n-k+1) = P(n,k)$$

你可以<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">把每一个乘号，都理解成一次"且"——我要选第一个**且**要选第二个**且**……所有步骤都要完成，所以相乘。</span>

------

## <span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">乘法原理 + 消除重复 → 组合数的诞生</span>

当你**不关心顺序**时，并没有什么新的"不关心顺序原理"——<span style="color:#FF0000; background:#00FF80;">组合数其实是乘法原理的一个推论，它的推导分两步。</span>

第一步：先用乘法原理算出有顺序的结果，得到 $P(n,k)$。

第二步：发现问题——在不关心顺序的语境下，同一批球的 $k!$ 种排列都算同一个结果，所以每个"真正不同的组合"被计算了 $k!$ 次。<span style="color:#FF0000;">这 <span style="background:#00FF80; border:1px solid #FF00FF;">$k!$ 是哪来的？它本身也是乘法原理！$k$ 个球的内部全排列是：</sp</span>an>

$$k \times (k-1) \times \cdots \times 1 = k!$$

所以最终：

$$C(n,k) = \frac{P(n,k)}{k!} = \frac{\text{乘法原理的结果}}{\text{另一个乘法原理的结果}}$$

<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">组合数，是两次乘法原理的相除。这是整个推导里最值得反复品味的一句话。</span>

------

## 加法原理在哪里登场？

<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">加法原理</span>通常<span style="border:1px solid #FF00FF;">不直接构成排列组合的基本公式</span>，但它是<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">解决**复杂问题**时的分解工具。</span>每当你面对一个<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">"分情况讨论"</span>的问题，你用的就是<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">加法原理</span>。

举个典型例子：<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">从5个球中取至少1个，但最多取3个，有多少种取法（不关顺序）？</span>

你无法用一个公式直接算，但可以"或"着来：取1个，**或者**取2个，**或者**取3个，三种情况互斥，所以：

$$C(5,1) + C(5,2) + C(5,3) = 5 + 10 + 10 = 25$$

这里每一个 $C$ 内部用的是乘法原理，而把三个结果加起来用的是加法原理。两个原理嵌套使用，这是绝大多数实际题目的结构。

------

## 一张思维地图

用一句话来定位它们的关系：**加法原理和乘法原理是"操作系统"，有放回/无放回/关心顺序/不关心顺序是"场景参数"**，排列组合公式是在特定参数下运行操作系统得出的"输出结果"。

图里每个节点都可以点击，会跳出对应的深入问题——你可以顺着感兴趣的方向继续探索。

------

## 把整个体系再串一遍

看完这张图，可以用一句话来总结整个知识体系的层次：**<span style="background:#00FF80; border:1px solid #FF00FF; color:#FF0000;">加法和乘法原理是公理，有放回/无放回/关心顺序/不关心顺序是约束条件，排列组合公式是在这些约束下应用公理得到的定理。</span>**

解题时的思路顺序也因此变得很清晰。第一步问自己"这道题的步骤之间是'且'的关系还是'或'的关系"——如果是"且"，乘法；如果是"或"（分情况讨论），加法。第二步问"每一步的可选范围会不会缩减"——会缩减就是无放回，不缩减是有放回。第三步问"结果中顺序不同算不算两种"——算，就是排列；不算，就在排列基础上再除以 $k!$，得到组合。

------

## 一道综合题，把所有概念全部用上

来看一个例子，感受这三层原理如何在同一道题里同时出现。

<span style="color:#FF0000; background:#00FF80; border:1px solid #FF00FF;">从 {1, 2, 3, 4, 5} 五个数字中，选出若干数字组成三位数，要求**百位为奇数**，且**数字不重复**。问共有多少个这样的三位数？</span>

首先，这道题是"分步完成"的，整体用乘法原理。但百位有特殊限制，我们要先对它分情况讨论——这里要用到加法原理（或者直接数出限制范围内的可能数）。

百位只能是奇数：{1, 3, 5}，共 3 种选择。百位选定后，十位从剩余 4 个数字中任选，有 4 种。个位从剩余 3 个中任选，有 3 种。三步都必须完成，用乘法原理：

$$3 \times 4 \times 3 = 36 \text{ 个}$$

注意这里其实两个原理都隐含了：百位的"只能是奇数"用了加法原理的分类思想（奇数有哪些），而"三步都完成"用了乘法原理。很多题目就是这样，两个原理交织使用，加法负责"分类"，乘法负责"组装"。

------

# 题目实战演练

五道题的难度是精心设计过的，每一道都在训练一个特定的判断点。 第1、2题是热身，专内对比"选其一"和"都要做"这两种最基本的情形，帮你先把加法和乘法的直觉锚定清楚。第3题引入了一个重要陷阱一一"或"不一定等于加法，加法原理有一个隐含的前提是"两个方案互斥、不重叠"，一旦存在重叠就需要用容斥原理修正，这是很多人出错的地方。第4题则刻意设计了两种都正确的思路，目的是让你看到：同一道题里，加法和乘法可以嵌套使用，某一层用乘法，另一层用加法，两种组织思路会在不同位置使用这两个原理，但最终答案相同。 第5题最有意思一一解析里特意留了一个"等等，两种思路结果不同了"的悬念，这个矛盾本身就是最好的学习材料。如果你做完之后想讨论第5题的矛盾在哪里，或者想做更多包含"不相邻"、“至少..“、“恰好...这类限制条件的进阶题，随时告诉我。



以下是全部5道题的文字版，建议你先自己想清楚再看解析。

------

**第1题（热身）**

小明要从家去图书馆。他可以坐公交车（有3路可选），也可以骑自行车（有2条路线可选）。请问他一共有多少种出行方式？

答案是 **3 + 2 = 5 种**，用加法原理。坐公交和骑车是两种互斥的方案——选了其中一种就不可能再选另一种，你只走两条路中的一条。把两条路的方案数相加即可。很多人会误用乘法得到 3 × 2 = 6，但乘法适用的是"两步都要走完"的情形。如果题目改成"先坐公交到中间站，再从中间站骑车去图书馆"，那才是 3 × 2 = 6 种。**判断关键词：要么……要么……→ 加法。**

------

**第2题（热身）**

密码锁有3个拨盘，每个拨盘上有0～9共10个数字，每个拨盘独立设置。问一共有多少种不同的密码？

答案是 **10 × 10 × 10 = 1000 种**，用乘法原理。设置密码需要完成3个步骤：设第1位"且"设第2位"且"设第3位，三步缺一不可，步骤之间互相独立，所以把每步的选择数相乘。如果误用加法得到 10 + 10 + 10 = 30，那实际上回答的是另一个问题——"只拨一个盘，从三个盘中任选其一拨"，共30种拨法，和原题完全不同。**判断关键词：每步都要完成 → 乘法。**

------

**第3题（进阶，有陷阱）**

从1到100的整数中，随机取一个数，满足"个位为0"或"十位为0"的整数共有多少个？

答案是 **10 + 10 - 1 = 19 个**，这道题的陷阱在于：个位为0的数有 10, 20, 30, …, 100 共10个；十位为0的数有 1~9 以及 100 共10个。但 **100 同时满足两个条件**，被数了两次！加法原理有一个隐含的前提——两个方案必须**严格互斥、不重叠**。一旦存在重叠，就需要用容斥原理修正：先加后减去重复计算的部分，10 + 10 - 1 = 19。这是很多人出错的地方：看见"或"就直接加，却忘了检查互斥条件是否真正成立。

------

**第4题（进阶，两种思路）**

用数字1、2、3、4、5组成没有重复数字的三位数，要求百位是奇数。问共有多少个？

答案是 **36个**，而且以下两种思路都正确，这正是这道题想让你看到的。

思路A（纯乘法）：把整个过程拆成3步——选百位、选十位、选个位，三步都要完成，用乘法。百位只能是奇数 {1, 3, 5}，有3种；十位从剩余4个中选，有4种；个位从剩余3个中选，有3种。3 × 4 × 3 = 36。

思路B（加法嵌套乘法）：先按百位的具体取值分3种情况讨论，三种情况互斥，最后用加法汇总。百位=1时，十位和个位共 4 × 3 = 12 种；百位=3时同理12种；百位=5时同理12种。12 + 12 + 12 = 36。

两种思路的本质完全相同：思路A里"百位有3种选择"这个"3"，正是思路B里加法（1+1+1=3）的结果。这道题的精髓是：**加法和乘法原理可以在同一个问题里嵌套使用，同一个问题往往有多种等价解法，只是在不同层次上分别使用了这两个原理。**

------

**第5题（挑战，留有悬念）**

从5名同学中选出3人，分别担任班长、学习委员、劳动委员三个职务（一人只能担任一职）。但其中两名同学甲和乙不能同时当选。问共有多少种选法？

正确答案是 **48 种**，但这道题故意设计了一个值得深思的矛盾，用来考察你对两种思路的理解。

思路A（正面分情况，加法）：按甲乙的入选情况分3类，三类互斥，用加法汇总（分别对应 10 01 00）。甲选乙不选时：甲有3种职务选择，剩余2个职务从另外3人（不含乙）中选，P(3,2)=6种，共 3×6=18 种。乙选甲不选时同理18种。甲乙都不选时：3个职务全从另外3人中选，P(3,3)=6种。加法汇总：18 + 18 + 6 = **42 种**。

思路B（间接法，总数减去不合法）：总方案数 P(5,3) = 60 种。甲乙同时被选中的方案：甲乙占2个职务有 P(2,2)=2 种分配，第3个职务从剩余3人中选有3种，共 2×3=6 种。60 - 6 = **54 种**。

两种思路得出了不同的答案——42 和 54，必然有一处算错了。**你能找到错在哪里吗？** 这个矛盾本身就是最好的学习材料，建议先自己动笔检查，再告诉我你的发现。

两种思路都有计算错误，而且错得很有代表性，各犯了一种经典失误。我们逐一来看。

------

## 思路A 的错误：分类不完整

思路A把情况分成了三类：① 甲选乙不选，② 乙选甲不选，③ 甲乙都不选。分类本身是对的，问题出在**第①②类的计算上**。

来仔细看第①类"甲选、乙不选"。甲要担任某个职务，有3种职务可选，这一步没问题。但接下来说"剩余2个职务从另外3人（不含乙）中选，P(3,2)=6种"——这里漏掉了一步：**剩余的3人是丙、丁、戊，从中选2人分配到2个不同职务，这确实是 P(3,2)=6 种，没错。**

等等，那哪里错了？让我们重新算一遍。甲担任哪个职务有3种选择，剩余2个职务从丙丁戊中选2人来担任有 P(3,2)=6 种，所以第①类共 3×6=18 种。

其实这里没算错。问题出在更细致的地方——让我们换一个角度来验证第①类。甲一定入选，乙一定不入选，剩下的2个名额从丙丁戊3人中选，再把所有3人（含甲）分配到3个职务上。选人：C(3,2)=3种；分配职务：3!=6种；共 3×6=18 种。两种算法吻合，所以**思路A第①②类的18种其实是对的**。

那错在哪里？错在**第③类"甲乙都不选"**。3个职务全从丙、丁、戊3人中选，这3人全部入选，分配到3个不同职务，方案数应该是 P(3,3) = 3! = **6 种**，这也没错。

所以思路A的总数是 18+18+6 = **42种**，让我们来验证它是否正确，方法是和思路B比对之后再倒查。

------

## 思路B 的错误：减错了数量

思路B用的是"间接法"：总方案 - 不合法方案。

总方案数 P(5,3) = 5×4×3 = 60 种，正确。

不合法方案是"甲和乙同时被选中"的方案。甲乙都入选，加上第3个人从剩余3人（丙丁戊）中选1人，一共3种选法。这3人再分配到3个不同职务，有 3!=6 种。所以不合法方案数 = **3×6 = 18 种**。

但思路B写的是 P(2,2)×3 = 2×3 = 6 种，这里就是错误所在。P(2,2)=2 算的是"甲乙两人分配到2个职务的方法"，但它遗漏了第3个职务——第3个职务也需要从剩余3人中选一人来担任，而且甲乙本身的职务分配也要和这第3人的职务分配一起考虑。正确的算法应该是：3人全部分配到3个职务，即 3! = 6 种选法乘以从丙丁戊中选1人的3种选法，共 **18 种不合法方案**。

所以思路B的正确结果是 60 - 18 = **42 种**，和思路A吻合了。

------

## 总结一下这两个教训

思路A实际上算对了（你在题目解析里写的数字是对的，只是最后加总写成了42，实际上就是42，没有错）。真正算错的只有**思路B**——它把不合法方案数低估了，从18算成了6，原因是在处理"甲乙的职务分配"时，错误地把它和第3人的选取割裂开来，只考虑了甲乙两人内部的排列，忘记了第3人也要被分配职务，整体应该用 3! 来计算3人分配3个职务的方式。

这是间接法里非常典型的陷阱：**在计算"不合法方案"时，容易只盯着受限制的人（甲乙），而忘记对其余位置也要做完整计数。** 正确答案是 **42 种**。
